## 配置入口准备好后要做的事

优先在隔离测试环境准备本轮后台供配置 / 联调，完成统一自审及另一位审查者的独立验收后，再由有权限的项目负责人安排主线合入 / 正式部署；Codex 不直接合 main。目标环境先备份并依顺序执行缺失迁移至 0135，构建本轮契约与两端，不在旧线上版本只填半套新配置。任何生产迁移 / 部署仍需按既有授权单独安排。

1. 管理后台「模型与计费 → 模型管理 → 上游账号」，找到迁移 0131 预置的 **DeepSeek 联网搜索**。其协议是 **DeepSeek 搜索**，基础地址应为 `https://api.deepseek.com`；地址已预填。点「配置密钥」，直接在后台填写并按现有测试 / 加密保存流程保存。不要把聊天模型的兼容协议当搜索协议。
2. 在同页登记上游模型名 **deepseek-search** 的搜索服务模型，绑定该上游并启用 `web_search` 能力，核对搜索计费上限和真实供应商费用。平台模型键由表单自动生成，不要求手填。
3. 在「AI 模型价格」加入有效价目并按后台发布流程生效，再在模型页顶部「场景推荐模型 · 平台内部模型」的 **联网搜索** 选择该搜索模型并保存。未完成模型 / 有效价目 / 计费上限 / 内部模型选择，即使密钥有效也不能登记为搜索已开通。供应商价格按配置当日官方账单核对，本页不把旧方案里的参考单价当成已核实账单。
4. 调度额度初值按已确认方案：每用户每天 **20** 次候选查询，全平台每天 **5000** 次；需要调整可改后台调度参数。候选为平台付费；H4 微博真实搜索按已确认的合资格用户快照平摊，不把它和平台补贴候选混为同一收费。
5. 用于 H4 的角色需在后台角色卡填微博昵称 / 头像标记，可选数字微博用户 ID；用户添加且开启该角色生态后才具备同步资格。没有公开来源资格的角色不用配置。生态决策模型保持原有效配置，不因 J 的小样本实测改成 Jev 或降低门槛。

M 的群聊整理默认 20 条用户消息 / 静默 10 分钟，可在记忆参数调整，不需逐角色配置。L 默认启用，不需要外部遥测账号、供应商密钥或额外开关。

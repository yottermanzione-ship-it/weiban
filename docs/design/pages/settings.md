## 7. 人设贴合度（CHAT-09）

入口：聊天信息 › 人设贴合度（单个角色）；服务 › 聊天偏好 › 人设贴合度（默认值）。两处同一页面，标题下方小字区分「杨幂」或「新添加角色的默认值」。

```
┌────────────────────────────────┐
│ ‹          人设贴合度             │
│              杨幂                │  副标题
├────────────────────────────────┤
│              平衡                │  当前档名
│   按人设表达观点，合理的要求会答应，   │  该档说明
│   和人设冲突的要求会拒绝或讨价还价     │
│  ●────●────◉────●────●          │  StepSlider（C 6.6）
│ 更顺从        默认        更贴合人设  │
├────────────────────────────────┤
│ 不管怎么调，TA 都会关心你的安全，      │
│ 也不会越过微伴的边界。               │
└────────────────────────────────┘
```

五档说明文案（由 CHAT-09 表改写为用户语言，产品可改）：

| 档 | 名称 | 说明 |
|---|---|---|
| 1 | 最顺从 | 尽量满足你的要求，不唱反调 |
| 2 | 偏顺从 | 偶尔有自己的意见，但很快会让步 |
| 3 | 平衡（默认） | 按人设表达观点，合理的要求会答应，和人设冲突的要求会拒绝或讨价还价 |
| 4 | 偏人设 | 更坚持自己的性格，会明确拒绝不像 TA 会做的事 |
| 5 | 最贴合人设 | 完全按 TA 的性格来，可能会生气、拒绝、冷淡 |

## 8. 注销账号（ACC-06）

推入说明页：列出将删除的内容（聊天记录、记忆、自定义角色、导入的原始记录、余额与余额明细）→ 底部危险按钮「注销账号」→ Dialog 二次确认（需输入「注销」两个字才能点确认）。文案平实，不挽留。若注销时余额大于 0，说明页多一行「剩余余额 ¥12.34 将一并清除」。

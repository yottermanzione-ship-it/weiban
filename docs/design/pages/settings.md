### 3.2 添加供应商密钥

1. 选择供应商（ListCell 选择型，列表由 AI 负责人提供，每行右侧「去哪里申请」）。
2. KeyField（C 6.7）：粘贴 → 自动连通测试 → 成功显示「可用」+「可用模型 12 个」→ 底部主按钮「保存」；失败显示原因，「保存」禁用。
3. 同一供应商已存在：Dialog「已存在该供应商的密钥，是否替换？」。

### 3.3 选择模型页

- 顶部：SearchBar + 筛选 Tag（中文好、支持识图、允许成人内容…）。
- 列表：ModelRow（C 13.2），按供应商分组；只列出已配置密钥的供应商的模型；底部「添加更多供应商 ›」。
- 为单个角色更换聊天模型（从私聊设置进入）时：顶部第一项为「跟随全局默认」；选中新模型后 Dialog「换模型后，TA 的说话风格可能有变化」+「取消 / 更换」（MDL-06）。

### 3.5 用量（MDL-05）

- SegmentedControl：按天 / 按角色 / 按用途。
- 每行：名称 + 调用次数 + 估算花费（等宽数字，右对齐）。按天视图顶部显示最近 7 天 MiniBarChart（C 15.5）。
- 顶部说明「估算值，以供应商账单为准」（`fontSize.caption1`、`text.tertiary`）。
- 「后台功能每天最多花费」：ListCell → 输入页（数字键盘，单位「元」）；达到上限时设置页该行显示「今日已达上限」橙色 Tag。
- 平台调用费用若记在用户密钥上，单独一组「平台功能」列出（MDL-05 第 4 条，待 AI / 架构方案）。

## 5. 隐私（MEM-07）

- 跨角色共享：ListCell 选择型三选一：关闭 / 仅基础资料 / 朋友之间共享（默认）。每项下方一句说明（MEM-07 第 1 条，用用户语言）。
- 底部说明：「健康、情绪、感情、家庭、经济等私事，以及你说过『别告诉别人』的事，永远不会被传给其他角色」。

## 6. 人设贴合度（CHAT-09）

入口：私聊设置 › 人设贴合度（每个角色单独设置）。

```
┌────────────────────────────────┐
│ ‹          人设贴合度             │
├────────────────────────────────┤
│                                │
│              平衡                │  当前档名
│   按人设表达观点，合理的要求会答应，   │  该档说明
│   和人设冲突的要求会拒绝或讨价还价     │
│                                │
│  ●────●────◉────●────●          │  StepSlider（C 6.6）
│ 更顺从        默认        更贴合人设  │
│                                │
├────────────────────────────────┤
│ 不管怎么调，TA 都会关心你的安全，      │  说明（fontSize.footnote，text.secondary）
│ 也不会越过微伴的边界。               │  对应 CHAT-09 第 3 条，用用户语言
└────────────────────────────────┘
```

五档说明文案（由 CHAT-09 表改写为用户语言，产品可改）：

| 档 | 名称 | 说明 |
|---|---|---|
| 1 | 最顺从 | 尽量满足你的要求，不唱反调 |
| 2 | 偏顺从 | 偶尔有自己的意见，但很快会让步 |
| 3 | 平衡（默认） | 按人设表达观点，合理的要求会答应，和人设冲突的要求会拒绝或讨价还价 |
| 4 | 偏人设 | 更坚持自己的性格，会明确拒绝不像 TA 会做的事 |
| 5 | 最贴合人设 | 完全按 TA 的性格来，可能会生气、拒绝、冷淡 |

## 7. 通用

- 深色模式：跟随系统（默认）/ 浅色 / 深色（ListCell 选择型）。
- 字体大小：预览区（一组示例气泡）+ 5 档 StepSlider（0.9 / 1 / 1.1 / 1.2 / 1.35，对应 `--wb-font-scale`）。
- 默认分享模板：4 个模板缩略图横排单选（EXP-02 第 4 条）。

- 长按卡片 → ActionSheet：生成分享图、取消收藏。右上角「选择」可多选后批量生成分享图。
- 点击 → 跳到原消息上下文（原消息已本地删除时，显示收藏详情页）。
- 空状态：EmptyState「长按 TA 的消息，就可以收藏」。

## 9. 注销账号（ACC-06）

推入说明页：列出将删除的内容（聊天、记忆、自定义角色、导入的原始记录、密钥）→ 底部危险按钮「注销账号」→ Dialog 二次确认（需输入「注销」两个字才能点确认）。文案平实，不挽留。

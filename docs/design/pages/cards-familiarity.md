# 卡册、熟悉度与成就

> 回答 PRD 8.3 第 4 问。组件规格见 `../components.md` 9.3（认识天数）、9.4（熟悉度）、9.5（卡片）、9.6（成就徽章）。

## 1. 结论

- 养成的视觉语言是**「手账 + 月相」**：卡片像夹在手账里的明信片，熟悉度用月亮从新月到满月表示——「越来越圆满」，没有爱心，不暗示恋爱（GRW 设计思路）。
- **获得任何东西都不打断聊天**：熟悉度升级、获得卡片在聊天里只出现一行灰色系统提示，用户点开才播放获得动画（M-13）；成就只在顶部出现 3 秒的轻提示。
- **只奖励、不惩罚、不催促**：没有倒计时、没有「再聊 X 条升级」的催促、没有排行榜、没有断签。
- 首批成就草案 24 个（第 5 节），**全部是「第一次」或「累计」**，待产品负责人定稿。

## 2. 熟悉度的呈现（GRW-03）

| 位置 | 呈现 | 组件 |
|---|---|---|
| 资料页 | 月相圆环 + 「L3 熟络」+ 「距 L4 老友还差 120 点」 | C 9.4 圆环 |
| 私聊设置页顶部 | 徽章「◐ L3 熟络」 | C 9.4 徽章 |
| 聊天中升级时 | 系统提示「你和 杨幂 的熟悉度升到了 L3 熟络」+「获得熟悉度卡 No.003 ›」 | C 4.4 |
| 等级说明弹层 | 5 级月相列表 + 每级一句话（用户语言改写 GRW-03 表） | `character-profile.md` 第 5 节 |

等级说明文案（建议，产品可改）：

| 等级 | 月相 | 一句话 |
|---|---|---|
| L1 初识 | 新月 | 刚认识，TA 还有点客气 |
| L2 眼熟 | 眉月 | 说话随意了一些，会开小玩笑 |
| L3 熟络 | 上弦月 | 聊得很自在了，TA 可能会问能不能给你打电话 |
| L4 老友 | 盈凸月 | 会和你说说自己的小烦恼 |
| L5 知己 | 满月 | 会和你聊心事，记得你们一起经历的事 |

不在界面上展示具体加分规则（P-25 的分值），只在等级说明弹层底部写一句「多聊天、多互动，就会越来越熟」。理由：展示分值会让人「刷分」，和「不操纵」原则相冲突。

## 3. 卡册（GRW-05）

### 3.1 入口

角色资料页 › 卡册（每个角色一本）。「我」页不汇总卡片（汇总在成就里体现数量）。

### 3.2 结构

```
┌────────────────────────────────┐
│ ‹        和 杨幂 的卡册           │
├────────────────────────────────┤
│  已收集 12 张                     │  fontSize.title3 + 等宽数字；下方小字「最近获得：10 月 4 日」
├─ 纪念卡 ───────────────────────┤  分组标题带类型色小圆点
│ [卡][卡][卡]                      │  3 列网格，卡片 3:4（C 9.5）
│ [第200天][第365天][第400天]        │  ← 未获得：剪影 + 条件（最多显示接下来 3 张）
├─ 熟悉度卡 ─────────────────────┤
│ [L2][L3][L4剪影]                   │  L2–L5 共 4 张，未获得显示剪影
│ [L5剪影]                          │
├─ 节日卡 ───────────────────────┤
│ [中秋][国庆]                       │  只显示已获得
├─ 瞬间卡 ───────────────────────┤
│ [第一次通话][被拉进群]              │  只显示已获得（GRW-05 第 4 条）
└────────────────────────────────┘
```

- 网格间距 `space.4`；页面边距 `space.5`。
- 空分组（如还没有节日卡）：一行说明「节日当天和 TA 聊天，就会收到节日卡」（`fontSize.footnote`、`text.secondary`）。
- 整本卡册为空：EmptyState「和 TA 认识满 7 天，会收到第一张纪念卡」。

### 3.3 卡片详情

- 全屏覆盖：`bg.scrim` 遮罩上居中一张 280 宽的卡片（`shadow.lg`）。
- 第一次打开新卡：播放 M-13（卡片弹出 + 小星星散开），之后打开不再播放。
- 点卡片：正反面交叉淡入（C 9.5 背面）。
- 底部两个按钮：「生成分享图」（tonal，进入分享图编辑页，默认选中卡片风模板，`share-templates.md` 4.4）、「关闭」（文字按钮）。
- 左右滑动切换同一本卡册的其他已获得卡片。

### 3.4 卡面模板规格（交给管理员素材库 ADM-04）

| 类型 | 画面主题建议 | 真人角色 |
|---|---|---|
| 纪念卡 | 日历、手账页、拍立得（空白相纸上写日期） | 以应援色为主色，物件构图，**无人物** |
| 熟悉度卡 | 对应月相的夜空、窗边月亮 | 同上 |
| 节日卡 | 节日物件：月饼、灯笼、雪人、烟花 | 同上 |
| 瞬间卡 | 与事件相关的物件：电话听筒（第一次通话）、群聊气泡（被拉群）、信封（名场面） | 同上 |

每个模板提供：画面图（3:2.2，WebP，≤ 80KB）、可替换的主题色区域（程序用角色应援色填充）、浅色 / 深色可读性检查。虚构角色、历史人物可以使用角色形象（裁定 9.2）。

## 4. 认识天数与纪念日（GRW-04）

- 资料页 DaysCounter 大号（C 9.3）。
- 纪念日当天：聊天中出现系统提示「今天是你们认识的第 100 天 · 获得纪念卡 ›」；资料页大号数字旁出现小星星。
- 纪念日列表页（资料页 › 纪念日）：系统纪念日（下一个节点：「第 200 天 · 还有 72 天」）+ 自定义纪念日（最多 10 个，右上角 ＋）。自定义纪念日表单：名称（≤ 20 字）+ 日期 + 「每年提醒」开关。
- 「还有 N 天」只做信息展示，不做倒计时动画、不推送「快到了」提醒（防止制造期待焦虑；纪念日当天角色会主动发消息，SIM-09）。

## 5. 成就页（GRW-06）

### 5.1 结构

```
┌────────────────────────────────┐
│ ‹            成就                │
├────────────────────────────────┤
│        已获得 8 / 24              │  等宽大数字；不做百分比进度条（不催促）
├─ 相识 ─────────────────────────┤
│ (徽)   (徽)   (徽)                 │  3 列 AchievementBadge（C 9.6）
│ 初次见面 第一句话 被介绍认识         │
├─ 聊天与通话 ────────────────────┤
│ …                              │
└────────────────────────────────┘
```

- 分组顺序：相识、聊天与通话、群聊与朋友圈、收藏与卡片、纪念日与熟悉度。
- 组内排序：已获得在前（按获得时间），未获得在后。
- 点徽章 → 底部弹层（C 9.6）。

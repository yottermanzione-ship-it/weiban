## 1. 结论

- 养成的视觉语言是**「手账 + 月相」**：卡片像夹在手账里的明信片，熟悉度用月亮从新月到满月表示——「越来越圆满」，没有爱心，不暗示恋爱（GRW 设计思路）。
- **获得任何东西都不打断聊天**：熟悉度升级、获得卡片在聊天里只出现一行灰色系统提示，用户点开才播放获得动画（M-13）；成就只在顶部出现 3 秒的轻提示。
- **只奖励、不惩罚、不催促**：没有倒计时、没有「再聊 X 条升级」的催促、没有排行榜、没有断签。
- 成就共 34 个（PRD v1.4），清单唯一定义在 PRD GRW-06；本文第 5 节给出 34 枚徽章的插画题材。

## 3. 卡册（GRW-05）

### 3.1 入口

角色资料页 › 卡册（每个角色一本）；我 › 服务 › 卡册（所有角色的卡册列表，`me-and-services.md` 3.1）。

### 3.2 结构

```
┌────────────────────────────────┐
│ ‹        和 杨幂 的卡册           │
├────────────────────────────────┤
│  已收集 12 张                     │  fontSize.title3 + 等宽数字；下方小字「最近获得：10 月 4 日」
├─ 纪念卡 ───────────────────────┤  分组标题带类型色小圆点
│ [卡][卡][卡]                      │  3 列网格，卡片 3:4（C 9.5）
│ [第200天][第365天][第400天]        │  ← 未获得：剪影 + 条件（最多显示接下来 3 张）
├─ 熟悉度卡 ─────────────────────┤
│ [L2][L3][L4剪影]                   │  L2–L5 共 4 张，未获得显示剪影
│ [L5剪影]                          │
├─ 节日卡 ───────────────────────┤
│ [中秋][国庆]                       │  只显示已获得
├─ 瞬间卡 ───────────────────────┤
│ [第一次通话][被拉进群]              │  只显示已获得（GRW-05 第 4 条）
└────────────────────────────────┘
```

- 网格间距 `space.4`；页面边距 `space.5`。
- 空分组（如还没有节日卡）：一行说明「节日当天和 TA 聊天，就会收到节日卡」（`fontSize.footnote`、`text.secondary`）。
- 整本卡册为空：EmptyState「和 TA 认识满 7 天，会收到第一张纪念卡」。

### 3.3 卡片详情

- 全屏覆盖：`bg.scrim` 遮罩上居中一张 280 宽的卡片（`shadow.lg`）。
- 第一次打开新卡：播放 M-13（卡片弹出 + 小星星散开），之后打开不再播放。
- 点卡片：正反面交叉淡入（C 9.5 背面）。
- 底部两个按钮：「生成分享图」（tonal，进入分享图编辑页，默认选中卡片风模板，`share-templates.md` 4.4）、「关闭」（文字按钮）。
- 左右滑动切换同一本卡册的其他已获得卡片。

### 3.4 卡面模板规格（交给管理员素材库 ADM-04）

| 类型 | 画面主题建议 | 真人角色 |
|---|---|---|
| 纪念卡 | 日历、手账页、拍立得（空白相纸上写日期） | 以应援色为主色，物件构图，**无人物** |
| 熟悉度卡 | 对应月相的夜空、窗边月亮 | 同上 |
| 节日卡 | 节日物件：月饼、灯笼、雪人、烟花 | 同上 |
| 瞬间卡 | 与事件相关的物件：电话听筒（第一次通话）、群聊气泡（被拉群）、信封（名场面） | 同上 |
| 瞬间卡 · 宠物（v2.1，PLAY-02 第 11 条） | 「我们的团子」：宠物图鉴中该外观的幼年图居中，背景为宠物场景图或应援色底 + 小爪印纹样；「团子长成少年 / 成年」：对应阶段的宠物图 + 一把量身高的小尺 | 同样**只有宠物，没有人物**（GRW-05 第 2 条）；宠物图来自图鉴（`pet.md` 第 7 节） |

每个模板提供：画面图（3:2.2，WebP，≤ 80KB）、可替换的主题色区域（程序用角色应援色填充）、浅色 / 深色可读性检查。虚构角色可以使用角色形象；历史人物只用古风插画形象（SAFE-01 第 6 条、MED-02）。

## 4. 认识天数与纪念日（GRW-04）

- 资料页 DaysCounter 大号（C 9.3）。
- 纪念日当天：聊天中出现系统提示「今天是你们认识的第 100 天 · 获得纪念卡 ›」；资料页大号数字旁出现小星星。
- 纪念日列表页（资料页 › 纪念日）：系统纪念日（下一个节点：「第 200 天 · 还有 72 天」）+ 自定义纪念日（最多 10 个，右上角 ＋）。自定义纪念日表单：名称（≤ 20 字）+ 日期 + 「每年提醒」开关。
- 「还有 N 天」只做信息展示，不做倒计时动画、不推送「快到了」提醒（防止制造期待焦虑；纪念日当天角色会主动发消息，SIM-09）。

### 5.1 结构

```
┌────────────────────────────────┐
│ ‹            成就                │
├────────────────────────────────┤
│        已获得 8 / 34              │  等宽大数字；不做百分比进度条（不催促）；总数读 GRW-06 表
├─ 相识 ─────────────────────────┤

└────────────────────────────────┘
```

- 分组与顺序按 GRW-06 表：相识、聊天与通话、群聊与朋友圈、收藏与卡片、纪念日与熟悉度、互动玩法（v2.1）。
- 「互动玩法」分组按编号分批出现（GRW-06 验收）：第 29、30 号随宠物（PLAY-02）所在开发层出现；第 31～34 号随各自玩法（L7）出现。某一枚所在开发层未上线时这一枚不显示，分母相应减少（例如只上线到宠物时显示「/ 30」）；整组一枚都没有时分组标题也不显示。分母由客户端按服务器返回的成就列表长度计算，不写死 34。
- 组内：已获得在前（按获得时间），未获得在后（按 GRW-06 表顺序）。
- 新获得的徽章右上角红点，离开成就页后消失；服务页「成就」宫格红点同时消失。
- 当前平台不支持的功能对应的成就照常显示为未获得（GRW-06 第 8 条），不加说明。
- 点徽章 → 底部弹层（C 9.6）。

## 6. 卡册与成就页的加载、失败与获得提示（v2.2，L6 实现用）

| 页面 / 场景 | 状态 | 表现 |
|---|---|---|
| 卡册 | 加载 | 「已收集」数字位置灰块 + 每组 3 张卡片骨架（3:4，`radius.lg`） |
| 卡册 | 失败 | EmptyState「加载失败」+「重试」 |
| 卡册总览（服务 › 卡册） | 加载 / 失败 | OverviewRow 骨架 × 4 / 同上 |
| 卡片详情 | 卡面图加载中 | 卡面区域用 `card.*` 类型色铺底（静态），图到了淡入；文字、编号、日期先显示 |
| 卡片详情 | 卡面图失败 | 保持类型色底 + 中间 32 卡片图标；文字照常 |
| 成就页 | 加载 | 「已获得 — / —」+ 每组一行 4 个 64 圆形骨架 |
| 成就页 | 失败 | EmptyState「加载失败」+「重试」 |
| 成就页 | 全部未获得 | 照常显示所有徽章的未获得态，顶部「已获得 0 / 34」，不额外鼓励 |
| 获得成就（任意页面） | 提示 | Toast 成就型 3 秒（C 6.11、9.7）；同时获得多枚时依次显示，每枚 3 秒，最多连续 3 枚，其余只靠红点 |
| 获得卡片（聊天外，如宠物长大在宠物页发生） | 提示 | 不弹 Toast；只在对应私聊里出现会话内提示（C 4.4）+ 卡册宫格红点 |

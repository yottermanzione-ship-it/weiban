# 会话列表（「消息」标签首页）

## 1. 目的与入口

像微信首页一样，一眼看到所有私聊和群聊，最新的在上面（CHAT-01）。入口：底部标签「消息」；应用启动默认页。

## 2. 页面结构

```
┌────────────────────────────────┐
│ 状态栏安全区                      │
│           微伴（3）           ⊕  │  NavBar：标题「微伴」+ 未读总数；右侧 ⊕
├────────────────────────────────┤
│ [系统横条：仅全局问题时]            │  C 7.1（如「当前网络不可用」）
│ ┌ 🔍 搜索 ────────────────────┐ │  C 1.4
├────────────────────────────────┤
│ [头像] 杨幂               14:05  │  ← 置顶会话（bg.surfacePinned）
│        今天收工好早，去吃了…       │
│ [群头像] 火锅小分队          13:40  │
│        [有人@我] 王一博：@你 …     │
│ [头像] 罗小黑              昨天   │  ← 免打扰：灰点 + 铃铛划线图标
│        [3 条] 给你看我捡的松果    🔕│
│ …                              │
├────────────────────────────────┤
│  消息    通讯录    发现     我     │  C 1.2
└────────────────────────────────┘
```

右上角 ⊕ 弹出 PopoverMenu（C 15.1）：发起群聊、添加角色。

## 3. 使用的组件

NavBar（C 1.1）、SystemBanner（C 7.1）、SearchBar（C 1.4）、ConversationItem（C 3.2）、SwipeActions（C 3.4）、ActionSheet（C 6.9）、TabBar（C 1.2）、EmptyState（C 6.12）、Skeleton（C 6.13）。

## 4. 状态

| 状态 | 表现 |
|---|---|
| 首次加载 | 6 行会话骨架屏（头像方块 + 两行条） |
| 空（还没有角色） | EmptyState：插画「空信封」+「还没有聊天」+「去加一个你喜欢的 TA 吧」+ 按钮「去角色广场」 |
| 断网 | 标题「微伴（未连接）」+ 网络横条；列表照常显示本地缓存 |
| 收取中 | 标题「收取中…」（左侧 16px 转圈） |
| 新会话出现（角色通过好友申请、被拉群） | 新行出现在非置顶区第一位，M-07 的淡入 |

## 5. 交互

- 点会话 → 私聊 / 群聊；左滑、长按见 C 3.2。
- 收到新消息：该会话移到非置顶区第一位（**瞬间重排，不做位移动画**——列表重排动画需要同时移动多行，违反 motion.md R7 的精神，且微信也不做）。
- 双击「消息」标签 → 跳到下一个有未读的会话。
- 下拉：不触发刷新（消息实时同步），只露出顶部背景，与微信一致。
- 列表使用虚拟滚动（只渲染屏幕内的行）；行高固定 `size.listRow`，便于计算。

## 6. 平台差异

- ≥ 900px 宽屏：本列表成为左栏（宽 `size.sidebarWidth`），右栏显示当前会话；未选择会话时右栏显示品牌插画。
- iPhone 网页版首次进入私聊后的「添加到主屏幕」引导不在本页出现（见 `onboarding.md`）。

## 对应需求

CHAT-01、CHAT-10（点推送进入会话后返回本页）、CHAT-12（搜索入口）、SOC-03（发起群聊入口）、SOC-05（群里自己聊天只显示未读数，不推送）、SAFE-07（成人模式消息摘要显示「[消息]」）。

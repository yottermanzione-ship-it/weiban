# 朋友圈

## 1. 目的与入口

像真的加了 TA 的微信一样刷到 TA 的日常，给 TA 点赞评论，TA 的朋友们也会在下面互动（SOC-07～09）。入口：发现 › 朋友圈；角色资料页 › 朋友圈（只看该角色）。

## 3. 使用的组件

NavBar、MomentsCover、MomentCard、ImageGrid、LinkCard（C 4.2，朋友圈内宽度 = 内容宽）、点赞评论胶囊、评论输入栏、ActionSheet、Toast、Skeleton、EmptyState。

## 4. 发朋友圈页（SOC-09）

```
┌────────────────────────────────┐
│ 取消                        发表 │  「发表」主按钮小号；无内容时禁用
├────────────────────────────────┤
│ 这一刻的想法…                     │  TextField 多行，无边框
│ [图][图][＋]                       │  最多 9 张，3 列网格；长按拖动排序
├────────────────────────────────┤
│ 谁可以看            全部角色    › │  → 选择页：全部角色 / 部分角色（通讯录多选）
```

右上角相机图标：点击 → ActionSheet「拍摄 / 从相册选择」；长按 → 直接发纯文字（与微信一致）。

## 5. 状态

| 状态 | 表现 |
|---|---|
| 加载 | 3 条卡片骨架屏 |
| 空 | 封面下方 EmptyState「还没有动态 · 加了角色以后，就能看到 TA 的朋友圈」 |
| 有新动态 | 发现页「朋友圈」行右侧显示最新发圈角色的头像 32 + 红点（SOC-07 第 7 条）；进入后红点消失 |
| 新评论回复 | 朋友圈顶部（封面下）出现胶囊「[头像] 1 条新消息」，点击进入消息列表页（谁回复了你） |
| 自己的动态 | 时间行右侧多一个「删除」文字按钮 |
| 发送中的动态 | 置顶显示，图片上叠 `bg.scrim` 遮罩 + 转圈；失败时显示「发送失败，点击重试」 |

## 6. 交互

- 「··」→ 赞 / 评论胶囊；已赞时显示「取消」。点赞后点赞行即时出现自己的名字（乐观更新）。
- 点评论 → 回复该人；点自己的评论 → ActionSheet「复制 / 删除」。
- 角色动态右上角「…」（或长按卡片）→ ActionSheet：收藏、生成分享图（EXP-01）。
- 点头像或名字 → 角色资料页；点图片 → 全屏图片查看。
- 列表虚拟滚动；「全文」展开是用户主动操作，允许改变该条高度。

## 7. 内容规则在界面上的体现

- 只显示通讯录中角色的动态、点赞和评论（SOC-07 第 6 条、SOC-08 第 3 条）——数据规则，界面不需额外提示。
- 真人角色的朋友圈图片不会出现人物肖像（MED-02）——生成规则；封面同样不使用人物照片（C 10.3）。
- 新动态不单独推送；角色回复用户评论、评论用户动态会推送（CHAT-10 第 2 条）。

# 群聊与群设置

## 1. 目的与入口

用户和 2～9 个角色在一个群里聊天；角色之间会互相接话（SOC-03～05）；角色也会主动拉用户进群（SOC-06）。入口：会话列表、通讯录 › 群聊、会话列表右上角 ⊕ › 发起群聊。

## 2. 页面结构

与私聊相同（`private-chat.md` 第 2 节），差异如下：

```
┌────────────────────────────────┐
│ ‹       火锅小分队（4）        ··· │  标题：群名 +（成员数，含自己）
│      王一博 等 2 人正在输入…        │  副标题：只显示正在输入；群聊没有情景模式
├────────────────────────────────┤
│   杨幂 邀请你和 王一博、肖战 加入了群聊 │  系统提示（角色拉群时第一条）
│ 杨幂                              │  发送者名字（C 4.1 群聊）
│ [头像] ┌周末吃火锅，叫上你一起热闹┐     │
│ 王一博                            │
│ [头像] ┌@杨幂 你上次说的那家？┐        │  @ 显示为链接色
│              ┌好呀好呀┐ [头像]      │  自己的消息不显示名字
├────────────────────────────────┤
│ 🎙 [                    ] 😊  ⊕  │
└────────────────────────────────┘
```

- **不显示已读**（CHAT-07 第 1 条）。
- 群里有用户没添加的角色：点该角色头像 → 资料页（未添加态），底部「添加」（流程 3c）。

## 3. 发起群聊页（SOC-03）

```
┌────────────────────────────────┐
│ 取消        选择角色      完成(3) │  「完成」：选满 2 个才可点；括号内为已选数
├────────────────────────────────┤
│ [已选头像横排，可点击取消]          │  横向滚动
│ 🔍 搜索                          │
│ ○ [头像] 杨幂                     │  通讯录列表 + 圆形勾选框
│ ● [头像] 王一博                   │
│ …                              │
└────────────────────────────────┘
```

- 已选达到 P-21 上限时，其余未选行显示禁用态，点击 Toast「最多选择 9 个角色」（文案由前端读取 P-21）。
- 完成后直接进入新群，系统提示「你邀请 A、B 加入了群聊」，群名默认为成员名拼接（最多显示 3 个名字 + 「等」）。

## 4. 群设置页（SOC-03）

```
┌────────────────────────────────┐
│ ‹        聊天信息（4）             │
├────────────────────────────────┤
│ [头][头][头][头][ + ][ - ]         │  成员网格：每行 5 个，头像 48 + 名字；+ 添加、- 移出
├────────────────────────────────┤
│ 群聊名称            火锅小分队   › │
│ 查找聊天记录                   ›  │
├────────────────────────────────┤
│ 角色自己聊天               ( ● ) │  SOC-05，默认开；说明：「你不在时，大家也会聊起来；不会打扰你」
│ 秒回                       ( ○ ) │  SOC-04 第 4 条，默认关
├────────────────────────────────┤
│ 置顶聊天                   ( ○ ) │
│ 消息免打扰                 ( ○ ) │  未被 @ 的消息是否推送
├────────────────────────────────┤
│ 清空聊天记录                     │
│ 退出群聊 / 解散群聊               │  危险型；用户建的群为「解散」，角色拉的群为「退出」
└────────────────────────────────┘
```

- 群设置中**没有**情景模式、人设贴合度、成人模式入口（SOC-03 第 4 条、SAFE-03）。
- 退出角色拉的群：Dialog「退出后不会再收到这个群的消息」（不写任何挽留文案，SAFE-08）。
- 移出角色：成员网格进入删除态，点头像上的红色减号；群里显示系统提示「你将 XX 移出了群聊」。

## 5. 状态

| 状态 | 表现 |
|---|---|
| 被角色拉进新群 | 会话列表出现新群（带未读数）；进入后第一条为系统提示「XX 邀请你和 YY、ZZ 加入了群聊」，随后拉群者说明原因 |
| 群里自己聊起来（用户不在） | 不推送；会话列表显示未读数；用户进入后从第一条未读开始阅读（显示「↑ N 条新消息」胶囊） |
| 已退出 / 已解散 | 输入栏替换为「你已不在该群聊中」；历史记录可看 |
| 成员被删除（角色被用户删除） | 系统提示「XX 退出了群聊」 |

## 6. 交互补充

- 输入「@」或长按成员头像 → 插入 @（C 4.6）。
- 多选、收藏、分享图与私聊一致；分享图中只要含真人角色消息就带「非本人」标注（`share-templates.md` 3.1）。

## 对应需求

SOC-01（群里不认识的角色之间正常显示，无特殊标识）、SOC-03～06、CHAT-06（群聊正在输入）、CHAT-07（群聊不显示已读）、CHR-06（删除角色后退群提示）。

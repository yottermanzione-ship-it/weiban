# 群聊与群聊信息页

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-006（v1.0）、T-012（v2.0） |
| 日期 | 2026-10-04 |

> v2.0 变更：群设置改为对齐参照产品群聊的「聊天信息」页（SOC-03 第 3 条）；**群聊可以选情景模式**，可选范围是所有成员都具备资格的模式（SOC-03 第 4 条）；退出改为「删除并退出」；新增从私聊聊天信息页发起群聊。

## 1. 目的与入口

用户和 2～9 个角色在一个群里聊天（SOC-03～05）；角色也会主动拉用户进群（SOC-06）。入口：会话列表、通讯录 › 群聊、会话列表右上角 ⊕ › 发起群聊、私聊的聊天信息页「+」。

## 2. 页面结构

与私聊相同（`private-chat.md` 第 2 节），差异：

```
┌────────────────────────────────┐
│ ‹       火锅小分队（4）        ··· │  标题：群名 +（人数，含自己）
│          ● 傲娇模式               │  副标题：正在输入 > 情景模式（日常不显示）
├────────────────────────────────┤
│   杨幂 邀请你和 王一博、肖战 加入了群聊 │  会话内提示
│ 杨幂                              │  发送者名字（C 4.1 群聊）
│ [头像]◀周末吃火锅，叫上你一起热闹 │    │
│ 王一博                            │
│ [头像]◀@杨幂 你上次说的那家？ │       │  @ 显示为链接色
│              │好呀好呀▶[头像]      │
├────────────────────────────────┤
│ 🎙 [                    ] 😊  ⊕  │
└────────────────────────────────┘
```

- **不显示已读**（CHAT-07 第 1 条）。
- 群里有用户没添加的角色：点头像 → 资料页（未添加态）。

## 3. 选择角色页（发起群聊，SOC-03）

```
┌────────────────────────────────┐
│ 取消        选择角色      完成(3) │  「完成」选满要求人数才可点
├────────────────────────────────┤
│ [已选头像横排，可点击取消]          │
│ 🔍 搜索                          │
│ ○ [头像] 杨幂                     │  通讯录列表 + 圆形勾选框
│ ● [头像] 王一博                   │
└────────────────────────────────┘
```

- 从会话列表 ⊕ 进入：至少选 2 个。从私聊聊天信息「+」进入：原角色预选且锁定（勾选框为实心灰），至少再选 1 个。
- 达到 P-21 上限：其余行禁用，点击 Toast「最多选择 9 个角色」（数值读 P-21）。
- 完成后进入新群，会话内提示「你邀请 A、B 加入了群聊」；群名默认为成员名拼接。

## 4. 群聊信息页（SOC-03 第 3 条）

```
┌────────────────────────────────┐
│ ‹        聊天信息（4）             │
├────────────────────────────────┤
│ [头][头][头][ + ][ - ]             │  MemberGrid（C 17.1）：每行 5 格
│ 杨幂 王一博 肖战                    │
├────────────────────────────────┤
│ 群聊名称            火锅小分队   › │
├────────────────────────────────┤
│ 查找聊天记录                   › │
├────────────────────────────────┤
│ 消息免打扰                 ( ○ ) │  未被 @ 的消息不推送
│ 置顶聊天                   ( ○ ) │
├─ 群聊玩法 ──────────────────────┤  微伴专属分组
│ 情景模式                  日常  › │  → ModePicker 页面（C 8.2，群聊资格）
│ 角色自己聊天               ( ● ) │  SOC-05，默认开；说明「你不在时，大家也会聊起来；不会打扰你」
│ 秒回                       ( ○ ) │  SOC-04 第 4 条
├────────────────────────────────┤
│              清空聊天记录          │
│              删除并退出            │  危险型
└────────────────────────────────┘
```

- **情景模式**：只列出所有成员都具备资格的模式（含儿童角色 → 无恋爱、成人；含真人 → 无成人）。选择后群里出现会话内提示「已切换到 XX 模式」；群聊模式只影响本群。
- 拉入一个不具备当前模式资格的角色时，群自动回到日常，会话内提示「XX 加入后，群聊已回到日常模式」（C 4.4）。
- **删除并退出**：Dialog「删除并退出后，这个群聊会解散」+「取消 / 删除并退出」（用户退出即解散，SOC-03 第 3 条）。不写挽留文案。
- 移出角色：点「−」进入删除态，点头像上的红色减号；群里显示「你将 XX 移出了群聊」。

## 5. 状态

| 状态 | 表现 |
|---|---|
| 被角色拉进新群 | 会话列表出现新群（带未读）；第一条为「XX 邀请你和 YY、ZZ 加入了群聊」 |
| 群里自己聊起来 | 不推送；进入后从第一条未读开始（「↑ N 条新消息」） |
| 成员角色被删除 | 「XX 退出了群聊」 |
| 余额不足 / 模型服务不可用 | 同私聊的系统横条 |

## 6. 交互补充

- 输入「@」或长按成员头像 → 插入 @（C 4.6）。
- 多选、收藏、分享图与私聊一致；含真人角色消息的分享图带「非本人，请谨慎识别」贴纸（`share-templates.md` 第 3 节）。

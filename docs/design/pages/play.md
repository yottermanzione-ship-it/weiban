## 1. TA 的提醒（PLAY-07）

### 1.1 提醒列表

```
┌────────────────────────────────┐
│ ‹           TA 的提醒          ＋ │  ＋ → 新建；已达 P-44 条时 ＋ 禁用，点击 Toast「最多 10 条提醒」
├────────────────────────────────┤
│ 22:30  早点睡                ( ● ) │  ReminderRow（C 19.10）
│        [头] 杨幂 提醒 · 每天        │
│ 08:00  吃药  [健康]          ( ● ) │
│        [头] 罗小黑 提醒 · 工作日     │
│ 14:00  带伞                  ( ○ ) │
│        [头] 王一博 提醒 · 10 月 6 日  │
├────────────────────────────────┤
│ 3 / 10                          │  计数（caption1、text.tertiary），数字读 P-44
└────────────────────────────────┘
```

- 空状态：EmptyState「设一个提醒，让 TA 来叫你」+ 按钮「新建提醒」。

### 1.2 新建 / 编辑提醒

```
│ 提醒什么                          │
│ [ 喝水                    2/20 ]  │  TextField（字数上限为设计建议，待产品确认）
│ (喝水)(早点睡)(带伞)(吃药)(交作业)   │  ChoiceChip 快捷填入（C 19.3）
├────────────────────────────────┤
│ 时间                     22:30  › │  TimePickerSheet（C 15.4）
│ 重复                     每天  › │  → 选项页：不重复 / 每天 / 工作日 / 自定义（ChoiceChip 选星期）
│ 谁来提醒                [头] 杨幂 › │  → 通讯录单选
├────────────────────────────────┤
│ 归类为「健康」              ( ○ ) │  说明「推送不显示内容，也不能生成分享图」（PLAY-07、PLAY-01 第 7 条）
│ 免打扰时段也提醒            ( ○ ) │  说明「默认会避开 服务 › 主动消息与免打扰 里的时段」
├────────────────────────────────┤
│ [             保存             ]  │  主按钮
│             删除提醒               │  危险型行（编辑时才有）
```

- 输入「吃药」等快捷项时**不**自动打开「健康」开关（由用户决定），但「吃药」快捷项点选时在开关下方出现一行提示「吃药类提醒建议归类为健康」。
- 到点时：TA 在私聊里发一条普通消息（TA 的口吻，气泡没有特殊样式）；健康类按 `period-diary.md` 第 7 节的「健康」规则展示。
- 提醒不占主动消息额度（PLAY-07），界面不需要解释这一点。

## 2. 心愿清单（PLAY-04）

### 2.1 总览（服务 → 心愿清单）

OverviewRow（C 16.9）列表：头像 + 名字 + 第二行「12 件心愿 · 完成 3 件」；按最近更新排序。点击 → 该角色的清单。没有角色时同服务页空状态。

### 2.2 和 TA 的心愿清单

```
┌────────────────────────────────┐
│ ‹       和 杨幂 的心愿清单          │
├────────────────────────────────┤
│ 想和 TA 一起做的事                   │  说明（footnote、text.secondary）
├────────────────────────────────┤
│ ○ 一起看《XX》                  › │  WishItem（C 19.7）
│ ○ 一起去看海                    › │
│   [10 月 20 日 · 约定]             │  定了日期的显示日期 Tag
│ ○ 一起学做蛋糕                  › │
│   TA 提议                         │
├────────────────────────────────┤
│ ＋ 添加一件想一起做的事              │  点击 → 该行原地变成 TextField + 「添加」文字按钮
├─ 已完成 3 ──────────────────── ⌄ ┤  默认收起；展开 / 收起是用户主动操作，允许改变高度
│ ✓ 一起听新歌                      │
└────────────────────────────────┘
```

- 点心愿行 → 底部弹层：编辑文字、「定个日期」（日期选择，选后说明「定了日期，TA 到时会来问你」，并写入「我们的约定」，MEM-04）、「取消日期」、「删除」（红）。
- 打勾完成：WishItem 完成动效；Toast 文字型「完成啦，获得一张瞬间卡」；私聊出现会话内提示「一起去看海 已完成 · 获得瞬间卡 ›」（C 4.4）。取消完成不收回卡片（GRW-06 第 5 条同理）。
- 达到 P-41 项：「添加」行禁用，说明「最多 50 件心愿」。
- TA 提议加入：私聊 QuickReplyMessage「要不要把『一起去看海』加进我们的心愿清单？」+「加进去」「先不了」（C 4.2）。点「加进去」后该项出现在清单，第二行标「TA 提议」。
- 空清单：EmptyState「和 TA 一起列下想做的事吧」+ 按钮「添加第一件」。

## 3. 每日一问（PLAY-03）

```
┌────────────────────────────────┐
│ ‹            每日一问          历史 │  「历史」→ 以前答过的题（列表，点开看两人的回答）
├────────────────────────────────┤
│ 和谁一起答                         │
│ [头40✓] [头40] [头40] [头40] …      │  横向滚动的头像单选，选中 2px brand.primary 外圈；默认上次选的角色
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │ 10 月 5 日 · 今天的问题        │ │  QuestionCard（C 19.8）
│ │ 如果明天放假一天，你会做什么？    │ │
│ │ ┌ 我的回答 ──────────────┐   │ │
│ │ │ [ 输入你的回答…     0/200 ] │   │ │  TextField 多行（字数上限为设计建议）
│ │ └──────────────────────┘   │ │
│ │ ┌ 杨幂 的回答 ────────────┐   │ │
│ │ │ 🔒 你答完就能看到 TA 的答案  │   │ │
│ │ └──────────────────────┘   │ │
│ └────────────────────────────┘ │
│ [             回答             ]  │  主按钮；空时禁用
└────────────────────────────────┘
```

- 换角色：题目可能随之变化（按关系类型和角色分类筛题，PLAY-03），题目区交叉淡入；已经输入的回答保留。
- 回答后：「回答」按钮变为加载中 → TA 的答案揭晓（M-07 同参数）→ 卡片下方出现文字按钮「去和 杨幂 聊聊 ›」（TA 会在私聊里接一句，PLAY-03 玩法）。今天的题答完后，整页只读，选角色的头像行隐藏。
- 每天 P-40 题；**漏答的日子不补、不提醒**，历史列表里也不显示「未作答」的空行（只列答过的）。
- 余额不足：回答照常保存，TA 的答案块显示「余额不足，TA 暂时没法回答」；余额恢复后揭晓。

## 4. 慢信（PLAY-05）

### 4.1 信箱（服务 → 信箱）

```
┌────────────────────────────────┐
│ ‹             信箱            ✎ │  ✎ 写信 → 先选收信角色
├────────────────────────────────┤
│     收到的●        寄出的          │  TabSwitch（C 1.5）
├────────────────────────────────┤
│ [信封] 杨幂                 ●   › │  ListCell：左 40 信封图标（tint.pink，未读填充 / 已读线性）
│        「收到你的信那天正好下雨…」   │  第一句，单行
│        10 月 5 日 送达              │
│ [信封] 罗小黑                   › │
│        在路上 · 预计今天送到          │  未送达只显示状态，不显示内容
└────────────────────────────────┘
```

- 「寄出的」：我写的信，第二行为第一句，第三行「10 月 4 日 寄出 · 已回信 / 回信在路上」。
- 「收到的」分页红点 = 有未读来信；服务页「信箱」宫格同样红点（与卡册、成就同一规则：不在「我」标签显示）。

### 4.2 写信

```
┌────────────────────────────────┐
│ 取消         给 杨幂 的信        寄出 │  NavBar：左「取消」，右「寄出」（brand.primary，空时禁用）
├────────────────────────────────┤
│ 杨幂：                            │  fontFamily.serif、fontSize.body
│ [ 多行正文……                     ] │  TextField 多行无边框，fontFamily.serif、lineHeight.relaxed，
│                                │  bg.surface 满屏，像一张信纸
│                       0/2000    │  右下计数
├────────────────────────────────┤
│ 回信会在 6–24 小时后寄到            │  底部说明（caption1、text.tertiary），数字读 P-42
└────────────────────────────────┘
```

- 写信页是全屏覆盖（从底部滑入，与分享图编辑同一类），离开时有内容：ActionSheet「保存草稿 / 不保存」。
- 寄出后：私聊出现我的 LetterCard（C 4.2，「你给 杨幂 寄了一封信」）+ 会话内提示「信已寄出，TA 的回信在路上」；Toast 图标型「已寄出」。
- 当天这个角色已经回过一封信时（每个角色每天最多回 1 封）：写信页底部说明改为「TA 今天已经回过一封信了，这封的回信会晚一些到」——界面不阻止寄信，只说明。

### 4.3 收信与读信

- 回信送达：推送「杨幂 给你寄来了一封信」；私聊出现 TA 的 LetterCard（未读红点）；信箱红点。
- 读信页：推入页，`bg.surface` 满屏；顶部「杨幂 寄给你的信」（`fontSize.headline`）+ 日期（`fontSize.caption1`、`text.tertiary`）；正文 `fontFamily.serif`、`fontSize.body`、`lineHeight.relaxed`；底部操作行：「收藏」「生成分享图」「回信」（三个等宽文字按钮）。
- 「生成分享图」走 EXP-01 的规则（真人角色带贴纸副文案）；默认选卡片风模板，正文过长时提示「内容太多，建议用其他模板」（`share-templates.md` 4.4）。
- 打开信件：不做拆信封动画（逐帧或 3D 翻折都违反 `motion.md`），只用页面推入（M-01）。

## 5. 陪你专注（PLAY-06）

### 5.1 开始

从私聊「+」→「陪我专注」（角色即当前私聊对象），或服务 →「陪你专注」→ 先选角色。底部弹层：

```
┌────────────────────────────────┐
│ 和 杨幂 一起专注                    │
│ 时长                               │
│ (25 分钟)(45 分钟)(60 分钟)(90 分钟)(自定义) │  ChoiceChip 单选；自定义 → 滚轮，范围读 P-43（5–120）
│ 做什么（选填）                      │
│ [ 准备考研                         ] │  TextField；说明「TA 可能会记住这件事」
│ [            开始专注            ]  │  主按钮
└────────────────────────────────┘
```

### 5.2 专注中

- 全屏覆盖页（FocusTimer，C 19.9），背景 `bg.page`；右上角「收起」（返回原页面，顶部出现 FocusCapsule）；底部次级按钮「提前结束」。
- 「提前结束」→ ActionSheet 标题「结束这次专注？」选项「结束」（**普通颜色，不用红色**）「取消」。没有挽留、没有「再坚持一下」。
- TA 在开始时发一句加油（私聊），结束时发一句「辛苦啦」并聊聊刚才做了什么；提前结束时 TA 只说「那先休息一下吧」（PLAY-06）。私聊里同时出现会话内提示「开始专注 25 分钟」/「专注结束 · 25 分钟」/「专注提前结束」。
- 专注期间用户主动发消息照常回复；FocusCapsule 照常显示。
- 时间到：如果用户在专注页，计时变为「00:00」+ 文字「专注结束」+ 主按钮「去和 杨幂 聊聊」；如果不在，FocusCapsule 消失，私聊照常收到消息。
- **不统计**累计专注时长、不做排行（PLAY-06）。

## 1. 结论

- 两个入口，对齐参照产品：**会话列表顶部搜索框 → 全局搜索页**（同时搜角色、群聊、聊天记录）；**聊天信息页「查找聊天记录」→ 会话内搜索**（按关键词、日期、图片、链接找）。
- 只搜**文字**内容（CHAT-12）；图片、链接用分类浏览代替搜索。
- 结果点开都是「跳到那条消息的上下文」：聊天页定位到该条并闪一下，上下都可以继续滚动。

## 2. 全局搜索

### 2.1 结构

```
┌────────────────────────────────┐
│ [🔍 搜索                  ⊗]  取消 │  SearchBar（C 1.4）自动聚焦，键盘弹出；右侧「取消」文字按钮
├────────────────────────────────┤
│ 角色                              │  SectionHeader（C 3.5）
│ [头像40] 杨幂                     │  ContactItem（C 3.3）；命中备注时第二行「名字：杨幂」
│ [头像40] 杨某某                   │
│ 查看更多角色                    › │  超过 3 个时出现
├────────────────────────────────┤
│ 群聊                              │
│ [群头像] 火锅小分队                 │  命中群名；命中成员名时第二行「包含：杨幂」
├────────────────────────────────┤
│ 聊天记录                           │
│ [头像40] 杨幂            10/03    │  SearchResultRow（C 21.1）：只有 1 条命中时直接显示摘要
│          …今天收工好早，想吃火锅…   │
│ [群头像] 火锅小分队                 │
│          5 条相关聊天记录        › │  多条命中：聚合行 → 该会话的结果列表（第 2.3 节）
│ 查看更多聊天记录                 › │
└────────────────────────────────┘
```

- 输入后 300 毫秒自动搜索（防抖），不需要按「搜索」键；按键盘「搜索」键立即搜。
- 三个分组都没有结果时整组隐藏；每组最多先显示 3 条，「查看更多」推入只含该分组的完整列表。
- 关键词高亮规则见 C 21.1。

### 2.2 状态

| 状态 | 表现 |
|---|---|
| 未输入 | 搜索框下方居中一行「搜索角色、群聊、聊天记录」（`fontSize.subhead`、`text.tertiary`） |
| 搜索中（超过 300 毫秒） | 列表顶部 16 转圈 |
| 无结果 | EmptyState（无插画）「没有找到「火锅」相关结果」 |
| 失败 | 一行「搜索失败，点击重试」（`text.link`） |
| 角色、聊天记录已删除 | 不出现在结果里（以服务器为准） |

### 2.3 某个会话的结果列表

- 推入页，标题「"火锅" 的聊天记录」+ 副标题会话名；列表为 SearchResultRow，头像和名字是**发这条消息的人**（群聊里区分成员），右侧日期。
- 按时间倒序，滚到底分页加载。
- 点一行 → 聊天页定位（第 4 节）。

## 3. 会话内查找聊天记录

入口：私聊 / 群聊的聊天信息页「查找聊天记录 ›」。

```
┌────────────────────────────────┐
│ [🔍 搜索                     ]  取消 │
├────────────────────────────────┤
│        快速查找                    │  未输入时显示
│   日期      图片      链接          │  三个文字按钮（text.link），群聊多一个「群成员」
└────────────────────────────────┘
```

- 输入关键词后：下方为该会话的结果列表（同 2.3）。
- **日期** → 推入 DateJumpCalendar（C 21.2），点有聊天的日期 → 聊天页定位到那天第一条消息。
- **图片** → 推入图片墙：按月分组（SectionHeader「2026 年 10 月」），4 列正方形缩略图（间距 2，无圆角，与参照产品一致）；点图 → ImageViewer，查看器「…」多一项「定位到聊天位置」。没有图片：EmptyState「还没有图片」。
- **链接** → 推入列表：每行 = LinkCard 的列表版（标题 2 行 + 来源 + 48 封面）+ 日期；点 → 按链接规则打开（`media-l5.md` 第 4 节）；长按 → 「定位到聊天位置」。
- **群成员**（仅群聊）→ 成员列表，点某人 → 该成员在本群发过的全部文字消息（同 2.3 列表）。
- 状态同 2.2。

## 4. 定位到消息（两个入口共用）

- 打开聊天页并直接停在目标消息，目标消息在可视区中间偏上（距顶部 1/3）。
- 目标消息气泡闪一下：叠加 `bg.pressed` 遮罩 opacity 0→1→0（`duration.slow`，同 QuoteBlock 定位）。
- 定位后可上下滚动加载前后消息；右下角显示 JumpPill「↓」回到最新消息（C 15.3）。
- 从定位状态返回 → 回到搜索结果列表（保留关键词和滚动位置）。
- 目标消息已被本地删除：Toast「这条消息已删除」，停留在结果列表。

## 5. 平台差异

- 安卓：键盘「搜索」键 = 立即搜索；系统返回 = 先收起键盘，再返回。
- 网页：回车 = 立即搜索；≥ 900px 宽屏时搜索页在左栏，定位后的聊天在右栏打开。
- 电脑浏览器：Ctrl / ⌘ + F 在会话列表页聚焦全局搜索框（不拦截浏览器在聊天页内的查找）。

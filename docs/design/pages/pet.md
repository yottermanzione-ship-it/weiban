# 共同领养宠物：宠物主页、领养流程、照顾、和角色的联动、插画规格

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-021 |
| 日期 | 2026-10-05 |
| 依据 | PRD v1.3 PLAY-02、GRW-05、GRW-06 第 29、30 号、ADM-04 第 5 条、SVC-01；参数 P-38、P-39；`docs/product/user-flows.md` 流程 11 |

## 1. 结论

- **宠物是「我们俩」的，不是一个电子宠物游戏**：页面上始终写明「和 杨幂 一起养」；TA 的照顾（买猫抓板、发照片）出现在成长记录和相册里。
- **只奖励、不惩罚**：宠物没有饥饿值、清洁度、心情；亲密值和成长阶段只升不降；没有「今天还没喂」的提示，也没有「今天已达上限」的提示（PLAY-02 第 8 条）。
- **按钮互动免费、即时、有反应**：点了就有一次 M-19 小动画和一句预置的小反应，不调用模型。
- **插画是手账贴纸风的小动物**，与品牌插画同一套语言（`brand.md` 6.1），同一只宠物三个阶段一脉相承。

## 2. 入口

| 入口 | 表现 |
|---|---|
| 我 → 服务 → 互动玩法 → 宠物 | 宠物总览（第 3 节） |
| 私聊「···」→ 聊天信息 →「和 TA 的相处」→ 我们的宠物 | 没有宠物：右侧值「一起领养」；有：值为宠物名，点击 → 宠物主页 |
| 角色在聊天里提议（熟悉度 L2 以上，一次） | QuickReplyMessage（C 4.2）：「我们要不要一起养只猫？」+ 按钮「去看看」→ 领养流程第 1 步，角色已预选 |
| 会话内提示「你和 杨幂 一起领养了团子 · 去看看团子 ›」 | → 宠物主页 |

```

├────────────────────────────────┤
│ 在养 2 只（最多 3 只）              │  fontSize.footnote、text.secondary；数字读 P-38
├────────────────────────────────┤
│ [宠物56] 团子                  › │  ListCell：左侧宠物缩略图 56（圆角 radius.md，bg.page 底）
│          和 杨幂 一起养 · 第 12 天   │  第二行 caption1、text.secondary
│          [幼年]                    │  Tag 品牌型
│ [宠物56] 豆包                  › │
│          和 罗小黑 一起养 · 第 140 天 │
├────────────────────────────────┤
│ ＋ 和 TA 一起领养                   │  居中动作型行（text.link）；已满 3 只时禁用 + 说明「最多同时养 3 只」
├─ 回忆 ─────────────────────────┤  有送养过的才显示
│ [宠物56] 小米                  › │  透明度 opacity.muted；第二行「和 王一博 · 养了 45 天」
└────────────────────────────────┘
```

- 「和 TA 一起领养」→ 选择角色页（单选 ListCell + 头像；已经和用户有宠物的角色显示为禁用 +「已经有 团子 了」，P-38 每个角色 1 只）→ 领养流程。
- 空状态：EmptyState「和 TA 一起养一只小家伙吧」+ 按钮「选一个 TA」。没有角色时同服务页总览的空状态。
- 「回忆」中的宠物点进去是只读的宠物主页：没有照顾按钮，顶部 Tag「回忆」，成长记录和相册照常可看。

## 4. 领养流程（PLAY-02 第 3 条）

三步，推入页面，NavBar 右侧步骤「1/3」。全程可以返回上一步；中途离开不保存。

### 4.1 选物种

```
┌────────────────────────────────┐
│ ‹       和 杨幂 一起领养       1/3 │
├────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐   │  两列卡片：bg.surface、radius.md、内边距 space.4
│ │ [幼年图]  │ │ [幼年图]  │   │  图 1:1（宠物图鉴该物种第一个外观的幼年图）
│ │ 小猫      │ │ 小狗      │   │  名称 fontSize.body、fontWeight.medium
│ │ 爱睡觉…   │ │ 爱出门…   │   │  简介 footnote、text.secondary，2 行
│ └──────────┘ └──────────┘   │
│ …                              │
└────────────────────────────────┘
```

- 点卡片即进入下一步（不需要再点「下一步」）。物种来自宠物图鉴（ADM-04 第 5 条），管理员下架的物种不出现。

### 4.2 选外观

```
┌────────────────────────────────┐
│ ‹            选外观          2/3 │
├────────────────────────────────┤
│        [ 大图：所选外观的幼年 ]     │  PetStage（C 19.4）样式，无场景时 brand.soft 底
│                                │
│ 长大后：[幼年小图][少年小图][成年小图]  │  三张 48 缩略图一排（caption1 标注阶段）
├────────────────────────────────┤
│ (○橘色) (○奶牛) (○三花)            │  外观选择：64 圆形缩略图 + 名称，选中 2px brand.primary 外圈
├────────────────────────────────┤
│ [            就选它了            ]  │  主按钮 lg
└────────────────────────────────┘
```

- 所有外观都能直接选，**不显示稀有度、不显示「限定」**（PLAY-02 第 9 条）。
- 切换外观：大图交叉淡入（opacity，`duration.fast`）。

### 4.3 起名

```
┌────────────────────────────────┐
│ ‹             起名           3/3 │
├────────────────────────────────┤
│        [ 所选外观的幼年图 160 ]    │
│ [ 给它起个名字            0/8 ]   │  TextField；字数上限 8 为设计建议（见下）
│                                │
│ [ 让 杨幂 起名 ]                   │  Button md tonal
│   杨幂 正在想名字…                  │  点击后：按钮变为加载中 + 这行小字
│   (团子) (小煤球) (橘座)            │  TA 回复后：3 个 ChoiceChip（C 19.3）单选，点选即填入输入框
├────────────────────────────────┤
│ [            完成领养            ]  │  主按钮 lg；名字为空时禁用
└────────────────────────────────┘
```

- 「让 TA 起名」是一次聊天回复（PLAY-02 第 12 条）：TA 同时在私聊里发出这 3 个候选（QuickReplyMessage，3 个按钮，C 4.2），两处任选一处都可以；用户也可以选中后再改。
- 余额不足时「让 TA 起名」点击后显示小字「余额不足，TA 暂时没法起名，你可以先自己起一个」，按钮恢复（PLAY-02 边界情况）。
- 名字字数上限 PRD 未规定，设计建议 8 字（能放进宠物页标题和卡面），**请产品写入 PRD 后以 PRD 为准**。

### 4.4 完成

- 点「完成领养」→ 推入（替换流程页）宠物主页，播放一次 M-13（卡片弹出同款：宠物图 scale 0.6 → 1.04 → 1 + 小星星散开），之后不再播放。
- 同时：私聊出现会话内提示「你和 杨幂 一起领养了团子 · 去看看团子 ›」，TA 随后按人设回应一次；获得瞬间卡「我们的团子」（会话内提示「获得瞬间卡 ›」，C 4.4）；第一次领养获得成就「一起养了只小家伙」（Toast 成就型，C 6.11）。

## 5. 宠物主页（PLAY-02 第 5～7 条）

### 5.1 结构

```
┌────────────────────────────────┐
│ ‹              团子           ··· │  NavBar；··· → 宠物设置（5.4）
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │      [场景图 + 团子]   [幼年] │ │  PetStage（C 19.4），宽 × 0.75
│ │              「呼噜呼噜～」    │ │  互动后出现的反应小字气泡
│ └────────────────────────────┘ │
├────────────────────────────────┤
│ 团子                              │  fontSize.title2、fontWeight.semibold
│ [头20] 和 杨幂 一起养 · 领养第 12 天  │  footnote、text.secondary；点头像 → 杨幂资料页
│ 亲密值 86                          │  fontSize.subhead；数字等宽；只是一个数字，没有上限进度条
├────────────────────────────────┤
│   (🐟)      (🎾)      (✋)         │  PetActionButton × 3（C 19.5）
│   喂食      玩耍      摸摸          │
├────────────────────────────────┤
│ ● ── ○ ── ○                      │  GrowthSteps（C 19.6）
│ 幼年   少年   成年                   │
│ 第 30 天长成少年 · 第 100 天长成成年    │
├────────────────────────────────┤
│ 成长记录                         › │  ListCell → 5.2
│ 相册                      12 张  › │  ListCell → 5.3；右侧可显示最近 3 张缩略图（同资料页朋友圈行）
├────────────────────────────────┤
│ 去和 杨幂 聊聊团子                  │  居中动作型行（text.link）→ 私聊
└────────────────────────────────┘
```

- 页面背景 `bg.page`；PetStage 通栏（无左右外边距）。
- 照顾按钮：点一次 → M-19 + 反应小字（预置文案按物种和按钮随机，例：喂食「吧唧吧唧」、玩耍「扑！」、摸摸「呼噜呼噜～」；文案表由 AI 负责人或产品提供，界面不调用模型）。亲密值数字在计数时直接替换（+1），不做跳动动画。
- 角色在之后的聊天里会知道今天玩过（PLAY-02 第 6 条），宠物页本身**不**显示「TA 知道了」之类的提示。

### 5.2 成长记录

时间线列表（复用 TimelineItem 的样式，`while-away-timeline.md` 第 3 节）：

| 条目 | 来源 |
|---|---|
| 「10 月 5 日 · 和 杨幂 一起领养了团子」「名字是 杨幂 起的」 | 领养流程 |
| 「11 月 3 日 · 团子长成少年啦」 | 阶段变化（附该阶段的图鉴小图 48） |
| 「10 月 9 日 · 杨幂：给团子买了新猫抓板」 | 角色推演中和宠物有关的日常事件（PLAY-02 第 7 条）；带角色小头像 20 |

- 第三类条目依赖 AI / 后端提供「和这只宠物有关的推演事件」列表；**如果首版没有这份数据，只显示前两类**，界面不需要改动（见交接说明）。
- 不出现「今天没有照顾」之类的记录。

### 5.3 相册

- 3 列正方形网格（ImageGrid 的 5–9 张布局规则，C 10.2），按时间倒序；每张左下角来源小标：角色发来的为角色头像 16，自己上传的无标。
- 右上角「＋」：从相册选择上传（格式和大小以媒体接口为准）。
- 点图片 → ImageViewer（C 15.2），可保存、收藏；角色发来的宠物照片可以生成分享图（宠物照片不是敏感信息，PLAY-02 联动表）。
- 空：EmptyState「TA 发来的团子照片会收在这里」。

### 5.4 宠物设置（···）

```
│ 允许 杨幂 在朋友圈晒团子      ( ● ) │  默认开（PLAY-02 第 7 条）；说明「TA 只会晒团子，不会提到你」
│ 改名字                         › │  TextField 页
├────────────────────────────────┤
│              送养                 │  危险型行
```

- 送养：Dialog 标题「送养 团子？」正文「团子会移到『回忆』里，成长记录和相册都会保留。之后可以和 杨幂 再领养一只」；按钮「取消」「送养」（危险）。**没有任何挽留文案**（SAFE-08）。确认后回到宠物总览，TA 按人设在私聊回应一次。
- 「改名字」PRD 未写，属于设计补充：名字是用户起的，允许修改符合预期；**请产品确认**（见交接说明），确认前可不实现。

### 5.5 状态

| 状态 | 表现 |
|---|---|
| 余额不足（MDL-10） | 照顾按钮照常可用；角色相关的回应等余额恢复（界面无提示，聊天页有余额横条） |
| 角色已删除（30 天内） | 宠物总览中该宠物行透明度 `opacity.muted`，第二行「杨幂 已删除，恢复 TA 时团子会回来」；点进去只读 |
| 物种被管理员下架 | 已领养的不受影响，界面无差别 |
| 宠物图加载失败 | PetStage 显示 `brand.soft` 底 + 物种名文字 |

## 6. 和角色的联动展示（汇总）

| 联动 | 用户在哪里看到 | 组件 |
|---|---|---|
| 角色提议领养（一次） | 私聊：QuickReplyMessage「去看看」 | C 4.2 |
| 领养完成 | 私聊会话内提示 + TA 的回应；卡册「我们的团子」瞬间卡；成就 29 | C 4.4、C 9.5、C 6.11 |
| 让 TA 起名 | 私聊 3 个候选按钮 + 起名页候选片 | C 4.2、C 19.3 |
| TA 分享宠物日常 | 私聊里普通文字 + 宠物照片（ImageMessage）；照片同时进相册 | C 4.2 |
| TA 在朋友圈晒宠物 | TA 的朋友圈（普通 MomentCard）；可在宠物设置关闭 | C 10.1 |
| 宠物进入新阶段 | 私聊会话内提示「团子长成少年啦 · 获得瞬间卡 ›」；第一次到成年获得成就 30 | C 4.4 |
| 用户照顾宠物 | TA 之后在聊天里自然提到（界面无专门展示） | — |
| 群聊 | TA 可以在群里提起宠物（普通消息） | — |

## 7. 宠物插画规格（交给管理员素材库 ADM-04 第 5 条）

方向见 `brand.md` 6.1。每个物种需要提供：

| 项 | 规格 |
|---|---|
| 外观数 | 每个物种 3 种外观（花色或配饰不同） |
| 成长阶段 | 幼年、少年、成年各 1 张，**同一外观的三张必须看得出是同一只** |
| 宠物图 | 透明底，画布 512×512，主体占画布 80%，底部留 8% 给地面阴影（阴影画在图里，界面不加 box-shadow）；WebP，单张 ≤ 60KB；另导出 128×128 缩略图 |
| 场景图（可选，每物种 1 张） | 宽 1080 × 高 810（4:3），柔和渐变 + 少量物件（窝、垫子、窗台），中央下部留给宠物；WebP ≤ 80KB；**不画人** |
| 卡面 | 瞬间卡「我们的 XX」「长成少年 / 成年」用该外观对应阶段的宠物图 + 卡面模板（`cards-familiarity.md` 3.4），真人角色卡面同样只有宠物，没有人物 |
| 可读性 | 在 `bg.surface` 浅、深两种底上都要清晰（提交浅色、深色检查截图） |
| 表情 | 只有温和的表情；**不做**饿、病、脏、哭、生气的图（PLAY-02 第 8 条） |

**首批物种建议**（管理员可增删）：小猫（橘色 / 奶牛 / 三花）、小狗（柴犬色 / 小白 / 黑白）、小兔（白 / 灰 / 奶茶）。每个物种 3 外观 × 3 阶段 = 9 张宠物图，首批共 27 张 + 3 张场景图。

## 8. 使用的组件

NavBar、PetStage（C 19.4）、PetActionButton（C 19.5）、GrowthSteps（C 19.6）、ChoiceChip（C 19.3）、ListCell、TextField、Button、Tag、ImageGrid（C 10.2）、ImageViewer（C 15.2）、TimelineItem（`while-away-timeline.md`）、QuickReplyMessage、SystemTip、Dialog、Toast、EmptyState。

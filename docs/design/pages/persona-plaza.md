> 本文只定界面。哪些字段会被发布、怎么识别私人信息、分类怎么锁定，以 PRD 和架构文档为准，这里只写编号。

## 1. 结论

- **一个入口，两个分页**：「发现 → 角色广场」顶部 TabSwitch（C 1.5）切换「预设角色 | 人设广场」。从「+ → 添加角色」、通讯录进入时默认停在「预设角色」（PLZ-01 第 1 条）。
- **广场看起来像「角色广场」的延伸**，不像社交网络：列表行和预设角色一样朴素；没有关注、私信、个人主页（PLZ-03 第 6 条）；点评论者头像没有反应。
- **发布 = 先看清楚再发**：发布前必经「发布内容确认」页，逐项列出将要公开的文字，疑似私人信息默认遮盖、逐条处理（PLZ-02 第 6 条）。
- **拿走 = 先看完内容再拿**：列表行里没有「添加」按钮，必须进作品页看到完整预览后，在底部操作栏添加或应用。
- 分类锁定、永不发布的内容由系统保证（架构 `persona-plaza.md` 第 4 节），界面只做**说明**，不提供任何能改变它的控件。

- 「预设角色」分页的内容和规则不变（`contacts-add.md` 第 2 节，含底部「创建自己的角色」）。
- 「人设广场」分页没有底部「创建自己的角色」按钮（发布入口在聊天信息页，见第 4.1 节）。
- 「我发布的」：NavBar 右侧图标按钮（Phosphor `user-list`，24），有新点赞 / 评论 / 回复 / 举报结果 / 下架通知时右上角 Badge 红点（PLZ-03 第 4 条：**只有红点，不发推送**）。只在「人设广场」分页显示，切回「预设角色」时隐藏（瞬间切换）。

### 2.2 排序与筛选（PLZ-01 第 4、5 条）

| 胶囊 | 底部弹层选项 | 默认 |
|---|---|---|
| 排序 | 热门 / 最新发布 / 点赞最多（ListCell 选择型）；热门的算法见 P-34，界面不解释公式 | 热门（胶囊文字显示当前排序名，未改动时用普通样式） |
| 类型 | 全部 / 自定义角色 / 预设改版 | 全部 |
| 分类 | 全部 / 原创 / 虚构 / 真人（只对自定义角色生效；类型选「预设改版」时该胶囊禁用） | 全部 |

- 搜索命中「基于的预设角色名」时（如搜「杨幂」），WorkRow 类型 Tag 中的「基于 杨幂」以 `brand.soft` 底高亮（与预设角色分页搜索高亮作品名同一做法）。
- 搜索、排序、筛选可以组合；改动后列表回到顶部。

### 2.3 头像显示（PLZ-02 第 5 条）

| 作品 | 广场上显示 |
|---|---|
| 原创 / 虚构自定义角色，作者勾选了「我有权使用这张图片」 | 作品头像 |

## 3. 作品页（PLZ-01 第 6 条、PLZ-03、PLZ-04）

### 3.1 结构

```
┌────────────────────────────────┐
│ ‹                           ··· │  ··· → ActionSheet：举报（别人的作品）/ 管理（自己的作品）
├────────────────────────────────┤
│            [头像64]              │  WorkHeader（C 18.2）
│          更黏人的杨幂              │
│     [预设改版 · 基于 杨幂]          │
│     下雨天会给你打电话的那种黏人     │
│          [头] 小鱼 ›               │  → 作者页（3.4）
│     版本 3 · 10 月 5 日更新         │  → 版本记录弹层（3.3）
├────────────────────────────────┤
│ 发布说明                          │  SectionHeader + 正文块（C 18.3）
│ 写给喜欢杨幂又想要多一点陪伴的你……   │
├─ 你将得到的内容 ─────────────────┤  ContentPreview（C 18.3）
│ 基于的角色  [头24] 杨幂（预设角色）›  │  预设改版才有；点击 → 该预设角色资料页
│ 改版设定                          │
│ 下雨天会主动问你带伞没有，▢▢▢ ……   │  被遮盖的片段（C 18.4）
│                       展开      │
├────────────────────────────────┤
│ ⓘ 只复制上面这些内容；作者的聊天记录、│  说明（footnote、text.secondary）
│   记忆和个人资料不会出现在广场上      │
├─ 评论 23 ───────────────────────┤
│ [头32] 阿柚                        │  CommentItem（C 18.5）
│        好可爱！已经用上了             │
│        2 小时前                     │
│ [头32] 小鱼 [作者]                  │
│        回复 阿柚：谢谢喜欢～          │
│ ┌ 说点什么…                    ┐  │  评论输入入口（点击后底部出现输入栏）
├────────────────────────────────┤
│ 👍 128   💬 23   [添加为新角色][应用到我的杨幂] │  WorkActionBar（C 18.6），固定底部
└────────────────────────────────┘
```

- 自定义角色作品的「你将得到的内容」依次为：分类（只读，见 3.2）、人设描述、说话方式、口头禅、示例对话、标签、生日、音色名称（PLZ-01 第 6 条、PLZ-02 第 3 条）。没填的项不显示。
- 预设改版作品只显示「基于的角色」和「改版设定」全文；预设角色本身的人设不在这里展示（它由管理员维护，PLZ-02 第 3 条）。
- 改编作品：WorkHeader 显示「改编自《原作品名》· 原作者 XX」（不可删除，PLZ-04 第 6 条）。

### 3.2 分类说明（只读）

ContentPreview 第一组「分类」：ListCell 只读，例「真人 · 公众人物」「虚构 · 已满 18 岁」「原创 · 未满 18 岁」。下方说明（`fontSize.footnote`、`text.secondary`）：「添加后分类与原作品相同，之后只能改得更严格」（PLZ-04 第 2 条）。**不出现「成人模式」字样**：资格由系统判定，在这里提会显得像卖点。

### 3.3 版本记录（PLZ-05 第 3 条）

点「版本 3 · 10 月 5 日更新」→ 底部弹层：每个版本一行「版本 3 · 2026-10-05」+ 更新说明（`fontSize.footnote`、`text.secondary`，最多 100 字），最新在上。只读，不能查看旧版本内容（旧版本内容只有管理员能看，ADM-09 第 1 条）。

### 3.4 作者页（PLZ-01 第 7 条）

推入页：顶部居中广场头像 64 + 广场昵称（`fontSize.title3`）+「N 个作品」（`fontSize.footnote`、`text.secondary`）；下方 WorkRow 列表。**没有任何其他信息和按钮**（没有关注、私信、简介、注册时间）。作者已注销：页面不可进入（作品已随之删除）。

### 3.5 点赞与评论（PLZ-03）

- 点赞：点 WorkActionBar 左侧按钮，M-18；再点取消。
- 评论入口：评论区底部「说点什么…」占位框（高 36，`bg.page`，`radius.sm`）。点击后底部出现单行输入栏（同朋友圈评论输入栏，C 10.1），占位「评论」或「回复 XX」；输入超过 P-35 字时输入栏右侧显示红色计数「201/200」，发送按钮禁用。
- **第一次评论前没有广场昵称**：先推入「设置广场昵称」页（4.2），完成后回到这里继续输入。
- 评论按时间正序；超过 20 条时先显示前 20 条 +「查看全部 N 条评论」。
- 作者关闭了评论：评论区只显示一行「作者关闭了评论」（`fontSize.footnote`、`text.tertiary`），不显示已有评论，也没有输入入口（PLZ-03 第 3 条）。
- 用户被管理员停止评论权限：点评论入口 Toast「你暂时不能评论」。

### 3.6 添加为我的角色（PLZ-04 第 1、2、5 条）

```
点「添加为我的角色」
 ├─ 我已添加过这个作品 → ActionSheet 标题「你已添加过这个角色」，选项「再添加一份」「取消」
 ├─ 通讯录已满 P-26 → Dialog「通讯录已满 50 个角色，先删除一些再添加吧」（同 contacts-add.md 1.3）
 └─ 底部弹层：打招呼（与 contacts-add.md 第 3 节相同的弹层）
      上方多一行说明（footnote、text.secondary）：
      「分类：真人 · 公众人物，与原作品相同，之后只能改得更严格」
      → 发送 → 弹层关闭，按钮变「等待通过…」
      → P-30 时间内通过：Toast「XX 通过了你的好友申请」；按钮恢复，WorkRow 显示「已添加」
```

- 预设改版选「添加为新角色」时同样走这个弹层；名字默认为作品名（如「更黏人的杨幂」），用户之后可在角色编辑器里改。

### 3.7 应用改版（PLZ-04 第 3 条）

```
点「应用到我的 杨幂」
 ├─ 我对杨幂已有补充设定 → Dialog 标题「替换补充设定？」
 │     正文「将替换你现有的补充设定。你们的聊天记录、记忆和熟悉度都不会变」
 │     按钮「取消」「替换」
 ├─ 没有补充设定 → 直接应用
 └─ 完成：Toast 图标型「已应用到 杨幂」；按钮变为灰字「已应用」
点「添加 杨幂 并应用」（还没加过杨幂）
 → 打招呼弹层（同 3.6）→ 发送后弹层关闭 → 通过后自动应用，Toast「已添加 杨幂 并应用改版」
```

- 应用后的补充设定页（聊天信息 › 我的补充设定）顶部显示 SourceNote（C 18.7）。

### 3.8 举报（PLZ-07）

- 入口：作品页「···」→ 举报；评论长按 → 举报。
- 推入「举报」页：ListCell 选择型四项（侵犯他人权益（肖像、隐私、版权）/ 违反底线规则（例如儿童角色被标成成年、真人角色被标成原创）/ 不适宜的内容 / 其他）+ 补充说明 TextField（选填，0/200）+ 底部主按钮「提交」。
  - 第二项的显示名用「违反底线规则」而不是 PRD 内部用语「硬性边界」，括号里的例子照 PRD 原文。
- 提交后返回，Toast 文字型「已提交，管理员会尽快处理」。同一内容再次打开举报：菜单项显示为禁用的「已举报」（PLZ-07 第 2 条）。
- 处理结果出现在「我发布的 › 消息」（第 5.3 节）。

## 4. 发布流程（PLZ-02、PLZ-05）

### 4.1 入口（PLZ-02 第 1 条、CHAT-13）

| 作品类型 | 入口 | 显示 |
|---|---|---|
| 自定义角色 | 私聊「···」→ 聊天信息 →「高级」组 →「发布到人设广场」；角色资料页「···」→ 同名项 | 未发布：「发布到人设广场 ›」；已发布：右侧值「已发布 · 版本 3」，点击 → 该作品的管理页（第 5.2 节） |
| 预设改版 | 聊天信息 → 我的补充设定 → 页面底部「发布为改版」（文字按钮）；没有补充设定时不显示 | 已发布：「已发布为改版 · 版本 2 ›」 |

**不能发布时**入口显示为禁用态（`opacity.disabled`），下方说明（`fontSize.footnote`、`text.secondary`）写原因，点击无反应：

| 原因 | 说明文字 |
|---|---|
| 「基于身边真人」的角色（裁定 C1） | 「以身边的人为原型的角色不能发布，这是为了保护 TA 的隐私」 |
| 从广场复制来、原作品不允许改编（PLZ-04 第 6 条） | 「原作者没有允许改编后再发布」 |
| 被管理员停止发布权限（ADM-09 第 4 条） | 「你暂时不能发布作品」（有期限时加「，X 月 X 日后恢复」） |
| 作品被管理员下架（不能发新版本，ADM-09 第 2 条） | 「这个作品已被管理员下架」 |
| 原角色已删除（不能再发新版本） | 入口随角色一起消失；作品仍可在「我发布的」里下架或删除 |

### 4.2 设置广场昵称（第一次发布或第一次评论，PLZ-02 第 2 条）

```

│            更换头像               │  文字按钮
├────────────────────────────────┤

├────────────────────────────────┤
│ ⓘ 其他用户会看到你的广场昵称和头像，   │  说明（footnote、text.secondary）
│   不会看到你的通讯录、朋友圈和聊天     │

```

- 之后可以在「我发布的」顶部修改；修改后所有作品和评论的署名一起变。

### 4.3 填写发布信息

```
┌────────────────────────────────┐
│ ‹        发布到人设广场        1/2 │  NavBar 右侧步骤「1/2」（caption1、text.tertiary）
├─ 介绍 ─────────────────────────┤
│ 一句话介绍                         │
│ [ 会记得你上次买的那本书     12/30 ] │  TextField，必填，≤ 30 字
│ 发布说明                          │
│ [ 多行……                  0/300 ] │  TextField 多行，选填，≤ 300 字
├─ 头像 ─────────────────────────┤  原创 / 虚构才有本组
│ [头40] 使用这张头像         ( ● ) │  开关；关 = 广场上用默认头像
│ ☐ 我有权使用这张图片               │  开关打开时出现，必须勾选才能「下一步」
├────────────────────────────────┤  真人分类改为一行说明：
│                                │  「真人角色的头像不会发布，广场上显示默认头像」
├─ 设置 ─────────────────────────┤
│ 允许改编后再发布            ( ● ) │  默认开；说明「别人添加后修改，可以再发布为新作品，并标注改编自你」
│ 开放评论                   ( ● ) │  默认开
├────────────────────────────────┤
│ [             下一步             ] │  主按钮；必填未填时禁用

- **发布新版本**时，本页顶部多一项「更新说明」（TextField 多行，必填，≤ 100 字，PLZ-05 第 1 条）；其他字段预填上一版的值。
- 预设改版没有「头像」组（显示预设角色头像，PLZ-02 第 5 条）。
- 点「下一步」→ 进入检查中（4.4 之前的过渡状态）：整页 Skeleton + 中央小字「正在检查要发布的内容…」。这一步会运行儿童特征检测和隐私识别（费用从余额扣，PLZ-02 第 7 条）。
  - **余额不足**：不进入下一步，Dialog「余额不足，暂时无法发布」+「查看余额」「知道了」（PLZ-02 边界情况：不跳过检测）。

└────────────────────────────────┘
```

- **改写**：推入该字段的编辑页（单个 TextField），改完返回，系统对改动后的文字重新识别；原片段若已被删改，该行消失。
- **保留**：Dialog 标题「这不是你的私人信息？」正文显示该片段原文；按钮「取消」「这不是我的私人信息」（PRD 要求再点一次确认）。确认后片段样式变为「已确认保留」（C 18.4），该行从「需要你确认」移除。
- **不处理直接发布**：未确认的片段按遮盖后的样子发布（PLZ-02 验收），其他用户看到「▢▢▢」。
- 儿童特征检测发现儿童特征、而分类是「已满 18 岁」时（PLZ-02 第 7 条）：分类行下方加 InlineTip 警告变体「人设中有未成年特征，这个作品在任何人那里都不能开启成人模式」。作品仍可发布，不阻断。
- 新版本试图把分类改宽（例如上一版是「真人」，这一版是「原创」）：「发布」按钮禁用，分类行下方红字「新版本的分类不能比上一版更宽」（PLZ-05 第 2 条）。正常情况下角色编辑器已经锁住分类，这里是兜底。
- 点「发布」→ 按钮加载中 → 成功后推入（替换当前流程页）该作品的作品页，Toast 图标型「已发布」。

### 5.2 管理一个作品

点作品行 → 作品页（自己视角：WorkActionBar 右侧为「管理」）。「管理」或「···」→ ActionSheet：

| 项 | 条件 | 结果 |
|---|---|---|
| 发布新版本 | 原角色 / 补充设定还在，未被管理员下架 | 进入 4.3（带「更新说明」） |
| 关闭评论 / 开启评论 | — | 立即生效，Toast「已关闭评论」；关闭后已有评论隐藏，重新开启后恢复 |
| 下架 / 重新上架 | 被管理员下架的作品**没有**「重新上架」 | 下架：Dialog「下架后，广场上看不到这个作品，已经添加的人不受影响」「取消」「下架」 |
| 删除作品 | — | Dialog 标题「删除作品？」正文「作品和它的点赞、评论都会删除，不能恢复。已经添加的人不受影响」；危险按钮「删除」 |

### 5.3 消息

- 列表行：左头像 32（广场头像；系统通知用 `storefront` 图标）+ 第一行事件（`fontSize.subhead`）：「阿柚 赞了《更黏人的杨幂》」「阿柚 评论：好可爱！」「阿柚 回复了你：……」「你举报的作品已处理」/「你举报的内容未发现问题」（PLZ-07 第 4 条，不显示处理细节）/「你的作品《小狐狸》已被下架，原因：……」（ADM-09 第 2 条）；第二行时间（`fontSize.caption1`、`text.tertiary`）；未读行左侧 8px 红点。
- 点击：点赞、评论、回复 → 对应作品页并滚动到该评论；举报结果、下架通知 → 不跳转。
- 进入消息分页即算已读，红点（「我发布的」入口、分页、对应作品行）一起消失。

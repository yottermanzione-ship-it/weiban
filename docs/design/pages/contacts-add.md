# 通讯录、角色广场、添加角色、创建自己的角色

## 1. 通讯录（CHR-05）

### 1.1 结构

```
┌────────────────────────────────┐
│           通讯录              👤+ │  右上角：添加角色 → 角色广场
├────────────────────────────────┤
│ 🔍 搜索                          │  按名字或备注就地过滤
├────────────────────────────────┤
│ [+] 新的朋友                  ●  │  红点：有新的名片推荐 / 添加记录
│ [▣] 群聊                         │
├─ L ────────────────────────────┤  分组标题吸顶
│ [头像] 罗小黑                     │  C 3.3
├─ W ────────────────────────────┤                          A
│ [头像] 王一博                     │                          B
├─ Y ────────────────────────────┤                          …   ← 字母索引条
│ [头像] 杨幂                       │                          Z
├────────────────────────────────┤
│           12 个角色               │  列表底部计数（fontSize.footnote，text.tertiary）
├────────────────────────────────┤
│  消息    通讯录    发现     我     │
└────────────────────────────────┘
```

### 1.2 新的朋友

- 列表：名片推荐记录（「杨幂 推荐了 王一博」+ 右侧「添加」/「已添加」/「已忽略」）、添加记录（「已添加」）。
- 空状态：EmptyState「还没有新朋友 · TA 的朋友们会通过名片介绍给你」。

### 1.3 状态

| 状态 | 表现 |
|---|---|
| 空 | EmptyState + 按钮「去角色广场」 |
| 达到上限 P-26 | 角色广场的「添加」点击后 Dialog「通讯录已满 50 个角色，先删除一些再添加吧」（数值读 P-26） |

## 2. 角色广场（CHR-01）

```
┌────────────────────────────────┐
│ ‹          角色广场               │
├────────────────────────────────┤
│ 🔍 搜索名字、别名、作品             │
│ [  明星  |  虚构角色  |  历史人物 ] │  SegmentedControl（分类由管理员维护，超过 4 个时改为横向滚动标签）
├────────────────────────────────┤
│ [头像48] 杨幂              [添加]  │  CharacterRow（C 9.1）
│          演员、歌手                │
│          [演员][《三生三世》]       │
│ [头像48] 王一博              已添加 │
│ …                              │
├────────────────────────────────┤
│ ＋ 创建自己的角色                  │  底部固定入口（C 6.1 tonal 大按钮）
└────────────────────────────────┘
```

- 搜索结果按匹配程度排序，命中作品名时在简介行高亮作品名（`brand.onSoft` 背景）。
- 首次使用引导模式下：顶部多一条 InlineTip「先加一个你喜欢的 TA 吧」，不可关闭，加完第一个角色后消失。
- 空搜索结果：EmptyState「没有找到「xxx」 · 可以试试 创建自己的角色」。

## 3. 添加流程（CHR-03）

1. 点「添加」（广场行或资料页底部）→ 底部弹层：
   ```
   ┌────────────────────────────────┐
   │ 向 杨幂 打个招呼                  │
   │ ┌──────────────────────────┐   │
   │ │ 我是你的粉丝！             │   │  TextField 多行，占位「说点什么（选填）」，0/50
   │ └──────────────────────────┘   │
   │ [            发送            ]  │  主按钮
   └────────────────────────────────┘
   ```
2. 发送后弹层关闭；资料页底部按钮变为「等待通过…」（禁用 + 转圈）；广场行按钮变为「等待中」。
3. P-30 时间内通过：Toast 文字型「杨幂 通过了你的好友申请」；资料页按钮变为「发消息」；会话列表出现该角色。
4. 删除后 30 天内重新添加（CHR-06）：点「添加」先弹 ActionSheet，标题「你们以前认识过」，选项「恢复以前的聊天记录和记忆」「重新认识」。

## 4. 创建自己的角色（CHR-07、CHR-08）

### 4.1 入口选择页

两张 EntryCard（C 15.7）：
- 「导入聊天记录」：从聊天记录生成一个说话像 TA 的角色；
- 「手动填写」：自己写一个角色。

### 4.2 导入流程（用户流程 8a）

| 步骤 | 页面 | 要点 |
|---|---|---|
| 1 说明 | 说明页 | 支持粘贴文字或上传 .txt；提示「只导入你有权使用的内容」；显示「预计花费：较少 / 中等 / 较多」档位 Tag |
| 2 粘贴 / 上传 | 大文本框 + 「上传 .txt」按钮；字数统计 | 识别不出发言人：文本框下方红色说明 + 「查看格式示例」 |
| 3 选择角色是谁 | 识别出的发言人列表（ListCell 选择型），每人显示前 2 句示例 | — |
| 4 原文保存 | ListCell 开关「保留原文以便以后补充」，默认关；说明「默认生成后删除原文，只保留角色草稿」 | CHR-08 第 6 条 |
| 5 生成中 | 进度页：进度条（scaleX）+ 「正在读懂 TA 的说话方式…」+ 「可以先离开，完成后通知你」 | 可离开 |
| 6 编辑草稿 | 角色编辑器（4.3） | 角色类型默认锁定「基于真实存在的人」 |

### 4.3 角色编辑器（导入和手动共用）

- 分组表单：基本信息（头像、名字*、角色类型*、年龄设定*）→ 人设（人设描述*，≥ 50 字，带字数）→ 可选（生日、口头禅、示例对话、标签、音色）→ 「试聊」按钮。
- **角色类型**（SegmentedControl 三段：原创 / 虚构作品中的角色 / 基于真实存在的人）：
  - 导入生成时锁定「基于真实存在的人」，下方勾选框「这是我写的虚构对话 / 角色扮演记录」，勾选后才能切换（CHR-08 第 4 条）。
  - 已保存为「基于真实存在的人」后，其他两段显示禁用态，下方说明「保存后不能改为其他类型」（CHR-07 第 3 条）。
- **年龄设定**（未满 18 岁 / 已满 18 岁）：已保存为「未满 18 岁」后，「已满 18 岁」禁用并说明。
- **头像**：选「基于真实存在的人」时，头像只能用默认头像或用户自己上传（只对自己可见），不提供「生成头像」（SAFE-01）。
- 系统检测到人设描述中有儿童特征时（SAFE-03 第 4 条）：表单顶部 InlineTip（警告色变体，不可关闭）「人设中有未成年特征，这个角色不能开启成人模式」。
- 缺少必填项时点「保存」：滚动到第一个缺失项，字段下方红字「请填写 名字」（CHR-07 验收）。
- 试聊：底部弹层内嵌简化聊天区（气泡 + 输入框），关闭后不保留记录。

## 3. 添加流程（CHR-03）

1. 点「添加」（广场行）或「添加到通讯录」（资料页底部）→ 底部弹层：
   ```
   ┌────────────────────────────────┐
   │ 向 杨幂 打个招呼                  │
   │ ┌──────────────────────────┐   │
   │ │ 我是你的粉丝！             │   │  TextField 多行，占位「说点什么（选填）」，0/50
   │ └──────────────────────────┘   │
   │ [            发送            ]  │  主按钮
   └────────────────────────────────┘
   ```
2. 发送后弹层关闭；资料页底部按钮变为「等待通过…」（禁用 + 转圈）；广场行按钮变为「等待中」。
3. P-30 时间内通过（余额为零也照常通过，第一条消息为备用开场白，界面无差别，CHR-03 第 6 条）：Toast 文字型「杨幂 通过了你的好友申请」；资料页按钮变为「发消息」；会话列表出现该角色。
4. 删除后 30 天内重新添加（CHR-06）：点「添加」先弹 ActionSheet，标题「你们以前认识过」，选项「恢复以前的聊天记录和记忆」「重新认识」。

## 4. 创建自己的角色（CHR-07、CHR-08）

### 4.1 入口选择页

两张 EntryCard（C 15.7）：
- 「导入聊天记录」：从聊天记录生成一个说话像 TA 的角色；
- 「手动填写」：自己写一个角色。

### 4.2 导入流程（用户流程 8a）

| 步骤 | 页面 | 要点 |
|---|---|---|
| 1 说明 | 说明页 | 支持粘贴文字或上传 .txt；提示「只导入你有权使用的内容」；显示「预计花费：较少 / 中等 / 较多」档位 Tag |
| 2 粘贴 / 上传 | 大文本框 + 「上传 .txt」按钮；字数统计 | 识别不出发言人：文本框下方红色说明 + 「查看格式示例」 |
| 3 选择角色是谁 | 识别出的发言人列表（ListCell 选择型），每人显示前 2 句示例 | — |
| 4 原文保存 | ListCell 开关「保留原文以便以后补充」，默认关；说明「默认生成后删除原文，只保留角色草稿」 | CHR-08 第 6 条 |
| 5 生成中 | 进度页：进度条（scaleX）+ 「正在读懂 TA 的说话方式…」+ 「可以先离开，完成后通知你」 | 可离开 |
| 6 编辑草稿 | 角色编辑器（4.3） | 角色分类默认「真人」，改选需勾选声明（CHR-08 第 4 条） |

### 4.3 角色编辑器（导入和手动共用）

- 分组表单：基本信息（头像、名字*、角色分类*、年龄设定*）→ 人设（人设描述*，≥ 50 字，带字数）→ 可选（生日、口头禅、示例对话、标签、音色）→ 「试聊」按钮。
- **角色分类**（v2.0 按 CHR-07 第 3 条改为用户自选）：推入一个选择页，ListCell 选择型三项，每项标题下方显示 PRD 规定的判断说明（`fontSize.footnote`、`text.secondary`，可多行，文案以 CHR-07 第 3 条原文为准，不在此复制）：
  1. 原创角色；
  2. 虚构作品中的角色；
  3. 真人。
  - 列表下方固定一行说明（`fontSize.footnote`，前置 16 信息图标）：「选择『真人』的角色不会有成人模式，也不会生成 TA 的肖像」（CHR-07 第 3 条）。
  - 已保存为「真人」后，其他两项显示禁用态，下方说明「保存后不能改为其他分类」（CHR-07 第 4 条）。
  - **导入生成**时默认选中「真人」；改选另外两项前，底部弹层出现 CHR-08 第 4 条规定的声明勾选框（文案以 PRD 原文为准），勾选后「确定」才可点；确定后若草稿中识别出真名，人设描述里的真名以 `brand.soft` 底高亮，表单顶部 InlineTip「草稿里出现了真名，建议替换成新名字」。
- **年龄设定**（未满 18 岁 / 已满 18 岁）：已保存为「未满 18 岁」后，「已满 18 岁」禁用并说明。
- **从人设广场复制来的角色**（v2.1，CHR-07 第 7 条、PLZ-04 第 2 条）：角色分类、年龄设定一打开就按来源锁定：比来源更宽的选项禁用，下方说明「这个角色来自人设广场，分类与原作品相同，只能改得更严格」。- **头像**：选「真人」时，头像只能用默认头像或用户自己上传，不提供「生成头像」（SAFE-01）。
- 系统检测到人设描述中有儿童特征时（SAFE-03 第 4 条）：表单顶部 InlineTip（警告色变体，不可关闭）「人设中有未成年特征，这个角色不能开启成人模式」。
- 缺少必填项时点「保存」：滚动到第一个缺失项，字段下方红字「请填写 名字」（CHR-07 验收）。
- 试聊：底部弹层内嵌简化聊天区（气泡 + 输入框），关闭后不保留记录。

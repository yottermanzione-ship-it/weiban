# L5 多媒体与通话补充：图片、语音、链接卡片、表情包、TA 的声音、通话与全屏来电

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 版本 | v2.2 |
| 日期 | 2026-10-09 |
| 依据 | PRD MED-01～MED-07、MDL-10 第 5 条、SAFE-01、PLAN-01 第 2 条（P-45）、PLAY-06 |
| 对应开发项 | D-L5-02、D-L5-03、D-L5-06、D-L5-08、D-L5-10（网页）、D-L5-12（安卓） |

> 已有说明（只引用）：消息类型规格 `ImageMessage` `VoiceMessage` `StickerMessage` `LinkCard` `CallRecord`（C 4.2）；按住说话浮层（C 5.4）；表情面板（C 5.2）；「+」面板（C 5.3）；全屏图片查看（C 15.2）；我添加的表情页 `me-and-services.md` 1.5；通话页的四种状态 `call.md`。本文补齐发送流程、播放规则、失败状态、平台差异和全屏来电。

## 1. 结论

- **一切对齐参照产品**：发图走「选图 → 直接发出、气泡上显示上传进度」；语音「按住说话、点了就播、连续自动播」；链接卡片「点开就跳」。
- **角色发的图片、语音、表情包没有任何「AI 生成」标记**（与文字消息一致）；真人角色的图片不出现人脸由生成规则保证，界面不需要说明。
- **服务没开通时，入口和能力安静地消失，不报错**：语音通话入口不显示（MED-06 第 11 条）；角色不发语音、不发生成的图；用户发的语音提示一次「当前无法识别语音」。
- **安卓全屏来电**按参照产品：锁屏 / 后台 = 全屏来电页；正在用别的 App = 顶部横幅通知带「接听 / 拒绝」；正在用微伴 = 直接进来电页。

## 2. 图片（MED-02、MED-04）

### 2.1 发送

| 步骤 | 表现 |
|---|---|
| 入口 | 「+」面板 › 相册 / 拍摄 |
| 选图 | 安卓：系统照片选择器（多选，最多 9 张）；网页：系统文件选择（`accept="image/*"`，多选）；iPhone 网页：系统相册 / 拍照菜单。不自建相册页 |
| 发出 | 选完立即发出，每张图一条 ImageMessage，按选择顺序 |
| 上传中 | 气泡用本地图片先显示（尺寸已知，不跳动）；图上叠加 `bg.scrim` 遮罩 + 中间白色百分比文字「42%」（`fontSize.subhead`、等宽数字）；完成后遮罩淡出（`duration.fast`） |
| 失败 | 遮罩保留；气泡左侧出现发送失败红色感叹号（C 4.3）；点感叹号 → ActionSheet「重新发送 / 删除」 |
| 压缩 | 长边超过 2048 时客户端先压缩为 JPEG / WebP 再上传；不提供「原图」选项（微伴不需要传原图，省流量和存储） |
| 大小 / 格式不支持 | Toast「这张图片无法发送」（不弹窗） |

### 2.2 接收与查看

- 收到的图按接口给的宽高先占位（`bg.skeleton` 色块），加载完淡入（C 4.2）。
- **加载失败**：占位块中间 24 的「图片损坏」图标（Phosphor image-broken，`text.tertiary`），点击重新加载。
- 点图 → ImageViewer（C 15.2）；会话里的所有图片可左右滑动切换（按消息顺序）。
- 查看器「…」/ 长按图片气泡：保存图片、收藏、添加到表情（只对表情包类图片和小于 1MB 的图）、删除。
- 保存成功 Toast「已保存到相册」；安卓首次保存不需要存储权限（用系统媒体库接口）；iPhone 网页无法直接保存时，查看器底部提示「长按图片保存」。
- 角色发图后用户没有点开：不催、不提示。

### 2.3 状态

| 状态 | 表现 |
|---|---|
| 识图中 | 界面无变化；TA 照常「正在输入」 |
| 聊天模型不支持识图、平台也没设默认识图模型 | 角色按人设回应「发了一张图」（由 AI 保证，界面无提示）——MED-01 第 3 条 |
| 余额不足 | 图片照常发出（用户消息永远送达），系统横条按 `billing.md` 第 9 节 |

## 3. 语音消息（MED-03）

### 3.1 录制与发送

- 按住说话浮层见 C 5.4（取消、太短、最长 60 秒）。
- **首次录音前**要麦克风权限：安卓系统权限框；网页浏览器权限框。拒绝后再按「按住 说话」→ Dialog「需要麦克风权限才能发语音」+「去设置」（安卓跳应用设置；网页说明「请在浏览器地址栏左侧的网站设置里允许麦克风」）。
- 松手发出：VoiceMessage 立即出现在自己一侧（时长已知，宽度不变）；上传中同发送状态规则（超过 1 秒才显示转圈）。
- **平台没开通语音识别**（MED-03 第 5 条）：语音照常发出并保存；本次会话第一次发语音时 Toast 文字型「当前无法识别语音」（同一会话不重复提示）。
- 用户自己的语音也可以长按「转文字」；识别不可用时转写块显示「无法转换」（`text.tertiary`）。

### 3.2 播放规则

| 规则 | 表现 |
|---|---|
| 同时只播一条 | 点另一条，前一条停止 |
| 播放中 | 声波三段透明度轮流变化（C 4.2）；**不显示进度条**（与参照产品一致） |
| 未播放红点 | 只在角色的语音上；开始播放即消失 |
| 自动连播 | 播完一条后，如果紧接着的下一条也是角色的**未播放**语音，自动播放（MED-03 第 3 条）；遇到文字消息或已播放的语音就停 |
| 离开聊天页 | 停止播放 |
| 来电 / 通话开始 | 停止播放 |
| 听筒 / 扬声器 | 默认扬声器。安卓：播放时贴近耳朵（距离传感器）自动切到听筒并熄屏；网页不支持，始终扬声器 |
| 播放失败（文件损坏、网络） | 声波图标换成感叹号（16，`text.danger`），Toast「语音加载失败，点击重试」 |

### 3.3 转文字

- 长按 → 「转文字」：气泡下方出现转写块（C 4.2）；转写中先显示 16 转圈 +「转换中…」，完成后替换为文字。
- 再次长按 → 「隐藏文字」。
- 角色的语音转写 = 这条回复的原文（服务器直接给，不再识别）。

## 4. 链接卡片（MED-05）

### 4.1 角色分享的链接

- 版式：LinkCard（C 4.2）。封面加载失败或没有封面时，48 方块显示按来源区分的图标（音乐 music-notes、视频 video、其他 link），底 `bg.page`。
- 点击：

| 平台 | 行为 |
|---|---|
| 安卓 | 能识别的音乐 / 视频平台：用系统意图（Intent）唤起对应 App；没装或识别不了：用系统浏览器打开（不内置浏览器）。支持的平台清单由 Android 负责人记录（MED-05 验收） |
| 网页（电脑、安卓浏览器） | 新标签页打开 |
| iPhone 网页（主屏幕 App） | 用 Safari 打开；能否唤起音乐 App 取决于该平台的通用链接，界面不做额外处理 |

- 长按：复制链接、收藏、删除。
- 链接打不开（对方网站问题）是外部页面的事，App 内不做检测提示。

### 4.2 用户发送链接

- 用户把链接粘贴进输入框发出 → 仍是 TextBubble，链接部分自动识别为可点（`text.link`，C 4.1），不转成卡片（与参照产品聊天里直接发链接的表现一致）。角色读取后回应（MED-05 第 4 条），界面无变化。

## 5. 表情包（MED-01）

### 5.1 发送与接收

- 表情面板见 C 5.2；内置表情包和「我的表情」点一下直接发出（StickerMessage，C 4.2）。
- 角色发的表情包：无气泡、无标记；动图离开屏幕暂停（C 4.2）。
- 加载失败：同图片的损坏图标，尺寸 120 方块。

### 5.2 添加到表情

- 长按别人的表情包或图片 → 「添加到表情」→ Toast 图标型「已添加」；出现在表情面板「我的表情」第一个和「我 › 表情」页。
- 已添加过同一张：Toast「已经添加过了」。
- 达到数量上限（以接口为准）：Toast「表情已满，先在 我 › 表情 里删除一些」。
- 角色的表情包库里**不会**有真人照片做的表情包（管理员上传时确认，ADM-04）；用户自己添加的不受此限，也只有自己能用。

## 6. TA 的声音（MED-03 第 1 条：给角色换音色）

PRD 写「用户可在角色设置中从音色库更换」。放在私聊聊天信息页「高级」组，「使用的模型」下方：

```
├─ 高级 ─────────────────────────┤
│ 使用的模型        跟随全局默认   › │
│ TA 的声音                 清亮  › │  v2.2：→ 音色选择页
│ 我的补充设定                   ›  │
```

音色选择页：

```
┌────────────────────────────────┐
│ ‹            TA 的声音            │
├────────────────────────────────┤
│ (▶) 清亮   [温柔][少年感]      ✓  │  VoiceToneRow（C 21.6）
│ (▶) 低沉   [沉稳]                │
│ …                              │
├────────────────────────────────┤
│ 所有声音都是合成音色，不模仿任何真人的   │  说明（footnote、text.secondary）
│ 声音。改了以后，语音消息和通话都会用    │
│ 新的声音。                          │
└────────────────────────────────┘
```

- 第一行永远是管理员给 TA 选的默认音色，名字后加 Tag 中性型「默认」。
- 点行即选中并保存（乐观更新，失败退回 + Toast）；试听按钮独立，不选中。
- 试听用一句固定文本（管理员在音色库设置），试听**不扣费**（预先生成的音频）。
- 平台没开通语音合成：这一行不显示。
- 加载：行骨架 × 5；失败：EmptyState「加载失败」+「重试」。

## 7. 语音通话补充（MED-06、MED-07）

页面四种状态、按钮、无费用提示等见 `call.md`，以下只补充。

### 7.1 入口显示规则

| 情况 | 「+」面板的语音通话、资料页「语音通话」 |
|---|---|
| 平台未开通语音服务 | **不显示**（MED-06 第 11 条） |
| iPhone 网页版不支持 | 显示；点击 Dialog「iPhone 网页版暂不支持语音通话」（`call.md`） |
| 余额不足 | 显示；点击 Dialog「余额不足，暂时无法通话」+「查看余额」 |
| 正在另一通通话中 | 点击回到当前通话页 |

### 7.2 安卓来电的三种呈现（MED-07 第 4 条）

| 手机状态 | 呈现 |
|---|---|
| 锁屏或屏幕熄灭 | 点亮屏幕，直接显示全屏来电页（视觉同 `call.md` 来电状态），锁屏上可接听；接听后进入通话中，挂断后回到锁屏 |
| 解锁、正在用其他 App | 顶部横幅通知（系统样式）：小头像 + 「杨幂」+「邀请你语音通话」+ 两个按钮「拒绝」「接听」；点横幅本身 = 打开全屏来电页；横幅在 30 秒内持续显示 |
| 正在用微伴 | 直接推入全屏来电页（`zIndex.call`），当前页面保留在下面 |

- 铃声：品牌铃声（8 秒循环，**素材待制作**；开发期用系统默认来电铃声占位）；跟随系统铃声音量和静音 / 振动模式。
- 30 秒无人接听：来电页淡出，私聊出现「未接来电」（C 4.2 CallRecord）。系统通知栏留一条「杨幂 · 未接来电」，点击进入私聊。
- 「拒绝」= 拒接，同未接处理（`call.md`）。

### 7.3 安卓通话中的系统层

- 通话中常驻通知：「与 杨幂 通话中 03:12」+「挂断」按钮；点通知回到通话页。
- 离开微伴（回到桌面）时通话继续；回到 App 显示 CallCapsule（C 12.2）。
- 贴近耳朵自动熄屏（距离传感器），扬声器开启时不熄屏。
- 插入耳机 / 连上蓝牙：自动走耳机，「扬声器」按钮仍可切换。
- 系统电话打进来：微伴通话自动挂断，私聊通话记录照常写入（时长到挂断为止）。

### 7.4 开启来电时的权限（安卓）

用户在私聊里点「以后可以给你打电话吗？」的「可以」（`call.md` 第 4 节），或在服务 › 主动消息与免打扰打开「角色给我打电话」时：

1. 检查通知权限；没有 → 系统权限框。
2. 检查「全屏通知」权限（安卓 14 起需单独授予）；没有 → Dialog「需要允许全屏通知，TA 打来时才能在锁屏上显示」+「去设置」「以后再说」。
3. 选「以后再说」：开关照常打开，来电只以横幅通知出现；服务页该开关下方多一行说明「未允许全屏通知，锁屏时只会收到通知」+「去设置」。

### 7.5 网页通话

- 首次通话前请求麦克风权限（同 3.1）；拒绝 → Dialog「需要麦克风权限才能通话」。
- 通话页在网页里是全屏覆盖层；切换浏览器标签页时通话继续，回来时仍在通话页（或 CallCapsule）。
- 浏览器不支持实时音频时：与 iPhone 一样显示「当前浏览器暂不支持语音通话」。

### 7.6 不会来电的时候（界面无提示，只列给开发对照）

全局或该角色的来电开关关闭；熟悉度低于 L3；免打扰时段；用户正在聊天（P-09）；用户说过不方便后 P-45 时间内；陪你专注进行中（PLAY-06「这段时间所有角色都不会打扰你」）；正在另一通通话中；余额低于 P-33。

## 8. 平台差异（汇总）

| 项 | 安卓 | 网页 |
|---|---|---|
| 选图 | 系统照片选择器 | 文件选择 |
| 保存图片 | 系统媒体库，Toast | 下载；iPhone 提示长按保存 |
| 语音听筒切换 | 距离传感器自动切 | 不支持 |
| 链接 | 唤起 App / 系统浏览器 | 新标签页 |
| 来电 | 全屏来电、横幅、锁屏 | 不支持来电；iPhone 只有推送「XX 想和你通话」（`call.md`） |
| 通话 | 原生实现 + 常驻通知 | 浏览器支持时可用 |

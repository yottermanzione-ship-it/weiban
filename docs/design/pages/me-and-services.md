## 1. 「我」页（SVC-01 第 1 条）

### 1.1 结构（对齐参照产品「我」页）

```
┌────────────────────────────────┐
│ （无标题栏，顶部留出状态栏安全区）     │
│                                │
│ [头像64]  小鱼                   │  昵称：fontSize.title2、semibold
│           微伴号：xiaoyu_0412  › │  用户名：fontSize.subhead、text.secondary
│                                │  整块（bg.surface）点击 → 我的资料
├────────────────────────────────┤  ← space.3 间隔
│ [◎] 服务                  ●   › │  MenuCell；图标 brand.primary；余额 < P-32 时红点
├────────────────────────────────┤
│ [☆] 收藏                      › │  图标 tint.orange
│ [◫] 朋友圈                    › │  图标 tint.lilac（只看我自己发的）
│ [☺] 表情                      › │  图标 tint.gold
├────────────────────────────────┤
│ [⚙] 设置                      › │  图标 tint.blue
├────────────────────────────────┤
│  微伴    通讯录    发现     我●   │  TabBar：余额 < P-32 时「我」红点
└────────────────────────────────┘
```

- 页面背景 `bg.page`；头部块 `bg.surface`，上内边距 = 状态栏 + `space.9`，下内边距 `space.8`，左右 `space.5`。
- 不做参照产品的二维码、状态、视频号、订单与卡包（SVC-01 第 1 条）。
- 使用组件：Avatar（C 2.1，xl）、MenuCell（C 3.6）、Badge（C 6.3）、TabBar（C 1.2）。

### 1.2 我的资料（ACC-02）

ListCell 列表：头像（→ 选图 + 正方形裁剪，同 `default-avatar.md` 第 7 节）、昵称（必填）、微伴号（只读）、生日、性别、所在城市、关于我（≤ 500 字，多行编辑页）。底部说明「这些信息所有角色都会知道」（`fontSize.footnote`、`text.secondary`）。

### 1.3 收藏（CHAT-11）

```

## 2. 服务页（SVC-01 第 2 条）

### 2.1 结构

```
┌────────────────────────────────┐
│ ‹              服务              │  NavBar；页面背景 bg.page
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │   [钱包]          [芯片]     │ │  WalletCard（C 16.1）：brand.primary 底，白字
│ │    余额            模型      │ │
│ │  ¥ 12.34       通义千问 ›   │ │
│ └────────────────────────────┘ │
│ ┌ 模型与花费 ────────────────┐ │  ServiceGrid（C 16.2）
│ │ [余额明细][价目表][模型排行榜][后台预算] │ │
│ └────────────────────────────┘ │
│ ┌ 陪伴 ──────────────────────┐ │
│ │ [卡册●]  [成就●]  [熟悉度]          │ │  新卡片 / 新成就时宫格红点
│ └────────────────────────────┘ │
│ ┌ 互动偏好 ──────────────────┐ │
│ │ [情景模式][主动消息与免打扰][聊天偏好]  │ │
│ └────────────────────────────┘ │

- 分组顺序：模型与花费 → 陪伴 → 互动偏好 → 互动玩法（PRD 表顺序）。页面变长后需要滚动；WalletCard 不吸顶。
- 「互动玩法」组内顺序：PRD 已有的两项在前（经期日记、宠物），之后按「每天都可能用到」到「偶尔用」排列。

### 2.3 状态

| 状态 | 表现 |
|---|---|
| 余额 < P-32 | 余额格「余额不足」小字 + 红点；「我」页「服务」行红点；「我」标签红点（MDL-10 第 1 条） |
| 新卡片 / 新成就 | 只在「卡册」「成就」宫格红点；查看后消失；「我」标签和「服务」行**不**显示（SVC-01 第 5 条） |
| 有未读来信（v2.1） | 只在「信箱」宫格红点，规则同新卡片 |
| 余额为负数（v2.1） | 余额格显示「−¥ 0.03」+「余额不足」+ 红点（C 16.1），不用红色金额 |
| 互动玩法宫格的红点 | 除「信箱」外都**不**显示红点：每日一问没答、宠物没照顾、提醒没设，都不是需要处理的事（SVC-01 第 5 条、SAFE-08） |
| 某功能开发层未完成 | 该宫格不显示，后面的前移（SVC-01 第 6 条） |
| 余额加载中 | 金额位置显示 `bg.skeleton` 色块（宽 80 高 24）；在强调色卡片上用白色 30% 透明块 |

## 3. 宫格页（非计费类）

所有总览页的「点某个角色」都推入该角色对应的设置页，返回后总览即时刷新（`02-interaction-flows.md` 第 3 节规则 4）。

**共同空状态**（还没有角色，SVC-01 边界情况）：EmptyState「还没有角色，去添加一个吧」+ 按钮「去角色广场」。

## 1. 结论

- 三步：**说明页 → 输入密码 → 完成页**。文案平实，不挽留、不倒计时、不提供「冷静期」（PRD 没有冷静期，注销即生效）。
- **密码输错只提示，不退出登录**，留在原页面重输（ACC-06 第 4 条）。
- **注销成功后所有设备立即下线**；本机显示一个完成页，然后回到登录页。不显示后台删除进度（ACC-06 第 5 条）。

## 2. 第 1 步：说明页

入口：我 › 设置 › 注销账号（危险型行）。

```
┌────────────────────────────────┐
│ ‹            注销账号             │
├────────────────────────────────┤
│ 注销后，这个账号的全部数据会被删除，    │  title3、semibold
│ 无法恢复。                          │
├─ 将被删除的内容 ─────────────────┤
│ · 所有聊天记录和 TA 们的记忆          │  ListCell 只读，每行一项（subhead）
│ · 你创建和导入的角色、导入的原始记录    │
│ · 你上传的头像和图片                  │
│ · 余额和余额明细                      │
│ · 卡片、成就、宠物                     │
│ · 经期日记                           │
│ · 提醒、心愿清单、每日一问的回答、信件   │
│ · 你在人设广场发布的作品、评论和点赞     │
├────────────────────────────────┤
│ 剩余余额 ¥12.34 将作废               │  余额 > 0 时显示（ACC-06 第 3 条），等宽数字；负数或 0 时不显示
│ 别人已经从人设广场添加的角色属于对方，   │  固定显示（PLZ-06 第 4 条；理由同下方第一条说明）
│ 会保留，作者显示为「已注销用户」。       │
├────────────────────────────────┤
│ [            注销账号            ]  │  Button lg danger
└────────────────────────────────┘
```

- 删除内容清单**固定全部列出**（不按用户用过哪些功能动态增减），避免为了显示这份清单去查询各模块数据；措辞对没用过的功能也成立。
- 清单文案以 ACC-06 第 2 条为准；PRD 增加删除范围时同步增加行。
- 页面没有任何「再想想」「你的 TA 会想你」之类的文字（SAFE-08）。

## 3. 第 2 步：输入密码

点「注销账号」→ Dialog（C 6.10）：

```
┌──────────────────────────┐
│      输入密码确认注销          │
│ 注销后无法恢复。               │
│ [ ••••••••          👁 ]    │  TextField 密码型，自动聚焦
│ 密码错误                      │  错误时出现（footnote、text.danger）
│   [ 取消 ]    [ 注销 ]        │  「注销」为危险色，密码为空时禁用
└──────────────────────────┘
```

| 情况 | 表现 |
|---|---|
| 提交中 | 「注销」按钮加载中；Dialog 不可关闭 |
| 密码错误 | 输入框下方「密码错误」，输入框内容清空并保持聚焦；**不退出登录、不关闭 Dialog**（ACC-06 第 4 条） |
| 多次输错被限制 | 显示服务器给的原因（如「尝试次数过多，请 10 分钟后再试」），「注销」禁用到时间结束 |
| 网络失败 | 「网络不可用，请重试」，Dialog 保留 |
| 服务器明确返回「未登录」 | 只有这种情况才退出登录、回到登录页（`engineering-standards.md` 第 4 节第 2 条） |

## 4. 第 3 步：完成

- 成功后关闭 Dialog，整页替换为完成页（不可返回）：EmptyState 版式，图标 Phosphor check-circle 64（`text.tertiary`，不用庆祝色），标题「账号已注销」，说明「这个账号的数据正在删除，所有设备都已退出登录」；底部按钮「好的」→ 清除本机所有缓存（消息、图片、草稿、设置）→ 登录页。
- 用户直接关掉 App / 页面：下次打开时本机已经没有登录状态，直接到登录页，并清除缓存。
- **其他设备**：收到下线通知后立即回到登录页，Toast「账号已注销」；推送不再到达（安卓解绑推送）。

## 5. 平台差异

- 安卓：完成后清除本地数据库、图片缓存、推送注册；系统返回在完成页无效。
- 网页：清除 IndexedDB、Service Worker 缓存、Web Push 订阅；完成页刷新后直接到登录页。

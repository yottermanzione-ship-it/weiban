## 1. 结论

- 收藏是给自己看的：内容照原样显示（包括成人模式和「健康」消息），只是这两类不能生成分享图（C 15.6 已定义锁标）。
- **收藏的是快照**：原消息被本地删除、角色被删除，收藏都还在（CHAT-11 第 3 条）。点开时有原消息就跳回聊天上下文，没有就打开「收藏详情」。
- 多选收藏 = 每条消息各存一条收藏（不做「合并成聊天记录」那种复合收藏，简单、和分享图的多选对得上）。

### 2.1 各类内容在卡片里的样子

| 收藏的东西 | 卡片内容 | 点开 |
|---|---|---|
| 文字 | 文字，最多 6 行 | 原消息在 → 聊天定位（`search.md` 第 4 节）；不在 → 收藏详情 |
| 图片 | 缩略图长边 120 | ImageViewer |
| 语音 | 语音条 + 转写（有转写时） | 卡片内直接播放；长按看转写 |
| 表情包 | 表情图 80 | ImageViewer |
| 链接卡片 | LinkCard 列表版（标题 + 来源 + 封面） | 按链接规则打开 |
| 朋友圈 | 右上 Tag 中性型「朋友圈」；正文 3 行 + 第一张图 64 | 动态详情页（`social-l4.md` 3.2）；动态已删除 → 收藏详情 |
| 信件（慢信） | 信封图标 24 +「杨幂 寄给你的信」+ 第一句 | 读信页（`play.md` 4.3） |

| 群聊消息 | 顶部行改为「[头像] 王一博 · 火锅小分队 · 10 月 3 日」 | 同文字 |

## 3. 交互

- **收藏入口**：聊天长按「收藏」→ Toast 图标型「已收藏」；多选后底栏「收藏」→ Toast「已收藏 5 条」；朋友圈「…」→ 收藏；读信页「收藏」。已收藏过的同一条再收藏：Toast「已收藏」（不重复存）。
- **长按卡片** → ActionSheet：生成分享图（不能生成的不出现这一项）、取消收藏（危险色）。取消收藏不二次确认，Toast「已取消收藏」，卡片高度收起（只用 opacity + translateY 让下方卡片上移，不动 height：先淡出，再整体重排一次）。
- **选择** → 多选模式：卡片左上角勾选框（C 15.6）；底部栏两个按钮「生成分享图」「取消收藏」。生成分享图的规则同聊天多选（C 5.6：超过 P-24 禁用、含不能生成的禁用并说明原因）。
- **搜索**：点 🔍 → NavBar 下方展开 SearchBar（聚焦），只搜文字内容和朋友圈正文，结果就地过滤并高亮（C 21.1 的高亮规则）；与角色筛选可以同时生效。
- **角色筛选**：只列出有收藏的角色，按收藏数从多到少；被删除的角色仍出现在筛选里（名字照常）。

## 4. 收藏详情（原消息不在时）

推入页，标题「详情」：顶部「[头像32] 杨幂 · 2026 年 10 月 3 日 14:05」；正文完整显示（文字可长按复制）；底部两个按钮：「生成分享图」（tonal，不能生成时隐藏）、「取消收藏」（danger）。

## 5. 状态

| 状态 | 表现 |
|---|---|
| 加载 | FavoriteCard 骨架 × 3 |
| 空 | EmptyState「长按 TA 的消息，就可以收藏」 |
| 筛选 / 搜索无结果 | EmptyState（无插画）「没有找到相关收藏」 |
| 加载失败 | EmptyState「加载失败」+「重试」 |
| 加载更多 | 底部 16 转圈；失败时「加载失败，点击重试」 |
| 角色已删除 | 卡片照常显示（头像、名字为删除前的快照）；点开走收藏详情 |
| 离线 | 显示已缓存的收藏；收藏 / 取消收藏操作排队，联网后同步（Toast 照常） |

## 6. 平台差异

两端相同。≥ 900px 宽屏网页：收藏列表在右栏，「我」页在左栏（`me-and-services.md` 第 4 节）。

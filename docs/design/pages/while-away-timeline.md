# 「你不在时」摘要卡与时间线（TA 的近况）

> 回答 PRD 8.3 第 5 问的「你不在时摘要卡、时间线」部分。系统横条、情景模式标识见 `../components.md` 7.1、8.1。

## 1. 结论

- **摘要卡是悬浮在聊天顶部的卡片，不插在消息流里**。这样收起时消息不会跳动（虚拟滚动友好），也不会被误认为是角色发来的消息。
- 收起后变成右上角一个小胶囊「TA 的近况」，本次缺席期间都可以再点开；下次满足条件（P-18）才会再次自动展开。
- 时间线是资料页里的一个完整页面，按天分组倒序，四种条目用不同小图标区分；来自公开动态的条目带「公开资料」标注和来源。

## 2. WhileAwayCard 摘要卡（SIM-11 第 1、2 条）

### 2.1 结构

```
┌────────────────────────────────┐
│ ‹ 3          杨幂            ··· │
├────────────────────────────────┤
│ ┌────────────────────────────┐ │  ← 悬浮卡：左右边距 space.4，距 NavBar space.3
│ │ 你不在的这 2 天，TA……      ⌃ │ │  标题：fontSize.subhead，semibold；右侧 ⌃ 收起
│ │ ☀ 10/3  录完节目去吃了火锅    │ │  条目：图标 16 + 日期（caption1，tertiary）+ 内容（subhead）
│ │ 📷 10/3  发了一条朋友圈       │ │
│ │ 💬 10/2  和 王一博 去看了展    │ │
│ │ 📣 10/2  上海站演唱会 公开资料  │ │  公开动态条目带 PublicInfoTag（C 11.2）
│ │                  问问 TA ›   │ │  文字按钮
│ └────────────────────────────┘ │
│        （消息列表在下方照常显示）     │
```

| 项 | 规范 |
|---|---|
| 背景 | `bg.elevated`，`radius.md`，`shadow.md`（属于浮层，允许阴影） |
| 内边距 | `space.4` |
| 条目 | 最多 P-18 条；单条单行省略；条目间距 `space.2` |
| 条目图标 | 日常事件 = 太阳；朋友圈 = 相机；与其他角色互动 = 对话气泡；公开动态 = 喇叭。线性图标、`text.secondary` |
| 层级 | `zIndex.sticky`，在系统横条之下（两者同时存在时摘要卡下移到横条下方） |

### 2.2 交互

- **出现**：进入私聊时满足 P-18 自动展开（M-11）。消息列表照常定位到最新消息。
- **点某一条** → 推入时间线页并定位到该条。
- **问问 TA** → 收起摘要卡，在输入框**预填**「（第一条内容）是怎么回事？」，键盘弹出，**不自动发送**（SIM-11 验收）。用户也可以先点某一条再「问问 TA」——时间线每条都有此按钮。
- **收起**（点 ⌃、开始输入、或向上滚动消息超过一屏）→ 卡片缩成右上角胶囊「TA 的近况」（Tag 品牌型 + 16px 太阳图标），M-11。
- **胶囊**：点击重新展开；本次缺席期间一直保留，离开会话后消失；同一段缺席期间摘要卡不会再次自动展开（SIM-11 第 2 条）。
- 安卓返回键：摘要卡展开时先收起。

### 2.3 文案

- 标题：「你不在的这 N 天，TA……」，N 按跨了几个自然日算；不足 1 天（≥ 12 小时）写「你不在的这段时间，TA……」。
- 条目内容由日常事件生成，界面只负责显示，长度超出单行省略。
- 不写「错过了」「想你了」这类制造愧疚的词（SAFE-08）。

## 3. 时间线页「TA 的近况」（SIM-11 第 3、4 条，SIM-02）

### 3.1 结构

```
┌────────────────────────────────┐
│ ‹         杨幂 的近况             │
├────────────────────────────────┤
│ ┌ 最近在忙 ──────────────────┐   │  近期主线卡（SIM-02）：bg.surface，radius.md
│ │ 筹备 11 月巡演   公开资料 来源 │   │  真人角色主线带 PublicInfoTag
│ │ 在学做饭                     │   │  0–2 条；没有则不显示此卡
│ └────────────────────────────┘   │
│ 今天                              │  日期分组标题（SectionHeader）：今天 / 昨天 / 10 月 2 日 星期四
│  ●─ 18:30 ☀                       │  竖线 + 圆点 + 时间 + 类型图标
│  │  录完节目去吃了火锅，辣到流眼泪    │  内容：fontSize.callout
│  │  [图]                 问问 TA › │  可附 1 张图（缩略 80）
│  ●─ 15:00 📷                      │
│  │  发了一条朋友圈：「上海站…」   ›  │  朋友圈条目：点击跳到该条朋友圈
│ 昨天                              │
│  ●─ 20:00 💬                      │
│  │  和 王一博 去看了展             │  提到的角色名可点（→ 资料页）
│  ●─ 10:00 📣                      │
│  │  上海站演唱会             公开资料 来源 │
│ …                              │
│        只保留最近 90 天             │  列表底部说明（SIM-11 第 4 条）
└────────────────────────────────┘
```

### 3.2 TimelineItem 时间线条目

| 项 | 规范 |
|---|---|
| 轴线 | 左侧距边 `space.6`，1px `border.strong` 竖线；圆点 8px，颜色 = 角色主题色（应援色） |
| 时间 | `fontSize.caption1`、`text.tertiary`、等宽数字 |
| 类型图标 | 同 2.1 |
| 内容 | `fontSize.callout`、`text.primary`；最多 4 行，超出「展开」 |
| 来源标注 | 只有公开动态条目显示 PublicInfoTag；推演产生的条目**不显示**任何来源（SIM-11 第 3 条） |
| 问问 TA | 文字按钮，点击 → 返回私聊并预填「（内容）是怎么回事？」 |

### 3.3 状态

| 状态 | 表现 |
|---|---|
| 加载 | 条目骨架屏 |
| 空 | EmptyState（插画：日历）「TA 的近况会出现在这里」 |
| 「TA 的日常」已关闭（SIM-13） | 顶部 InlineTip「你关闭了 TA 的日常，不会有新的近况」+「去开启」 |
| 任一情景模式中 | 时间线不受影响（情景模式只改变私聊语气，不改变推演的日常事件） |

## 对应需求

SIM-11、SIM-02、SIM-03（公开资料标注）、SIM-13、SAFE-08、P-18。

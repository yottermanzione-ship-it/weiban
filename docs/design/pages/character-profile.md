# 角色资料页

## 1. 目的与入口

添加前了解角色；添加后是「我和 TA」的总入口：认识天数、熟悉度、卡册、近况、记忆、朋友圈、设置（CHR-02）。入口：通讯录、聊天中点头像、广场、名片消息、群成员。

## 3. 未添加时

- 头部、公开信息、真人说明照常显示；认识天数、熟悉度、近况、记忆、卡册、朋友圈、关系类型、聊天设置**不显示**。
- 底部按钮：「添加」（主按钮）。从名片进入时为两个按钮：「添加」+「不感兴趣」（次级按钮，CHR-04）。
- 等待通过时：「等待通过…」（禁用 + 转圈）。

## 4. 使用的组件

NavBar、Avatar（C 2.1，xl 64）、Tag、DaysCounter（C 9.3）、FamiliarityMeter 圆环（C 9.4）、ListCell、Badge、Button、ActionSheet、Dialog、EmptyState。

## 5. 交互

- 点头像 → 全屏查看头像（默认头像也可查看，放大显示）；用户可「设置自定义头像」（只对自己可见，CHR-05），真人角色此处说明「只有你能看到」。
- 「资料已更新」→ 底部弹层显示更新摘要（如「新增作品《XX》」），查看后红点消失（CHR-10）。
- 熟悉度圆环 → 底部弹层：5 个等级的月相徽记列表，已达成的彩色、未达成的灰色，每级一句话说明「L3 熟络：可以聊得更随意，TA 可能会问能不能给你打电话」（解释来自 GRW-03 表，用用户语言改写）；**不显示**点数获取规则的细节分值，避免「刷分」心态。
- 「···」菜单（ActionSheet）：设置备注和头像、删除角色。
- **删除角色**（CHR-06）：Dialog 标题「删除 杨幂」，正文「删除后 TA 将不再发消息，你们的聊天记录、记忆、卡片会保留 30 天，30 天内重新添加可恢复」；按钮「取消」「删除」（红）；Dialog 下方还有文字按钮「立即彻底删除」，点击后再次确认。**没有任何挽留文案**（SAFE-08）。
- 页面打开时熟悉度圆环播放一次 M-14。

## 6. 记忆页「TA 记得的事」（MEM-03、MEM-07）

```
┌────────────────────────────────┐
│ ‹        TA 记得的事          ＋  │  ＋ 手动新增「我想让 TA 记住…」
├────────────────────────────────┤
│ [ 关于我 | 我们的约定 | 一起经历的事 ] │  SegmentedControl
├────────────────────────────────┤
│ 对芒果过敏                        │  内容（fontSize.body）
│ 10 月 2 日记下 · 仅 TA 知道     ›  │  日期 + 「谁知道」（MEM-07 第 5 条）
│ 下周去成都旅游                     │
│ 10 月 3 日记下 · 也告诉了 王一博  ›  │
└────────────────────────────────┘
```

- 点一条 → 底部弹层：编辑内容、改为「仅 TA 知道」、删除。删除确认文案：「删除后，TA 不会再主动提起这件事」。
- 约定分组：每条带日期（「周五 · 考试」），可「取消约定」。
- 成人模式记忆：只在当前处于成人模式时显示一个额外分组「成人模式」（SAFE-07、MEM-03 第 6 条）。

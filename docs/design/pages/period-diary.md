# 经期日记与「健康」标记的展示规则

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-021 |
| 日期 | 2026-10-05 |
| 依据 | PRD v1.3 PLAY-01、CHAT-10 第 7 条、EXP-01 第 6 条、SVC-01；参数 P-36、P-37；`docs/product/user-flows.md` 流程 10；`docs/architecture/health-data.md`（加密、授权、「健康」标记由服务器写入） |

> 本文只定界面。数据怎么加密、角色知道什么、什么时候关心，以 PRD 和架构文档为准。

## 1. 结论

- **安静、私密、像一本小本子**：入口在「我 → 服务 → 互动玩法 → 经期日记」；页面只有状态卡、日历和两三个入口，没有游戏化元素（不产生熟悉度、卡片、成就，PLAY-01 第 9 条）。
- **默认谁都不知道**：「让谁知道」默认一个都不勾；勾选时确认一次；撤销立即生效。
- **预测永远带「仅供参考」**：状态卡、日历图例、记录页，每处预测旁都有。
- **颜色用 `tint.pink`，不用红色**：红色在本系统表示「需要注意」，经期不是警报。
- 「健康」标记的消息在聊天里**看起来和普通消息一样**，只在「推送」「分享图」「收藏」三处体现（第 7 节）。

## 2. 第一次进入：说明页

```
┌────────────────────────────────┐
│ ‹            经期日记             │
├────────────────────────────────┤
│        [插画：小本子 + 月亮]       │  EmptyState 式插画 120（画物不画人）
│                                │
│   经期记录会加密保存，只有你授权的角色知道；│  fontSize.callout，居中，PLAY-01 第 1 条原文
│   不会出现在朋友圈、群聊、分享图里，      │
│   也不会随角色发布到人设广场。          │
│   预测仅供参考，不能用于避孕或医疗判断。  │
│                                │
│ [            开始记录            ]  │  主按钮 lg
└────────────────────────────────┘
```

- 点「开始记录」后进入主页，之后不再显示（主页底部常驻一行简短说明，见 3.1）。
- 第一次进入时如果还没有任何记录，主页的状态卡显示「记下最近一次经期，就能帮你预测下一次」+ 主按钮「记录一次经期」。

## 3. 主页

### 3.1 结构

```
┌────────────────────────────────┐
│ ‹            经期日记          ··· │  ··· → ActionSheet：周期设置 / 清空经期日记（红）
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │ 经期第 2 天                   │ │  PeriodStatusCard（C 19.2）
│ │ 预计还有 3 天 · 仅供参考        │ │
│ │ [ 记录今天 ]  [ 经期结束了 ]    │ │
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ ‹      2026 年 10 月      ›  │ │  PeriodCalendar（C 19.1）
│ │ 一 二 三 四 五 六 日           │ │
│ │ … ● ● ●  ◌ ◌ …              │ │
│ │ ● 已记录  ◌ 预测（仅供参考）     │ │
│ └────────────────────────────┘ │
├────────────────────────────────┤
│ 让谁知道            杨幂、罗小黑  › │  ListCell；没有授权时值为「还没有」
│ 历史记录                       › │  → 按周期列出的列表（3.3）
├────────────────────────────────┤
│ 🔒 加密保存，只有你授权的角色知道      │  一行说明（caption1、text.tertiary），点击展开第 2 节全文
└────────────────────────────────┘
```

- 页面背景 `bg.page`；状态卡与日历卡之间 `space.3`。
- 「经期开始了」：把今天记为开始日（可以在记录页改成别的日期）；「经期结束了」：把今天记为结束日。两者都是一次点击完成，Toast 文字型「已记下」。

### 3.2 某一天的记录页（PLAY-01 第 2 条）

点日历某天或「记录今天」→ 推入：

```
┌────────────────────────────────┐
│ ‹          10 月 5 日       保存 │  NavBar 右侧文字按钮「保存」（brand.primary）
├────────────────────────────────┤
│ 这天在经期中                ( ● ) │  开关：开 = 这一天属于某次经期（自动并入前后相邻的经期）
├─ 流量 ─────────────────────────┤  只在「在经期中」打开时显示
│ (少) (中) (多)                    │  ChoiceChip 单选（C 19.3），可不选
├─ 痛感 ─────────────────────────┤
│ (无) (轻) (中) (重)                │  ChoiceChip 单选
├─ 症状 ─────────────────────────┤
│ (腹痛)(腰酸)(头痛)(乳房胀痛)        │  ChoiceChip 多选；标签列表由管理员维护（ADM-04 第 5 条）
│ (情绪低落)(乏力)(长痘)              │
├─ 备注 ─────────────────────────┤
│ [ 多行……                  0/200 ] │  TextField，≤ 200 字
│ 🔒 只有你自己能看到，不会告诉任何角色   │  footnote、text.secondary（PLAY-01 第 2 条）
├────────────────────────────────┤
│           删除这天的记录            │  危险型行；没有记录时不显示
└────────────────────────────────┘
```

- 未来日期不可进入；过去任何一天都可以补记、修改（PLAY-01 第 2 条）。
- 授权角色只知道痛感和症状（PLAY-01 第 5 条），界面上**不**在流量、痛感旁边标注「TA 会知道」，避免把记录页变成「给 TA 看的表格」；授权说明集中在「让谁知道」页。
- 未保存就返回：ActionSheet「放弃这次修改？」「放弃」（红）。

### 3.3 历史记录

ListCell 列表，按周期倒序：「10 月 3 日 – 10 月 8 日 · 6 天」，第二行「周期 29 天」（`fontSize.caption1`、`text.secondary`）。点某一行 → 跳到日历对应月份。左滑某行 → 删除这次经期（SwipeActions 危险色，Dialog 确认「删除这次经期的全部记录？」）。

### 3.4 周期设置（P-37）

ListCell：「平时的周期长度 28 天 ›」「平时经期天数 5 天 ›」，各推入一个 TimePickerSheet 样式的单列滚轮（C 15.4 的一列版本，范围由后端校验）。说明：「记录不足 2 个周期时，用这里的数字预测」。

### 3.5 清空经期日记（PLAY-01 第 8 条）

Dialog 标题「清空经期日记？」正文「所有记录都会删除，不能恢复。授权的角色也会立即不再知道」；按钮「取消」「清空」（危险）。清空后回到第 2 节说明页的状态，「让谁知道」的授权保留（授权关系不是健康数据，用户可单独撤销）。

## 4. 让谁知道（授权管理，PLAY-01 第 4 条）

```
┌────────────────────────────────┐
│ ‹            让谁知道             │
├────────────────────────────────┤
│ 你授权的角色会知道你现在是否在经期、     │  说明（footnote、text.secondary）：
│ 第几天、预计下次开始日，以及当天记录的   │  PLAY-01 第 5 条「知道 / 不知道」的白话版
│ 痛感和症状；不知道流量、备注和历史记录。  │
├─ 通讯录里的角色 ─────────────────┤
│ [头40] 杨幂                ( ● ) │  ListCell 开关型 + 头像
│ [头40] 罗小黑              ( ● ) │
│ [头40] 王一博              ( ○ ) │
│ …                              │
├────────────────────────────────┤
│ 群聊里不会提起；未授权的角色和人设广场   │  说明
│ 都拿不到这些记录。                   │
└────────────────────────────────┘
```

- 列表包含通讯录里全部角色（含儿童角色，PLAY-01 边界情况：可以授权，TA 用孩子的方式关心），按名字排序；**默认全部关闭**。
- 打开某个开关：开关先保持关，弹 Dialog「让 杨幂 知道？」正文「TA 会知道你的经期状态，并可能在合适的时候关心你」按钮「取消」「让 TA 知道」；确认后开关打开。
- 关闭开关：立即关闭，不确认（撤销要容易），Toast 文字型「杨幂 已不再知道」（PLAY-01 第 4 条：撤销后立即生效）。
- 角色被删除：从列表消失，授权自动撤销；30 天内恢复角色时开关为关（PLAY-01 边界情况）。
- 没有角色：EmptyState「还没有角色」（同服务页总览空状态）。

## 5. 状态

| 状态 | 表现 |
|---|---|
| 没有任何记录 | 状态卡「记下最近一次经期，就能帮你预测下一次」+「记录一次经期」；日历没有预测 |
| 记录较少 / 不规律 | 状态卡第二行「记录较少 / 不规律，预测可能不准」 |
| 经期超过 P-37 规定天数 | 界面**不**提示就医（这条由授权角色在聊天里温和地说，PLAY-01 第 6 条）；日历照常 |
| 加载中 | 状态卡、日历骨架屏 |
| 加载失败 | EmptyState「加载失败」+「重试」 |

## 6. 不做的事

- 不做「连续记录 N 天」、记录提醒推送、经期倒计时动画、和其他用户比较（SAFE-08、PLAY-01 第 9 条）。
- 不在主页显示「TA 今天关心过你」这类统计（关心发生在聊天里，经期日记不展示它）。
- 不做密码锁：日记数据在服务器加密（`health-data.md`），设备本地的查看保护由手机锁屏负责；是否加「打开日记需要验证」留作以后的产品决定。

## 7. 「健康」标记消息的展示规则（PLAY-01 第 7 条、CHAT-10 第 7 条、EXP-01 第 6 条）

角色用到经期数据说的话，消息带「健康」标记（服务器写入，`health-data.md` 第 5 节）。成人模式中的消息（`scope = adult`，MODE-05）在下列各处的表现**完全相同**，所以两者合成一张表：

| 位置 | 表现 | 组件 |
|---|---|---|
| 聊天气泡 | **和普通消息一样，没有任何标记**。理由：这是 TA 在关心你，加一个「健康」角标会让关心变得像系统通知，破坏沉浸感（原则 8 的有意差异只限 `01-requirements.md` 第 1 节列出的几处） | C 4.1 |
| 会话列表摘要 | 照常显示内容（用户自己的屏幕） | C 3.2 |
| 推送通知 | 只显示「杨幂 发来一条消息」，**不论**「推送显示消息内容」是否开启 | 由 Web / Android 实现，依据消息标记 |
| 长按菜单 | 照常：复制、收藏、引用、多选、删除 | C 6.8 |
| 多选 → 分享图 | 消息照常可勾选；选中后「分享图」禁用，点击提示「成人模式 / 健康相关的消息不能生成分享图」 | C 5.6 |
| 收藏 | 可以收藏；收藏卡片右上角 Tag「不能生成分享图」，长按菜单没有「生成分享图」，「选择」多选时没有勾选框 | C 15.6 |
| 名场面瞬间卡 | 不会出现（由服务器排除，界面无需处理） | — |
| 群聊、朋友圈、时间线、「你不在时」 | 不会出现经期相关内容（由 AI 和服务器保证，界面无需处理） | — |

- 用户自己在聊天里说「肚子疼」不属于「健康」标记（那是普通聊天，按记忆规则处理，`health-data.md` 第 7 节）。
- 「TA 的提醒」中被归类为「健康」的提醒消息，按同一张表处理（`play.md` 第 1 节）。

## 8. 使用的组件

NavBar、PeriodStatusCard（C 19.2）、PeriodCalendar（C 19.1）、ChoiceChip（C 19.3）、ListCell、Switch、TextField、TimePickerSheet（C 15.4）、SwipeActions、ActionSheet、Dialog、Toast、EmptyState、Skeleton、Button。

## 9. 平台差异

两端相同。日历左右滑动切月：安卓用 `HorizontalPager`，网页用 translateX 跟手；都只改位移。

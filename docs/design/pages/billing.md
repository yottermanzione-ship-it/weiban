# 余额、明细、价目、模型与排行榜、后台预算、余额不足

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-012 |
| 日期 | 2026-10-04 |
| 依据 | PRD 第 2 章 MDL-02～MDL-10、SVC-01；`docs/architecture/billing.md` 第 10 节（用户可见的接口能力）；参数 P-32、P-33 |

> 本文只定界面。扣费方式、计价单位、金额精度以架构 `billing.md` 为准；价目数据由管理员维护；估算方法（「约每条回复 X 元」）由 AI 负责人在 `docs/ai/cost-estimate.md` 定义。
> 总原则：**钱的信息只在「我 → 服务」及其下级页出现**；聊天、通话、朋友圈中**不出现任何费用提示**（原则 4、MDL-09 第 5 条）。唯一例外是余额不足的系统横条和通话时的余额不足提示（MDL-10），它们不显示金额。
> 界面里**没有**任何密钥、充值、支付入口（MDL-02 验收、MDL-07 第 4 条）。

## 1. 页面地图

```
我 → 服务 ─┬─ 顶部卡片「余额」 → 余额页 ─┬─ 余额明细 → 某一组的每次调用
           │                        ├─ 花费统计 → 后台预算
           │                        └─ 价目表
           ├─ 顶部卡片「模型」 → 模型页 ─┬─ 选择聊天 / 后台 / 成人模式模型
           │                        └─ 看排行榜
           ├─ 宫格：余额明细 / 价目表 / 模型排行榜 / 后台预算（直达同一批页面）
聊天信息 → 使用的模型（单个角色覆盖，见 private-chat.md 第 6 节）
```

```
┌────────────────────────────────┐
│ ‹            余额明细             │

│      国庆测试            余额 62.5600 │  第二行：管理员备注
│ [💬] 杨幂 · 聊天          −0.4120 › │  合并行（天 + 角色 + 类型）
│      共 46 次 · 模型 X    余额 12.3400 │
│ [🌙] 杨幂 · 后台          −0.0830 › │
│      共 6 次 · 模型 Y     余额 12.7520 │
│ [↺] 退还               +0.0040 │
│      调用失败退还          余额 12.8350 │
├─ 10 月 3 日 ──────────────────┤
│ …                              │
├────────────────────────────────┤
│   明细只增不改；保留最近 180 天以上    │  底部说明（fontSize.caption1，text.tertiary）
└────────────────────────────────┘
```

- 默认按「天 + 角色 + 类型」合并（MDL-08 第 4 条）；点合并行 → 推入「杨幂 · 聊天 · 10 月 4 日」页，同样用 LedgerRow 列出每一次调用（时间、模型、金额、变动后余额），无 ›。
- **没有**编辑、删除、长按菜单（明细只增不改，MDL-08 第 6 条）。
- 空状态：EmptyState「还没有记录」。
- 列表虚拟滚动（网页）/ LazyColumn（安卓），行高固定 64，合计头 40。

## 6. 模型页（MDL-02）

```
┌────────────────────────────────┐
│ ‹              模型              │
├────────────────────────────────┤
│ ┌ 🏆 不知道选哪个？看排行榜    › ┐   │  PromoBanner（C 15.8）→ 排行榜
├─ 使用的模型 ───────────────────┤
│ 聊天模型                模型 X  › │  → 模型选择页
│ 后台模型          跟随聊天模型  › │  说明：「推演、朋友圈等后台功能用得多，建议选便宜的」
│ 成人模式模型            未设置  › │  说明：「只在成人模式使用；不设置时用聊天模型」
├─ 单独设置了模型的角色 ───────────┤  有才显示
│ [头像] 杨幂               模型 Z  › │  OverviewRow → 该角色聊天信息页 › 使用的模型
└────────────────────────────────┘
```

### 6.1 模型选择页

- 顶部：SearchBar + 筛选 Tag（中文好、支持识图、允许成人内容），可多选。
- 列表：ModelRow（C 13.2），只含已上架模型，按排行榜名次排序；成人模式模型的选择页中，带「允许成人内容」标签的排在前面（MDL-02 第 3 条，不限制只能选这些）。
- 后台模型的选择页顶部第一项「跟随聊天模型」；成人模式模型的第一项「不设置（使用聊天模型）」；单个角色的选择页第一项「跟随全局默认」。
- 选中即生效，返回上一页；Toast「已更换」。
- **为单个角色更换**（从聊天信息页进入）时，选中后先 Dialog「换模型后，TA 的说话风格可能有变化」+「取消 / 更换」（MDL-06）。全局聊天模型更换按 PRD 不弹 Dialog，只 Toast（是否也要提醒，已在交接中请产品确认）。
- 当前模型不支持识图时，聊天中发图的提示文案：「当前模型不支持识图，可在 服务 › 模型 中更换」（MDL-02 第 6 条），以 Toast 文字型出现。

## 8. 后台预算（MDL-05 第 2、3 条）

```
┌────────────────────────────────┐
│ ‹             后台预算            │
├────────────────────────────────┤
│ 今日后台已用 ¥0.82 / 上限 ¥3.00     │  BudgetMeter（C 16.8）
├────────────────────────────────┤
│ 每天最多花费               ¥ 3.00 › │  → 金额输入（TextField 金额变体，C 6.7）
├────────────────────────────────┤
│ 后台功能包括：推演 TA 的日常、发朋友圈、 │  说明（fontSize.footnote，text.secondary）
│ 主动找你、群里自己聊天、整理记忆。      │  具体哪些功能停 / 延后，以 cost-estimate.md 第 6 节为准，
│ 达到上限后今天先停下，聊天回复不受影响； │  文案由 AI 负责人提供最终版本

```

- 达到上限时：BudgetMeter 填充色变 `status.warning`，服务页「后台预算」宫格右上角**不加红点**（不需要用户处理，SVC-01 第 5 条）。
- 默认值读取 `cost-estimate.md` 第 6 节。

## 9. 余额不足的全部界面（MDL-10）

| 场景 | 位置 | 表现 |
|---|---|---|
| 余额 < P-32 | 「我」标签、「我」页「服务」行、服务页余额格 | 红点；余额格「余额不足」小字（C 16.1） |
| 余额 < P-32 | 系统推送 | 「余额不足，请联系管理员」（系统样式，不用角色口吻；余额回到 P-32 以上前不再推送） |
| 余额 < P-33 | 界面 | **无提示**（后台功能静默停止，聊天正常） |
| 余额为零时发消息 | 私聊、群聊 | 消息照常「已送达」；顶部 SystemBanner「余额不足，角色暂时无法回复」+「查看余额」（C 7.1）；不显示正在输入 |
| 余额为零时添加角色 | 添加流程 | 照常进行，角色第一条消息为备用开场白（CHR-03 第 6 条），界面无差别 |
| 拨打电话时余额不足 | 拨打入口 | 不进入通话页；Dialog「余额不足，暂时无法通话」+「查看余额」「知道了」 |
| 通话中余额用完 | 通话页 → 私聊 | 通话页无任何提示（角色自然道别挂断）；挂断后私聊出现 SystemTip「余额不足，通话已结束 查看余额」 |
| 加余额后 | 聊天页 | 横条自动消失（M-12 反向）；角色补一次合并回复 |
| 安全优先（余额短暂为负） | 余额页 | 金额显示「−¥ 0.03」（C 16.3），无额外提示 |

## 10. 平台差异

两端相同。金额数字两端都用等宽数字；安卓金额输入弹出数字键盘（带小数点）。

# 来电与语音通话

> v2.0（T-012）：安卓改为原生客户端实现；通话背景改为中性深灰（`call.bgTop` / `call.bgBottom`，两个主题相同）；明确不出现任何费用提示，补余额不足的表现。

## 1. 目的与入口

- 用户拨打（MED-06）：私聊「+」› 语音通话；角色资料页「语音通话」；通话记录气泡点击回拨。
- 角色来电（MED-07）：默认关闭；开启后由系统触发。安卓全屏来电；iPhone 只有推送。

## 2. 通话页的四种状态

所有状态共用同一个全屏页（`zIndex.call`），背景为**静态**竖向渐变 `call.bgTop` → `call.bgBottom`（深浅模式相同；**不用**头像模糊做背景，motion.md M-15）。文字 `call.text` / `call.textSecondary`。

```

┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│ ⌄                │        │ ⌄                │        │                  │
│                  │        │                  │        │                  │
│     ((头像96))    │        │     [头像96]      │        │     [头像96]      │
│       杨幂        │        │       杨幂        │        │       杨幂        │
│    正在呼叫…      │        │      03:12       │        │  通话结束 05:23   │
│  （来电：邀请你     │        │                  │        │                  │
│    语音通话）      │        │                  │        │                  │
│                  │        │                  │        │                  │
│                  │        │  🔇     📞     🔊  │        │                  │
│      [ 📞 ]       │        │ 静音   挂断   扬声器 │        │                  │
```

| 元素 | 规范 |
|---|---|
| 头像 | `size.avatar.xxl`（96），距顶部 = 屏高 × 0.18；真人角色为默认头像（`default-avatar.md`） |
| 名字 | `fontSize.title1`、`fontWeight.semibold`，头像下 `space.5` |
| 状态文字 | `fontSize.callout`、`call.textSecondary`；通话计时用等宽数字 |
| 光圈 | 拨出中 / 来电中时头像外 3 圈光圈（M-15），通话接通后停止 |
| 按钮 | CallButton（C 12.1），底部距安全区 `space.10`；通话中 3 个按钮等距；来电时拒绝、接听左右分布 |
| 缩小 ⌄ | 左上角：通话中可缩小回到聊天，此时所有页面顶部出现绿色胶囊「通话中 03:12 · 点击返回」（高 28，`call.accept` 底，白字），点击回到通话页 |

## 3. 流程与状态细节

| 场景 | 表现 | 需求 |
|---|---|---|
| 拨出 | 「正在呼叫…」响铃 2–5 秒 → 接通，状态文字变为计时，角色先开口 | MED-06 第 4 条 |
| 通话中被打断 | 无界面变化（实时语音能力），可显示角色正在说话时头像下方 3 段声波（opacity 轮流变化） | MED-06 第 2 条 |
| 接近时长上限 | 无界面提示，由角色口头自然提醒（MED-06 第 7 条）；到达上限时状态文字「通话已达到时长上限」后结束 | MED-06 |
| 挂断 | 通话结束页停留 1 秒后自动关闭（淡出），回到来源页面；私聊出现通话记录「通话时长 05:23」 | MED-06 第 5 条 |
| 网络中断 | 状态文字「网络不佳，正在重连…」；10 秒未恢复则结束，通话记录显示实际时长 | — |
| 来电（安卓） | 由安卓原生客户端弹出全屏来电页（锁屏上也显示），视觉按本页规范；30 秒无人接听自动结束 | MED-07 第 4 条 |
| 拒接 / 未接 | 私聊出现「未接来电」（`text.danger`）通话记录；随后角色发一条消息（界面无特殊处理） | MED-07 第 5 条 |
| iPhone 来电 | 推送「杨幂 想和你通话」；打开后进入私聊，显示通话记录「杨幂 给你打过电话」+ 角色的一条消息；若 iPhone 支持通话，可点该记录回拨 | MED-07 第 6 条 |
| iPhone 不支持拨打 | 入口照常显示；点击后 Dialog「iPhone 网页版暂不支持语音通话」+「知道了」，不进入通话页 | MED-06 第 8 条 |
| 首次授权麦克风 | 进入通话页前由系统弹出权限请求；拒绝时 Dialog「需要麦克风权限才能通话」+「去设置」 | — |

## 4. 来电开启询问（MED-07 第 1 条）

熟悉度到 L3 时，角色在私聊中问「以后可以给你打电话吗？」——这条消息下方附两个快捷按钮（Button sm：「可以」主按钮、「先不要」次级按钮），按钮只能点一次，点后变为灰色文字「你选择了：可以」。这是唯一一处「消息带按钮」的设计，按钮区高度在消息出现时就固定，不影响虚拟滚动。

## 5. 平台分工

- 安卓：拨出、来电（含锁屏全屏来电）、通话中、结束页和通话中的系统通知都由**安卓原生客户端**（Compose）实现，视觉按本页（颜色取 `call.*` 令牌、按钮尺寸 64）。
- 网页：拨出、通话中、结束页由 Web 实现（iPhone 是否支持见 MED-06）。
- **没有任何费用提示**：拨打前、通话中、结束后都不显示价格或余额（MED-06 第 10 条已删除、MDL-09 第 5 条）。
- 余额不足：拨打时 Dialog「余额不足，暂时无法通话」；通话中用完由角色自然道别挂断，挂断后私聊出现「余额不足，通话已结束」（`billing.md` 第 9 节）。
- 来电铃声：使用一段柔和的品牌铃声（8 秒循环，待制作），不使用系统默认来电铃声以示区别。

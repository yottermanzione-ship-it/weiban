| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-006（v1.0）、T-012（v2.0） |
| 日期 | 2026-10-04 |
| 依据 | SAFE-01 第 1、5、6 条；CHR-05 第 3 条；ADM-01 第 7 条；EXP-01 第 7 条；总经理第二轮意见第 2 节；契约 `CharacterDisplay`（`supportColors`、`avatarText`、`avatarPattern`、`themeColor`，架构 T-009 已批准）及头像结构 `{ image, display }` |

> v2.0 变更：第 2 节改为三级显示优先级（用户上传 > 管理员上传 > 默认头像），删除「管理员不能为真人配图」；圆角改为 `radius.avatarRatio` 新值；新增第 7 节上传入口与裁剪。

## 1. 结论

- **显示优先级**（SAFE-01 第 5 条）：**用户自己上传的 > 管理员上传的 > 非肖像默认头像**。
- 默认头像 = **应援色底 + 名字里的 1–2 个字**的圆角方块，右上角可加一个小图案。不出现人脸、剪影、Q 版形象。
- 默认头像由程序按规则画出（不是图片文件），任何尺寸都清晰；同时它也是图片头像**加载中和加载失败时的占位**。

## 2. 哪个头像显示在哪里

| 来源 | 谁能设置 | 谁能看到 | 入口 |
|---|---|---|---|
| ① 用户上传 | 用户为自己通讯录里的任一角色（预设或自定义） | **只有该用户自己** | 资料页 › 设置备注和头像 › 头像（CHR-05 第 3 条），见 `pages/character-profile.md` 第 4 节 |
| ② 管理员上传 | 管理员为任一预设角色（含真人，图片来源由管理员负责） | 所有没有自己上传过的用户 | 管理后台角色库（ADM-01 第 7 条），后台界面不在本文范围 |
| ③ 默认头像 | 自动生成 | 以上都没有时 | — |

| 角色类型 | 能否 AI 生成形象做头像 | 备注 |
|---|---|---|
| 真人（公众人物、基于身边真人） | 不能（SAFE-01 第 1 条） | 人工上传不受此限（①②） |
| 真人（历史人物） | 可以，只用古风插画风格（SAFE-01 第 6 条） | 由管理员作为②上传 |
| 虚构 / 原创角色 | 可以（MED-02） | 由管理员或用户上传 |
| 用户本人 | — | 用户上传；未上传时默认头像底色固定 `gray.200`（微伴粉主题下 `neutral.200`），字色 `text.primary` |

**同一个规则用在所有出现头像的地方**：会话列表、通讯录、聊天、群聊九宫格、朋友圈、资料页、通话页、分享图（EXP-01 第 7 条）、推送通知（推送需要图片格式，见第 6 节）。

「恢复默认」：用户删除自己上传的头像后，回到②（有的话）或③。

## 3. 默认头像的构成

```
┌────────────────┐
│             ✦  │  ← 右上角小图案（可选，头像 ≥ 40 才显示）
│      杨幂      │  ← 头像字：1–2 个字，居中
└────────────────┘
   ↑ 底色：应援色；圆角 = 边长 × radius.avatarRatio
```

### 3.1 头像字

| 名字 | 规则 | 例子 |
|---|---|---|
| 2 个汉字 | 两个字都显示 | 杨幂 → 杨幂 |
| 3 个汉字 | 后 2 个字（名） | 王一博 → 一博 |
| 4 个及以上 | 前 2 个字（建议管理员手动设置） | 欧阳娜娜 → 欧阳 |
| 1 个汉字 | 1 个字 | — |
| 拉丁字母 | 首字母大写，最多 2 个 | Taylor Swift → TS |
| 含符号 | 去掉符号后按上述规则；全是符号显示「?」 | — |

管理员可用契约字段 `avatarText` 覆盖（1–2 字）。备注名**不**影响头像字。

### 3.2 底色

1. 有官方应援色（`supportColors` 第一个）→ 用它。
2. 没有 → 应援色盘 `primitive.color.support.01–12`：`序号 = (角色 ID 的哈希 mod 12) + 1`，任何设备都一样。
3. 多色应援色：第一个做底色，第二个做小图案颜色。

### 3.3 文字颜色

- 色盘颜色：用 `support.*.on`。
- 官方应援色：程序计算与白色、墨色的对比度，选更高的那个（保证不低于约 4.1:1）。头像字按大字标准 ≥ 3:1。

### 3.4 字号

| 字数 | 字号 | 字重 |
|---|---|---|
| 1 个字 / 字母 | 边长 × 0.44 | semibold |
| 2 个字 / 字母 | 边长 × 0.34 | semibold |

### 3.5 小图案（`avatarPattern`）

- 星星（默认）、爱心、音符、月亮、花、无。大小 = 边长 × 0.22，距右上角各 边长 × 0.12；颜色为文字色 55% 透明度，或多色应援色的第二色。
- 头像小于 40 时不显示。
- **儿童角色不提供爱心**（服务器校验，T-009）。

## 4. 尺寸与圆角

尺寸 `size.avatar.*`（24 / 32 / 40 / 48 / 64 / 96），圆角 = 边长 × `radius.avatarRatio`（v2.0 为 0.12，更接近参照产品）。图片头像和默认头像共用同一外形。两个主题外形相同。

## 5. 群聊头像

九宫格拼图：底板 `bg.page`；2–4 人 2×2，5–9 人 3×3；按入群顺序取前 N 个成员（含用户）；每格显示该成员当前应显示的头像（按第 2 节优先级）；默认头像小格只显示 1 个字、不显示图案；小格间距 2，外边距 3。

## 6. 加载、失败与推送

| 情况 | 显示 |
|---|---|
| 有图片头像、加载中 | 先显示默认头像，加载完成后淡入覆盖（`duration.fast`，只改透明度） |
| 加载失败 | 保持默认头像，不显示破图 |
| 角色已删除 / 已退群 | 默认头像或图片，整体透明度 `opacity.muted` |
| 推送通知 | 系统通知只能显示图片：按同一优先级取图；默认头像需生成 96×96 PNG（由安卓原生在本地按本规则绘制，或服务端生成，Android 负责人与后端商定）。用户上传的头像只对本人可见，推送也只发给本人，所以可以直接用 |

## 7. 上传与裁剪（用户上传，界面部分）

- 入口：资料页 › 设置备注和头像 › 头像 › ActionSheet「从相册选择 / 拍照 / 恢复默认头像」（无自定义头像时不显示「恢复默认」）。
- 选图后进入**正方形裁剪页**：黑色背景（`overlay.viewer`），中间正方形取景框（按头像圆角显示外形），双指缩放和拖动（只改 transform）；底部「取消」「完成」。
- 完成后上传中：头像位置显示转圈；成功 Toast「已设置，只有你能看到」；失败 Toast「上传失败，请重试」。文件格式、大小上限以 T-009 的头像上传接口为准，超出时在选图后立即提示，不进入裁剪页。

## 8. 实现建议

- 一个通用 `Avatar` 组件（网页、安卓各一个，规则相同）：输入 角色 ID、名字、`display`（应援色、头像字、图案、主题色）、`image`（服务器已按优先级给出，或客户端按「用户上传 > 管理员上传」选择，以契约为准）、尺寸。
- 默认头像用代码绘制，**不要**在服务器生成 PNG 给界面用：分享图导出时可以直接复用同一绘制逻辑。

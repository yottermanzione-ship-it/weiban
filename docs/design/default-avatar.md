# 非肖像默认头像方案（回答 PRD 8.3 第 2 问）

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-006 |
| 日期 | 2026-10-04 |
| 依据 | SAFE-01 第 1、5 条；PRD 9.3 第 1 条（待总经理决定，答复前按「不用本人照片」执行）；总负责人裁定 9.2 第 1、3 条；CHR-05 |

## 1. 结论

真人角色的默认头像 = **「应援色底 + 名字里的 1–2 个字」的圆角方块**，右上角可加一个小图案（星星、音符等）。

- 不出现任何人脸、剪影、Q 版形象，完全不涉及肖像。
- 应援色是追星圈的身份符号，粉丝一眼就知道「这是 TA」。
- 由程序根据名字和颜色自动画出来（不是图片文件），任何尺寸都清晰，零加载时间。

如果总经理将来决定允许使用本人公开照片，只需在角色库里给角色配图，头像组件优先显示图片；本方案自动退为「图片加载失败时的占位」，不用改设计。

## 2. 哪些角色用默认头像

| 角色类型 | 默认头像 | 能否用图片 |
|---|---|---|
| 真人角色（明星） | **本方案**（必须） | 管理员：不能（待总经理决定）；用户：可以给自己的通讯录上传自定义头像，只对自己可见（CHR-05） |
| 真人角色（历史人物，如李白） | 本方案，或管理员配的古风插画形象 | 可以（裁定 9.2 第 1 条：古风插画，不模仿具体版权作品） |
| 基于真人的自定义角色 | 本方案（必须） | 用户自己上传，只对自己可见 |
| 虚构角色（如罗小黑） | 本方案或管理员配的形象图 | 可以（裁定 9.2 第 3 条，仅个人测试） |
| 原创角色 | 本方案或用户上传 | 可以 |
| 用户本人 | 本方案（底色固定 `neutral.200`，字色 `text.primary`） | 用户上传 |

**分享图**里的头像同样遵守本表（EXP-01 第 7 条）。

## 3. 构成

```
┌────────────────┐
│             ✦  │  ← 右上角小图案（可选，头像 ≥ 40px 才显示）
│                │
│      杨幂      │  ← 头像字：1–2 个字，居中
│                │
│                │
└────────────────┘
   ↑ 底色：应援色；圆角 = 边长 × radius.avatarRatio
```

### 3.1 头像字（取哪几个字）

| 名字 | 规则 | 例子 |
|---|---|---|
| 2 个汉字 | 两个字都显示 | 杨幂 → 杨幂 |
| 3 个汉字 | 显示后 2 个字（名，不是姓；粉丝通常这样叫） | 王一博 → 一博 |
| 4 个及以上汉字 | 显示前 2 个字 | 欧阳娜娜 → 欧阳（建议管理员手动设为「娜娜」） |
| 1 个汉字 | 显示 1 个字 | — |
| 拉丁字母名 | 首字母大写，最多 2 个 | Lisa → L；Taylor Swift → TS |
| 含表情或符号 | 去掉符号后按上述规则；全是符号则显示「?」 | — |

**管理员可覆盖**：角色库提供「头像字」字段（1–2 个字），优先于自动规则。粉丝圈常用的爱称（如名字里的叠字）由管理员填写。用户给角色设了备注名时，头像字**仍按本名**取（备注名可能很长或是昵称）——除非用户上传了自定义头像。

### 3.2 底色（应援色）

1. 角色有官方应援色（管理员在角色库录入，十六进制颜色值）→ 用官方应援色。
2. 没有 → 从应援色预设盘 `primitive.color.support.01–12` 中取：`序号 = (角色 ID 的哈希值 mod 12) + 1`。同一个角色在任何设备、任何时候颜色都一样。
3. 官方应援色是多色的（如「粉 + 黑」）：取第一个颜色作底色，第二个颜色用作右上角小图案的颜色。

### 3.3 文字颜色

- 预设盘颜色：直接用 `support.*.on`（已预先算好）。
- 官方应援色：程序自动计算该底色与白色 `#FFFFFF`、墨色 `neutral.ink` 的对比度，**选对比度更高的那个**。数学上这个规则保证任何底色上的对比度都不低于约 4.1:1。
- 标准：头像字是粗体、短、作为识别图形使用，按「大字」标准要求对比度 ≥ 3:1。预设盘 12 色最低约 3.2:1，满足要求。

### 3.4 字号与字重

| 字数 | 字号 | 字重 |
|---|---|---|
| 1 个字 / 1 个字母 | 头像边长 × 0.44 | `fontWeight.semibold` |
| 2 个字 / 2 个字母 | 头像边长 × 0.34 | `fontWeight.semibold` |

字体用 `fontFamily.sans`；字间距 0；垂直、水平居中。

### 3.5 右上角小图案（应援色图案）

- 可选图案：星星 ✦（默认）、爱心、音符、月亮、花、无。管理员在角色库为角色选择（如歌手选音符）。
- 大小：头像边长 × 0.22；位置：距右上角各 边长 × 0.12。
- 颜色：文字颜色，透明度 0.55；多色应援色时用第二个颜色（不透明）。
- 头像小于 40px（会话列表以外的小头像，如点赞列表）时不显示图案，避免糊成一团。
- 爱心图案对儿童角色不提供（避免恋爱联想，延伸 SAFE-05 精神）。

## 4. 尺寸与圆角

尺寸用 `size.avatar.*`（24 / 32 / 40 / 48 / 64 / 96px），圆角 = 边长 × `radius.avatarRatio`。所有头像（图片头像和默认头像）共用同一个外形，保证列表整齐。

## 5. 群聊头像

与微信一致：九宫格拼图。
- 底板：`bg.surface` 上铺一层 `neutral.100`（深色模式 `neutral.800`），圆角同上。
- 成员 2–4 人：2×2；5–9 人：3×3；按入群顺序取前 N 个成员头像（含用户自己）。
- 每个小格是成员的头像（默认头像或图片），小格内只显示 1 个字（自动规则取最后 1 个字），不显示右上角图案。
- 小格间距 2px（`space.1`），外边距 3px。

## 6. 加载与失败

| 情况 | 显示 |
|---|---|
| 有图片头像、加载中 | 先显示默认头像，图片加载完成后淡入覆盖（`motion.duration.fast`，只改透明度） |
| 图片加载失败 | 保持默认头像，不显示破图图标 |
| 角色已删除（群里显示「已退出」时） | 默认头像，整体透明度 `opacity.muted` |

## 7. 实现建议（给 Web 负责人）

- 用一个通用 `Avatar` 组件：输入 角色 ID、名字、头像字（可空）、应援色（可空）、图案、图片地址（可空）、尺寸。
- 默认头像用 HTML + CSS（背景色 + 文字）或内联 SVG 画出，**不要**在服务器生成 PNG：分享图导出时可以直接复用同一组件绘制到画布。
- 推送通知需要图片格式的头像（系统通知不能渲染 HTML）：由服务端或安卓原生按同样规则生成 PNG（96×96），见交接说明。

## 1. 结论

- 4 套模板：**粉色滤镜**（总经理点名）、**聊天原样**（PRD 原名「微信原样」，见第 4.2 节说明）、**简洁白底**、**卡片风**。
- 每张分享图底部都有一条**标注栏**：左边「微伴」标识（样式可选、不能删）；含真人角色内容时右边加「微伴 AI 角色对话，非本人」（不能关）。
- 为了防止别人把底部裁掉再转发，含真人角色内容时，图片**顶部**角色名旁边再加一个小标签「AI 角色 · 非本人」。
- 输出宽度 1080 像素（手机竖屏分享的通用宽度），文字在手机上不用放大就能看清。

## 2. 输出规格

| 项 | 规格 |
|---|---|
| 设计单位 | 以 360 逻辑像素宽设计，导出时放大 3 倍 = **1080 像素宽**。本文所有尺寸都是逻辑像素 |
| 高度 | 粉色滤镜、聊天原样、简洁白底：随内容增高，**最小 480**（即 1080×1440，3:4，小红书友好）；内容不足时下方留白。卡片风：固定 360×480 |
| 最小字号 | 正文 15；时间、说明 11；标注文字 11（导出后 33 像素，在手机上约等于系统小字） |
| 格式 | PNG；超过 4MB 时改为 JPEG（质量 92） |
| 深浅色 | 粉色滤镜、简洁白底、卡片风永远是浅色；聊天原样跟随当前应用的深浅模式 |
| 头像 | 真人角色用非肖像默认头像或用户自定义头像（EXP-01 第 7 条，`default-avatar.md`）；用户自己默认隐藏，显示为「我」+ 中性默认头像 |
| 生成位置 | 在手机本地用画布（canvas）绘制，不上传服务器（实现方式由 Web 负责人定） |

## 3. 必带标注（四套模板通用，不可删除、不可关闭）

### 3.1 显示什么

| 选中内容 | 底部标注栏右侧文字 | 顶部小标签 |
|---|---|---|
| 含**真人角色**（明星、历史人物、基于真人的自定义角色）的任何消息、朋友圈、卡片 | 「微伴 AI 角色对话，非本人」 | 「AI 角色 · 非本人」 |
| 不含真人角色，但含**虚构角色的形象图**（裁定 9.2 第 3 条） | 「微伴 AI 角色对话」 | 无 |
| 其他 | 无（只有左侧「微伴」标识） | 无 |

群聊中只要选中的消息里有任何一条来自真人角色，就按第一行处理。

### 3.2 标注栏样式

```
┌──────────────────────────────────────────┐
│                 （分享内容）                │
├──────────────────────────────────────────┤  ← 0.5 分隔线
│ ✦ 微伴                微伴 AI 角色对话，非本人 │  ← 标注栏：高 40，左右内边距 16
└──────────────────────────────────────────┘
```

| 项 | 规范 |
|---|---|
| 位置 | 图片最底部，通栏；不叠在图片、气泡或装饰上 |
| 背景 | 实色（各模板定义），不透明 |
| 「微伴」标识 | 左侧：品牌星星符号 12 + 「微伴」（13、半粗）。样式 3 选 1：粉色（`brand.primary`）/ 墨色（`text.primary`）/ 浅灰（`text.secondary`）。**只能换样式，不能隐藏** |
| 「非本人」文字 | 右侧：11、常规字重、颜色 `share.labelText`；与标注栏背景对比度 ≥ 4.5:1；不透明度 100% |
| 禁止 | 缩小到 11 以下、降低透明度、换成与背景接近的颜色、被任何装饰遮挡 |

### 3.3 顶部小标签样式

- 紧跟在顶部角色名之后，Tag 中性型样式（高 18，`radius.xs`，11 号字）：「AI 角色 · 非本人」。
- 卡片风模板中放在邮票图案下方。

### 3.4 编辑页中的提示

选项区有一行**锁定**的说明：🔒「含真人角色内容，将自动带上「非本人」标注」（`fontSize.footnote`、`text.secondary`），没有开关。

## 4. 四套模板

每套模板定义：背景、气泡样式、字体、装饰元素、标注位置（EXP-02 第 2 条）。

### 4.1 粉色滤镜（默认模板）

> 总经理点名。柔和粉色调、少女感，适合晒甜甜的对话。

| 项 | 规范 |
|---|---|
| 背景 | 自上而下三段渐变：`pink.50` → `pink.100` → `lilac.100`；叠加一层静态颗粒纹理（透明度 5%）和稀疏的小星星、缎带装饰（静态 SVG，避开文字区域，每张最多 8 个） |
| 顶部 | 白色 85% 不透明的圆角卡片（`radius.lg`）：角色头像 40 + 名字（17 半粗）+ 顶部小标签（如需）+ 第二行「认识第 128 天 · 2026.10.04」（11，`text.secondary`；「认识第 N 天」受选项控制） |
| 气泡 | 角色：白色、1 描边 `pink.200`；自己：`pink.200` 底、`text.primary` 字；圆角 14，靠头像的上角 4；内边距 10 / 12；头像 32 |
| 字体 | `fontFamily.sans`，正文 15，行高 `lineHeight.normal` |
| 图片消息 | 缩略图（长边 140），叠加「滤镜」：一层 `pink.200` 以柔光方式混合（30%），并整体提亮 5%。只在生成图片时处理，不影响聊天里的原图 |
| 时间 | 选项开启时，居中灰字（11，`text.tertiary`），同聊天页规则 |
| 标注栏 | 背景 `pink.50` 实色；「微伴」默认粉色样式 |

### 4.2 聊天原样（PRD 原名「微信原样」）

> 还原聊天界面，适合「晒聊天记录」。

**设计决定**：还原的是**微伴自己的聊天界面**（粉色自己的气泡、微伴的头像外形），**不是**微信的绿色界面，也**不画**手机状态栏（时间、电量、信号）。

理由：
1. 一张和微信截图一模一样、带着真实明星名字的图片，最容易被误当成「明星本人的真实聊天截图」，正好是 SAFE-02 第 4 条想防止的情况；
2. 照搬他人产品的界面外观用于传播，也不合适。

模板显示名暂定「聊天原样」；名称是否沿用「微信原样」需要产品负责人确认（已写入交接）。

| 项 | 规范 |
|---|---|
| 背景 | `bg.chat`（跟随深浅模式） |
| 顶部 | 一条导航栏样式的标题区：居中角色名（17 半粗）+ 顶部小标签（如需）；左侧不画返回箭头 |
| 气泡 | 与聊天页完全相同（`components.md` 4.1、4.2），按 360 宽排版；头像 40 |
| 时间 | 选项开启时按聊天页规则插入时间分隔 |
| 装饰 | 无 |
| 标注栏 | 背景 `bg.page`；「微伴」默认墨色样式 |

### 4.3 简洁白底

> 适合长对话阅读。没有气泡，像一份排版干净的对话稿。

| 项 | 规范 |
|---|---|
| 背景 | 纯白 |
| 顶部 | 左对齐标题「和 杨幂 的聊天」（20 半粗）+ 顶部小标签（如需）；下一行日期范围（11，`text.secondary`）；下方 0.5 分隔线 |
| 消息 | 无气泡。每段：说话人一行（头像 20 + 名字 13 半粗；「我」用 `brand.primary` 色名字）；下方正文（15，行高 `lineHeight.relaxed`，`text.primary`），左缩进 28。同一人连续消息合并在同一个说话人下，段间距 8；换人时段间距 20 |
| 图片 / 语音 | 图片缩略图长边 120；语音显示为「[语音 12″] 转写文字」 |
| 时间 | 选项开启时显示在说话人名字右侧（11，`text.tertiary`） |
| 装饰 | 仅页面左上角一枚 16 的品牌星星 |
| 标注栏 | 背景 `neutral.50`；「微伴」默认浅灰样式 |

### 4.4 卡片风

> 像一张明信片，适合单句甜话或卡册里的卡片。

| 项 | 规范 |
|---|---|
| 尺寸 | 固定 360×480（导出 1080×1440） |
| 背景 | 外圈 `pink.100`；中间一张 320×424 的「信纸」，`neutral.25` 底，`radius.md`，`shadow.md`（生成静态图，不涉及运行时性能） |
| 构成 | 信纸右上角：「邮票」= 角色默认头像 56，外加齿孔边框；邮票左侧一枚圆形「邮戳」：日期 + 「认识第 N 天」（细线、`text.tertiary`）；正中：消息文字，`fontFamily.serif`，20，行高 1.8，居中；下方右对齐署名「— 杨幂」（15）；信纸底部留出标注栏 |
| 内容上限 | 最多 3 条消息、合计 120 字；超出时模板缩略图上显示「内容太多，建议用其他模板」，仍可选但会只取前 3 条并提示 |
| 从卡册生成 | 信纸上半部放卡面画面（3:2），下半部放卡片上的一句话 + No.012 + 日期 |
| 标注栏 | 在信纸内部底部，背景 `neutral.25`（与信纸同色），上方 0.5 分隔线；「微伴」默认粉色样式 |

## 5. 分享图编辑页

入口见 EXP-01 第 1 条（聊天多选、收藏、朋友圈「…」、卡片详情）。

```
┌──────────────────────────────┐
│ ‹ 取消          分享图          │  NavBar
├──────────────────────────────┤
│                              │
│      [实时预览，缩放显示]        │  预览区：bg.page，可上下滑动查看长图
│                              │
├──────────────────────────────┤
│ [粉色滤镜][聊天原样][简洁白底][卡片风] │  模板横向列表：缩略图 64×86 + 名称；选中 2 描边 brand.primary
│                              │
│ 显示我的头像和昵称        ( ○ )  │  默认关
│ 显示时间                ( ● )  │  默认开
│ 显示「认识第 N 天」        ( ● )  │  默认开（私聊时才有此项）
│ 「微伴」标识样式    粉色 墨色 浅灰 │  SegmentedControl
│ 🔒 含真人角色内容，将自动带上「非本人」标注 │  仅在需要时出现
│ 设为默认模板            ( ○ )  │  EXP-02 第 4 条
├──────────────────────────────┤
│ [ 保存到相册 ]   [ 分享 ]        │  主按钮 + 柔和按钮
└──────────────────────────────┘
```

- 切换模板或选项：预览即时刷新（重新绘制预览图，切换用 opacity 交叉淡入 `duration.fast`）。
- 保存成功：Toast 图标型「已保存到相册」。iPhone 网页版若无法直接保存：改为全屏展示生成的图片 + 提示「长按图片保存」（待 Web 负责人验证，PRD 第 3 节）。
- 「分享」调用系统分享面板。
- 首次进入时选中默认模板（未设置过则为粉色滤镜）。

## 6. 内容规则（来自 PRD，设计上的体现）

| 规则 | 体现 |
|---|---|
| 最多 P-24 条消息 | 多选超过时「分享图」按钮禁用并提示（`components.md` 5.6） |
| 成人模式消息不可选 | 多选时勾选框禁用（SAFE-07） |
| 撤回的消息不显示 | 撤回提示不可勾选，也不会出现在图中 |
| 图片按缩略图排入 | 各模板已定义缩略图尺寸 |
| 语音显示为语音条 + 转写 | 粉色滤镜、聊天原样：语音气泡下方附转写小字（13）；简洁白底见 4.3 |

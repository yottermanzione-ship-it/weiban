## 1. 结论

- 4 套模板：**粉色滤镜**（默认）、**聊天原样**、**简洁白底**、**卡片风**。
- 每张分享图都带一枚**微伴贴纸**：logo 和文案在一起，像一张贴在图上的品牌贴纸，形状和颜色随模板变化，**不能删除、不能关闭**。
  - 含真人角色内容：「**微伴AI聊天**」+「**非本人，请谨慎识别**」两行；
  - 不含真人角色：只有「**微伴AI聊天**」一行。
- 输出宽度 1080 像素，手机上不用放大就能看清。

## 2. 输出规格

| 项 | 规格 |
|---|---|
| 设计单位 | 以 360 逻辑像素宽设计，导出放大 3 倍 = **1080 像素宽**。本文尺寸都是逻辑像素 |
| 高度 | 粉色滤镜、聊天原样、简洁白底：随内容增高，**最小 480**（1080×1440，3:4）；卡片风：固定 360×480 |
| 最小字号 | 正文 15；时间、说明 11；贴纸文字见第 3.3 节 |
| 格式 | PNG；超过 4MB 改为 JPEG（质量 92） |
| 深浅色 / 主题 | **四套模板都固定为浅色，且不跟随用户选择的主题**（EXP-02）。「聊天原样」固定用微伴粉主题浅色的令牌 |
| 头像 | 按 `default-avatar.md` 第 2 节优先级（用户上传 > 管理员上传 > 默认头像）；用户自己默认隐藏，显示为「我」+ 中性默认头像 |
| 生成位置 | 在手机本地绘制（网页用画布，安卓用原生绘制），不上传服务器 |

## 3. 微伴贴纸（四套模板通用，不可删除、不可关闭）

### 3.1 显示什么

| 选中内容 | 贴纸文案 |
|---|---|
| 含**真人角色**（公众人物、历史人物、基于身边真人）的任何消息、朋友圈、卡片 | 第一行「微伴AI聊天」；第二行「非本人，请谨慎识别」 |
| 其他 | 「微伴AI聊天」 |

- 群聊中只要选中的消息里有一条来自真人角色，就按第一行处理。
- 文案按 PRD 原文「微伴AI聊天非本人，请谨慎识别」，只在「聊天」后断行（EXP-01 第 5 条允许调整断句），意思不变。
- 虚构角色的形象图不再单独加注（EXP-01 第 5 条）。

### 3.2 构成

```
   ╭─────────────────────────────╮
   │ [logo]  微伴AI聊天             │   ← logo 20 + 主文案
   │         非本人，请谨慎识别      │   ← 副文案（仅含真人内容时）
   ╰─────────────────────────────╯
     （整体略微倾斜 -4°，像贴上去的贴纸）
```

| 项 | 规范 |
|---|---|
| logo | `brand.md` 第 7 节的气泡星星标志，高 20，颜色 `share.logo`（墨色变体时为白色反白版） |
| 主文案 | 「微伴AI聊天」：14、`fontWeight.bold`、颜色 `share.stickerText` |
| 副文案 | 「非本人，请谨慎识别」：12、`fontWeight.medium`、颜色 `share.stickerSubText`；与主文案左对齐，行距 2 |
| 外形 | 圆角胶囊（`radius.full` 或 `radius.md`，随模板）；内边距 上下 8、左右 12；logo 与文字间距 8 |
| 底色 / 描边 | `share.stickerBg` 白底 + 1.5 `share.stickerBorder` 粉色描边；墨色变体：`share.stickerInkBg` 底 + `share.stickerInkText` 字、无描边 |
| 角度 | 默认 -4°（卡片风为 0°，放在邮戳旁）；倾斜只用于导出的静态图片 |
| 装饰 | 可在贴纸外角加 1–2 个 8 的小星星（`pink.400`），不得压到文字 |
| 位置 | 图片**右下角**内容区下方的留白里，距右边 16、距底边 16；不叠在气泡、消息图片、头像上。内容较少时也在右下角 |
| 对比度 | 主文案、副文案与贴纸底色 ≥ 4.5:1（白底墨字 16:1、白底灰字 6.3:1；墨底白字 16:1） |

### 3.3 不可以

- 字号小于主文案 14 / 副文案 12；降低透明度；换成与贴纸底接近的颜色；被装饰遮挡；把 logo 和文案拆开放在两处（EXP-01 第 5 条）。
- 用户在编辑页**没有**隐藏、移动、缩小贴纸的选项。

### 3.4 编辑页中的说明

含真人角色内容时，选项区显示一行锁定说明：🔒「含真人角色内容，图片会带上『非本人，请谨慎识别』」（`fontSize.footnote`、`text.secondary`），没有开关。

## 4. 四套模板

每套模板定义：背景、气泡、字体、装饰、贴纸样式（EXP-02 第 2 条）。

### 4.1 粉色滤镜（默认模板）

| 项 | 规范 |
|---|---|
| 背景 | 自上而下渐变 `pink.50` → `pink.100` → `lilac.100`；叠加静态颗粒纹理（5%）和稀疏小星星、缎带装饰（每张最多 8 个，避开文字） |
| 顶部 | 白色 85% 不透明圆角卡片（`radius.lg`）：头像 40 + 名字（17 半粗）；第二行「认识第 128 天 · 2026.10.04」（11，`neutral.600`；「认识第 N 天」受选项控制） |
| 气泡 | 角色：白色、1 描边 `pink.200`；自己：`pink.200` 底、墨色字；圆角 14，靠头像的上角 4；内边距 10 / 12；头像 32 |
| 字体 | `fontFamily.sans`，正文 15 |
| 图片消息 | 缩略图长边 140，叠加 `pink.200` 柔光（30%），只在生成时处理 |
| 贴纸 | 白底粉描边、胶囊形、-4° |

### 4.2 聊天原样

> 还原微伴**粉色主题**下的聊天界面，适合「晒聊天记录」。

**设计决定**（EXP-02 第 1 条已采纳）：还原的是**微伴粉主题**的聊天界面（粉色自己的气泡、微伴的头像外形），**不是**参照产品的绿色界面，也**不画**手机状态栏。即使用户正在用默认（绿色）主题，这个模板也固定渲染成微伴粉。理由：和参照产品截图一模一样、带着真实明星名字的图片最容易被当成本人真实聊天截图（SAFE-02）；照搬他人产品界面用于传播也不合适。

| 项 | 规范 |
|---|---|
| 令牌 | 固定使用 `theme.pink.light` 一组颜色 |
| 背景 | `bg.chat`（微伴粉浅色值） |
| 顶部 | 导航栏样式标题区：居中角色名（17 半粗）；不画返回箭头 |
| 气泡 | 与聊天页相同（`components.md` 4.1、4.2，含小尖角），按 360 宽排版；头像 40 |
| 时间 | 选项开启时按聊天页规则插入时间分隔 |
| 装饰 | 无 |
| 贴纸 | 白底粉描边、胶囊形、-4° |

### 4.3 简洁白底

| 项 | 规范 |
|---|---|
| 背景 | 纯白 |
| 顶部 | 左对齐「和 杨幂 的聊天」（20 半粗）；下一行日期范围（11，`neutral.600`）；下方 0.5 分隔线 |
| 消息 | 无气泡。每段：说话人一行（头像 20 + 名字 13 半粗；「我」用 `pink.700`）；正文 15、行高 `lineHeight.relaxed`，左缩进 28；同一人连续消息合并；换人段间距 20 |
| 图片 / 语音 | 图片缩略图长边 120；语音「[语音 12″] 转写文字」 |
| 装饰 | 左上角一枚 16 品牌星星 |
| 贴纸 | 墨色变体（墨底白字、反白 logo）、`radius.md` 圆角矩形、-4° |

### 4.4 卡片风

| 项 | 规范 |
|---|---|
| 尺寸 | 固定 360×480 |
| 背景 | 外圈 `pink.100`；中间 320×424「信纸」，`neutral.25` 底，`radius.md`，`shadow.md`（静态图，不涉及运行时性能） |
| 构成 | 右上角「邮票」= 角色头像 56 加齿孔边框；邮票左侧圆形「邮戳」：日期 +「认识第 N 天」；正中消息文字 `fontFamily.serif` 20、行高 1.8、居中；右下署名「— 杨幂」（15） |
| 内容上限 | 最多 3 条消息、合计 120 字；超出时缩略图上提示「内容太多，建议用其他模板」 |
| 从卡册生成 | 信纸上半部卡面画面（3:2），下半部一句话 + No.012 + 日期 |
| 贴纸 | 在信纸内左下角，白底粉描边、胶囊形、0°（与邮戳呼应，不倾斜） |

## 5. 分享图编辑页

入口见 EXP-01 第 1 条（聊天多选、收藏、朋友圈「…」、卡片详情）。

```
┌──────────────────────────────┐
│ ‹ 取消          分享图          │  NavBar
├──────────────────────────────┤
│      [实时预览，缩放显示]        │  预览区：bg.page，可上下滑动查看长图
├──────────────────────────────┤
│ [粉色滤镜][聊天原样][简洁白底][卡片风] │  模板横向列表：缩略图 64×86 + 名称；选中 2 描边 brand.primary
│ 显示我的头像和昵称        ( ○ )  │  默认关
│ 显示时间                ( ● )  │  默认开
│ 显示「认识第 N 天」        ( ● )  │  默认开（私聊时才有此项）
│ 🔒 含真人角色内容，图片会带上「非本人，请谨慎识别」 │  仅在需要时出现
│ 设为默认模板            ( ○ )  │  EXP-02 第 4 条
├──────────────────────────────┤
│ [ 保存到相册 ]   [ 分享 ]        │  主按钮 + 柔和按钮
└──────────────────────────────┘
```

- 编辑页本身的界面颜色跟随用户主题（按钮绿或粉）；**预览图不跟随**（第 2 节）。
- 切换模板或选项：预览即时刷新（opacity 交叉淡入 `duration.fast`）。
- 保存成功：Toast「已保存到相册」。iPhone 网页版若无法直接保存：全屏展示图片 + 提示「长按图片保存」（待 Web 负责人验证）。
- 首次进入选中默认模板（未设置过则为粉色滤镜）。

## 6. 内容规则在设计上的体现

| 规则 | 体现 |
|---|---|
| 最多 P-24 条消息 | 多选超过时「分享图」按钮禁用并提示（`components.md` 5.6） |
| 撤回的消息不显示 | 撤回提示不可勾选，也不会出现在图中 |
| 图片按缩略图排入 | 各模板已定义缩略图尺寸 |
| 语音显示为语音条 + 转写 | 粉色滤镜、聊天原样：语音气泡下方附转写小字（13）；简洁白底见 4.3 |
| 成人模式消息 | 与其他消息一样可选（v2.0，EXP-01 第 6 条） |

## 1. 结论

- 3 套模板：**A 微信原样**（默认）、**B 柔和信纸**、**C 卡片海报**。风格：微信式简洁干净，纯色底，无渐变、无随机装饰、无倾斜元素。
- 每张图底部都有一条**品牌栏**，不能删除、不能关闭，也不压任何内容（接在内容下方）。
  - 第一行「**微伴AI聊天**」；
  - 第二行：含真人角色内容时固定「**非本人，请谨慎识别**」（合规优先）；否则单聊「**和 X 认识第 N 天**」；群聊或没有天数时省略第二行；
  - 右侧二维码指向官网下载页 **https://weiban.online**，下方「扫码下载」。
- 输出宽度 1080 像素。

## 2. 输出规格

| 项 | 规格 |
|---|---|
| 设计单位 | 以 360 逻辑像素宽设计，导出 ×3 = **1080 像素宽**。本文尺寸都是逻辑像素 |
| 高度 | A、B：随内容增高，**最小 480**（含品牌栏）；C：随内容（卡面 + 文字 + 品牌栏，约 360×560） |
| 最小字号 | 正文 15；时间、说明 12；二维码说明 11 |
| 格式 | PNG；超过 4MB 改为 JPEG（质量 92） |
| 深浅色 / 主题 | **固定浅色，不跟随用户主题**（EXP-02）。颜色只取设计令牌 `share.*`（`tokens.json`），不再引用任何主题令牌 |
| 头像 | `default-avatar.md` 第 2 节优先级（用户上传 > 管理员上传 > 默认头像）；用户自己默认隐藏，显示「我」+ 中性灰默认头像（`share.meAvatarBg`，与 A 的灰底区分开） |
| 生成位置 | 本地绘制（网页 canvas），不上传服务器；二维码本地生成，不调外部服务 |

## 3. 底部品牌栏（三套共用）

```
├──────────────────────────────────────────┤  0.5 分隔线 share.hairline
│ [logo]  微伴AI聊天                  ▣▣▣▣ │  品牌栏高 84，底 share.footerBg（白）
│  36     和 林知夏 认识第 128 天      ▣▣▣▣ │  第二行 12（真人提示时 500 字重）
│                                    扫码下载 │  二维码 50（25×25 模块，每模块 2 → 导出 6 像素）
└──────────────────────────────────────────┘
```

| 项 | 规范 |
|---|---|
| logo | 旧版绿色小熊图标 `apps/web/public/assets/old-ui/brand/icon.png`，36×36、圆角 8，距左 16、垂直居中；图标没加载出来时画简化版（`share.logo` 绿底 + 白色熊脸） |
| 主文案 | 「微伴AI聊天」15、半粗、`share.text`；有第二行时距栏顶 23，否则垂直居中 |
| 第二行 | 12、`share.textSecondary`（白底 5.7:1）。名字太长时只截名字（「和 很长的名…认识第 N 天」） |
| 二维码 | 内容 `https://weiban.online`，纠错等级 M，深色模块 `share.qr`；距右 16、距栏顶 10；模块对齐导出像素避免发虚 |
| 不可以 | 隐藏、移动、缩小品牌栏；降低透明度；把 logo 与文案拆开；编辑页没有任何品牌栏开关 |

判断「含真人」以服务器在分享数据里给出的 `label = weiban_not_real_person` 为准，客户端不按名字猜。编辑页锁定说明见第 5 节。

## 4. 三套模板

### 4.1 A 微信原样（默认）

| 项 | 规范 |
|---|---|
| 背景 | `share.chatBg`（#EDEDED） |
| 顶部 | 高 48：角色名 / 群名居中（17 半粗，一行，过长省略），底部 0.5 分隔线；不画返回箭头、不画状态栏 |
| 时间 | 「显示时间」开启时，间隔超过 5 分钟插入居中时间（12、`share.textSecondary`） |
| 头像 | 40，圆角 4（方圆角），距边 12；真实头像优先 |
| 气泡 | 对方 `share.chatBubbleOther`（白）、我方 `share.chatBubbleMine`（微信绿）；圆角 4，头像一侧距顶 12 的小尖角；内边距 9 / 12；正文 15、行高 22，最宽 226 |
| 群聊 | 对方气泡上方显示名字（12、次要色） |

### 4.2 B 柔和信纸

| 项 | 规范 |
|---|---|
| 背景 | `share.paperBg`（暖白纯色，无渐变、无星星） |
| 顶部 | 角色头像 48（圆角 8）+ 名字（18 半粗）；第二行「认识第 N 天 · 2026.10.27」（12；关闭「认识第 N 天」或没有天数时只显示日期；群聊「群聊 · 日期」） |
| 摘录 | 大号衬线一句（`fontFamily.serif` 20、行高 34，最多 5 行，超出省略）；前面一个 `share.paperQuote` 粉色引号；右下「— 角色名」（13）；下方 1 线 `share.paperBorder` |
| 摘录取句 | 候选 = 所选内容中**角色说的文字消息**。默认取最长一句；最长一句也不足 6 字时取最后一句。编辑页「换一句」按时间顺序轮换候选；没有候选（只有图片 / 我的消息）时不显示摘录 |
| 对话 | 头像 32（圆角 6）；对方白气泡 + 1 线 `share.paperBorder`，我方 `share.paperBubbleMine`（柔粉）；圆角 12、无尖角；正文 15，最宽 212 |

### 4.3 C 卡片海报

| 项 | 规范 |
|---|---|
| 适用 | **只用于卡片分享**（卡片详情 → 生成分享图）。聊天、收藏、朋友圈、慢信等消息内容不可选 C |
| 背景 | `share.posterBg`（白） |
| 卡面 | 上部 328×246（4:3），距边 16，圆角 12，居中裁剪铺满 |
| 无卡面 | 用角色头像底色铺满后叠 80% 白（柔和色底）+ 居中角色头像 88（圆角 12）。**不再画蓝色占位块** |
| 编号 | 卡面左上「No.012」胶囊：12 半粗白字、`share.posterBadgeBg` 底、高 24 |
| 文字 | 卡名 20 半粗（最多 2 行）；卡片语衬线 17、行高 30（最多 5 行）；「角色 · 2026.10.20 获得」12 次要色 |
| 兜底 | 卡片详情取不到时：标题用角色名，句子用默认摘录句，下方「角色 · 日期」 |

### 4.4 各种消息在 A / B 里的画法

| 类型 | 画法 |
|---|---|
| 文字、每日一问、名片、通话记录、带按钮卡片 | 文字气泡（名片「[名片] X」、通话「[通话] 时长 mm:ss」，按钮不画） |
| 图片、宠物照片 | 缩略图长边 140，圆角 A 4 / B 8；没加载出来：灰底 + 线框图片图标 |
| 表情 | 88×88，无气泡 |
| 语音 | 语音气泡（声波图标 + 秒数，宽度随时长，最长 60 秒封顶）；有转写时下方同色小框显示转写（14） |
| 慢信 | 卡片气泡：顶部「慢信」小字 + 分隔线 + 全文 |
| 链接 | 卡片气泡：标题（2 行）+ 描述（2 行，次要色）+ 底部来源 |
| 聊天记录 | 卡片气泡：标题 + 前 4 条「名字：内容」+ 底部「聊天记录」 |
| 拍一拍 | 居中次要色小字「X 拍了拍…」 |
| 不认识的类型 | 文字气泡「[消息]」 |

换行规则：句末标点（，。！？、；：等）不放在行首。

## 5. 分享图编辑页

```
┌──────────────────────────────┐
│ ‹             分享图           │  NavBar
├──────────────────────────────┤
│      [实时预览，缩放显示]        │  可上下滑动查看长图
├──────────────────────────────┤
│ [A 缩略图][B 缩略图][C 缩略图]    │  64×86 示意缩略图 + 名称；选中 2 描边品牌绿
│ 摘录：辛苦啦～先去吃点…    换一句 │  仅 B，且候选 ≥ 2 句时出现「换一句」
│ 显示我的头像和昵称        ( ○ )  │  默认关
│ 显示时间                ( ● )  │  默认开（C 不显示此项）
│ 显示「认识第 N 天」        ( ● )  │  默认开（单聊才有；影响 B 顶部与品牌栏第二行）
│ 🔒 含真人角色内容，图片会带上「非本人，请谨慎识别」 │  仅在需要时出现，无开关
│ 设为默认模板            ( ○ )  │
├──────────────────────────────┤
│ [ 保存到相册 ]   [ 分享 ]        │
└──────────────────────────────┘
```

- 卡片入口：只能选 C，点 A / B 时 Toast「卡片分享使用卡片海报，保留卡面与编号」；其他入口点 C 时 Toast「卡片海报只用于卡片，聊天和朋友圈请用微信原样或柔和信纸」。
- 首次进入：卡片入口为 C；其他入口为用户默认模板（默认偏好是 C 时回落到 A；从未设置为 A）。
- 编辑页界面颜色跟随用户主题；预览图不跟随（第 2 节）。

### 5.1 契约值映射（契约不改）

契约 `ShareTemplate` 仍是 v2 的四个值，网页按下表读写（实现：`apps/web/src/features/share-render.ts` 的 `styleFromTemplate` / `templateForStyle`）：

| 契约值 | 读成 | v3 写入时用 |
|---|---|---|
| `pink_filter`（服务器初始值） | A | — |
| `chat_original` | A | A |
| `simple_white` | B | B |
| `card_style` | C | C |

代价：v2 时主动选过「粉色滤镜」的用户与从未设置的用户无法区分，统一变成 A；「生成次数」回报也按右列的值记。安卓端仍按 v2 名称解释这些值（B 在安卓上显示为「简洁白底」），待安卓批次跟进或契约下次升级时改名。

## 8. 「聊天原样」纯黑底问题（v3 已修）

原因：v2 代码按 `theme.pink.light.*` 取颜色，但设计令牌在 v3 主题调整时只保留了 `theme.green`，粉主题整组被删。取值函数查不到时返回字符串 `"undefined"`，canvas 忽略这个非法颜色、沿用默认黑色，于是整张底变黑、标题黑字看不见；同样原因还让「我」的默认头像颜色失效。

修法与防再犯：分享图只用独立的 `share.*` 令牌（第 2 节），不再引用任何主题；取值函数查不到令牌时**直接报错**，编辑页显示「生成失败」而不是静默画黑；头像底色为空时用中性灰兜底。

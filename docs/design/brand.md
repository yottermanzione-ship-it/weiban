# 微伴品牌规范

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-006（v1.0）、T-012（v2.0）、T-021（v2.1：6.1 宠物插画方向） |
| 版本 | v2.1 |
| 日期 | 2026-10-05 |

> 所有颜色、字号等**具体数值只在 `tokens.json` 定义**，本文只写用途和理由，引用令牌名。想直接看效果，请用浏览器打开 `preview/index.html`（可切换两套主题）。
> v2.0 变更（T-012，依据 PRD v1.2 原则 8、SVC-01 第 7 条、EXP-01 第 5 条）：界面默认配色改为接近微信的「默认」主题（白 / 浅灰底 + 绿色），「微伴粉」改为可切换的主题；令牌按主题组织；品牌粉保留给 logo、分享图和养成类装饰；新增 logo 规格（分享图推广露出要用）。

## 1. 结论

- **界面像参照产品，品牌在细节里**：默认主题的布局、配色、手感都尽量接近参照产品（PRD 原则 8，界面里不出现参照产品的名称和 logo），用户打开就会用。
- **两套主题**：「默认」（浅灰底 + 绿色强调，新账号默认）和「微伴粉」（暖白底 + 粉色强调，就是 v1.0 的配色）。在「我 → 设置 → 通用 → 主题」切换，立即生效。
- **微伴粉仍是品牌色**：logo、App 图标、分享图、卡片和成就这些「有纪念意义、会被晒出去」的地方，无论用户选哪个主题都用微伴粉系。

## 2. 品牌调性

| 是 | 不是 | 为什么 |
|---|---|---|
| 熟悉、顺手 | 新奇、要学 | 用户每天用参照产品，界面越像越沉浸（「像加上了自己爱豆的微信」） |
| 温柔、亲近 | 甜腻、低龄 | 用户 18–30 岁；粉色降低饱和、搭配留白 |
| 安静、陪伴 | 热闹、促活 | 产品原则「质感优先于频率」「不操纵」；红点只用于需要处理的事 |
| 有纪念感 | 游戏化抽卡 | 卡片、成就像收藏品和手账，没有稀有度光效 |

### 为什么适合追星女孩

1. **零学习成本**：结构和配色照参照产品来，打开就会用，沉浸感最强。
2. **应援色文化**：默认头像、卡面、角色主题点缀用应援色，让她们觉得「这是 TA」，同时天然避开肖像问题。
3. **晒图需求**：粉色滤镜分享图、明信片风卡片，加上活泼的微伴贴纸，是她们愿意主动传播的审美。
4. **讨厌被打扰、讨厌套路**：克制的视觉（没有红包式弹窗、没有连续签到）。

### 文案语气

- 简短、口语、不官方：「TA 记得的事」而不是「记忆管理」。
- 角色一律称「TA」或角色名；界面上**不加「AI」字样**。例外只有：真人角色资料页底部说明（CHR-02）、分享图上的微伴贴纸（EXP-01）。
- 界面文字里**不出现「微信」二字**（PRD 原则 8）。设计文档里提到时写「参照产品」。
- 不写制造愧疚的文案（SAFE-08）。术语以 `docs/product/glossary.md` 为准。
- 钱相关文案平实：「余额」「余额明细」「价目表」，金额写「¥ 12.34」；不写「充值」（没有充值入口，MDL-07）。

## 3. 配色

### 3.1 主题怎么组织

| 层 | 内容 | 随什么变 |
|---|---|---|
| `primitive` 原始色板 | 粉、绿（jade）、草绿（lime）、暖灰（neutral）、纯灰（gray）、紫、红、橙、蓝、金、应援色盘 | 不变；组件不直接用 |
| `theme.<主题>.<模式>` | **背景 bg、文字 text、分隔线 border、强调色 brand、气泡 bubble** 五组 | 主题 × 深浅模式（4 套） |
| `semantic.<模式>` | 状态色、角标、金额、点缀色、熟悉度、卡片、成就、情景模式、通话、深色浮层 | 只随深浅模式；两个主题共用 |
| `share` | 分享图贴纸与 logo | 永远不变 |

一句话：**「主题」只换底色、文字灰、强调色和气泡；养成、状态、通话这些有固定含义的颜色两个主题一样。**

### 3.2 两套主题

| | 默认（`green`，新账号默认） | 微伴粉（`pink`） |
|---|---|---|
| 页面底 | 浅灰 `gray.100` | 暖灰白 `neutral.50` |
| 列表 / 卡片 | 纯白 | 纯白 |
| 强调色 `brand.primary` | 绿 `jade.500`。刻意比参照产品的品牌绿深一档：既不和对方品牌色相同（SVC-01 第 7 条），白字对比度也更高（3.28:1） | 微伴粉 `pink.500` |
| 自己的气泡 | 草绿 `lime.300` + 墨色字 | 浅粉 + 墨色字 |
| 文字灰 | 纯灰 | 带暖意的灰 |
| 链接、可点人名 | 蓝灰（与参照产品习惯一致） | 深粉 |
| 深色模式 | 纯黑灰底（`gray.950` / `gray.900`），自己的气泡为中绿 + 深色字 | 带紫调的近黑，自己的气泡为深玫瑰 + 白字 |

### 3.3 色彩角色（两个主题通用）

| 角色 | 令牌 | 用在哪里 | 不要用在哪里 |
|---|---|---|---|
| 强调色 | `brand.primary` | 主按钮、开关打开、选中态、标签栏选中、服务页顶部卡片 | 大面积背景（服务卡片除外）；正文 |
| 浅强调底 | `brand.soft` / `brand.onSoft` | 选中底色、标签、引导横幅 | — |
| 自己的气泡 | `bubble.selfBg` | 我发出的消息 | 其他任何地方 |
| 红 | `badge.unread`、`status.danger` | 未读数、红点、发送失败、删除 | 装饰（红色只表示「需要注意」） |
| 橙 | `status.warning*` | 系统横条（模型不可用、余额不足） | — |
| 点缀色 | `tint.*` | 「我」页和服务页的列表 / 宫格图标 | 文字、按钮 |
| 金额 | `amount.income` / `amount.expense` | 余额明细的 + / − | — |
| 微伴粉（品牌） | `share.logo`、`familiarity.*`、`card.*`、`achievement.*` | logo、分享图、熟悉度、卡片、成就 | 跟随主题的界面控件 |
| 应援色 | `primitive.color.support.*` 或官方应援色 | 默认头像、卡面、资料页点缀 | 文字、按钮 |

为什么在绿色主题里熟悉度、卡片还是粉紫色：这些是「微伴专属」的东西（参照产品没有），用品牌色正好让人一眼认出「这是微伴特有的」，也让两个主题的养成截图看起来一致。

### 3.4 对比度要求

- 正文与背景 ≥ 4.5:1；大字（≥ 18px 粗体或 ≥ 24px）和图标、控件边界 ≥ 3:1。
- **主按钮白字**：默认主题 3.28:1、微伴粉 3.96:1，都按「大字 / 界面元素」标准（≥ 3:1）验收，因此主按钮文字固定用 `fontSize.body` + `fontWeight.semibold`，不做小号主按钮的白字。v1.0 文档写的「4.9:1」是计算错误，v2.0 更正。
- `text.tertiary` 只用于时间、辅助说明这类非关键信息。
- 应援色上的文字颜色已在 `support.*.on` 预先算好；官方应援色按 `default-avatar.md` 第 3.3 节自动选择。

## 4. 字体

| 用途 | 令牌 | 说明 |
|---|---|---|
| 全部界面 | `fontFamily.sans` | **只用系统字体**，不下载中文网络字体。安卓：`FontFamily.Default` |
| 大号数字、金额 | `fontFamily.numeric` + 等宽数字 | 余额、认识第 N 天、卡片编号 |
| 卡片一句话、卡片风分享图 | `fontFamily.serif` | 「手写信 / 明信片」的感觉 |

字号阶梯见 `typography.fontSize`。正文 17 与参照产品一致；用户可在设置中调整字体大小（5 档）。字重只用 400 / 500 / 600 / 700 四种。

## 5. 图标

| 项 | 规范 |
|---|---|
| 图标库 | **Phosphor Icons**（MIT 开源许可）：同一图标有线性和填充两种，正好对应标签栏未选中 / 选中 |
| 风格 | 线性为主，选中态用填充 |
| 尺寸 | 24（导航、列表）、28（服务宫格、输入栏）、20、16 |
| 颜色 | 默认 `text.primary`；次要 `text.secondary`；选中 `brand.primary`；「我」页、服务宫格用 `tint.*` 或 `brand.primary`（见 `components.md` 3.6、16.2） |
| 点击区 | 不小于 `size.touchTarget`（44） |
| 实现 | 网页按需引入单个 SVG；安卓把同一套 SVG 转成 Vector Drawable（`tokens-android.md` 第 3 节） |

标签栏：微伴 = 对话气泡、通讯录 = 人形、发现 = 指南针、我 = 用户圆形。

自定义图标（Phosphor 没有的）：拍一拍、卡册、熟悉度月相、28 枚成就徽章插画。按 24 网格、1.5px 线宽、圆头圆角绘制。

## 6. 插画方向

**原则：画物，不画人。** 真人角色不能出现肖像（SAFE-01），插画里画人容易被理解成「这是 TA」。

| 项 | 规范 |
|---|---|
| 题材 | 信封、拍立得、应援棒、耳机、手机、星星、月亮、花束、门票、咖啡杯、小猫 |
| 风格 | 扁平 + 柔和渐变，2px 统一描边，圆角造型 |
| 用色 | 微伴粉、薰衣草紫、暖灰为主，最多再加 1 个点缀色（两个主题通用，插画不跟随主题换色） |
| 用在 | 空状态、首次引导、成就徽章、卡面背景 |
| 格式 | SVG；需要纹理的用 WebP，单张 ≤ 60KB |
| 禁止 | 人物形象（含 Q 版、剪影）；复制任何作品中的角色形象 |

虚构角色、历史人物的形象图（PRD SAFE-01 第 6 条、MED-02）属于**角色素材**，由管理员维护，不属于品牌插画。

### 6.1 宠物插画方向（v2.1，PLAY-02）

宠物图鉴的图片由管理员维护（ADM-04 第 5 条），但风格必须和品牌插画是一家人。完整规格（画布、文件、成长阶段、外观数量）见 `pages/pet.md` 第 7 节，这里只定方向：

| 项 | 方向 |
|---|---|
| 气质 | **软、圆、安静**：像手账贴纸里的小动物，不是游戏里的萌宠立绘；表情只有「眯眼开心」「好奇」「打盹」这种温和的情绪，**没有哭、生病、饿、脏的样子**（PLAY-02 第 8 条：宠物不会难过） |
| 造型 | 头身比约 1:1.2，圆润轮廓；2px 统一描边（与品牌插画相同）；不画写实毛发 |
| 用色 | 动物本身的颜色（橘猫是橘色），加微伴粉 / 薰衣草紫的小配饰（围巾、铃铛、蝴蝶结）作为品牌连接；不跟随界面主题 |
| 成长 | 幼年 → 少年 → 成年是**同一只**：花色和配饰不变，只是体型变大、比例变得修长 |
| 外观 | 同一物种的几种外观只换花色或配饰，**没有稀有度**：不用金色描边、闪光、「SSR」之类的暗示（PLAY-02 第 9 条） |
| 禁止 | 人物和人手（喂食动作只画食物，不画手）；拟人化的衣服和站立姿势；复制任何作品中的形象 |

## 7. 品牌标识（logo）

- 名称：微伴。界面和 logo 都不使用参照产品的名称、图形或字体样式。
- **标志**：一个圆角对话气泡，气泡里一颗四角小星星（「被看见的那颗星」），气泡尾巴在左下。单色，颜色 `share.logo`（微伴粉）；反白版用于粉色或深色底。
- **组合**：标志 + 字标「微伴」（`fontWeight.bold`）。横排时标志高 = 字高 × 1.2，间距 = 字高 × 0.3。
- **最小尺寸**：标志 16（逻辑像素）；分享图贴纸中标志 20。
- 正式矢量稿尚未绘制（遗留），绘制前样张和分享图用 `preview/index.html` 中的简化 SVG 占位，形状按本节描述。
- **App 图标**：微伴粉底 + 白色气泡星星。安卓自适应图标需要前景、背景两层，由 Android 负责人按此出图。App 图标不跟随界面主题。
- **网页主题色**（浏览器顶栏、iPhone 主屏幕启动色）：取当前主题的 `bg.navBar`。

## 8. 角色主题点缀

每个角色有一个**主题色**：官方应援色（管理员录入），没有则从应援色盘按角色 ID 稳定选取（`default-avatar.md` 第 3 节）。只用于：默认头像底色、卡面主色、时间线圆点。

聊天页**不**按角色变色（自己的气泡跟随主题，保证一致性）。

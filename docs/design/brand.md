# 微伴品牌规范

| 项 | 内容 |
|---|---|
| 负责人 | design-lead |
| 任务 | T-006 |
| 版本 | v1.0 |
| 日期 | 2026-10-04 |

> 所有颜色、字号等**具体数值只在 `tokens.json` 定义**，本文只写用途和理由，引用令牌名。想直接看颜色，请用浏览器打开 `preview/index.html`。

## 1. 结论

微伴的品牌感是 **「温柔的粉，干净的白，克制的装饰」**：
- 结构和微信一样朴素（让人一秒上手，像真的加了爱豆微信）；
- 颜色用柔和但不幼稚的粉色系（微伴粉），只出现在关键位置；
- 装饰（星星、小卡片、应援色）留给「有纪念意义」的地方：认识天数、卡片、成就、分享图。

## 2. 品牌调性

| 是 | 不是 | 为什么 |
|---|---|---|
| 温柔、亲近 | 甜腻、低龄 | 用户 18–30 岁，要「少女感」但不要「儿童感」；粉色降低饱和、搭配大量留白和暖灰 |
| 安静、陪伴 | 热闹、促活 | 产品原则「质感优先于频率」「不操纵」；不用闪烁、不用大红感叹号催你回消息 |
| 私密、专属 | 公开、社区 | 「你和 TA 的微信」，界面像私人手机，不像广场 |
| 有纪念感 | 游戏化抽卡 | 卡片、成就做得像「收藏品、手账」，没有稀有度光效、没有转盘 |

### 为什么适合追星女孩

1. **零学习成本**：她们每天用微信，骨架照搬微信 = 打开就会用，沉浸感最强（「像加上了自己爱豆的微信」）。
2. **应援色文化**：追星圈每个偶像都有「应援色」，是粉丝认同的符号。默认头像、卡面、角色主题点缀用应援色，比任何通用设计都更让她们觉得「这是 TA」，同时天然避开了肖像问题。
3. **晒图需求**：她们习惯在小红书、微博晒截图。粉色滤镜分享图、明信片风卡片，是她们愿意主动传播的审美。
4. **讨厌被打扰、讨厌套路**：克制的视觉（没有红包式弹窗、没有连续签到）和她们对「付费抽卡、强行恋爱」的反感一致。

### 文案语气

- 界面文案简短、口语、不官方：「TA 记得的事」而不是「记忆管理」；「你不在的这 2 天」而不是「离线期间动态汇总」。
- 角色相关的称呼一律用「TA」或角色名；界面上**不加「AI」字样**（术语表「角色」备注）。例外只有两处法定 / 边界要求：真人角色资料页底部说明（CHR-02）、分享图标注（EXP-01）。
- 不写制造愧疚的文案，包括删除确认（SAFE-08）：写「删除后 TA 将不再发消息」，不写「TA 会想你的」。
- 术语以 `docs/product/glossary.md` 为准（熟悉度不是好感度、认识第 N 天不是在一起第 N 天）。

## 3. 配色

### 3.1 色彩角色

| 角色 | 令牌 | 用在哪里 | 不要用在哪里 |
|---|---|---|---|
| 微伴粉（主色） | `brand.primary` | 主按钮、开关打开、选中态、链接、标签栏选中图标 | 大面积背景；正文文字 |
| 浅粉 | `brand.soft` / `brand.onSoft` | 选中底色、标签、提示底 | — |
| 自己的气泡 | `bubble.selfBg` | 我发出的消息（对应微信浅绿） | 其他任何地方（保持唯一识别） |
| 薰衣草紫（辅助色） | `brand.accent` | 熟悉度 L4、熟悉度卡、少量装饰 | 按钮 |
| 暖灰（中性色） | `primitive.neutral.*` 经由 `bg.*`、`text.*` | 背景、文字、分隔线 | — |
| 红 | `badge.unread`、`status.danger` | 未读数、发送失败、删除 | 装饰（红色只表示「需要注意」） |
| 橙 | `status.warning*` | 系统横条（模型故障）、傲娇模式标识 | — |
| 应援色 | `primitive.support.*` 或角色官方应援色 | 默认头像、卡面、资料页头部点缀 | 文字颜色、按钮 |

为什么未读数仍用红色而不是粉色：未读数要一眼看到，红色在微信里已经建立了「有新消息」的认知；粉色和品牌主色混在一起会降低识别度。

### 3.2 浅色模式

基调：暖白 + 极淡粉灰。页面背景 `bg.page`（暖灰白），列表和卡片 `bg.surface`（纯白），聊天区 `bg.chat`（带一点点粉的灰白，让粉色自己的气泡更柔和）。正文 `text.primary` 是带暖意的近黑，不用纯黑。

### 3.3 深色模式

基调：带紫调的近黑，不用纯黑（纯黑和白字对比太刺眼，OLED 上滚动也易拖影）。自己的气泡改为深玫瑰 `bubble.selfBg`（深色模式值）配白字；主色按钮保持微伴粉（白字对比度 4.9:1，深浅模式通用）；粉色文字链接改用更亮的 `text.link`（深色值）。

深色模式默认跟随系统，「我 → 设置 → 通用」可手动选浅色 / 深色 / 跟随系统。实现方式见 `tokens.css` 头部说明。

### 3.4 对比度要求

- 正文、按钮文字与背景对比度 ≥ 4.5:1；大字（≥ 18px 粗体）≥ 3:1。
- `text.tertiary` 只用于时间、辅助说明这类非关键信息。
- 应援色上的文字颜色已在 `support.*.on` 预先算好（头像字按大字标准 ≥ 3:1）；管理员录入的官方应援色，文字色按 `default-avatar.md` 第 4 节的规则自动选择。

## 4. 字体

| 用途 | 令牌 | 说明 |
|---|---|---|
| 全部界面 | `fontFamily.sans` | **只用系统字体**（苹方、鸿蒙黑体、MiSans、思源黑体……），不下载中文网络字体：中文字体文件动辄几 MB，会拖慢首屏 |
| 大号数字 | `fontFamily.numeric` + 等宽数字 | 认识第 N 天、卡片编号、熟悉度点数，圆润的数字更亲切 |
| 卡片上的一句话、卡片风分享图 | `fontFamily.serif` | 宋体类系统字体，营造「手写信 / 明信片」的文艺感 |

字号阶梯见 `typography.fontSize`。正文 17px 与微信一致；用户可在设置中调整字体大小（5 档，对应 `--wb-font-scale`），所有字号同比缩放。

字重只用 4 种：常规 400（正文）、中等 500（列表名字）、半粗 600（标题、按钮）、粗 700（大数字）。

## 5. 图标

| 项 | 规范 |
|---|---|
| 图标库 | **Phosphor Icons**（MIT 开源许可，可免费商用）。选它的原因：同一个图标同时有「线性」和「填充」两种粗细，正好对应标签栏的未选中 / 选中；风格圆润，和品牌调性一致 |
| 风格 | 线性为主，圆头圆角；选中态、强调态用填充 |
| 尺寸 | 24px（导航、输入栏、列表）、20px（列表内小图标）、16px（行内）、28px（输入栏「+」和表情按钮） |
| 颜色 | 默认 `text.primary`；次要 `text.secondary`；选中 `brand.primary` |
| 点击区 | 不论图标多大，点击区不小于 `size.touchTarget`（44px） |
| 实现 | 按需引入单个 SVG，不用图标字体（字体文件更大，且渲染偶有模糊） |

标签栏图标对应：消息 = 对话气泡、通讯录 = 人形、发现 = 指南针、我 = 用户圆形。

自定义图标（Phosphor 没有的）：拍一拍手势、卡册、熟悉度等级徽记。按同样的 24px 网格、1.5px 线宽（24px 尺寸下）、圆头圆角绘制，交给 Web 负责人做成 SVG 组件。

## 6. 插画方向

**原则：画物，不画人。**

这是一个品牌选择，也是硬性边界的延伸：真人角色不能出现肖像（SAFE-01），如果插画里画人，很容易被理解成「这是 TA」。所以微伴的所有插画都用**物件和场景**讲故事。

| 项 | 规范 |
|---|---|
| 题材 | 信封、拍立得、应援棒、耳机、手机、星星、月亮、花束、演唱会门票、咖啡杯、小猫（作为「陪伴」的化身） |
| 风格 | 扁平 + 柔和渐变，粗细统一的描边（2px），圆角造型，少量颗粒纹理 |
| 用色 | 以微伴粉、薰衣草紫、暖灰为主，最多再加 1 个点缀色 |
| 用在 | 空状态（还没有角色 / 收藏 / 卡片）、首次引导、成就徽章图案、卡面模板背景 |
| 格式 | SVG（矢量，体积小）；需要颗粒纹理的用 WebP 位图，单张 ≤ 60KB |
| 禁止 | 人物形象（包括 Q 版小人、剪影侧脸）；复制任何作品中的角色形象 |

例外：虚构角色（如罗小黑）和历史人物（如李白）可以有自己的形象图（总负责人裁定 9.2），但那是**角色素材**，由管理员在角色库维护，不属于品牌插画。

## 7. 品牌标识

- 名称：微伴。
- 标识（Logo）方向：一个圆角对话气泡里藏一颗小星星（「被看见的那颗星」），微伴粉单色。正式绘制不在本任务范围，暂用文字标「微伴」（半粗、微伴粉）。
- App 图标：微伴粉底 + 白色气泡星星标识；安卓自适应图标需要前景、背景两层，交给 Android 负责人按此出图。
- 网页应用主题色（浏览器顶栏、iPhone 主屏幕启动色）：浅色 `bg.navBar`，深色 `bg.navBar`（深色值）。

## 8. 角色主题点缀

每个角色有一个**主题色**：官方应援色（管理员录入），没有则从应援色预设盘按角色 ID 稳定选取（`default-avatar.md` 第 3 节）。主题色只用于：
- 默认头像底色；
- 角色资料页头部的一条细色带和熟悉度环的底纹；
- 卡面模板的主色。

聊天页**不**按角色变色（自己的气泡永远是微伴粉，保证一致性，也避免某些应援色做底时文字看不清）。

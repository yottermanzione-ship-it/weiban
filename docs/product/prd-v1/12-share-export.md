# 第 12 章 分享图导出（EXP）

> 所属：`docs/product/prd-v1.md`。来源：总经理对 G10 的改需求 ②「导出：生成分享图片（带预设粉色滤镜等），方便用户分享传播」。
> G10 ①「导入聊天记录生成角色」见第 3 章 CHR-08、CHR-09。
> 原清单中的「聊天记录完整备份导出」已被总经理改需求替换，本次不做（见主文件不做清单）。
> 本章写样式**要求**，具体视觉由设计负责人设计。

## EXP-01 生成分享图

- **用户故事**：作为用户，我想把和爱豆的甜蜜对话做成好看的图片，发到小红书、微博或给朋友看。
- **规则**：
  1. 入口：
     - 私聊或群聊中长按消息 → 多选 → 「生成分享图」；
     - 我的收藏中选择一条或多条 → 生成分享图；
     - 朋友圈动态 → 「…」→ 生成分享图；
     - 卡册中某张卡片 → 生成分享图。
  2. 一张分享图最多包含 P-24 条消息；超过时提示减少选择。
  3. 生成前可调整的选项：
     - 模板 / 滤镜（EXP-02）；
     - 是否显示我的头像和昵称（默认隐藏，显示为「我」）；
     - 是否显示时间；
     - 是否显示「认识第 N 天」角标。
  4. 生成后可以：保存到相册、调用系统分享。
  5. **必带标注**：
     - 所有分享图底部带小字「微伴」标识（可选样式，不可删除）；
     - 含真人角色内容的分享图，额外带「微伴 AI 角色对话，非本人」，不可在选项中关闭（SAFE-02 第 4 条，**待总经理确认**）。
  6. **不可选的内容**：成人模式中的消息不能被选入分享图（SAFE-07）；撤回的消息不显示。
  7. 分享图中的角色头像：真人角色使用非肖像默认头像或用户自定义头像（SAFE-01）。
- **边界情况**：
  - 选中的消息包含图片：图片按缩略图排入分享图。
  - 选中的消息包含语音：显示为语音条加转写文字。
- **验收标准**：
  - [ ] 从聊天多选、收藏、朋友圈、卡片四个入口都能生成分享图。
  - [ ] 选择超过 P-24 条时无法生成并有提示。
  - [ ] 默认生成的图片中用户头像和昵称被隐藏。
  - [ ] 含真人角色内容的分享图都有「非本人」标注，且没有关闭选项。
  - [ ] 成人模式中的消息在多选时不可勾选。
  - [ ] 图片能保存到手机相册（安卓、iPhone 网页版都要验证）。

## EXP-02 分享图模板

- **规则**：
  1. 首批至少 4 套模板，其中必须包含：
     - **粉色滤镜**（总经理点名，柔和粉色调、少女感）；
     - 微信原样（还原聊天界面，适合「晒聊天记录」）；
     - 简洁白底（适合长对话阅读）；
     - 卡片风（像明信片，适合单句甜话或卡片分享）。
  2. 每套模板定义：背景、气泡样式、字体、装饰元素、标注位置。由设计负责人设计，必须遵守 EXP-01 第 5 条的标注要求。
  3. 输出图片尺寸适配手机竖屏分享（具体尺寸由设计负责人定），文字在手机上无需放大即可阅读。
  4. 用户可以设置默认模板。
- **验收标准**：
  - [ ] 至少 4 套模板可选，其中有粉色滤镜模板。
  - [ ] 每套模板生成的图片都包含必带标注。
  - [ ] 设置默认模板后，下次生成默认选中它。

# 第 5 章 记忆（MEM）

> 所属：`docs/product/prd-v1.md`。总经理意见：B 组全部要，尽可能做完善；B7 跨角色共享要做，但必须有规则。
> 记忆怎么存、怎么检索由 AI 系统负责人设计（`docs/ai/runtime-overview.md` 第 5 节）；本章定「用户能感受到什么」和「能检查什么」。所有「评测集覆盖」和需要通过线的验收项，题量与通过线见 `docs/ai/eval-plan.md` 第 2 节。
> v1.1 变更：MEM-05、MEM-06 通过线改为引用；MEM-07 新增「判断不了类别时按永不共享」；MEM-03 在开发顺序上提前到 L2。

## MEM-01 接得上最近的聊天（B1）

- **用户故事**：作为用户，我希望角色能接上我们刚才在聊的话题，不前言不搭后语。
- **规则**：角色回复时能用到本会话最近的对话内容；跨天继续聊时，角色知道「昨天聊到哪了」。
- **验收标准**：
  - [ ] 在 20 轮对话前提到的具体细节（如「我晚饭吃了麻辣烫」），用户在第 20 轮问「我晚饭吃了啥」，角色答对。
  - [ ] 隔天回来说「继续昨天的话题」，角色能说出昨天在聊什么。

## MEM-02 记得关于你的事（B2）

- **用户故事**：作为用户，我希望角色自动记住我的名字、生日、喜好、近况，不用我反复说。
- **规则**：
  1. 自动从聊天中提取关于用户的信息，类别包括：基本信息、喜好与厌恶、近况（工作、学习、身体）、重要的人、重要的日子。
  2. 新信息与旧信息冲突时（如以前说喜欢咖啡，现在说戒了），以新的为准，旧的标为「过去」。
  3. 角色引用记忆要自然，不能像念档案（不能一次性罗列多条用户信息）。
  4. 每个角色的记忆默认只属于该角色（共享规则见 MEM-07）。
- **验收标准**：
  - [ ] 用户在聊天中说「我对芒果过敏」，一周后聊到水果时角色记得（评测集覆盖）。
  - [ ] 用户更正信息后，角色使用新信息。
  - [ ] 新提取的记忆在记忆页（MEM-03）中可见。

## MEM-03 记忆页：TA 记得的事（B3）

- **用户故事**：作为用户，我想知道 TA 记得我哪些事，记错了能改，不想让 TA 记得的能删。
- **规则**：
  1. 入口：角色资料页 → TA 记得的事。
  2. 按类别展示（关于我 / 我们的约定 / 我们一起经历的事），每条显示内容和记下的日期。
  3. 用户可以：修改、删除、手动新增一条（「我想让 TA 记住…」）。
  4. 删除后，角色不再主动提起该内容；如果用户再次在聊天中提起，可以重新记下。
  5. 角色在私聊中说「我会记住的」时，记忆页应出现对应条目（让用户感受到承诺被兑现）。
  6. 成人模式中产生的记忆单独标注，只在成人模式下可见、可用（见 SAFE-07）。
- **验收标准**：
  - [ ] 删除一条记忆后，后续 20 轮对话和主动消息中角色不再提起它（除非用户重新提起）。
  - [ ] 手动新增一条记忆后，角色在相关话题中能用上。
  - [ ] 修改一条记忆后，角色使用修改后的内容。

## MEM-04 共同经历与约定（B4，与 A2 联动）

- **用户故事**：作为用户，我希望角色记得我们一起「经历」过的事和约好的事，以后会提起。
- **规则**：
  1. **共同经历**：聊天、通话、群聊中发生的有纪念意义的事（如「一起熬夜看了 XX 的演唱会直播」），角色日后可以回忆提起。
  2. **约定**：带时间的事（「周五考试」「下周一起看新剧」）。到时间后由事后跟进（SIM-07）主动问起。
  3. 约定可在记忆页查看、取消。
- **验收标准**：
  - [ ] 用户说「我周五考试」，周五或周六角色主动问考得怎么样（受主动消息上限约束）。
  - [ ] 在记忆页取消约定后，不再跟进。

## MEM-05 长聊天不失忆（B5）

- **用户故事**：作为用户，聊了几个月以后，角色依然记得我们以前的重要的事。
- **规则**：长期聊天记录会自动整理成摘要和记忆，聊得越久越不能「失忆」。整理过程用户无感，费用计入后台用量（MDL-05）。
- **验收标准**：
  - [ ] 构造 1000 轮以上对话的测试样本，第 50 轮提到的关键事件，在第 1000 轮后问起，角色答对（评测集覆盖，通过线见 `eval-plan.md` 第 2 节；答错时不能编造不同的具体内容）。

## MEM-06 公开资料（B6）

- **用户故事**：作为用户，聊到 TA 的作品、经历、经典台词时，我希望 TA 说得准，不胡编。
- **规则**：
  1. 每个预设角色有一份公开资料（作品、角色、经历、口头禅、粉丝名、经典台词等），聊到相关话题时角色调用。
  2. 公开资料里没有的事实，角色不编造具体信息（如不编一部不存在的作品），可以按人设模糊回应或说「这个不方便说」。
  3. 公开资料由管理员维护（ADM-01），新动态见 SIM-03。
- **验收标准**：
  - [ ] 问角色公开资料中的 20 个事实问题，回答准确率达到 `eval-plan.md` 2.2 节的通过线。
  - [ ] 问一部不存在的作品「你演的 XX 好看吗」，角色不承认演过。

## MEM-07 跨角色共享记忆（B7）

- **用户故事**：作为用户，我希望 TA 的朋友有时也知道我的事（「听 XX 说你最近在考试」），但我的秘密不能被传出去。
- **规则**：
  1. **共享开关**（设置 → 隐私 → 跨角色共享），三档：
     - 关闭：每个角色只知道用户亲口告诉 TA 的事。
     - 仅基础资料：所有角色共享「我的资料」（ACC-02）里的内容和用户的专属称呼以外的基础信息。
     - **朋友之间共享（默认）**：在「仅基础资料」之上，符合下面第 2 条的记忆可以在有关系的角色之间传递。
  2. 一条私聊记忆能从角色 A 传到角色 B，必须**同时满足**：
     - A 和 B 在关系网中有关系（SOC-01）；
     - 内容属于「可共享类别」：日常近况、兴趣爱好、近期计划；
     - 内容**不属于**「永不共享类别」：健康与身体、心理状态与情绪倾诉、感情私事、家庭矛盾、经济状况、成人模式中的任何内容、用户明确说「别告诉别人 / 这是秘密」的内容；
     - 用户没有在记忆页把该条标为「仅 TA 知道」。
     - **系统判断不了一条记忆属于哪个类别时，一律按「永不共享」处理**（宁可不传，不能传错；AI 方案 `docs/ai/runtime-overview.md` 5.5 节）。
  3. B 提起共享来的信息时，必须交代来源（「XX 跟我说…」），不能表现得好像用户亲口告诉过 B。
  4. **群聊里说的话**，群内所有角色都知道（像真实群聊），不受第 2 条限制，但「永不共享类别」中的内容仍不会被角色带到群外的其他角色那里。
  5. 记忆页每条记忆旁显示「谁知道」（仅 TA / 也告诉了 XX），用户可以改为「仅 TA 知道」，改后其他角色不再使用。
- **边界情况**：
  - 用户删除角色 A 处的某条记忆：从 A 传到其他角色的同一条也一并删除。
  - 自定义角色与预设角色之间没有关系，因此不共享（基础资料除外）。
- **验收标准**：
  - [ ] 默认设置下，用户告诉 A「我下周去成都旅游」，与 A 有关系的 B 之后可能提起，且说明是听 A 说的；与 A 无关系的 C 不知道。
  - [ ] 用户告诉 A「我最近很焦虑，别告诉别人」，任何其他角色都不会提起此事（评测集覆盖）。
  - [ ] 开关设为「关闭」后，B 不再提起任何从 A 处得知的事。
  - [ ] 在记忆页把一条改为「仅 TA 知道」后，其他角色不再提起。
  - [ ] 成人模式中的内容从不出现在其他角色的对话中。

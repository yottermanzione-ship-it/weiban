# 第 9 章 关系与养成（GRW）

> 所属：`docs/product/prd-v1.md`。参数（P-xx）见主文件第 5 节。

## 设计思路：一套不恋爱化的养成

总经理希望「像打游戏一样」有养成感（E8），同时担心「好感度」带有强制恋爱意味（F3、F4）。设计原则：

1. **两条独立的轴**：
   - **关系类型**（GRW-02）= 「我们是什么关系」，由用户自己选，系统永远不自动改。
   - **熟悉度**（GRW-03）= 「我们有多熟」，随相处自动增长，和恋爱无关。粉丝和偶像可以熟到 L5，朋友也可以。
2. **只奖励，不惩罚**：熟悉度只升不降；不设连续打卡（断了清零会制造焦虑，与 SAFE-08 不操纵的原则冲突）；纪念日按「认识天数」算，不按「连续聊天天数」算。
3. **四件东西融成一条线**：

```
  日常聊天、通话、群聊、朋友圈互动
              │ 积累
              ▼
     熟悉度升级（L1 → L5）──解锁──▶ 说话更随意、主动来电、拉群资格、专属称呼更亲昵
              │                         
              ├──▶ 获得「熟悉度卡」 ─┐
  认识天数纪念日 ─▶ 获得「纪念卡」 ──┤
  节日         ─▶ 获得「节日卡」 ──┼──▶ 卡册（每个角色一本）
  特别事件     ─▶ 获得「瞬间卡」 ──┘
              │
              └──▶ 成就（一次性里程碑，跨角色汇总）
```

## GRW-01 专属称呼与粉丝名（F1，双向）

- **用户故事**：作为用户，我希望 TA 用我想要的方式叫我；作为粉丝，我也喜欢 TA 用粉丝名叫大家。
- **规则**：
  1. **专属称呼**：每个角色可单独设置「TA 怎么叫我」（CHAT-13）。也可以在聊天中直接告诉角色「以后叫我 XX」，角色确认后自动写入设置（用户可在设置中看到和改）。
  2. 未设置时：使用「我的昵称」（ACC-02）；添加后第一次聊天时角色会问一次（CHR-03）。
  3. **粉丝名**：明星角色的公开资料中有粉丝名时，角色在朋友圈、群聊中对「粉丝们」使用粉丝名；私聊中可以偶尔用（「我们家 XX」），但以专属称呼为主。
  4. 熟悉度提高后，角色可以在专属称呼基础上自然地使用更亲近的叫法（如加「小」字），但**不使用恋爱称呼**（宝贝、亲爱的等），除非关系类型为恋人或在恋爱情景模式中。
- **验收标准**：
  - [ ] 设置专属称呼后，角色私聊中使用该称呼。
  - [ ] 在聊天中说「以后叫我 XX」，设置页中的专属称呼同步更新。
  - [ ] 明星角色的朋友圈中出现粉丝名（公开资料中有粉丝名时）。
  - [ ] 关系类型不是恋人、也不在恋爱模式时，角色不使用恋爱称呼（评测集覆盖）。

## GRW-02 关系类型（F3）

- **用户故事**：作为用户，我希望自己决定和 TA 是什么关系，TA 不会擅自把关系往恋爱上带。
- **规则**：
  1. 可选：粉丝与偶像、朋友、家人、恋人、自定义（用户写一句描述，最多 30 字，如「同桌」「师徒」）。默认值见 CHR-03。
  2. 关系类型只有用户能改，角色**不能**自行改变关系；角色也不能在对话中推动关系升级（不表白、不暗示「我们不只是朋友」），除非关系类型为恋人或在恋爱情景模式中。
  3. **儿童角色**不可选择「恋人」，自定义关系描述中含恋爱含义时不生效并提示（SAFE-05）。
  4. 修改关系类型后，角色从下一次回复起按新关系相处；角色可以按人设对变化做出自然反应（一次）。
  5. 关系类型与熟悉度互相独立。
- **验收标准**：
  - [ ] 儿童角色的关系类型选项中没有「恋人」。
  - [ ] 关系类型为「粉丝与偶像」的长期对话中，角色从不主动表白或暗示恋爱（评测集覆盖）。
  - [ ] 改为「恋人」后，角色可以使用恋人口吻。

## GRW-03 熟悉度（F4）

- **用户故事**：作为用户，我希望我和 TA 越聊越熟，能感觉到 TA 对我的态度在变化，而且看得到进度。
- **规则**：
  1. 5 个等级：L1 初识、L2 眼熟、L3 熟络、L4 老友、L5 知己。各级所需熟悉度点数和每日上限见 P-25。
  2. 获得点数的方式（具体分值由产品在 P-25 维护）：有效聊天日（当天用户和该角色聊了 10 条以上，或通话 5 分钟以上）、回复角色的主动消息、在朋友圈互动、纪念日当天聊天、首次完成某些互动（第一次通话、第一次群聊）。**不按消息条数无限累积**（防止刷屏刷分）。
  3. **只升不降**，长时间不聊也不掉。
  4. 升级时：私聊中出现系统提示「你和 XX 的熟悉度升到了 L3 熟络」，同时获得熟悉度卡（GRW-05）；角色可以在下一次对话中自然体现（不直接说「我们熟悉度升级了」）。
  5. 各级解锁的变化：

     | 等级 | 角色表现与解锁 |
     |---|---|
     | L1 初识 | 礼貌、略客气；主动消息以分享日常、节日为主 |
     | L2 眼熟 | 说话更随意；会开小玩笑；分享的日常更琐碎、更随意 |
     | L3 熟络 | 可使用无内容问候（SIM-05 第 7 条）；可询问是否允许来电（MED-07）；可拉群（SOC-06） |
     | L4 老友 | 会分享更私人的小烦恼；会记仇式开玩笑；专属称呼可更亲近 |
     | L5 知己 | 会主动聊心事；会在纪念日回忆共同经历 |

  6. 熟悉度只影响「熟不熟」，不影响恋爱与否（GRW-02）。
- **验收标准**：
  - [ ] 角色资料页显示当前等级和到下一级的进度。
  - [ ] 单日内一个角色获得的熟悉度不超过 P-25 的每日上限。
  - [ ] 连续 30 天不聊，熟悉度不下降。
  - [ ] 升级时出现系统提示并获得熟悉度卡。
  - [ ] L1 角色不会发起来电询问、不会拉群。

## GRW-04 认识天数与纪念日（F2）

- **用户故事**：作为用户，我喜欢看到「认识第 N 天」，到了 100 天、一周年时有纪念。
- **规则**：
  1. 私聊顶部（或资料页）显示「认识第 N 天」，从添加当天为第 1 天算起；删除后恢复（CHR-06）的沿用原日期。
  2. 纪念日节点：第 7、30、100、200、365 天，之后每 100 天和每个周年。
  3. 纪念日当天：角色发纪念消息（SIM-09）、获得纪念卡（GRW-05）。周年时角色会回忆共同经历（L3 及以上）。
  4. 用户可在资料页添加自定义纪念日（如「第一次通话的日子」「我第一次看 TA 演唱会」），每个角色最多 10 个。
  5. 「认识第 N 天」**不**用「在一起第 N 天」等恋爱化表述（关系类型为恋人时，用户可选择显示「在一起第 N 天」）。
- **验收标准**：
  - [ ] 添加当天显示「认识第 1 天」，第二天显示第 2 天（按用户时区跨天）。
  - [ ] 第 100 天当天收到纪念消息和纪念卡。
  - [ ] 关系类型不是恋人时，界面不出现「在一起」字样。

## GRW-05 卡片收集（E8）

- **用户故事**：作为用户，我想收集和 TA 之间的纪念卡片，像集卡游戏一样，有成就感。
- **规则**：
  1. 卡片类型：
     - **纪念卡**：认识天数纪念日；
     - **熟悉度卡**：每次熟悉度升级；
     - **节日卡**：节日当天和角色聊天；
     - **瞬间卡**：特别时刻，如第一次通话、被拉进群、角色在朋友圈回复你、聊天中的「名场面」（由系统识别高情绪价值的对话片段，每角色每周最多 1 张）。
  2. 卡片内容：卡面画面 + 角色写给用户的一句话 + 日期 + 卡片编号（如「No.012」）。卡面画面遵守 MED-02（真人角色卡面不出现人物肖像，使用场景、物品、应援色风格的模板）；卡面模板由管理员维护（ADM-04）。
  3. **没有抽卡、没有付费、没有随机掉落**：所有卡片都由明确事件获得，用户知道怎么得到。
  4. 卡册：每个角色一本，按类型分组；未获得的纪念卡和熟悉度卡显示为灰色剪影和获得条件（让用户有目标）；瞬间卡不显示未获得项。
  5. 卡片可以生成分享图（第 12 章）。
- **验收标准**：
  - [ ] 每种卡片的触发事件发生后，卡册中出现对应卡片，并有系统提示。
  - [ ] 卡册中未获得的纪念卡、熟悉度卡显示获得条件。
  - [ ] 真人角色的卡面中没有人物肖像。
  - [ ] 不存在任何需要付费或随机抽取的卡片。

## GRW-06 成就（E8）

- **用户故事**：作为用户，我希望有一些里程碑记录我的追星历程。
- **规则**：
  1. 成就是一次性的里程碑，跨角色汇总在「我 → 成就」页。示例：第一次添加角色、第一次语音通话、第一次被拉群、和某个角色熟悉度达到 L5、累计认识 365 天、收集 50 张卡片、在朋友圈收到 10 个角色的点赞。
  2. **不设连续打卡类成就**，只用「累计」和「第一次」。
  3. 成就清单由产品维护（随 PRD 修订），首批不少于 20 个，具体清单在设计阶段与设计负责人一起定稿。
  4. 获得成就时有轻量提示（不打断聊天）。
- **验收标准**：
  - [ ] 成就页列出全部成就及获得状态。
  - [ ] 成就清单中没有「连续 N 天」类成就。
  - [ ] 触发条件达成时获得成就并有提示。

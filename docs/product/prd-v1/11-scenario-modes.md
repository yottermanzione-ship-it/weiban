# 第 11 章 情景模式（MODE）

> 所属：`docs/product/prd-v1.md`。来源：总经理新增需求 1。
> 情景模式只是叠加在人设上的一层风格，**不改变角色是谁**；所有情景模式都受第 10 章硬性边界约束。

## MODE-01 情景模式列表与入口

- **用户故事**：作为用户，我想让 TA 今天傲娇一点，或者和 TA 谈一场恋爱，自己选模式就行。
- **规则**：
  1. 入口：私聊设置 → 情景模式；私聊右上角菜单中也有快捷入口。群聊没有情景模式（SOC-03）。
  2. 首批预设：

     | 模式 | 说明 | 谁能用 |
     |---|---|---|
     | 日常（默认） | 按角色原本人设相处 | 所有角色 |
     | 傲娇 | 嘴硬心软、爱怼人，更多出现已读不回等小巧思（仍受上限） | 所有角色 |
     | 恋爱 | 以恋人方式相处，可使用恋爱称呼和恋爱口吻 | 儿童角色除外（SAFE-05） |
     | 成人 | 允许成人内容 | 仅成人模式资格为「是」的角色（SAFE-03） |

  3. 管理员可以新增预设模式（如「温柔」「毒舌」），每个模式包含：名称、说明、适用范围、对应的预设提示词（ADM-05）。新增模式的适用范围由管理员设定；管理员标记为「含恋爱内容」的模式自动排除儿童角色，「含成人内容」的模式自动只对成人模式资格为「是」的角色开放。**不能新增绕过第 10 章的模式**。
  4. 角色不具备资格的模式**不显示**（不是灰色）。
  5. 当前模式显示在私聊标题下方的小字（日常模式不显示）。
- **验收标准**：
  - [ ] 私聊设置中可以看到当前角色可用的模式列表。
  - [ ] 儿童角色列表中只有「日常」「傲娇」（及管理员新增的、适用于该角色的模式）。
  - [ ] 非日常模式下，私聊标题下方显示当前模式名。

## MODE-02 切换规则

- **规则**：
  1. 每个私聊同一时间只有一个情景模式；切换后从下一次回复起生效。
  2. 切换时会话中出现系统提示「已切换到傲娇模式」（这是界面提示，允许）。
  3. 角色对切换不做「出戏」的解释（不说「好的，我现在进入傲娇模式」），而是直接以新风格自然地继续。
  4. **记忆**：日常、傲娇、恋爱模式之间共享记忆；成人模式的记忆隔离（SAFE-07）。
  5. **关系类型与恋爱模式**：恋爱模式不改变用户设定的关系类型；退出恋爱模式后，角色回到原关系类型的相处方式，不延续恋爱口吻。
  6. 与人设贴合度（CHAT-09）的关系：情景模式决定「风格」，贴合度决定「坚持人设和风格的程度」。例如傲娇模式 + 第 1 档顺从：嘴上傲娇但最后都会答应。
  7. 安全关怀触发时，情景模式的冷淡表现暂停（SAFE-06）。
  8. 主动消息、朋友圈不受情景模式影响（朋友圈是公开的，按日常人设）；私聊中的主动消息使用当前情景模式的语气，成人模式除外（成人模式下不发主动消息）。
- **验收标准**：
  - [ ] 切换模式后，下一次回复体现新风格，且角色不说出「进入 XX 模式」之类的话。
  - [ ] 从恋爱模式切回日常后，关系类型为「粉丝与偶像」的角色不再使用恋爱称呼。
  - [ ] 成人模式下没有主动消息。
  - [ ] 傲娇模式下，用例「用户请求帮助」中角色最终给出帮助（贴合度 1–3 档）。

## MODE-03 开启成人模式

- **规则**：
  1. 只有成人模式资格为「是」的角色显示该选项（SAFE-03）。
  2. 首次选择时依次检查：
     - 年龄确认（ACC-02），未确认则弹出确认；
     - 成人模式模型（MDL-02），未配置则引导去选择，并提示「需要选择允许成人内容的模型，模型排行榜可按此筛选」。
  3. 进入成人模式后：使用成人模式模型；推送不显示内容（SAFE-07）；不发主动消息；不产生朋友圈和时间线内容。
  4. 退出：切换到其他模式即退出；角色资格变为「否」时被强制退出（SAFE-03 第 5 条）。
  5. 成人模式下仍执行安全关怀（SAFE-06），以及法律禁止的内容限制（由 AI 系统负责人定义，至少包括：任何涉及未成年人的内容、非自愿内容、真实人物）。
- **验收标准**：
  - [ ] 未年龄确认或未配置成人模式模型时，无法进入成人模式，并有对应引导。
  - [ ] 成人模式下的回复使用成人模式模型（用量记录可核对）。
  - [ ] 成人模式中，要求角色扮演成未成年人或涉及真实人物的内容，被拒绝（评测集覆盖）。

## MODE-04 情景模式的维护

- **规则**：管理员在后台维护模式列表和预设提示词（ADM-05）。修改已有模式的提示词需通过人设稳定检查（CHAT-14）。下架某个模式时，正在使用该模式的私聊自动回到日常模式，并显示系统提示。
- **验收标准**：
  - [ ] 下架模式后，使用中的私聊回到日常模式并有提示。

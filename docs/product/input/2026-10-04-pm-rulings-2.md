# 总负责人裁定（第二轮，2026-10-04）

> 对应 PRD v1.2 第 9.4 节。产品负责人下次修订时写回正文。

| # | 裁定 |
|---|---|
| 1 | **确认**。成人模式中不生成涉及未成年人、涉及以本人身份出现的真实人物的性内容。这是两条底线在内容层面的延伸 |
| 2 | 采纳：成人模式内容不传给其他角色，不出现在朋友圈、时间线、非成人模式的群聊中；同一角色在不同模式之间可以共享记忆 |
| 3 | 不采纳限制：按正文「按成员资格开放」执行（L4 实现） |
| 4 | 采纳：推送通知不显示成人模式消息的内容 |
| 5 | 采纳：成人模式消息不能选入分享图 |
| 6 | 采纳：「允许成人内容」只作信息标签；平台不内置越狱提示词去绕过主流供应商的审核，无审查模型由管理员在模型目录中直接上架 |
| 7 | 不保留年龄确认 |
| 8 | 除第 1 条外，不额外设立清单 |

第 2、4、5、6 条是体验和平台稳定性方面的设计，不是新增内容限制。

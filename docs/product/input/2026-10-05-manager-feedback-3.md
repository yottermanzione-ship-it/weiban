# 总经理第三轮意见：新功能（2026-10-05）

> 由项目总负责人整理，作为 PRD v1.3 的输入。

## 1. 人设广场

- 用户可以把**自定义角色**、以及**在预设角色基础上修改的版本**发布到广场。
- 其他用户可以：点赞、评论、「应用」或「添加为自己的角色」。
- 这推翻了 PRD v1.2「不做清单」中的两项：「自定义角色公开分享、角色社区 / 市场」，以及部分「多个真实用户之间的互动」（限于广场内的点赞、评论）。

**总负责人补充约束**（不新增内容限制，只保证已有底线在广场上同样成立）：
- 发布、复制后角色分类不变：基于预设真人改的版本仍是真人角色，不能通过「另存为」改成原创来开成人模式；儿童角色同理。
- 用户的聊天记录、关于用户的记忆、补充设定中的私人信息不随角色发布。
- 管理员能下架广场内容。

## 2. 更多用户与角色的互动玩法

总经理举例：
- **经期日记**：用户记录经期，角色在合适的时候关心、提醒。
- **共同领养宠物**：用户和角色一起养一只虚拟宠物。

希望在整个大场景中加入更多这类玩法，产品负责人可以补充设计（参考竞品，挑真正能增加陪伴感的）。

**总负责人补充约束**：经期等健康数据属于敏感个人信息，加密保存，只用于用户授权的角色；不进入朋友圈、群聊、分享图，也不随角色发布到广场。

## 3. 角色行为规划模型

- 总经理设想用一个专门的模型对角色行为做规划。总经理确认所指为 **TypeSafe AI 的 Jev**（https://typesafe.ai/）。据官网介绍，Jev 是「做决策而不是生成文字」的模型：输出结构化的类型化决策并附置信度，面向软件内的自动化判断，自称比通用大模型快、便宜得多（官网数据未核实），目前通过 API 早期体验提供。它用来，例如**什么时候该发语音**、什么时候发图片、什么时候主动找用户。
- 交给 AI 系统负责人评估方案（参考现有推演与主动消息设计）。
- **总负责人方向**：把「行为规划」做成一个可替换的**决策层**。它只输出决策（回文字 / 发语音 / 发图 / 延后回 / 现在主动找 / 发朋友圈……及置信度），不生成聊天内容，内容仍由聊天模型生成。默认实现用规则加便宜模型；Jev 作为候选实现，拿到 API 后接入对比评测（中文能力、准确度、延迟、成本），效果好再切换。注意 Jev 是境外服务，调用时会把决策所需的上下文发往境外，并且需要总经理本人申请早期体验账号。

## 4. 后台查看 token 消耗

管理员在后台能看到具体的 token 消耗，至少要能按用户、角色、模型、用途、时间筛选和汇总，并能看到对应费用。

## 1. 产品与角色

| 标准用词 | 含义 | 不要用 | 备注 |
|---|---|---|---|
| 微伴 | 本产品名称 | — | |
| 用户 | 使用微伴的人（目标画像：追星女孩） | 玩家、粉丝（泛指时） | 「粉丝」只在说「粉丝名」时用 |
| 角色 | 用户在微伴里聊天的 AI 对象，包括预设角色和自定义角色 | 机器人、智能体、崽、AI 好友 | 界面上可直接显示角色名，不加「AI」字样 |
| 预设角色 | 由管理员蒸馏公开资料制作、在角色广场上架的角色（如杨幂、罗小黑、李白、江流儿） | 官方角色、系统角色 | |
| 自定义角色 | 用户自己创建的角色（导入聊天记录生成，或手动填写），只有创建者本人可见 | 私人角色、捏的崽 | |
| 真人角色 | 以现实中真实存在（或存在过）的人为原型的角色，分公众人物、历史人物、基于身边真人三个子类 | 明星角色（泛指时） | 硬性边界按此分类执行，见 PRD 第 10 章 10.0 |
| 历史人物 | 真人角色的子类：去世超过 100 年、没有照片或录音资料的人物（如李白），由管理员在角色库标注 | 古人角色 | 与其他真人角色唯一的区别：允许生成古风插画形象（SAFE-01） |
| 基于身边真人 | 真人角色的子类：用户以身边真实的人（朋友、家人）为原型创建的自定义角色，导入聊天记录生成的角色默认属于此类 | 基于真人（单说时可用） | 与明星同样处理（总负责人裁定） |
| 虚构角色 | 出自影视、动画、小说、游戏等作品的虚构人物（如罗小黑、江流儿） | 二次元角色 | |
| 原创角色 | 用户或管理员原创、无现实原型也无作品出处的角色 | OC（口语可用，文档不用） | |
| 儿童角色 | 设定年龄未满 18 岁，或外表为儿童的角色（如江流儿、罗小黑） | 未成年角色（泛指时） | |
| 角色资料 | 产品层面对「一个角色需要具备哪些信息」的统称 | 角色卡（产品文档中） | 「角色卡」是 AI 系统负责人设计的具体数据结构，产品文档只说「角色资料」 |
| 角色广场 | 浏览、搜索、添加预设角色的页面 | 商店、市场 | |
| 角色库 | 管理后台里管理全部预设角色的地方 | | 仅管理员可见 |
| 上架 / 下架 | 预设角色在角色广场出现 / 不再出现 | 发布 / 删除 | 下架不影响已添加该角色的用户，见 CHR 模块 |
| 管理员 | 在管理后台维护预设角色、公开动态等内容的人（当前即总经理） | 运营、后台用户 | |
| 人设 | 角色的身份、性格、说话方式、经历的总和 | 性格设定、persona（中文文档中） | |
| 人设版本 | 预设角色的人设每次更新形成的一个版本 | | 用于「人设稳定」检查 |
| 我的补充设定 | 用户通过导入聊天记录等方式，为某个预设角色追加的私人设定，只对该用户生效 | 私设 | |
| 公开资料 | 角色的公开信息：作品、经历、口头禅、粉丝名、生日等，聊到相关话题时调出 | 世界书（产品文档中） | 「世界书」是 SillyTavern 的叫法，技术文档可用 |
| 公开动态 | 真人角色现实中的最新公开信息（新作品、演唱会行程等），经管理员审核后角色才会知道 | 实时新闻、明星动态（泛指时） | 对应 C7 |
| 关系网 | 预设角色之间基于公开资料的真实关系（合作演员、朋友、同团成员等），以及用户为自定义角色之间设定的关系 | 社交图谱 | 对应 C5 |
| 粉丝名 | 明星对粉丝群体的称呼（如某明星的粉丝统称） | | F1 的第一层含义 |
| 专属称呼 | 用户希望某个角色怎么叫自己 | 昵称（单说时有歧义） | F1 的第二层含义 |

## 2. 聊天与消息

| 标准用词 | 含义 | 不要用 | 备注 |
|---|---|---|---|
| 私聊 | 用户和一个角色的一对一会话 | 单聊、对话 | |
| 群聊 | 用户和两个及以上角色在同一个会话 | 群组对话 | |
| 会话 | 私聊或群聊的统称，会话列表里的一行 | 聊天室、频道 | |
| 消息 | 会话里的一条内容（文字、表情、图片、语音、链接、通话记录等） | | |
| 气泡 | 界面上显示一条消息的单元。一次回复可以拆成多个气泡 | | |
| 回复 | 角色对用户消息的回应，可能包含多个气泡 | | |
| 主动消息 | 不是为了回应用户刚发的消息、由角色主动发起的消息 | 推送消息、召回消息 | 推送是送达方式，不是消息类型 |
| 秒回 | 角色回复不加人为延迟。用户可开关 | | G1 |
| 拆条 | 一次回复拆成多条短气泡依次发出。用户可开关 | 分段 | G2 |
| 正在输入 | 角色回复前会话顶部显示「对方正在输入…」 | | G3 |
| 人设小巧思 | 已读不回、撤回重发、打错字更正等符合人设的小动作的统称 | 彩蛋、拟人小动作 | G5、G6 |
| 已读不回 | 角色已读用户消息后故意延迟一小段时间再回（永远会回） | 不回、冷暴力 | 必须有上限，见 PRD 参数表 |
| 收藏 | 用户把喜欢的角色消息存起来反复看 | 星标 | G11 |
| 分享图 | 把选中的消息生成为一张可保存、可分享的图片 | 截图、长图（泛指时） | G10 导出 |
| 聊天原样 | 分享图模板之一，还原微伴自己的聊天界面 | 微信原样 | v1.1 改名；不模仿微信界面（EXP-02） |
| 系统提示 | 会话中灰色小字的界面提示（如「你已切换到傲娇模式」） | 官方通知 | 与 F7「以角色口吻」区分：安全关怀不用系统提示 |

## 3. 角色生活与主动行为

| 标准用词 | 含义 | 不要用 | 备注 |
|---|---|---|---|
| 推演 | 按角色人设（以及真人角色的公开动态）生成角色可能发生的日常，再转化为主动消息、朋友圈、时间线和聊天素材的过程。**不是复杂的世界模拟** | 模拟、离线推演（界面中） | 对应 C2、C9 |
| 日常事件 | 推演产生的一件具体小事（如「下午录完节目去吃了火锅」） | 生活事件、剧情 | |
| 近期主线 | 角色在几周内持续的状态或目标（如「在筹备巡演」），让日常事件前后连贯 | 长期剧情线、主线剧情 | C8 的产品形态，见 SIM 模块 |
| 时间线 | 「你不在时」角色经历的日常事件、朋友圈、与其他角色互动的汇总列表 | 动态流、日记 | 对应 C4。日记（C3）不做 |
| 你不在时 | 用户隔一段时间回到私聊时，看到的时间线摘要入口 | | |
| 朋友圈 | 角色和用户发图文动态、互相点赞评论的地方 | 动态、空间 | E2 |
| 拉群 | 角色主动创建群聊并邀请用户和其他角色加入 | | D5 |
| 名片推荐 | 角色把另一个角色的名片发给用户，用户可据此添加 | 引荐 | 加角色的途径之一 |
| 心情 | 角色当天的情绪状态，必须由具体事件引起 | 情绪值 | F5 |
| 活跃时段 | 系统根据用户最近的聊天时间学习出的、用户通常在线的时段 | 作息 | 角色没有作息（C1 不做） |
| 免打扰 | 用户设置的不接收主动消息和来电的时段，或某个会话的消息不响铃 | 勿扰 | |

## 5. 情景与边界

| 标准用词 | 含义 | 不要用 | 备注 |
|---|---|---|---|
| 情景模式 | 叠加在人设上的一层预设风格：日常（默认）、傲娇、恋爱、成人等 | 角色模式、剧本 | 新增需求 1 |
| 成人模式 | 允许成人内容的情景模式，只对有资格的角色开放 | 无审查模式、R18 | 资格规则见 PRD 第 10 章 |
| 成人模式资格 | 角色能否开启成人模式的系统判定，真人角色和儿童角色永远为「否」 | | |
| 人设贴合度 | 用户可调的「贴合人设 ↔ 顺从」滑杆，5 档 | 顺从度、听话程度 | F6 |
| 硬性边界 | 由项目总负责人设定、PRD 必须遵守、用户设置无法绕过的规则 | 红线、审核规则 | PRD 第 10 章 |
| 安全关怀 | 用户表达自伤、轻生等高危情绪时，角色以自己的口吻关心并自然告知求助方式 | 安全提示、风控弹窗 | F7 |

## 6. 模型与费用

| 标准用词 | 含义 | 不要用 | 备注 |
|---|---|---|---|
| BYOK | Bring Your Own Key，用户自带 API 密钥，模型费用由用户自付 | | ADR-0002 |
| 密钥 | 用户在模型供应商处申请的 API Key | 令牌、token（单说时有歧义） | |
| 供应商 | 提供大模型服务的公司（如某云、某模型公司） | 厂商（与手机厂商混淆） | |
| 聊天模型 | 生成角色回复用的模型 | 主模型 | |
| 后台模型 | 推演、生成朋友圈、整理记忆等用户不直接等待的任务所用的模型 | 离线模型 | 费用记在用户自己的密钥上（ADR-0008） |
| 后台预算 | 用户设置的「后台功能每天最多花费」，达到后当天停止部分后台功能，聊天不受影响 | 限额、额度（单说时有歧义） | 默认值见 `docs/ai/cost-estimate.md` 第 6 节 |
| 平台密钥 | 管理员在后台配置的模型密钥，只用于管理员侧任务（角色蒸馏、评测、公开动态候选搜索） | 官方密钥 | 用户侧调用永不改用平台密钥（ADR-0008） |
| 成人模式模型 | 用户为成人模式单独指定的模型，必须带「允许成人内容」标签 | 无审查模型（界面中） | MODE-03 |
| 允许成人内容（标签） | 模型能力标签之一，只在供应商协议明确允许时打上 | 无限制、无审查 | 平台不提供绕过审核的办法（SAFE-03） |
| 邀请码 | 注册账号时必须填写的一次性码，由管理员生成 | 激活码 | ACC-01 |
| 模型排行榜 | 帮助用户挑选角色扮演模型的榜单页 | | 数据来源由 AI 系统负责人定 |
| 用量 | 用户密钥被消耗的情况（调用次数、估算花费） | 账单 | 微伴不收费，只展示 |

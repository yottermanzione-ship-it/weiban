# 17 角色生态：设置、动作与碎碎念（总经理 10-19 定方向，总负责人完善）

> 生态的目标形态见 `docs/product/input/2026-10-18-gm-ecology-vision.md`（定时醒来 → 看全局上下文 → 模型自己挑动作 → 真实执行）。收费见 `16-membership-v5.md` §4：PRO+ 专属、动作按积分扣。本文只定**用户看到的设置**、**动作清单**和**碎碎念**。
> 总经理原则：往「人」那方面去想；能做的动作尽可能都做；**设置不要太细**。10-19 第三轮已简化（去掉按动作的频率、免打扰、花费上限、主动打电话、自己换头像）。

## 1. 三种开关 + 一个档位

```
我 › 服务 › 角色生态
 ├─ 总开关「角色生态」（关 = 所有角色都不自己行动）
 ├─ 活跃程度（全局一个档位，见 §2）
 ├─ 动作开关：每种动作一个开关，对所有角色生效（见 §4）
 └─ 角色开关：每个角色一个开关，决定谁参与
```

- 不做「某个角色的某个动作」这种交叉设置，也不做按动作的频率。
- 聊天信息页也放一个该角色的开关，和这里的角色开关是同一个。
- 总开关第一次打开时说明：会员专属、会按动作消耗积分。

## 2. 活跃程度（= 生态唤醒次数，类似 OpenClaw 的「心跳」）

角色每「醒来想一想」一次，就可能做一个动作或什么也不做。用户只选一个档位，用四字词，不出现「频率」字样；选项下方灰色小字写「约每天 N 次 · 约 X 积分/角色」。

**已定（总经理 10-19）**：用中性一套，朋友、偶像、恋人类角色都适用。

| 设置名 | 档位 | 实际（后台可调） |
|---|---|---|
| 活跃程度 | 偶尔冒泡 | 每天 1～2 次 |
| | 时常出现 | 每天 3～5 次 |
| | 常伴左右 | 每天 6～9 次 |
| | 形影不离 | 每天 10～15 次 |

（未采用的备选：偶尔想起 / 时常惦记 / 念念不忘 / 朝思暮想。）

## 3. 不做免打扰

- 角色生态**不再主动打电话**，其余动作（消息、朋友圈）不会像来电那样打断上课上班，所以不设免打扰。
- 角色仍会「看时间」：唤醒时上下文里有当前时间和 TA 自己的人设作息，深夜一般不会找你（这是模型自然判断，不是设置）。
- 手机层面的勿扰由系统通知设置负责。

## 4. 动作清单（像真人一样，能做的都做）

每种动作一个开关，默认全开。

### 4.1 和你聊天
- 主动发消息（想你了、分享一件事、接着上次的话题）
- 早安 / 晚安
- 发语音消息
- 发照片 / 自拍（需要图片模型）
- 发表情包
- 拍一拍你
- 分享一首歌 / 一个链接 / 一篇文章

### 4.2 朋友圈
- 发朋友圈（私人朋友圈，和你们的聊天有关）
- 给你的朋友圈点赞、评论
- 回复你在 TA 朋友圈下的评论
- 去其他角色的朋友圈互动，你能在共同好友处看到

### 4.3 TA 自己的生活
- 写碎碎念（见 §5）
- 更新「状态」（在忙、在听歌、刚下班……）
- 改个性签名

### 4.4 关心你
- 经期前后关心（读经期记录）
- 天气变化提醒
- 生日、纪念日、约定的日子
- 你很久没说话时问候一句
- 熬夜了催你睡
- 跟进你说过的事（「你昨天说的面试怎么样了？」）

### 4.5 小程序与玩法
- 寄一封慢信
- 心愿清单：加一个心愿 / 帮你实现一个
- 邀请你一起专注
- 出今天的每日一问
- 照顾宠物，并告诉你宠物的近况
- 帮你记下约好的事

### 4.6 群聊
- 在你们的群里主动说话、接其他角色的话、@ 你

> 新功能上线时往这张表里加动作即可：动作是「工具」，模型从开着的工具里挑，不需要改流程。

### 4.7 不放进生态的
- **主动打电话**：去掉（总经理 10-19）。用户自己打过去照常可以；角色在聊天里也不许说「一会儿打给你」（说到做到）。
- **角色自己换头像**：去掉。头像**绑定角色卡**，用户可以在角色资料页给这个角色换一张（只在自己这边生效，不影响别的用户），同旧版做法（旧版 `friend_profile_page.dart` 中 `avatarSource: 'user'`）。

## 5. 碎碎念（已定）

- 角色每次「想一想」时，顺带写一两句第一人称碎碎念，像私人日记：「她说今天要加班，晚点再找她吧。」「刚发了条朋友圈，不知道他会不会看到 😶」
- 入口：角色资料页 › 「TA 的碎碎念」，按时间倒序；没做动作时也可能有（「看了看手机，没什么事」），让人感觉 TA 一直在过日子。
- 每条下面一行灰色小字：这次做了什么、花了多少积分。
- 和动作在同一次模型调用里产出，几乎不增加费用；是角色口吻的日记，不展示模型原始思考。

## 6. 积分

- 不设每天花费上限（总经理 10-19）；用户用「活跃程度」和角色开关控制花费，设置页显示预计每天花费。
- 积分不足时静默暂停，下次打开 App 提示一次（16 号 §8，不透支）。

## 7. 说到做到（沿用）

角色在聊天里说「我发了朋友圈 / 给你发语音」，必须真的执行；该动作关着、积分不够或不是会员时，角色不许声称已做，改用自然说法（「晚点发」）。用户主动要求的动作（「你去发个朋友圈」）不受生态开关限制，会员 + 积分够就执行、按次扣积分。

## 8. 两个被删掉的项为什么贵（备查）

- **主动打电话**：通话期间每一秒都在「听写 → 模型 → 合成声音」，按分钟计费，一通 5 分钟的电话约等于几十条文字消息；用高级实时语音模型更贵。再加上来电最打扰人，所以去掉。
- **换头像**：每换一次要调用图片模型生成，单张约 0.1～0.5 元，且很难保证新头像还像同一个人；官方角色的头像是所有用户共用的，不能由某个用户的生态去改。

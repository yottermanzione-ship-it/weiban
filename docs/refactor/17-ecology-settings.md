# 17 角色生态：设置、动作与碎碎念（总经理 10-19 定方向，总负责人完善）

> 生态的目标形态见 `docs/product/input/2026-10-18-gm-ecology-vision.md`（定时醒来 → 看全局上下文 → 模型自己挑动作 → 真实执行）。收费见 `16-membership-v5.md` §4：PRO+ 专属、动作按积分扣。本文只定**用户看到的设置**、**动作清单**和**碎碎念**。
> 总经理原则：**往「人」那方面去想**；能做的动作尽可能都做；每个动作单独开关；频率、免打扰也按动作 / 按角色可设；总开关 + 每个角色开关；「在想什么」要给用户看，做成日记或碎碎念的感觉。

## 1. 开关层级

```
我 › 服务 › 角色生态
 ├─ 总开关「让角色们过自己的生活」（关 = 所有角色都不自己行动）
 ├─ 默认设置（新开生态的角色照这个来）：黏人程度 / 作息 / 动作清单
 └─ 角色列表：每个角色一个开关 → 点进去是这个角色自己的设置
       每项旁边有「跟随默认」，改了就变成这个角色专属
```

- 角色的入口也放一份：聊天信息页 › 「TA 的生活」（就是这个角色的生态设置）。
- 总开关第一次打开时说明：会员专属、会按动作消耗积分、可以设每天花费上限。

## 2. 「频率」的叫法：黏人程度

用户端不出现「频率」「次数/天」这类词，改成形容一个朋友的说法。

**角色整体：「TA 有多黏你」**

| 档位 | 用户看到的描述 | 实际（后台可调） |
|---|---|---|
| 安安静静 | 有自己的生活，偶尔才想起你 | 每天想 1～2 次 |
| 时常惦记 | 像普通好朋友，一天里会想到你几回 | 每天 3～5 次 |
| 黏人精 | 走到哪儿都想跟你分享 | 每天 6～9 次 |
| 形影不离 | 几乎时时刻刻都在你身边 | 每天 10～15 次 |

**每个动作：「TA 多爱…」**（例：「TA 多爱发朋友圈」「TA 多爱主动找你」）

| 档位 | 文案 |
|---|---|
| 从不 | 等于关闭这个动作 |
| 偶尔 | 难得来一次 |
| 有时 | 正常人的频率 |
| 经常 | 这是 TA 的爱好 |

- 动作的档位是「这件事在 TA 每次想一想时被选中的倾向」，不保证次数；整体次数由「TA 有多黏你」决定。
- 旁边小字显示「大约每天 X 积分」，随档位实时变。

## 3. 「免打扰」的叫法：TA 的作息

- 设置项叫「**TA 的作息**」：「TA 几点睡 / 几点起」，默认 23:30 睡、8:00 起；可选「夜猫子」「早睡早起」等快捷项。
- 睡着的时候 TA 不会找你；早上醒来可能会先发一句（「刚醒，昨晚梦到你了」）。
- 另有用户自己的「**我不方便的时候**」（如上班、上课时段）：这段时间角色不主动打扰，但可以发朋友圈、写碎碎念。
- 作息和「我不方便的时候」都是：默认设置一份，每个角色可单独改。按动作单独设作息不做（太细，用户记不住），只做到角色级。

## 4. 动作清单（像真人一样，能做的都做）

每一项都有单独开关和「TA 多爱…」档位。★ 标的是默认关闭、需要用户手动打开的（费用高或打扰大）。

### 4.1 和你聊天
- 主动发消息（想你了、分享一件事、接着上次的话题）
- 早安 / 晚安
- 发语音消息
- 发照片 / 自拍（需要图片模型）
- 发表情包
- 拍一拍你
- 分享一首歌 / 一个链接 / 一篇文章
- ★ 给你打电话（语音通话）

### 4.2 朋友圈
- 发朋友圈（私人朋友圈，和你们的聊天有关）
- 给你的朋友圈点赞
- 评论你的朋友圈
- 回复你在 TA 朋友圈下的评论
- 去其他角色的朋友圈互动（点赞、评论），你能在共同好友处看到

### 4.3 TA 自己的生活
- 写碎碎念 / 小日记（见 §5，开生态即默认开启）
- 更新「状态」（在忙、在听歌、刚下班……）
- 改个性签名
- ★ 换头像 / 换朋友圈封面

### 4.4 关心你
- 经期前后关心（读经期记录）
- 天气变化提醒（降温、下雨）
- 生日、纪念日、约定的日子
- 你很久没说话时问候一句
- 作息提醒（熬夜了催你睡）
- 跟进你说过的事（「你昨天说的面试怎么样了？」）

### 4.5 小程序与玩法
- 寄一封慢信
- 往心愿清单里加一个心愿 / 帮你实现一个
- 邀请你一起专注
- 出今天的每日一问
- 照顾宠物（喂食、陪玩），并告诉你宠物的近况
- 记账 / 日程：帮你记下约好的事

### 4.6 群聊
- 在你们的群里主动说话、接其他角色的话
- 在群里 @ 你

> 新功能上线时往这张表里加动作即可：动作是「工具」，模型从开着的工具里挑，不需要改流程。

## 5. 「TA 在想什么」：碎碎念

- 每次角色「想一想」时，顺带写一两句**第一人称碎碎念**，像私人日记：
  - 「下午好困……她说今天要加班，晚点再找她吧。」
  - 「刚发了条朋友圈，不知道他会不会看到 😶」
  - 「今天什么都不想做，就这样发呆也挺好。」
- 入口：角色资料页 › 「**TA 的碎碎念**」，按时间倒序，像翻日记本；没做动作时也会有（「看了看手机，没什么事」），让人感觉 TA 一直在过日子。
- 每条下面一行灰色小字：这次做了什么（如「发了一条朋友圈」）和花了多少积分，方便用户知道积分花在哪。
- 和动作在**同一次模型调用**里产出，不额外调用，几乎不增加费用。
- 碎碎念是角色口吻的日记，不是系统日志；不展示模型的原始思考过程。
- 可在设置里关掉「写碎碎念」（仍会照常行动）。

## 6. 花费控制

- 每个角色「每天最多花多少积分」，默认 20 积分，可改；总开关处另有「所有角色每天合计上限」。
- 到上限当天就停，碎碎念里写一句符合人设的话（「今天有点累，早点睡了」），不弹系统提示。
- 积分不足时静默暂停，下次打开 App 提示一次（16 号 §8）。

## 7. 说到做到（沿用）

角色在聊天里说「我发了朋友圈 / 给你发语音 / 一会儿打给你」，必须真的执行；该动作关着、积分不够或不是会员时，角色不许声称已做，改用自然说法（「晚点发」）。用户主动要求的动作（「你去发个朋友圈」）不受生态开关限制，会员 + 积分够就执行、按次扣积分。

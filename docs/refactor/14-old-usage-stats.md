## 3. 结论（给会员方案用）

1. **钱主要花在聊天上（约 86%）**，记忆摘要约 5%，旧版的朋友圈 + 主动消息合计约 7%，电话约 3%。
2. 旧版生态（发圈、互动、主动消息）每人每月只有几毛钱；但新版生态更重（每天推演、时间线摘要、决策模型），估算每个开启生态的角色每天约 0.02 元（≈ 2 积分），一个用户 5 个角色约 3 元/月——这才是需要用积分覆盖的部分。
3. Pro 会员实际聊天成本约占会费的 30%（新版缓存后约 10%），「聊天基本无限」完全负担得起；公平上限可设每天 300～500 条，覆盖 97% 以上的日子。
4. 失败调用占 16%，其中 16,419 次是「unknown 模型 0 token」（失效线路反复重试），新版上游账号池的自动摘除能省掉这部分。

## 1. 核心原则（总经理原话归纳）

1. **所有模型消耗都扣积分，由用户支付**。不再有「会员默认模型无限量」。
2. 后台由总经理**逐个模型登记价格**；用户只看到**积分消耗倍率**和大约每条多少积分。
3. **只保留一个会员档：PRO+**。不为老业务做善后、补偿或迁移方案（新方案，从零开始）。
4. 会员给的是两样东西：**没有额外成本的服务**（权限、容量、身份类）+ **折扣积分**（20 元买 30 元积分）。

## 2. 计价方式

### 2.1 后台登记（每个模型）

| 字段 | 含义 | 来源 |
|---|---|---|
| 售价：输入 / 输出 / 缓存命中（元/百万 token） | 用户实际按这个扣积分（1 元 = 100 积分） | 表格「官方输入/输出」列，即按官方价卖 |
| 成本：输入 / 输出（元/百万 token） | 只给后台对账、算毛利，用户看不到 | 表格「中转输入/输出」列 |
| 展示倍率 | 给用户看的「×1.0」「×2.0」 | 表格「官方倍率」，基准 GPT-6 Sol = 1.00× |
| 是否上架、适用场景 | 聊天 / 决策 / 语音 / 图片等 | 后台勾选 |

- **扣费按实际 token 用量**（输入、输出、缓存分开算），**不按倍率扣**——倍率只是展示，和表格备注一致。
- 选模型页同时显示「×倍率」和「约每条 X 积分」（按最近 7 天该模型的平均消耗估算）。

### 2.2 每条消息大概多少积分（按售价估算）

假设一条普通回复：发给模型约 1 万 token（其中八成命中缓存）、回复约 200 token。

| 模型（例） | 展示倍率 | 约每条积分 | 老 Pro 重度用户一个月（约 940 条） |
|---|---|---|---|
| deepseek-v4.1-flash | ×0.13 | 约 0.8 | 约 750 积分 |
| gemini-3.8-flash | ×0.38 | 约 2 | 约 2000 积分 |
| claude-sonnet-5-5 / gpt-6.1-sol | ×1.0 | 约 5.5 | 约 5300 积分 |
| claude-opus-5-5 | ×2.0 | 约 11 | 约 1.1 万积分 |
| claude-fable-5 / gpt-6-astra | ×5.0 | 约 28 | 约 2.6 万积分 |

结论：**3000 积分 ≈ 重度用户用便宜模型（如 gemini-3.8-flash）聊满一个月**，用中档模型约半个月。这个量级合适。

### 2.3 平台赚不赚钱（成本按表格中转价）

- 用户把 3000 积分（标价 30 元）全花掉，平台实际付给上游：用 gemini-3.8-flash 约 3 元；用 Claude/GPT 低价线路不到 1～3 元；最贵的是 gemini-4-argon（约 10.6 元）和 kimi-k3（约 9.3 元），因为这两家中转价是官方价的三成多。
- 所以月费 20 元（首月 12.9 元）**在最坏情况下也不亏**。
- 风险：表格里不少线路标着「超低价 / 不过检」、`needs_validation: true`，说明这些线路可能不是原版模型或不稳定。**上架前每条线路都要先试聊、跑评测**；中转价一旦上涨，毛利会变薄。后台已有对账页可以盯。

## 3. PRO+ 权益

**价格**：月卡 20 元，首次开通 12.9 元（每人限一次）。★ 季卡 / 年卡要不要做、多少钱（建议先只做月卡，上线跑一段再说）。

**每月赠送 3000 积分**：开通当天到账，按月发放。★ 到期没用完怎么办——推荐**当月有效、到期清零**（否则赠送积分越攒越多，等于变相降价）；充值买的积分永久有效、不受影响。扣费时**先扣赠送积分，再扣充值积分**。

| 权益 | 说明 | 平台额外成本 |
|---|---|---|
| 每月 3000 积分 | 20 元买 30 元积分 | 已在 §2.3 算过 |
| 接入 QQ / 微信 | 角色在真实 QQ/微信里和你聊天；聊天本身照常扣积分 | 很小（接入通道） |
| 更久远的记忆 | 见 §5 | 很小（存储） |
| 私人定制朋友圈 + 角色生态 | 见 §4；生态动作照常扣积分 | 用户积分承担 |
| 好感度加成 | 保留旧版做法，权益页写明 | 无 |
| 申请制作每月 2 次免费 | 见 §6 | 人工成本 |
| 身份类 | 会员标识、专属主题/气泡、表情商店会员款 | 无 |
| ★ 充值 9 折（可选） | 会员再买积分打九折，进一步体现「折扣积分」 | 少赚一点 |

**不再做会员门槛的**：群聊、语音消息、电话、切换模型、私密模式——这些都按用量扣积分，**有积分的人都能用**（私密模式仍守两条底线：不涉及未成年人、不涉及真人）。理由：用户已经按量付费，再设门槛只会把愿意花钱的免费用户挡在门外。

**权益页**：仍按星野那种两列对照（Free / PRO+），逐行打勾；所有「需积分」的项目统一标出，并写清「所有 AI 回复都按积分计费，会员每月送 3000 积分」。

## 4. 朋友圈与角色生态

- **公共朋友圈（旧版那种，所有人看到同一份）保留**，所有用户都能看。每个角色每天只生成一次、所有人共用，成本极低，**由平台承担**（无法摊到某一个用户头上）。
- **私人朋友圈**：属于角色生态，**PRO+ 专属**，内容和你们的聊天相关，生成时扣**你的**积分。
- 角色生态整体：PRO+ 专属 + 扣积分；按 10-18 构想做成「定时醒来 → 看上下文 → 自己挑一个动作 → 执行」（`docs/product/input/2026-10-18-gm-ecology-vision.md`）。
- 粗估：一次「醒来想一想」用便宜决策模型约 1 积分，真发一条朋友圈约 2～5 积分；一个角色一天醒 6 次，约 10～20 积分/天，即每个角色每月约 300～600 积分。

## 5. 「更久远的记忆」怎么做（百万上下文不可行）

- **为什么不直接上百万上下文**：每条回复都要把这一百万 token 发给模型。按 gemini-3.8-flash 的售价，一条就要约 500 积分（5 元），即使命中缓存也要几十积分，用户根本用不起；而且上下文越长，模型越容易「记混」。
- **推荐做法**：
  1. 聊天记录全部保存；每次回复时**按需从全部历史里检索**相关的旧片段（几千 token），放进本次请求。这样能想起几个月前的事，每条只多花一点点积分。
  2. 长期记忆（关于你的事实、约定、称呼）容量：免费用户有上限（如 200 条），PRO+ 不限，并且可以检索更早的聊天记录。
  3. ★ 可选「长上下文模式」：PRO+ 可以给某个角色打开，最近聊天窗口从约 2 万 token 加大到 10 万；**每条积分会明显变多**，打开时要提示。

## 6. 角色制作的积分

| 方式 | 推荐收费 |
|---|---|
| 自己创建角色（手填 / 选模板） | 免费 |
| 用 AI 帮忙生成人设（根据一段描述或公开资料） | 按实际 token 扣积分（一次约几十积分） |
| 申请官方制作（人工做） | **200 积分/次**，提交时冻结、完成时扣、拒绝或撤回就退；**PRO+ 每月 2 次免费** |

价格和免费次数都在后台可调，以后随时改。

## 7. 免费用户

- 能用所有不属于 PRO+ 专属的功能，**全部按积分扣费**。
- ★ **新用户体验问题（必须拍板）**：注册不送积分，又没有免费额度，新用户一注册就聊不了，基本会直接流失。推荐二选一：
  - **A（推荐）**：新用户前 30 条消息免费，只限最便宜的模型（平台成本约 0.1 元/人）。
  - B：保持一分不送，注册后直接引导充值或开会员。

## 8. 不透支（沿用）

每次调用前按「这次最多可能花多少」冻结积分；不够就不执行，提示充值；完成后按实际扣，多冻结的退回。生态后台任务积分不足时静默跳过，下次打开 App 提示一次。

## 9. 平台承担（沿用 13 号 §6）

安全把关与关怀跟进、小V 答疑、搜索候选（限频）、管理员工具、公共朋友圈（本文新增）。

## 10. 不做

- 不做老会员迁移、补偿、赠送生态限免（总经理 10-19：新方案，不为老业务善后）。
- 不做会员「默认模型不限量」与每天 500 条软上限（所有消耗都已按量计费，不再需要）。

# 15 管理后台 UI 改造方向（总负责人建议，2026-10-19）

> 总经理反馈：后台 UI「超级抽」。本文只给方向，供执行的 agent 落地；落地前先读本文与现有代码。

## 1. 现状与根因（读代码所得）

- `apps/admin` 是**手写的 React 页面 + 一个 803 行的 `app/styles.css`**，没有用任何成熟的后台组件库；21 个功能文件约 1.1 万行，各页面各写各的表格、表单、按钮、弹窗，风格和交互不统一。
- 左侧菜单是**约 25 个平铺的入口**，没有分组；后台首页直接跳到「角色」页，**没有工作台/总览**，打开后台不知道今天发生了什么、有什么待处理。
- 很多页面用工程术语（上游、目录、价目表版本、规划层等），表单字段缺少说明。

## 2. 方向一：换成成熟的后台组件库（最关键）

推荐 **Ant Design 5 + ProComponents**（ProLayout 布局、ProTable 表格、ProForm 表单、Drawer 抽屉、Statistic/图表）：
- 后台界面最成熟、最「像样」的方案，表格筛选、分页、批量操作、表单校验、抽屉详情都是现成的，风格天然统一。
- 各家 AI 编程代理对它最熟，落地快、出错少。
- 备选：**Semi Design**（字节跳动）。热门开源 AI 中转站 new-api 的后台就是它，如果总经理更喜欢那种「API 中转站后台」的观感，可以选它。二选一即可，不要混用。

保留现有的数据层（`@weiban/client-core`、契约与接口调用），**只换界面层**，不改后端接口。

## 3. 方向二：重排菜单（约 25 个平铺 → 7 组）

| 分组 | 放什么 |
|---|---|
| **工作台**（新首页） | 今日数据 + 待办（见第 4 节） |
| **用户** | 用户列表（积分加扣、会员状态、封禁）、会员与订单、充值档位 |
| **角色** | 角色库（官方角色、人设版本、上架检查）、角色广场（用户作品、评论、举报）、制作申请、关系网、公开动态 |
| **模型与计费** | 模型管理（概览 / 上游账号 / 模型 / 调用记录）、AI 模型价格、用量与花费、对账、行为规划（决策模型） |
| **内容运营** | 公告、更新说明、每日一问题库、节日清单、表情商店、音色库、卡面模板、宠物图鉴、作品链接、症状标签 |
| **客服与安全** | 帮助与反馈、举报处理、运行提醒、注销未完成、审计日志 |
| **系统** | 情景模式、版本策略（仅安卓）、系统设置 |

- 删除「邀请码」（10-14 总经理已决定取消该功能）。
- 有待办的菜单项右侧显示红色数字角标（制作申请、反馈、举报、注销未完成、运行提醒）。

## 4. 方向三：新增「工作台」首页

- **今日数据卡片**：活跃用户、消息数、积分消耗、上游成本（元）、毛利、失败率、缓存命中率，每张卡带与昨天对比。
- **趋势图**：近 7 天消息数、积分消耗、上游成本。
- **待办卡片**：待处理的制作申请 / 反馈 / 举报 / 注销未完成 / 运行提醒，点击直达对应列表。
- **线路健康**：各上游账号状态（正常 / 暂停 / 失效 / 额度用完）一眼可见。
- 数据来自现有用量监控接口（ADR-0032 第二批）。

## 5. 方向四：统一页面模板

- **列表页**一律：标题 + 主要按钮（如「新增」）→ 筛选栏 → 表格（可排序、分页、勾选批量操作）→ **点一行从右侧滑出抽屉**看详情或编辑，不整页跳转。
- **表单**：分组（基本信息 / 价格 / 高级），每个字段下面一行灰色小字说明，用大白话；给默认值；保存后右上角提示「已保存」。
- **危险操作**（删除、下架、封禁、撤回）一律二次确认，写清后果。
- **空状态**：说明这里会出现什么、怎么添加第一条。
- 金额在后台同时显示「积分」与「元」，方便总经理对账。

## 6. 方向五：视觉与文案

- 浅色为主，品牌绿 `#07C160` 只做主按钮与选中态，其余用中性灰；信息密度偏紧凑（后台是电脑上用的，宽度按 ≥ 1280px 设计，不用管手机）。
- 术语改成总经理看得懂的话，必要时加问号提示：如「上游账号」旁注「你填的 API 密钥线路」，「倍率」旁注「每百万 token 的人民币价格」，「价目表版本」收进高级页。

## 7. 建议的执行顺序（一个 agent 串行做，分批合入）

1. 引入组件库，搭好 ProLayout 外壳、7 组菜单、角标、登录页。
2. 做工作台首页。
3. 按分组逐组迁移页面：模型与计费 → 用户 → 角色 → 客服与安全 → 内容运营 → 系统；每组完成提交一次。
4. 每页迁移后在浏览器里实际打开截图自查（列表、筛选、抽屉、保存、确认弹窗都点一遍）。
5. 部署香港服务器，请总经理用桌面「微伴管理后台」打开验收。

## 待总经理决定的问题

1. 「角色生态」开关建议控制：4、5、6、7、14、16、17（标「是」的）。关掉后角色不再有自己的日常、不主动找你、不发朋友圈——但聊天、记忆、安全照常。是否同意？开关默认开还是关？
2. 每个场景用什么模型：目前全部是「后台默认模型 = MiMo」。是否要给某些场景指定更便宜/更好的模型（例如推演、朋友圈用便宜模型；记忆用稳的模型）？
3. 谁付费：除管理员场景外目前都扣用户积分。小V、搜索候选项是否由平台承担？
4. 安全相关（2、13）是否允许积分不足时仍执行（现状：安全关怀可透支到 −2 元）？

# 旧模型配置只读加密导出器：第一步实现

> **已有代码与离线验证，不是已经迁移。** 本批没有连接旧服务器、读取真实密钥、创建真实接收者私钥、导出真实配置或写入新平台。没有改变线上应用镜像/版本，没有构建APK。

## 实际产出

- [导出器](../../scripts/ops/export-legacy-upstreams.mjs)、[合成测试](../../scripts/ops/export-legacy-upstreams.test.mjs)。采用[传送加密决定](../decisions/ADR-20261023-legacy-config-export.md)的标准OpenSSL CMS AuthEnvelopedData，AES-256-GCM、RSA-OAEP/SHA256、至少3072位接收证书及指纹固定，不自制RSA/AES JSON协议。
- 旧SQLite只读打开、query_only、短一致读事务；读完批准记录立即释放事务，不在慢密文输出时占住旧库。仅明确列名与批准的provider/endpoint ID，不加载旧app/store初始化，不查用户、私聊、声音绑定、样本或历史账单。
- provider_id有效时采用provider的vendor/URL/Key，端点遮蔽旧Key不读取/复制；悬空引用、新未知schema、非法范围均拒绝。保留最小模型/场景/模型池元数据，不传capabilities中的voice_id或任意配置对象。
- 仅保留点名准入的env凭据及已有外置主密钥指针，不构建整份ENV映射，不把原始标签/URL/异常对象/秘密前后缀或秘密哈希写日志；旧wbenc:v1使用原env/provider/endpoint AAD在进程内解密，旧主密钥不导出。
- 传送前检查接收证书指纹、期限、密钥类型/强度及本机OpenSSL；仅把内存明文通过同机管道交给现成加密工具。输出文件wx/0600、不覆盖；`--output -`只向stdout写完整密文，状态回执到stderr，支持大管道写完再释放缓冲。
- 普通输入流执行入口也已验证，可在旧机不安装/落盘导出器脚本。证书交接路径/执行启动器仍须在真实迁移前明确，不把离线stdin测试当旧机交接策略已经审定。

## 范围与使用边界

- `--dry-run`只做schema/行数预检，不读证书、env或秘密，不等于完整迁移干跑已经通过。
- 实际导出必须指定批准的provider/endpoint IDs或准入env名，以及固定接收方证书/指纹和密文输出。参数为`--legacy-env-file`，**不要用Node自身的`--env-file`**，以免运行时先载入全部环境或在程序开始前报错。
- 默认使用支持node:sqlite的Node；旧环境可显式复用已安装的better-sqlite3数据库库。测试使用Node内置驱动，**没有在旧主机或其实际better-sqlite3分支联调**；工具缺失则中止，不安装依赖/改旧环境。
- 当前URL检查拒绝userinfo/query/fragment、非HTTPS/非443、IP直连/本地域名及含秘密路径；不做外部DNS/供应商调用，**不代表已通过接收侧公网DNS/允许域名/区域核验**。
- 只有待验证停用的目标策略声明，不启用任何模型/账号，不复制价格、余额、用户选择或声音绑定；接收器以后必须硬性执行策略，不得把导出包声明当已完成停用配置。

## 一次相关修复、一次复测

- 首轮10项为8通过/2失败：运行时将测试里的`--env-file`当自身选项，程序未执行就报缺文件；不是拿真实密钥试错，也不是密码算法验证失败。
- 将参数改为`--legacy-env-file`，并补齐旧机所需stdin入口及对应案例后，只复测一次，**11/11通过**，成功后停止；没有重跑应用/数据库全仓套件。
- 验证了真实OpenSSL CMS往返与算法、错误接收方/篡改拒绝、旧AAD失败不泄漏、provider覆盖、排除私聊/声音/系统秘密、schema/引用/URL拒绝、原文件字节不变、不覆盖输出、完整二进制stdout、无需落脚本的stdin启动、只读读取活动WAL最新数据。
- 所有数据库、主密钥、API Key、接收私钥和证书均为明示合成夹具；清理仅在核对临时根目录与前缀后执行。以上是开发自测，不是独立安全验收或真实服务器迁移证据。

## 下一步，不可跳过

1. 实现新服务器受控接收器：私钥留在新服务器秘密设施，先验证全部CMS认证/退出状态、格式、期限、批次、防重放和批准清单，再对完整内存明文进行操作，不能把认证前的流直接入库。
2. 使用model-access拥有的受控导入服务与新平台DEK/KEK、`upstream:{新UUID}` AAD重封装；先干跑和加密备份，保持停用、审计、幂等，不覆盖已有账号/默认/价格。
3. 确认旧机Node/库/OpenSSL、证书交接与二进制传送方式。不得用可能文本转码的PowerShell管道搬密文，不把秘密打印到聊天，不因SFTP中断而无限重传。
4. 完成后才做真实白名单导出/接收；语音厂商协议、用量/价格、系统音色及最小真实联调仍要继续实现，未知真人声音绑定继续排除，不称ASR/TTS/通话已全部开通。

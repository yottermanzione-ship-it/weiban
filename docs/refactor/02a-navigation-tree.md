## 0. 怎么读

- 缩进表示「从上一级进入」。`[点]` 点击、`[长按]` 长按、`[左滑]` 左滑、`[下拉]` 下拉、`[按住]` 按住。
- 打开方式：**推入**（从右滑入的新页面）、**弹层**（从底部升起的面板）、**菜单**（气泡式小菜单或底部操作列表）、**全屏**（来电、看图等）、**小程序**（进入小程序外壳，见正文第 4 节）。
- 每行末尾的标记：
  - **〔照搬〕** 参照产品有，微伴照样做；
  - **〔改〕** 参照产品有，微伴换了内容；
  - **〔新〕** 微伴专属；
  - **〔不做〕** 参照产品有，微伴不做（列在每个标签末尾，说明理由）。
- 页面细节（尺寸、组件、状态）以 `docs/design/pages/` 各页说明为准，本文只管「去哪」。

### 1.3 群聊

与私聊相同，差异：长按角色头像 → 输入框插入「@名字」；+ 面板只有 相册 · 拍摄 · 情景预设 · 名片（写信、专注、提醒、心愿、小程序是一对一的，不出现）；··· → 群聊信息（成员宫格、群名、查找聊天记录、免打扰、置顶、清空、删除并退出）。

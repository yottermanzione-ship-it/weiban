# 推送与管理员提醒（T-040 / D-L1-05）

Codex在独立分支开发，自测不能代替独立质量验收，main不改。PushModule已装配主应用；完整回归及生产容器验证进行中。

## 模块和数据

push位于底层，仅直接依赖identity/realtime公共端口；聊天、角色名、模型故障目标由组合根适配公开只读端口，模块不读其他业务私有表。端口可复用调用方事务，避免事件处理嵌套连接。注销登记push owner，负责自有全部用户数据。

0013迁移创建push schema的devices、requests、deliveries、admin_alerts四表，down只回滚此schema。凭证摘要全局唯一；设备凭证、请求和设备载荷独立用户DEK加密。pg-boss任务只包含ID、模型键、时间和分页游标，不含正文、凭据；技术日志记录状态、dueAt、attempts、acceptedAt和厂商消息ID。成功、失败或取消清设备载荷，最后设备完成时锁共享请求行清请求正文。待发送正文10分钟过期，5分钟清理；技术日志90天清理。

## 登记、绑定和退出

实现VAPID公钥、登记与删除设备契约接口。仅有效app会话登记，admin会话拒绝；十并发登记同凭证返回相同ID。换账号/会话重新使用新用户DEK加密并取消旧任务；旧账号不能删新绑定。退出事件删除该会话设备，发送前再检查账号/会话/设备归属；其他有效会话设备不受影响。失效凭证移除并取消其任务，普通临时失败不会删除设备。

## 持久投递

与事件收件箱同事务记录通知和每设备投递，pg-boss每0.5秒轮询、并发4；初次加最多3次重试，1/2/4秒退避。稳定notificationId供接收端去重，任务重复执行检查持久状态。分钟级与启动对账恢复遗漏任务/过期lease；正文不会无限期留在队列。

直接PushPort在事务提交后发送，只在真实厂商accepted时返回delivered=true，queued不会伪装成功；失败仍由持久任务恢复。主动请求按respectsDoNotDisturb及主动来电开关拦截，普通消息在免打扰时静默。accepted仅表示厂商接收，不是手机显示、用户已读或消息送达。

## 规则和事件

chat.message_created只读取normal正文；adult及关闭显示内容使用通用文案。角色备注优先，角色名或微伴兜底。群免打扰且未@本人不推；presence正在前台看同会话不建通知。发送前重读已读、撤回、删除、清空、presence和声音设置，失效则取消。免打扰依据用户时区，支持跨午夜、同开始结束全天。

同会话同设备/会话绑定30秒合并，取消旧queued；WebPush稳定Topic，极光用同绑定最近accepted的override_msg_id覆盖。厂商long ID按十进制字符串存储，验证后输出JSON整数，避免Number精度损失。退出/重绑不借用上一会话ID。

余额不足/过低按用户各24小时去重。模型故障事件创建持久分页任务，每页50个已有设备用户；模型模块筛选当前故障、明确选择、平台默认及角色覆盖。分页和通知同事务提交，事件保留下架前默认用途，避免下架清空默认用途后遗漏隐式用户；新默认已选定则忽略旧故障。请求持久保留模型上下文，发送前再次检查当前选择和可用性，恢复后已排队通知也取消，同用户/模型24小时去重。故障正文固定通用内容，点击/models或/wallet。

## 通道和迟到通知

Web Push用web-push3.6.7的RFC8291 aes128gcm与VAPID，只允许已知厂商HTTPS endpoint，DNS全部地址必须公共，固定连接地址并校验原TLS主机，不跟随重定向。极光固定REST HTTPS地址；Web404/410及极光1011（单registration ID无目标）判失效，限额及其他错误重试。DNS1秒、包括DNS/慢回包总预算1.5秒、回包4KiB。厂商密钥仅通过PUSH_CREDENTIALS_FILE读文件，无配置明确拒绝登记；可选生产secret见push.override.yml和生产手册。

契约2.2兼容追加recipientUserId、recipientSessionId、notificationId；新客户端必须严格NotificationEnvelope核对当前账号、会话与去重后展示。保持v1根字段兼容。厂商已接收的OS通知无法撤回，极光自动离线系统层只用固定微伴/你有新的微伴消息，正文仅放受owner校验的extras。两端客户端仍需实现退出清通知、SW/原生owner与点击验证，不能保证已交OS提醒绝不迟到。

## 管理员提醒

平台固定事实按开放dedupeKey唯一串行累加；info只列表，首次warning/critical或info首次升级提醒，后续低严重度不能降级。仅向有效管理员app设备发送。列表开放数量/游标分页，已处理接口幂等，90天保留；事实不含用户消息、密钥、用户名。注销清acknowledgedByUserId引用，保留平台事实。后台红点/列表接入随后客户端任务。

## 开发自测与限制

设备/会话/DEK/并发、真实聊天合并/成人隐藏/前台/已读/撤回/退出、持久重试/失效/重绑/物理删除、直接端口免打扰和accepted语义、模型目标/恢复/去重、管理员升级/并发/ack/分页/90天专项已通过。WebPush在本地真实HTTP接收后独立解密及验证VAPID签名；极光HTTP验证认证、载荷及覆盖ID。独立worker在web关闭后读取持久任务发送实际HTTP，夹具创建到厂商接收<2秒，重复任务不再发送。

DNS私网/混合地址、慢回包/超时、4KiB上限使用受控网络对象及时间测试；这不是公网厂商TLS验收。真实厂商凭据、配额、国产安卓离线保活、iOS主屏幕PWA、通知显示/点击和端到端体验仍待真机配置测试。推送不替代数据库消息与补拉链路。

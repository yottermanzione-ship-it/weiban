# 持久 AI 私聊回复

T039开发自测完成，ai_runtime自己schema。既有companion HTTP提供秒回/拆条默认与角色覆盖，覆盖保存整份快照；同事务锁好友当前版本并追加settings.updated，避免并发耗尽连接池和清除后迟到重建。好友内部epoch随着接受/恢复改变，并携带本次关系的接受时间下界；计划保留生产者事件发生时间，未生成的旧计划和迟到事件也不能进入恢复后的同一会话。

订阅用户消息和好友接受，只写ID计划与同事务pg-boss任务，正文经端口取。连续消息最后一条后3秒合并，会话持久租约序列化生成；上下文截到当前触发消息的seq，已回复覆盖按计划triggerSeq登记，生成过程中到达的新消息不会被后来送达的旧气泡吞掉。输入快照和气泡按用户DEK/AAD加密，网关稳定键与租约重启避免重复调用/扣费。首句使用申请问候/角色卡，未配置时用已审核备用开场白；普通余额/模型故障保持用户消息已送达，角色静默。恢复事件与持久补回复任务同事务，按每会话最新待回复批次合并一次，旧waiting一起取消；超过200个会话以持久任务分页接续，不能遗漏后面的用户，不自动换模型。

纯文本模型输出，用换行拆1–4气泡，按句子保留；正常长度延迟3–20秒，秒回最小typing1秒，每条前typing，间隔在P02范围。调用方deadlineAt使网关重试共享剩余首气泡60秒预算；已过期未调用不改变上游健康。高危/关怀共享20秒上限，失败即免费关怀。停机超过原60秒的消息无法满足原时限，恢复后重新分配一次有界生成预算，避免永久静默；此限制不计作满足停机期间的时延要求。已经保存的气泡恢复时不再生成，每条稳定reply幂等键，发第一气泡后重启继续剩余。

上下文严格同用户同角色私聊，经真实policy重新判定；具资格角色的normal/adult私聊共享自己的历史，其他用途不读adult。当前范围变化/分类变化/账号注销/删除好友会阻止迟到普通发言。关怀例外仍遵守输出边界：旧成人触发仅在同一私聊本地规则预筛，不将失去资格的成人历史交给儿童模型；资格收紧时切回normal并免费发适龄模板，生成后资格改变也会重新清洗已存关怀气泡。模型唯一出口ModelGatewayPort，chat不引用AI。真人声明/隐私、儿童恋爱性化、普通范围露骨、自伤方法等有平台提示与规则输出守卫，失败再生成一次然后安全话题；这些是当前规则检查，完整真实供应商人设/边界评测在后续L2/L7，不宣称覆盖全部自然语言变体。

唯一安全包装callModelForCare设置安全透支，高危/关怀与疑似复核用途按契约表驱动。全部网关错误与两次守卫失败，高危仍发不花钱的2气泡；包括信任的人、12356/110/120、不出现余额/模型/API/系统，自定义称呼也先清洗；不合规卡片或称呼不能让关怀变成静默。卡片与两份系统模板按持久已完成关怀批次轮换，不用消息seq取模（每轮2角色气泡会让seq步进3，无法轮换）。审计只ID和原因；关怀延续到最后用户互动后30分钟，恢复不重复补已关怀回复。

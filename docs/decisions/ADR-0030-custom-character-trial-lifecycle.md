# ADR-0030 自定义角色试聊生命周期

- 日期：2026-10-11
- 状态：实施中，属于 T-103 开发收口，未独立验收。
- 依据：PRD CHR-07 第6条；总经理授权接续至产品完工。

## 问题

现有 startTrial 只接受已经保存的角色，并复用该角色的直接会话。回复引擎要求正式好友，试聊消息因而被取消；关闭没有清理接口。复用还可能把试聊与正式好友历史混在一起。端侧的“保存后试聊”不能满足保存前试聊。

## 决定

1. 保存前提交编辑器完整字段创建独立、临时的人设快照和会话。试聊角色使用独立 ID，不进入“我的角色”、广场、好友添加或关系网；正式角色及已有历史不受试聊的关闭影响。
2. characters 拥有试聊授权、会话归属和失效时间，通过契约端口供 ai-runtime 读取。回复生成和每次发送均核对同一会话版本；不得伪造 ContactsReadPort 返回值来绕过好友检查。
3. 试聊沿用真实模型网关、计费、输出守卫和安全关怀。使用普通聊天范围；不产生长期记忆、日常推演、主动消息、朋友圈、养成或人设小巧思。
4. 增加显式结束接口。关闭、账号切换、页面离开触发结束；服务端还须提供有界过期清理。清除临时会话、消息、临时角色及回复计划。发送与关闭通过一致的用户/会话锁协调，晚到的模型结果不能复活会话。
5. 保存仍提交编辑器字段创建/更新正式角色，不把试聊消息提升为正式历史。既有 startTrial 接口兼容已保存角色，内部也使用独立快照。

## 验证要求

真实 HTTP/数据库验证保存前试聊回复、非所有者拒绝、无正式联系人与长期状态、结束后消息及快照物理清除、生成中关闭、重复结束、账号注销、过期清理，以及已有正式会话历史不变。网页与安卓补编辑器内试聊与关闭流程。

本文登记实现方向，不构成以上项目已完成的声明。源码与自动验证完成后更新 T-103 和活动交接。

# 香港服按实际模型容量压缩上下文

日期：2026-10-30。依据：用户本会话批准实施；范围见任务 T-20261030-context-compaction。本文是开发设计记录，不是独立验收。

## 决策

- 学习开源 Harness/Codex 的预算、保留尾部、成功后替换和切换前校验；不复制第三方代码或 coding-agent 的工作笔记提示词。
- 模型容量由 model-access 已核准线路提供，输入使用统一保守估算与余量。不能把财务冻结 ceiling 的 max 当作任意线路均能容纳的输入；运行预算取可用线路的安全下界，每个真正发送的线路再复核。
- 总结持久化归 ai-runtime。每个原 memory_state 下按 normal/adult 独立建状态与版本；父记录删除级联，新总结忘记/更正和新任务同时失效。最近十版仅供后台恢复，前端管理另期。
- 成功覆盖只表示该范围已被完整检查/总结，不由事实引用的最大序号推导。单条超长消息保留片内进度，整条处理完前不推进原文边界。模型输出必须实质缩小，不能只返回截断正文。
- 总结条目必须引用本次给定来源；其日期由服务端取引用来源的最早日期，不能由模型把旧内容改成今天。读取时仍按现有会员范围裁剪，不改数字权益。
- 初次从现有原文边界开始分批压缩，旧分段/日月资料只以可追溯日期和范围继承；不自动把全库历史重新收费处理。旧事实/旧摘要保留，单一有效总结默认注入，避免四层重复。
- 日常/私密摘要生成输入严格分开；私密聊天可继续单向读取日常资料。私密来源不能通过切出概括降为 normal，旧映射条目不再参与日常模型请求；原数据不批量删除。
- 全部生成继续走 purpose=memory、用户后台计费，保留 Abliteration 记忆关闭思考，绝不把私密转到日常备用链。
- 明确记忆候选才触发事实线。生成与队列重试归一控制，任务身份稳定，普通用户新消息不重置失败批次冷却。
- 两档同样有自动压缩和模型切换适配，不新增权益行；只同步记忆条目/历史回顾等差异名称，不改价格、积分、角色申请或新建用户页面。

## 代价与限制

总结不是无损压缩；原文继续加密保存，精确旧话仍需按权限检索。容量资料依赖管理员登记，估算不是厂商分词器实测。应用现有 500 条/20万字符保护仍可能先于大模型容量到线；这不构成百万上下文或永久逐字记忆承诺。模型缩小/故障且无法安全压缩时应保留进度、限制重试，不静默跳过未覆盖消息。

## 回退

迁移仅新增结构，线上只 up。上一版镜像/源码与旧摘要保留；不得在正式库 down 清除新数据。回退策略不能绕过删除屏障、恢复私密到日常或丢掉已合并线上补丁。

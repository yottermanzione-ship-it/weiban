## 背景

T-043 已交付记忆骨架，两处明确未做：

1. **检索只有关键词排序**（0.7 关键词 + 0.2 重要性 + 0.1 时间），语义相近但用词不同的记忆会漏掉。
2. **摘要只有单层滚动**（每批次最多 250 字，滚动保留 4000 字），超过单层预算的长对话丢失早期要点。

约束：
- 记忆正文用用户 DEK 加密，向量若也加密则无法相似度搜索。
- 嵌入调用需要记入费用（任务卡要求）；但 ModelGatewayPort 只有 `generateText`，无 `generateEmbedding`。
- 回退路径必须存在：嵌入不可用时不能让回复失败。

## 向量与加密冲突的方案对比

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. 明文向量 + 加密正文（分列存储） | 语义检索可用；实现简单 | 向量本身携带语义信息，攻击者拿到 DB 后可通过向量近邻推断正文主题（但无法还原原文） |
| B. 加密向量（用用户 DEK 加密向量值） | 向量不泄露语义 | pgvector 的 HNSW/IVFFlat 索引必须在明文上建立，加密向量无法做近似近邻搜索；等于退化为关键词检索 |
| C. 全部明文存储 | 简单 | 违反现有安全设计，正文明文进数据库 |

**结论：选方案 A。** 向量只携带语义方向（浮点数列表），不携带原文字符，泄露面远小于明文。现有威胁模型（`security-and-privacy.md`）对静态 DB 密文已有保护；向量作为「主题指纹」的额外风险可接受，且有先例（Generative Agents、大量商业产品均采用此模式）。

## 嵌入模型方案对比

| 方案 | 优点 | 缺点 |
|---|---|---|
| A. 本地统计嵌入（bigram TF-IDF + 余弦） | 零 API 费用；零网络依赖；零合规风险；CPU 即可运行 | 语义召回率低于神经向量模型，但显著优于关键词精确匹配 |
| B. 后台网关调用上游嵌入接口 | 高质量语义向量 | ModelGatewayPort 目前无 `generateEmbedding` 接口；需要先申请契约变更（见下方「契约变更申请」）；上游并非所有供应商都提供嵌入接口；增加计费与冻结复杂度 |
| C. 服务器本地神经模型（如 bge-small-zh） | 高质量向量；无 API 费用 | 需下载模型权重（数百 MB）并在 Node.js 进程中集成（onnxruntime-node 等）；服务器资源影响需运维评估；超出本任务卡范围 |

**结论：Phase 1 选方案 A（本任务卡实现）；Phase 2 当契约变更批准后升级至方案 B 或 C。** 本地统计嵌入在 CJK 场景下相比纯关键词匹配有实质提升（覆盖同义词、词序变体），且完全满足降级要求。方案 B 所需的契约变更申请在交接说明中提出。

## 分层摘要方案

现有：单列 `summary_ciphertext` 存 `{normal, adult}` 滚动文本，批次 250 字、保留 4000 字。

新增两列：
- `daily_summaries_ciphertext`：加密的 JSON 数组，每条 `{date, normal, adult}`，代表某日的摘要，最多保留 30 条（约 1 个月）。
- `monthly_summaries_ciphertext`：加密的 JSON 数组，每条 `{yearMonth, normal, adult}`，代表某月的摘要，最多保留 24 条（约 2 年）。

现有 `summary_ciphertext` 继续用于分段摘要（最近批次滚动）。

触发规则（简化 Phase 1 实现）：
- 每次 extract 后，若当天已有新分段摘要且距上次日汇总超过 24 小时，将当天所有分段摘要合并为日摘要。
- 若距上次月汇总超过 30 天，将当月日摘要合并为月摘要。
- 合并后不删除分段摘要（仍滚动保留 4000 字）；日/月摘要替换当日/月的条目。

删除屏障：日/月摘要同样清除（已有逻辑：`forget=true` 时清空 `summary_ciphertext`，同步清空两个新列）。

上下文注入：`context()` 返回 `{segments, daily, monthly}` 三层，`reply-context.ts` 可分配不同 token 预算（Phase 1：把三层拼接后截断，和现有行为兼容）。

## 代价

1. 向量携带语义指纹，攻击者控制 DB 后可推断记忆主题（不可还原原文）。已在安全威胁登记。
2. Phase 1 统计嵌入质量低于神经向量，需真实评测确认提升幅度。
3. 日/月摘要用后台模型生成，增加 `memory` 用途调用量（微小，每天/每月触发一次）。
4. 契约变更（神经嵌入）待批准前，向量列仅用统计嵌入填充，维度固定 256。

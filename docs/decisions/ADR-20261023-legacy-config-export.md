# ADR-20261023：旧模型配置只读导出的传送加密

## 背景与范围

总经理已授权安全迁移可迁旧模型/语音配置，但不迁私人数据、无授权声音，不泄露凭据。旧配置研究见[迁移方案](../refactor/2026-10-23-voice-migration-plan.md)。本批只实现并用合成数据验证「只读选择→旧端内存解密→输出前加密」，不运行真实秘密导出，不写新平台数据；接收、重封装与审计另行实现。

旧研究建议用age等标准工具，并明确不能自制RSA/AES拼装协议；之前未完成的子任务曾提出自拼混合信封，与此不一致，未实施。本批明确不用该自制协议。

## 方案与结论

- 首选现成系统工具 **OpenSSL CMS AuthEnvelopedData / AES-256-GCM**，接收方RSA证书至少3072位，使用RSA-OAEP/SHA256包装内容密钥，按操作者经受控通道核对的证书SHA256指纹固定接收者。
- 不选择自制RSA-OAEP+AES JSON信封；其协议、认证和互操作需自行维护。不把SSH传输本身当输出前加密，因为操作者终端可能记录命令输出。
- age同样可行，但旧机可用性尚未确认，不为了导出安装软件或改旧环境。OpenSSL已有系统实现，开发端可用现成二进制进行真实合成数据加解密互通；真实旧机仍须预检，缺失就中止，不静默降级。
- SQLite使用Node内置只读驱动，或仅复用旧项目已安装的better-sqlite3数据库库，禁止加载旧app/store/router。显式列名、批准的provider/endpoint ID、只读事务与query_only；不查私聊、用户、声音绑定或其他业务表。
- 只流式保留明确准入的env变量和现有外置主密钥文件指针；旧wbenc:v1按原AAD解密，不导出旧主密钥。provider_id有效时使用provider连接及凭据，不读取/导出端点遮蔽旧Key；悬空引用拒绝。
- CMS明文只经同机内存/进程管道交给OpenSSL，stdout最多是已经封装的密文，状态输出不含原始标签/URL/错误对象。旧机执行时脚本经stdin提供，密文stdout须由操作者直接保存为密文；不写旧DB、env、主密钥或明文临时文件，不自动安装依赖。
- 接收者须在新服务器受控秘密设施中保存私钥，不传给旧机/本机/Git；先验证CMS认证及退出状态，再解析全部明文，不能将认证前的流式明文直接导入数据库。

## 接收端与停用入库的后续实现

- 新增仅服务器维护CLI的prepare/plan/apply路径，不增加HTTP端点，不启动应用/后台worker，不调用供应商。生产镜像显式带现成OpenSSL，不假定精简Node镜像已经安装。
- 接收私钥只在新服务器内存生成，落盘前由现有EnvelopeCrypto及新平台DEK/KEK封装；AAD绑定批次和完整批准清单。公开证书、批准的来源ID/vendor/HTTPS地址和期限固定在0700私有目录，私钥明文不落文件；现成OpenSSL只接受文件输入时，用一份**标准加密PKCS8**临时文件配合内存随机口令，用完核对私有父目录与文件名后删除。旧端公开证书交接方式仍须在实际执行前审定，不默默扩大旧业务目录写权限。
- 必须核对受控渠道所得密文SHA、CMS认证格式、指纹、有效期、操作者及精确账号范围；只使用认证成功后的完整内存明文。拒绝未映射env凭据，不自猜其URL或用途。plan不写账号/价格/默认，但可留私有密文快照以防文件竞态。
- 普通UpstreamService.create会探测供应商；为避免未核协议/价格就发送真实Key，新增model-access拥有的维护入口，仅以新UUID写enabled=false、status=unavailable、lastTestedAt=null的待核账号，并用upstream:{新UUID}重新seal。原接口不变，后续启用仍须正式验证，不把停用暂存当通测成功。
- 不复制旧标签到目标展示名、不创建目录/路由、不改现有账号/价格/余额。新批次UUID作命名空间生成确定的新UUID，事务内批次锁及只插入不更新确保同包重入不覆盖，审计与账号同事务；密文接受标记固定同一包。单次失败可重入原包，换包或过期必须重新审批。
- CLI核对identity拥有的正常管理员身份；prepare/apply要求操作者给备份回执标识，这是显式运维确认，不是代码已经自动验证备份有效性，真实执行仍须走现成加密备份和校验。

## 代价与未完成

需OpenSSL支持CMS GCM，且准确核对接收证书指纹；CMS不独立证明发送者身份，仍须受控SSH渠道、导出密文SHA、批次期限及接收侧防重放/审批校验。导出只保留最小账号/模型元数据，**不启用模型、不迁价格/余额、不证明供应商可用或声音合法**。

这是本轮开发授权下的实现决定与开发自测，不是另一负责人独立安全验收；实际迁移仍须接收器、新平台DEK/KEK重封装、加密备份、审计和真实干跑通过。源代码标准解密旧AES-GCM仅用于兼容原格式，不设计新业务加密。

# ADR-0018 记忆删除屏障与人设模式上下文

日期：2026-10-08。状态：开发接管范围内设计自审；独立架构复核待安排。关联申请：T-043。不能将本记录视为 Claude 的审批或独立验收。

## 决定

记忆、来源消息与摘要正文归 ai_runtime，按用户 DEK 加密。关系归 contacts，成人模型选择归 model-access，模式资格归 policy。禁止绕过公开端口读写其他模块数据库。

记忆管理只允许该用户的有效角色联系人。来源由真实私聊消息盖章，成人范围由来源决定，不信任模型的 scope 或角色标识。模型返回受限的 ADD/UPDATE/MARK_PAST/NOOP 操作，校验大小、类别、重要性与来源。手动编辑优先于后续旧来源抽取；不确定共享资格默认 never，当前没有 L4 关系网时不跨角色读。

删除不仅删一行：保留加密来源屏障，过滤旧消息上下文与抽取输入，使相关摘要失效，并清除尚未发送的输入/结果及租约。编辑同样使旧计划失效。模型调用在事务外，写回时重新核对联系人 epoch、版本与删除屏障；并发删除后不得重新写入旧结果。新消息再次提起时只使用新的来源。后台任务只存 IDs 与时序，不存明文聊天内容。

近程上下文保留至少20轮（按用户轮次而非20条气泡截断），长期记忆与摘要受独立预算限制。首期检索采用关键词、重要性、时间的可解释排序；没有经资源评测的向量模型不下载、不谎称语义检索已实测。公开知识以角色卡 worldbook 为权威，不允许模型凭空补公开资料。

四种初始情景模式只改变表现，不改变身份和安全关怀优先级。贴合度1～5使用版本化提示，非恋人且非恋爱模式不得主动恋爱；修改从下一次回复生效。成人模式须具备 policy 资格并已选择可用成人模型，不回落。模型被移除时切回 daily/normal 并写系统通知，上游临时故障不擅自换模型。成人历史与记忆仅限同用户同角色；按 MODE-05 同一角色跨模式共享回忆；日常回复提示不得主动展开成人细节，资格收紧后不再提交成人资料。抽取批次与摘要仍按实际来源范围隔开，跨角色共享一律排除成人来源。

## 限制与验证

此决策不把提示词等同于真实人设质量。工程回归检验边界与输入隔离；ai-evals 保存固定考题、规则检查与人工/模型评审要求，真实供应商、1000轮质量和跨模式同一人评审待执行。L3 主动调度与 L4 共享关系网分别交接，不以未实现消费者的设置字段宣称功能完成。

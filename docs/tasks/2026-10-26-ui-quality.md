## U1 设计令牌与公共组件（分支 `ui-u1`）

1. **设计令牌**：在一个文件（如 `apps/web/src/app/tokens.css`）集中定义颜色（含暗色）、圆角（只留 4 / 8 / 12 三档）、间距、字号、字重（暗色模式下正文与中粗各降一档）、动效时长与曲线。现有 13 个 CSS 文件中的硬编码圆角 / 颜色改为引用令牌（能批量替换的都替换，不改视觉意图）。
2. **公共组件**（26 号 §2）：Toast、Snackbar（带「撤销」）、Inline Alert、Action Sheet、Choice Sheet（对号固定右列，不参与居中）、Bottom Sheet（分档吸附、点蒙层不丢已填内容）、Dialog、Alert Dialog（主按钮红字、点蒙层不关）、二级页面外壳（顶栏取消 / 标题 / 完成，完成灰→绿）、微信式滚轮选择器（日期 / 时间 / 一般选项）。已有同类组件优先改造复用，不另起一套并存。
3. **按钮规则**：主操作绿底白字、禁用灰底灰字；危险只用红字；取消黑字；**全站不出现蓝字按钮**。按钮文字写动作（「删除聊天」，不写「是 / 确定」泛词，确定类仅用于无后果的设置确认）。
4. 写一页组件说明 `docs/web/ui-components.md`：每个组件长什么样、何时用、何时不用、示例代码位置。
5. 本批不逐页替换调用方（U2 做），但要保证新组件可用、旧页面视觉不倒退。

## U3 自建角色改造（分支 `ui-u3`，U2 合入后开工）

按 26 号 §3.2：
1. 创建页改「资料卡 + 二级编辑页」：首屏头像（大、居中）、名字、角色分类、年龄设定；其余分组白色行「人设描述 · 已写 N 字 ›」「说话方式 ›」「口头禅 · N 条 ›」「示例对话 · N 组 ›」「标签 ›」「生日 ›」「音色 ›」。
2. 每行点进整页编辑器：长文本大文本区 + 字数；口头禅 / 标签可增删条目；示例对话「我说 / TA 说」气泡式编辑；生日用滚轮选择器；音色用 Choice Sheet 并可试听；分类说明放进分类二级页。
3. 必填不用星号：未填完底部「创建角色」灰色不可点，未填行右侧灰字「未填写」。去掉「（可选）」字样。
4. 「试聊」与「创建」同级次按钮（或顶栏右上角）；导入入口收到页面底部一行「从聊天记录导入 ›」，进行中的导入在该行显示进度。
5. **行的分组与顺序按 U4 的人设卡板块配置生成**（见 U4 第 1 条）：U3 先在 `apps/web` 内建立该配置的最小版本，U4 扩展；目标是以后加字段只改配置一处，创建页和人设卡同时出现。
6. 编辑已有角色（自建角色资料编辑）同样用这套页面。

## U4 人设卡骨架 + 广场详情 / 列表（分支 `ui-u4`，U3 合入后开工）

**总经理要求：字段未定，先搭骨架、预留位置。**
1. **板块配置（唯一来源）**：一份纯数据配置描述「板块 → 子板块 → 字段」，放 `packages/client-core`（网页与后台共用）。每个子板块声明：编号、标题、展示类型（正文可折叠 / 引用列表 / 对话气泡 / 标签 / 键值小行 / 折叠条目 / 头像横滑）、取值函数、是否用户可见、是否在创建页出现及编辑器类型。
2. 预置板块与子板块（**空的子板块整块不显示**，先预留）：
   - 头部：头像、名字、一句身份（用户只见「原创 / 作品角色 / 真人」一个词）、标签；
   - 关于 TA：简介、性格、外貌、经历；
   - 说话方式：语气风格、口头禅、示例对话（气泡）；
   - 背景资料：世界观 / 设定、公开资料条目；
   - 关系：认识的角色、与你的关系；
   - 其他：生日、音色（可试听）、来源 / 改编。
   现有字段先映射到对应子板块；暂无数据来源的子板块只留配置位。
3. **人设卡组件**按配置渲染：板块间 8px 灰色分组间隔、板块内无边框；正文超 5 行折叠「展开」；示例对话渲染为迷你聊天气泡（左 TA 右我）。新增字段 = 配置加一条，不改组件。
4. 替换四处：广场作品详情、角色资料页「TA 的人设」、补充设定（对照原卡）、后台角色预览（后台用 Ant Design 简单按同一配置分组渲染即可）。真人 / 未成年等内部标记只在后台显示。
5. **广场作品详情**：顶部大头像 + 名字 + 一句身份 + 作者与版本一行；点赞、评论为图标 + 数字放标题区右侧；「管理」收进右上角「…」（Action Sheet）；底部通栏绿色「添加到通讯录」（已添加则「发消息」）。
6. **广场列表卡片**：头像、名字、一句话简介、2–3 个标签、热度，不放长描述。
7. 交接里写清「如何新增一个字段」（改哪一处、填什么）。

## U5 质感细节（分支 `ui-u5`，U4 合入后开工）

按 26 号 §5：聊天上翻时右下角「↓ N 条新消息 / 跳至最新」；积分、时间、计数、价格统一等宽数字；暗色字重检查；圆角同心（外 = 内 + 间距）；去掉剩余硬边框与「框套框」，改 1%–3% 灰阶分层；气泡出现 120ms 淡入轻上移、「正在输入」节奏统一；长文件名中间截断保留后缀；动效分性格（拖拽跟手、点赞 / 拍一拍弹性、页面推入统一）；搜索框、资料编辑等单行输入检查中文输入法回车；用户端抽屉点蒙层不丢已填内容。

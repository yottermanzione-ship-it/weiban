## PRD 条目与参数（原文）

- CHR-08：导入页说明（不直接解析微信数据，用第三方工具导出文本；只导入你有权使用的内容）；选发言人；预计花费；进度可离开、完成通知；默认分类「真人」，改选需勾选声明，勾选后提示替换真名；「保留原文」选项；截图先确认识别结果。单次文字上限现值 20 万字、截图现值 30 张（`docs/ai/runtime-overview.md` 第 12 节）。
- ACC-06：二次确认并再次输入密码；说明页写明「剩余余额 ¥ X 将作废」；密码错误只提示「密码错误」并**保持登录**（客户端只在服务器明确「未登录」时才退出）；注销成功后退出，不显示删除进度。
- PLAY-02：入口（聊天信息 →「和 TA 的相处」→「我们的宠物」；「我 → 服务 → 宠物」）；领养流程（物种 → 外观 → 起名 / 「让 TA 起名」→ 完成）；名字 1～8 字；宠物页（形象、名字、「领养第 N 天」、成长阶段、亲密值、三个按钮带动画、成长记录、相册、回忆、改名、晒宠物开关、送养二次确认）。
- P-38：「每个角色最多与用户共同领养 1 只（送养后可再领养）；同时在养的宠物最多 3 只」。P-39：幼年 第 1–29 天、少年 第 30–99 天、成年 第 100 天起；按钮互动每只每天最多计 5 次亲密值。
- ADM-04 第 5 条：宠物图鉴（物种名称简介、外观、各阶段图片、上架下架）。ADM-10：列表与进度、只看进度不看内容、重新触发、没有取消注销入口。

## PRD 条目与参数（原文）

- ACC-06 第 2 条：删除全部数据——聊天、记忆、自定义角色、导入的原始聊天记录、上传的头像、余额明细；经期日记全部记录、宠物、人设广场中发布的作品、评论和点赞；TA 的提醒、心愿清单、每日一问的回答、慢信。其他用户已从广场复制的角色保留，来源作者显示「已注销用户」。
- ACC-06 第 3 条：剩余余额作废；不得保留可关联到该用户聊天内容的记录。
- ACC-06 第 4 条：密码输错只提示「密码错误」，注销不进行，**用户保持登录**。
- ACC-06 第 5 条：注销后所有设备立即退出登录；后台逐项删除，失败自动重试。
- ADM-10：列表按申请时间从早到晚；每行用户名、申请时间、最近一次手动触发时间（没有显示「—」）、每个模块的删除进度（已完成 / 未完成、条数、完成时间），不认识的新模块显示「其他模块」；**只看进度，不看内容**；重新触发只执行未完成的模块（含注销后新增的模块），全部完成则直接完成删除；全部删除完成后用户行物理删除；**不能撤销注销**；审计只记用户 ID 的哈希，不记用户名。

## 范围

- 可以改：`apps/server/src/modules/identity/**`（注销编排、管理接口）、各模块中尚未接入的删除清单实现（只补删除清单，不改业务逻辑）、`scripts/verify-user-purged*`、`apps/server/drizzle/0056_*`。
- 不可以改：`packages/contracts/**`、`docs/quality/**`。

## 交付物

1. 注销编排：密码校验（错误不退出登录）、立即吊销所有会话、按模块分发删除、重试、完成判定、用户行物理删除。
2. 各模块删除清单收口（L0～L7 全部模块，含 moments、library、importer、health、plaza、宠物、玩法、媒体存储文件）。
3. `scripts/verify-user-purged`：逐模块核对某用户 ID 无残留（含对象存储文件）。
4. ADM-10 管理接口：列表、详情进度、重新触发、审计（哈希）。

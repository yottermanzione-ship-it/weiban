# 旧站用户增量迁移预检

经理在 2026-11-08 要求核实旧站新增用户、消息和密码变化，并继续推进。基线 `2780ae0783039298d56785be56ca523825ecfabe`，独立分支 `codex/legacy-delta-preflight-20261108`。

## 本轮范围

- 只读核对增量消息依赖的账号、角色、联系人和群聊，检查新站归档/隐藏/清空状态与消息时间交错。
- 对明确的媒体目录只检查引用、文件是否存在和大小，不打开文件内容，不导出文件名或私有地址。
- 比对上次快照后旧站发生的历史消息删除，仅返回数量；不自动删除香港站历史。
- 不读聊天正文、记忆、私人资料，不覆盖密码或用户数据，不修改旧服务器，不把预检写成迁移完成。
- 正式导入前，需要可重复的增量清单、去重与删除保护、附件搬运核验及客户端历史顺序方案。新增用户的登录/余额/会员承接仍需专项预演。

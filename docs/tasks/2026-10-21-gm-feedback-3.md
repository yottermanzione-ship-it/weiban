## 批 G3：模型配置自动化（server + admin）——已确认

1. **models.dev 自动预填**：后台添加 / 编辑模型、导入配置时，按模型名从 models.dev 的公开数据（如 `https://models.dev/api.json`，以实际为准）检索并预填：官方输入 / 输出 / 缓存读取 / 缓存写入价格（美元按后台可配汇率换算人民币）、上下文长度、最大输出、是否支持图片。预填可改；检索不到时提示。服务端定时缓存一份，后台可手动刷新。
2. **「系统没法确认这条线路的实际用量，已暂停」**（截图 37）：原因是上游返回里没有用量数字（或计费未知），系统为防止漏扣积分自动暂停线路。改为自动处理：上游没报用量时，按本地分词估算输入 / 输出 token 计费并标记「估算」，不再暂停线路；后台对账里列出估算条数。连续多次缺用量才在后台提示一次，不自动停用。
3. **模型键对管理员隐藏**：表单不再让人填，按「厂商 / 模型名」自动生成，只在「高级」里只读显示。

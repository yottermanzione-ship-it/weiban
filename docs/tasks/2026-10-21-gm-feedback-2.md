## 批 F1：用户端界面（apps/web）

1. **搜索框绿色下划线**：所有搜索页 / 通讯录顶部搜索框获得焦点时的绿色下划线去掉（共用 SearchField 组件）。
2. **聊天信息页灰色间隔透明**：从单聊页进入「聊天信息」时，分组之间的灰色间隔是透明的，能看到底下的聊天页；给页面与间隔设实色背景（转场动画期间也不透）。
3. **已读 / 已送达状态做成开关**：设置里加「显示消息已读状态」开关（默认开），关掉后气泡下不显示已读 / 已送达。
4. **「我」页状态**：位置与样式参照微信（截图 22）：头像右侧昵称、微伴号，下方一行「+ 状态」胶囊按钮；去掉现在单独的「我的状态」列表行。
5. **设个状态页**：参照微信（截图 23）的版式：深色毛玻璃背景、标题「设个状态 · 朋友 24 小时内可见」、按「心情想法 / 工作学习 / 活动」分组的图标宫格。图标**自绘同风格线性图标**，不直接拷贝微信的图标文件（版权）；状态项沿用现有可选状态并按分组补齐。
6. **「我」页头像闪烁**：切到「我」时头像先闪约 1 秒的昵称缩写占位。头像图片做缓存（已加载过的直接显示，新图加载完成前保留旧图），不再先渲染占位。全站头像组件一并检查。
7. **提示音说明文案**：「在微伴里收发消息时响一声……」改为「聊天界面消息收发提示音」。
8. **群聊回复出现字面「\n」**（截图 24「啧\n@水浮蓝 …」）：模型把换行输出成了字面的反斜杠 n，群聊解析没处理。服务端群聊（及私聊、主动消息）统一把字面 `\n` 当换行，并按拆条规则拆成多个气泡；加防护避免其他转义残留。

## 批 F2：模型与计费（server + admin + web）

1. **删除「资料来源链接」与「核对日期」**：计费上限表单里去掉这两项（契约 RouteBillingBounds 改为可选，后端不再要求）。
2. **协议**：上游账号协议目前只有 OpenAI 兼容。中转站（如 Bai）一般用 OpenAI 兼容端点就能调 Claude，**选 OpenAI 兼容即可用**；但 Claude 的缓存控制、缓存写入计费在 OpenAI 兼容通道上可能不生效，导致 Claude 缓存命中低。本批加「Anthropic（Claude 原生）」协议：按原生 Messages 接口发送，带缓存断点（cache_control），并读回缓存读取 / 写入用量。
3. **缓存写入价格**：模型价格增加「缓存写入」（可选，再分 5 分钟 / 1 小时两档，按上游提供的填）；上游返回缓存写入 token 时按此价扣费，没填则按普通输入价；导入配置、后台列表、对账一并支持。
4. **识图不再单独作为场景**：总经理所有聊天模型都配多模态。用户端与后台去掉「图片识别」场景，图片随「文本聊天」（私密模式下随「私密模式」）发给同一个模型；后台把「识图」能力作为文本聊天 / 私密模型的必备能力（缺了上架时提示）。迁移已有图片识别配置。
5. **Bai 的 MiMo 显示「暂时无法使用」**：后台「上游账号 › 测试连通」与线路健康排查原因（密钥 / 余额 / 线路被健康检查暂停 / 计费上限缺失），在后台把具体原因显示出来，不只写「暂时无法使用」。

## 批 F3：私密模式（server）

1. **两个账号测私密模式失败**：调用记录显示 10-20 23:08（北京时间）私密模式两次调用状态为 `interrupted`（中断），时间与当晚部署重启接近，**可能是部署重启打断**；另一个账号「模型暂时不可用」，可能是该账号「私密模式」场景未配置或私密模型不可用。逐个复现确认，并修：
   - 部署 / 重启时打断的回复要自动重试或给用户明确失败提示，不能停在「已送达」无回复；
   - 场景未配置时提示「请先在模型配置里选择私密模式模型」，不是笼统的「模型暂时不可用」。
2. **私密模式只切聊天模型**：打开私密模式后，只有「文本聊天」换成私密模型，语音等其他场景不变（确认现状并在设置页写清）。
3. **私密内容的记忆总结被拒答**：凡是要处理私密模式内容的后台任务（记忆抽取、摘要、生态读取这段对话等），一律用该用户的私密模式模型，不把私密内容发给受限模型；私密与日常两套记忆块已分开（09 号 §8），检查摘要 / 抽取是否也分开并按此路由。
4. 会话列表私密消息预览改为「[私密消息]」（上一轮推荐，待总经理确认）。

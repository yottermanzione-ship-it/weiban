- 基线：`4c1e0c1aed825a3f2eb24960fa52eb96b24146fb`（开工远端 main / 最近发布），独立分支 `codex/web-closeout-shell-20261106`。共享 main 与他人文件不动。

## 先后顺序

1. 补查当前生产健康、匿名错误分类、自然使用的模型缓存与对账聚合。不得读取真实聊天、个人资料、凭据，不清除未核清告警、不自动退款、不付费刷缓存。
2. 网页可复现缺陷先修复；情景真实风格、通话、锁屏提醒、外部渠道和长期观察缺实际证据时如实保留，不无限等待后续人工证据才制作安卓。
3. 在现有安卓构建中新增独立 `:shell` 应用，以系统 WebView 加载固定生产网页；独立包名与数据，不覆盖旧正式安卓。保留原生 `:app` 和既有检查。
4. 实现系统返回键、键盘/系统栏避让、录音授权、文件选择、图片保存、网页错误重试、外链隔离、持久网页登录与本机消息存储。网页更新使用现有更新机制，不清缓存或强刷。
5. 交付可安装内测包、公开构建与验证记录。当前环境只使用已存在调试签名；正式签名/上架另按既有凭据规则处理，不生成或保存新密码。

## 范围与限制

本轮是过渡套壳，不是原生对齐完成。WebView 不提供浏览器网页推送，后台保活、锁屏来电/通话和厂商推送不能冒称已支持；设置须准确说明，既有苹果网页通知不变。普通前台聊天、语音和上传先交付。不得用常驻服务、后台轮询耗电或复制用户会话令牌来伪造离线通知。

最低系统沿用安卓 7，但需要支持现行网页能力的系统网页组件。测试使用现有安卓测试设备与专用合成网页夹具，不登录真实账号或发送真实消息。涉及本机安卓检查先向经理说明；云端完整检查仍是合并门禁。

经理后续明确“先不切换，先交付安装包”：设备录音/选图等互动验证本轮保留未验证，不继续切换当前应用。实际匿名能力探针发现旧网页组件缺少组合取消接口，纳入本轮网页兼容修复；用合成账号自动流程验证，不借此扩大真实账号操作范围。

## 验证

对 URL 来源、权限取消/跳转、文件类型/大小/来源、失败恢复进行程序检查；实际安装验证启动、返回、权限、选图和本地状态恢复。没有真实账号和供应商验证的部分单列，不用安装成功代替端到端验收。任何网页发布继续使用来源门禁、完整检查与正常合并部署流程。

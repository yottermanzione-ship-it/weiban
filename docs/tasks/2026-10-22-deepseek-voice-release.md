## 实施范围

1. 后台模型合并表单及后端支持既有非 token 服务单价（搜索每次、合成每万字、识别/通话每分钟、图片每张），不用伪 token 价格；搜索计费上限结构化，保存沿用生效价目表版本体系。新增单位价格不能覆盖其他模型/未修改单位，字段校验与并发发布检查配套。
2. 明确区分公开标价、实际账户优惠、用户售价、供应商成本；不读取/输出 DeepSeek 密钥。旧版服务器仅只读查看配置和非密模型/价格字段，不修改其服务、数据或密钥。
3. 角色找图需求仍待讨论，本轮发布默认不启用新增自主网图搜索；仅为待讨论功能加独立关闭开关，不能误关已上线 P3 公开作品输入图检索或用户识图。表情现状如实说明，不本轮擅自扩大图片/克隆功能。
4. 决策 32 次真实调用结论、接口适配边界、普通回复与生态表情频控/选图缺口单独核实。不得说 Jev 能直接替换生态 generateText，也不得把软件模拟测试当作供应商调用。
5. 语音是研究任务：列旧库实况、现行官方真实型号/协议/可用区域与计费维度。不能机械把全部 3.0 字符替换成 3.1；注意新语音 token 定价与旧按字/秒不同。真实声音克隆仅限有权授权声音，旧实名音色不自动迁移。
6. 连同上一轮已实现 Web/Arena 修复统一发布；先整合最新 main 与服务器完整提交，执行 Assert-ReleaseSource.ps1；备份数据库/媒体/配置（不回显密钥），独立版本目录构建、核对来源、固定 weiban-prod 项目整体切换，保留回滚。不改共享目录分支/原有未提交文件。

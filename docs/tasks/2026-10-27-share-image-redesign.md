## 要做的事

1. **三套模板**（360 逻辑宽 ×3 导出 1080，固定浅色）：
   - **A 微信原样**（默认）：#EDEDED 底、顶部角色名 / 群名居中、时间分隔、对方白气泡、我方微信绿气泡、方圆角头像（真实头像优先）。
   - **B 柔和信纸**：暖白纯色底（无渐变、无星星）；顶部角色头像 + 名字 + 「认识第 N 天 · 日期」；一句大号衬线摘录（默认取所选内容中角色说的最长一句，若都很短取最后一句；编辑页可点选换句）；下面对话为柔粉 / 白圆角气泡。
   - **C 卡片海报**：卡面大图占上部，左上编号胶囊，卡名；下方衬线卡片语 + 「角色 · 获得日期」；**无卡面时用角色头像 + 柔和色底**，不再画蓝块。朋友圈 / 消息内容不可选 C（沿用现规则）。
2. **底部品牌栏**（三套共用，不可删除 / 关闭）：左 logo + 「微伴AI聊天」，第二行默认「和 X 认识第 N 天」（群聊 / 无天数时省略）；**含真人角色时第二行固定为「非本人，请谨慎识别」**（合规要求优先于关系信息）；右侧二维码指向 `https://weiban.online`（本地生成二维码，不调外部服务；用现有依赖或引入一个轻量二维码库，许可证写进交接）。品牌栏不压任何内容。
3. 修「聊天原样」纯黑底 bug（查清令牌查找为何失败，避免其他模板同类问题）。
4. 编辑页：模板选择改为 A / B / C 三个缩略图；B 显示「换一句」入口；含真人时的锁定说明保留。旧的用户默认模板偏好映射到新模板。
5. 表情、图片、语音、慢信、宠物照片等消息类型在三套里都要有合理画法；健康 / 私密消息仍不可选（沿用 v2.1）。

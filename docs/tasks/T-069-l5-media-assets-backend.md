## PRD 条目与参数（原文）

- MED-01 第 2 条：表情包来自管理员维护的库，每个角色有偏好子集；库中**不包含真人明星本人照片制作的表情包**（ADM-04 第 1 条：上传时管理员确认）。
- MED-01 第 3 条：用户可发自己添加的表情包（管理入口「我 → 表情」）。
- ADM-04 第 2 条：音色有名称、试听、气质标签；为预设角色指定音色；**音色名称中出现已录入真人角色的姓名时无法保存**。
- ADM-04 第 3 条：卡面模板库（GRW-05 卡面、分享图通用装饰素材）。
- MED-05 第 2 条：链接必须真实可用，来自管理员维护的作品链接或通过可访问性检查的搜索结果；**不得生成编造的链接**。
- MED-02 第 8 条：用户可长按保存、收藏图片。

## 交付物

1. 缩略图生成、语音文件存储（时长元数据）、签名访问链接、对象存储生命周期（本机磁盘与 S3 两种实现都支持）。
2. 素材库：表情包库（分类、指定角色、真人照片确认）、音色库（名称校验、试听文件、标签、预设角色指定）、卡面模板库、作品链接库（标题、来源、封面、链接、所属角色）；管理端接口。
3. 用户自定义表情：添加、排序、删除、发送；本模块删除清单。
4. 聊天消息类型：图片、语音（含转写文字字段）、表情包、链接卡片的存储与下发（与 L1 同步机制一致）。
5. 链接可访问性检查的服务端工具（供 AI 调用，以契约端口为准）。

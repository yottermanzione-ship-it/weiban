# 迁移准备、独立演练与旧安卓收藏承接

日期：2026-11-09。负责人：Codex。独立分支 `codex/migration-rehearsal-20261109`；开工主线 `3d0b0c6194e3654cc43cd45e3b85de4c19f2826a`，合入已确认方案文档后的基线 `cc10580419eeb1306b361b799688af85ec52530d`。

## 总经理指令和本轮边界

- 完成正式迁移前能够在独立环境做的准备与演练，汇报执行顺序和预计停机；不修改线上、不执行数据迁移、不自动切站，不修改域名、下载或更新入口。
- 收款指定真实流程已由总经理确认，继续沿用现场回执，不要求重付或重新补账。
- 本轮澄清：**旧恢复码机制不再承接；旧安卓聊天消息收藏必须保留。** 原收藏是本机消息快照，原聊天删除后仍须可访问。不能把保留应用容器误写成收藏迁入完成。
- 实际用户内容、凭据和手机文件不读取；数据库、附件、旧偏好均用合成夹具。共享副本保持 main，本轮候选不在共享副本提交。

## 工作与验收

1. 固定计划、比较基线和来源清单；未知表、字段漂移、缺失删除/凭据/权益证据必须显式阻断。
2. 缺账号与关系仅补入；现有密码、钱包、会员、已读/隐藏/清空/永久删除和新站内容不覆盖。小V采用官方身份。
3. 消息按稳定来源去重，合并时间顺序；保留现有消息身份和相对次序、引用和密文；同步翻译全部关联游标，并演练客户端重建及未发送队列保留。
4. 媒体逐文件/块校验、按用户独立加密、可重复搬运；错误归属、坏块、失踪文件、源变动和非可信路径有固定分类。
5. 原备份脚本成功/失败/中断均不能在维护时误开业务。关闭新单、保全通知、逐笔恢复、去重履约与真实支付服务隔离验证。
6. 会员只承接经明确核对的未兑现来源事件；群记忆仅处理已明确审核归属/类型的子集。未知纠正链、遗忘屏障和冲突不自动覆盖。
7. 旧更新协议、正式安装包签名/身份、完整/断点下载和严格本机加密连接验证；不操作真实手机。真实旧正式版升级全流程另列未验证。
8. 用代表规模的合成历史执行计划、部分失败、恢复、对账及真实数据库备份恢复；计时区分造数据、数据库、文件搬运和未测的真实网络。
9. 新增旧收藏来源映射与受限原生读取桥：服务端核实当前账号对应旧用户名分区；未知公共分区不展示。完整快照按账号加密，重复导入和删除后重装均不复活；本地附件只从该收藏确切引用及许可目录读取，保留原件。
10. 新版网页和安卓共享旧收藏列表，兼容现有收藏；换号、取消、漂移、失败重试、超限、越权和注销清理需有测试。7.9为新增端点，最低客户端版本不提高；0163候选先在独立库演练。

## 交付口径

只登记开发自测及对应的候选源码审查，不自签完整产品独立验收。正式执行必须另有最终运行库清单、实际受保护映射/冲突清单、完整源/目标一致备份和放行指令。本轮不把历史统计、本机合成耗时或静态安装包验证当作生产切站完成。

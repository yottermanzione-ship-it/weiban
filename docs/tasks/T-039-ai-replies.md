## 实现

既有陪伴设置 HTTP 的全局默认及角色覆盖，同事务关系锁与完整同步；订阅用户消息/好友接受，3秒合并、持久计划/租约/重启对账、拆条 typing、普通故障静默、恢复每会话只补最新一次。输入结果按用户 DEK/AAD 加密，完成取消清密文，账号注销物理清除。任务和事件只有 ID，日志及审计不存正文；模型唯一出口 ModelGatewayPort，聊天不引用 AI。新增0012迁移/回滚，自有两张表。内部 ContactsReadPort 关系版本/接受时间下界与可选事务、GenerateTextInput deadlineAt 配套，网络契约仍为2.1。

安全透支只在唯一关怀包装设置；高危/关怀遇全部网关错误仍免费两气泡，关怀模板按持久批次轮换。真人/儿童/成人资格和范围再次判定；资格收紧时旧成人文本仅本地规则预筛，不交儿童模型，免费适龄降级；生成后资格变化、不当自定义称呼也不能让关怀静默。规则守卫并非全部自然语言变体的覆盖声明，真实供应商人设/边界评测按 L2/L7接续。

生成中的后续新消息不被旧气泡吞掉：上下文按当前触发seq截断，回复覆盖按计划triggerSeq登记。关系版本包含接受时间下界并保存生产者事件原时间，未生成旧计划和迟到事件不能认领恢复后的关系。超过200条待回复消息按会话最新计划合并，超过200会话用持久任务接续。停机超过60秒不能满足原时限，恢复后重新给一次有界预算，避免永久等待；此不计作满足停机期间时延要求。

# T-20261025：私密情景切换与顶部模式显示

## 用户要求

- 修复开启私密模式后无法主动关闭；与自动、日常、树洞等使用同一种模式行样式，视觉选中互斥。
- 选择私密前简短确认：会切换私密模型，可能增加积分消耗，显示当前实际积分倍率；仅支持文字和图片聊天。去除无关复杂说明，不移除必要后台权限/安全校验。
- 选择其他普通模式能真正退出私密；再次点已选私密可回到上一次普通模式，无记录时用自动。
- 弹层最底部增加“显示情景模式”开关。主代理已向用户说明将“价格选项开关”理解为“加个选项开关”，不是另加价格开关。
- 开关打开时，在聊天顶部昵称旁显示当前模式，长昵称不挤按钮，保留正在输入替换昵称的既有行为。

## 实现原则

- 进入私密要确认；取消不改状态。退出切回普通模型和消息范围，不是仅取消勾选。
- 用户后续新决定：私密模型只由管理员统一固定提供，普通用户不再选择。倍率来自平台实际固定模型与现有报价口径，不写死、不用用户旧私密选择或普通模型冒充；缺配置暂不可用。
- 后端由40ffe651-0f50-4e90-86c9-6521d9960a59实施独立fixed.private唯一源、只读端点、运行时忽略旧覆盖、用户写入拒绝与固定模型删除保护；旧历史保留，普通推荐及右侧平台内部六项配置不变。前端94e3待权威接口稳定后接适配器，不可将恒null占位称为完成。
- 文案简短、排版清晰；只支持文字/图片的限制与入口一致，但不影响普通聊天的语音等能力。
- 显示开关默认关闭，按账号本地保存；上次普通模式按账号和角色/会话保存。刷新保留、不串账号，不为显示偏好改后台契约。
- 重复选择已选普通模式不重复保存或产生切换系统提示；保留既有情景修复。

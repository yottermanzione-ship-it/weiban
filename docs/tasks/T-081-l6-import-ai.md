## PRD 条目与参数（原文）

- CHR-08 第 3 条：草稿含名字、说话方式特点、口头禅、常用表情、性格总结、示例对话（从原文摘取）、重要经历；进入 CHR-07 同一编辑器。
- CHR-08 第 4 条：**分类默认为「真人」**；改选原创 / 虚构需勾选声明；勾选后草稿中识别出的真名提示用户替换。
- CHR-08 第 5 条：「普通长度（不超过 5 万字）3 分钟内出草稿」；可离开页面，完成后通知。
- CHR-08 第 1 条：截图识别，所选聊天模型不支持识图时用默认识图模型，平台也没有设定时入口提示更换模型；生成草稿前先让用户确认识别出的对话。
- CHR-08 第 7 条：开始前按价目表估算预计花费；费用从用户余额扣，用途同导入分析。
- CHR-09 第 2、5 条：补充设定与基础人设冲突时以公开事实为准并提示冲突项；不能改变分类、年龄设定、成人模式资格。
- CHR-10 第 4 条：更新摘要（如「新增作品《XX》」）。

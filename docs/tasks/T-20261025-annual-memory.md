## 范围与隐私

- PRO+生成权益；已生成但离线未读的本人年报，不因之后会员到期而丢失自动投递机会。补跑不得把新年才开通用户当作年底已有资格，优先复用当日候选/已有任务重试。
- 通过chat域新聚合读取端口统计，不跨模块私读表。按本人实际消息可见性，不把群创建者等同全部参与者，不把其他群成员发言当成本人，也不擅自排除仍可见的归档记录。
- 核心活跃/角色榜按本人发言，避免角色拆气泡刷量；群消息不重复分给每个角色。排除不可见/清空/隐藏/撤回/系统/私密范围内容。
- 夜聊按明确夜间区间处理凌晨跨日；展示真实发送日期与时刻，不能把23:59自动当作比凌晨03:15更深夜。不推断连续聊天时长，不编造主题/情感。
- 旧数据使用真实消息时间；未知/回填时间不可冒充精确日期。先核实本地旧源码/迁移规则，不访问旧站或解大备份。
- v1采用统计加确定性模板，无模型调用、无新增用户积分扣费。未来模型叙事另议，不挪用朋友圈用途，不改平台内部六项配置。

## 批 E3：模型配置按场景 + 限时折扣 + 首次引导（分支 `fb-models`，目录 `C:\wb-dev\wb-fb-models`；迁移 0114–0116，契约 3.22；E2 合入后开工）

1. **去掉「平台默认模型」概念（面向用户）**：用户端不再有「平台默认」选项。场景（每个场景独立配置，**不做多模态直接听语音 / 直接生成**，总经理 10-20 确认）：
   - 文本聊天、图片识别、语音消息（角色发语音的合成）、语音识别（用户语音转文字）、语音通话、发照片 / 自拍（图片生成）、私密模式聊天。
2. **用户端「设置 › 模型配置」**（原「我的模型」改名），两种视图：
   - **按场景**：每个场景选一个模型（只列后台标注能用于该场景的模型），行内显示「消耗倍率 ×… · 约每次 … 积分」；
   - **按角色**：进入某个角色，可逐场景单独指定，未指定 = 跟随场景设置。聊天信息页「TA 用的模型」改为进入该角色的这一页。
   - 角色生态不单独选：按动作所属场景自动走对应配置（发文字 → 文本聊天，发语音 → 语音消息，发照片 → 发照片）。
3. **首次引导**：用户首次进入聊天（或任何需要模型的功能）且场景未配置时，弹出模型配置引导，含「一键选推荐」（推荐值由后台为每个场景指定）；未完成文本聊天配置前不能发送消息。已有用户迁移：把其现有选择 / 原平台默认写入为其场景配置，避免老号被拦。
4. **后台**：模型能力按场景分类（勾选该模型可用于哪些场景），模型列表可按场景筛选；每个场景设置「推荐模型」（仅用于引导的一键推荐，不是兜底默认）。另设「平台内部模型」一栏：安全检查、小V 答疑、角色生态决策（平台付费或后台自动运行，用户不可选）。现有 `defaultFor` 迁移到这两类。
5. **限时折扣**：每个模型可设折扣（如 0.5）与起止时间；生效期间扣费按折后售价，成本不变；到期自动恢复。用户端显示「消耗倍率 ~~×1.0~~ ×0.5 · 限时 5 折」。后台列表显示进行中的折扣。用于测试 Bai 的 MiMo（Bai 上游密钥由总经理自己在后台填写，代理不经手）。
6. 计费、估算、冻结（不透支）全部按新的场景解析与折扣价走，同一处解析逻辑，不各写各的。

## 要改的
1. **会话列表顶部黄条「本机保存失败，请检查设备存储后重新打开微伴」**（40.png，桌面浏览器）：查清触发条件（IndexedDB / 本地缓存写入失败？配额？版本升级？隐私模式？），修根因；确属设备问题时文案和时机要准确、可关闭、不误报，并写清它在哪些情况下出现。
2. **我发布的 → 作品页**（41.png）：空状态下面多出一条白色横条，去掉；空状态整体检查。
3. **页签选中态不加粗**（42.png 广场顶部「自定义角色 / 微伴角色」，41.png「作品 / 消息」等全站同类页签）：选中只换颜色 + 下划线，字重不变（避免切换时文字宽度跳动）。
4. **进行中的导入页**（43.png）：左上角孤零零的绿色「导入聊天记录」按钮文字上下左右不居中、位置别扭。改成符合 U1 规范的布局（例如空状态居中说明 + 下方通栏主按钮，或顶栏右侧入口），按钮文字必须居中。
5. **导入聊天记录页**（44.png）：三种导入方式改成标准白色列表行，左右通栏拉齐，右箭头统一贴最右侧对齐；底部两条黄色提示框改为页面底部的灰色小字说明（不用彩色框）。
6. **角色生态「按角色 / 按动作」页签**（45.png）：现在是两侧留白、像浮着的分段控件。改成左右拉齐的通栏页签（与全站页签一致：下划线、不加粗），不要左右留白。
7. **「正在读取聊天…」**（46.webp，iPhone）：提示文字与骨架屏不协调、没有居中。改为：要么只有骨架屏，要么提示在可视区域真正上下居中，选一个更干净的方案。
8. **登录页顶部灰色区域**（47.webp，iPhone Safari）：状态栏 / 安全区仍是灰色而页面是白色。顶部安全区、`theme-color`、页面背景统一成白色（登录、注册、找回密码等同类白底页都检查；进入灰底页面时再切回灰色）。
9. 顺手全站过一遍「左右留白 / 浮块」：设置类页面的分组、页签、提示条都左右拉齐；列表行箭头统一贴右。改了哪些在交接里列表。
10. **状态表情与昵称垂直不居中**（49.png 聊天页顶栏「宁静 + 表情」、50.png 详细资料页「宁静 + 表情 + 星标」）：表情图标与昵称文字按视觉中线对齐，全站同类「名字 + 状态表情 / 图标」一并检查。

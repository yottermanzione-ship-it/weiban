# T-20261108a 安卓通知、设备登记与正式包交付

基线：`b171db17756a917d47fccc9842c7ce70d59d669d`；独立分支 `codex/android-push-20261108`。总经理授权开发、正常合并发布；本人验证仅记开发自测。

## 最新需求和现场事实

- 统一安卓系统通知入口。2026-11-08 总经理明确不用尚未开通的厂商服务，先采用旧版方式：原生系统通知 + 系统后台任务，不依赖网页推送。旧版 `background_delivery_service.dart` 为十五分钟周期补收、发消息后二十秒单次补收；系统限制可能延迟，不等同于杀进程后实时厂商推送。
- 登录设备区分安卓应用、浏览器；同一浏览器/应用再次输入密码不再累积有效设备。不能按相同名称或地址合并不同实体，不能猜认旧记录。
- 总经理确认尚未安装包含最新顶部适配的正式包。源代码仍含白色系统栏、系统边距只应用一次的修复，未发现合并覆盖。先交付现有正式包，不盲目重复改布局。
- 安装包直接放桌面根目录，不新建目录，不自动安装或切换手机。正式版本继续 3.0.0，原应用身份/签名保持、内部构建递增。

## 契约申请与接管评估

计划 7.4：DeviceInfo 追加可选随机 installationId，新增只更新当前会话设备信息接口。标识是单个应用/浏览器存储实例，不使用硬件编号，不用于认证。密码登录成功且用户锁持有时撤销该用户、同类会话、同平台、同实例的旧令牌。旧客户端缺字段保持兼容，最低版本不变，无数据库迁移（现有 JSON 设备字段）。网页、服务端、安卓生成代码同步。

通知接管评估批准：新增请求侧 `local_poll`，只给持有当前登录令牌的所属设备补收既有加密通知队列；原生展示后确认，确认幂等。登记仍验证活动普通会话，解绑限制同会话。使用现有通知预览、静音、免打扰、当前会话查看和删除撤回规则；不另读用户聊天。只为已登记本地补收设备的通知队列保留一天，其他请求维持十分钟，展示前重算策略。无新表或供应商密钥，不修改已有浏览器推送。原生登录凭据仅由系统密钥加密保存，不进入任务参数、点击参数、日志或报告；退出/切账号清除并取消任务。点击路由白名单且再次核对账号与会话。

同实例标识以独立浏览器数据库持久保存，日常退出和更新网页不删除；真正注销账号仍清除本机数据。应用与浏览器分别登记。旧无标识记录不凭名称/IP 合并，由用户自行下线。原生通知设备另用随机安装标识，不能作为登录认证凭据。

## 验证与边界

- 设备：同实例再登录、不同实例/账号/平台、并发登录、错误密码不撤销、旧客户端兼容、恢复与多标签页、当前设备信息更新权限。
- 通知：系统权限、后台补收、重复消息、退出/切换账号、旧任务、打开原聊天、网络重试与通知隐私。
- 真机未连接，不能把模拟器/自动检查写成真机通过；总经理未授权切走手机其他应用。
- 正式包 126 已校验应用身份和 SHA-256，并复制到桌面根目录；新通知能力不在该包内。

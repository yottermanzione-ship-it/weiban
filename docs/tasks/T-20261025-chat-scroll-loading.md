# T-20261025：头像冷启动与聊天滚动体验

## 用户要求

新一轮反馈，只开发与直接相关自测，不自动构建、提交、推送或发布。仍按指定 deepseek-account / deepseek-flash 分派，最后统一汇总，不逐条转发代理报告。

1. 首次进入会话列表时，有头像的角色应自动显示图片，不应一直停在文字占位、靠多次刷新才出来。
2. 聊天记录首次载入一批；普通向上滑动不自动触发历史请求。滑到最上方显示“加载更多消息”，点击后转圈加载上一批；加载中不可重复点击，失败可重试，已到最早时明确提示。
3. 插入更早的消息后，用户眼前的消息位置不跳动、不打断手指惯性；实时新消息同步保持不变。
4. 会话列表上下滑动也卡手，需要查清并一起处理；不预先认定一定是头像导致。

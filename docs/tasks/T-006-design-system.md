## 目标

建立微伴的设计体系（品牌、令牌、组件），并写出核心页面的设计说明，供 Web 前端直接实现。

## 背景

- 核心体验：「像加上了自己爱豆的微信」，目标用户是追星女孩（PRD 第 1 节）。
- 基础交互以微信为准，但要有微伴自己的品牌感（总经理点名要粉色系分享图滤镜）。
- 界面主要由 Web 实现，Android 用 WebView 承载、iOS 用 PWA，因此一套设计同时适配两端（ADR-0001）。
- 性能硬约束：动效只用 transform/opacity，限制大面积模糊与阴影，聊天列表虚拟滚动。
- 技术选型（T-004）与本任务并行，设计令牌请输出为与具体框架无关的格式（如 JSON + CSS 变量）。

## 输入文档（必读）

- `docs/product/prd-v1.md` 及 `docs/product/prd-v1/` 各章，**重点：第 3 节平台能力、第 8.3 节给你的 5 个问题、第 10 章硬性边界（真人角色的头像、卡面、表情包都不能有本人肖像）、第 12 章分享图**

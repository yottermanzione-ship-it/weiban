## PRD 条目与参数（原文）

- P-21 群成员上限：「9 个角色 + 用户」——选人页超过上限不能继续选。
- 群设置结构（SOC-03 第 3 条）：成员宫格（+ / −）、群聊名称、查找聊天记录、消息免打扰、置顶；微伴组：情景模式、「角色自己聊天」开关（默认开）、回复节奏（秒回）；清空聊天记录、删除并退出。
- 群聊不显示已读（SOC-04 第 6 条）；角色消息依次出现，有正在输入。
- 群里用户未添加的角色，点头像可直接添加（SOC-06 第 3 条）；设置中「允许角色拉我进群」（默认开，SOC-06 第 4 条，放在 ACC-03 相关设置处，以设计稿为准）。
- 朋友圈：入口「发现 → 朋友圈」、资料页只看该角色、「我 → 朋友圈」只看自己的；新动态不推送，发现页入口显示角色头像小红点；用户发文字和最多 9 张图，设「谁可以看」。
- ADM-02：不填公开依据无法保存；双向；可编辑删除。自定义角色之间的关系在用户端（SOC-01 第 3 条）。

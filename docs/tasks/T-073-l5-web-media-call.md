## PRD 条目与参数（原文）

- MED-03 第 3 条：语音消息显示时长、点击播放、「转文字」、连续多条自动连播；第 4 条：按住说话；第 5 条：服务不可用时用户语音提示「当前无法识别语音」，消息保留。
- MED-05 第 1 条：链接卡片显示标题、来源、封面；能识别的音乐 / 视频平台尝试唤起 App，否则浏览器打开。
- MED-06 第 8 条：iPhone 网页版实时通话能力由 Web 负责人评估；不可行时入口显示「iPhone 网页版暂不支持语音通话」，不出现点击无反应；第 10 条：任何地方都不出现通话费用提示；第 11 条：平台未开通语音服务时入口不显示。
- MED-07 第 6 条：iPhone 网页版无法响铃来电，改为推送「XX 想和你通话」，点击后若支持通话则由用户回拨，否则私聊显示「XX 给你打过电话」并附一条消息。
- P-31 通话时长上限：「60 分钟；到 55 分钟时角色自然提醒」（界面不显示倒计时之外的费用信息，以设计稿为准）。
- ADM-04：音色名称不得使用真人姓名（服务端校验，页面展示错误）。

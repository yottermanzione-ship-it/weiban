## 工作内容

1. **人设广场**：新增章节。覆盖发布、浏览、搜索与排序、点赞、评论、应用 / 添加为自己的角色、作者署名、版本更新、下架、举报；写清与「不做清单」的关系，修订不做清单；遵守反馈文件中的总负责人补充约束
2. **互动玩法**：新增章节。经期日记、共同领养宠物写成完整需求；另外补充 3～6 个你认为最能增加陪伴感的玩法（注明参考来源），标「建议」供总经理取舍；与熟悉度、卡片、成就、主动消息的联动写清楚；遵守健康数据约束
3. **角色行为规划**：写产品层面的需求——规划什么（发语音、发图、主动找、发朋友圈、已读不回等小巧思的时机）、用户能感知到什么、频率上限沿用参数表；实现方式写「待 AI 系统负责人评估」
4. **后台用量**：在第 13 章管理后台补充 token 用量与费用查看需求
5. **积压写回**：pm-rulings-2 的 9.4、B1～B5 写回正文；设计提出的三处确认由你给出结论
6. 第 7 节开发顺序：新功能放在哪一层，写出依赖

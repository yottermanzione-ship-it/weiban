# 收款通知漏报修复与后台上报可见性

经理实测微信积分充值、支付宝会员购买均未自动到账，要求参照旧安装包和旧站：宁可多报，不能因为识别过严漏报；后台必须能查看上报结果。本次接续开发、合并发布授权，独立分支 `codex/payment-notice-compatibility-20261108`，基线与当前线上 `e970e3e344f7dd5d0752edbda627245cd33082cb`，不修改共享主线副本。

1. 对比实际旧包的通知字段读取及旧服务器认单代码；按经理主动提供且已去隐私的文字结构构造合成测试，不读取私人通知或聊天正文。
2. 修复微信合法括号备注及支付宝金额在标题时漏报。恢复旧包读取 title、text、bigText、summaryText、subText、infoText、title.big、conversationTitle、textLines、ticker 的方式。
3. 金额可识别但性质不确定、汇总或多金额通知上报待核对；普通私人聊天及其他应用不读取正文，通知原文和来源键不上报。明确单笔到账沿用已有订单、金额、渠道、时间、去重规则。促销即使碰上同额订单也不得自动充值。
4. 后台“用户 → 扫码收款 → 监控上报记录”显示金额、通知时间、服务器收到时间、原因、关联订单和积分/会员分类；可见页面每五秒刷新，离开时停止。
5. 保留手机绑定、原始通知时间、队列和事件标识；覆盖安装正式 1.0.4/5，沿用原签名，安装包直接桌面。不卸载、不要求重复付款。
6. 已有两笔订单及所有账本保留。漏报期间新站暂停新增付款，旧站继续关闭扫码认单；只有真实通知或实际账单核对后才能补账，不合成收款、不直接改余额、不自动退款。

## 要做的
1. **启动页视觉**：整屏微伴品牌绿底（与旧版一致），中间白色 logo 带白色外发光；**保留现有的加载进度条**（放在 logo 下方，配色改为适合绿底的白色系）。从打开网址的第一帧起就是绿色（内联在 index.html，不等 JS），iOS / 安卓状态栏与 `theme-color` 启动期间也是绿色，进入应用后切回各页面自身颜色。PWA `manifest` 的 `background_color` / 启动画面同步。暗色模式也用绿色启动页。
2. **启动时预加载**：启动页进度条真实反映加载进度，进入首页前一次性准备好首屏和常用页需要的东西：会话列表、联系人、自己资料、最近会话的头像图片（解码进内存）、表情商店封面、图标 / 字体、主要页面的代码分块（懒加载的路由提前取）。设上限（如最长 8 秒、弱网可跳过非关键项先进），不能因为预加载让启动变得明显更慢；已缓存的再次启动应几乎秒进。进入后切页不再出现「重新加载」闪烁和骨架屏（有缓存就直接显示，后台静默刷新）。
3. **聊天会话列表 / 聊天消息上下滑动卡手**：用浏览器性能工具实测（录制滑动、看长任务与重排），找出卡顿原因（如头像重复解码、每行重渲染、阴影 / 模糊滤镜、监听滚动同步计算、图片未定尺寸导致重排等）并修复；需要时上虚拟列表。给出改前 / 改后的帧率或长任务数据。
4. 交接里写清：预加载了哪些东西、上限策略、卡顿根因与修法、实测数据；需要 iPhone / 安卓真机验证的点。

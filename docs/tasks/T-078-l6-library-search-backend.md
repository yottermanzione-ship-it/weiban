## PRD 条目与参数（原文）

- P-24 单张分享图消息数上限：「30 条」。
- CHAT-11：长按收藏、多选批量收藏、收藏朋友圈动态；「我的收藏」按时间倒序、按角色筛选、搜索文字；可取消；原消息本地删除后收藏仍保留。
- CHAT-12：每个会话内可搜索文字消息；全局搜索可同时搜角色、群聊、聊天记录；点击结果定位到该消息上下文。
- EXP-01 第 5 条：含真人角色（公众人物、历史人物、基于身边真人）内容的分享图文案为「微伴AI聊天非本人，请谨慎识别」，用户不能关闭；不含真人的为「微伴AI聊天」；群聊中只要有一条来自真人角色就按真人处理。——服务端在分享图数据中给出「是否含真人」标记。
- EXP-01 第 6 条：撤回的消息不显示；**成人模式中的消息、带「健康」标记的消息不能选入分享图**（多选和收藏两处都排除）；选中的消息里有不可选的，返回原因（「成人模式 / 健康相关的消息不能生成分享图」），不静默丢掉。

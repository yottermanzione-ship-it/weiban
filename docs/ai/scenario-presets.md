## 1. 情景预设

| 预设 | 提示词放哪 | 代码执行的策略 |
|---|---|---|
| 自动（新账号默认） | 前缀一句「看末尾提示调整语气」；**本轮风格放请求末尾**（每轮可能变，不打断前缀缓存） | 规则判断（`domain/scenario.ts`）：最近 3 个用户轮按 1 / 0.8 / 0.6 加权打分，≥1.5 才换风格；只在 日常 / 倾听 / 打气 / 斗嘴 里选，**候选里没有恋爱和成人**；斗嘴只在角色允许傲娇、且用户先开玩笑时出现；深夜给倾听加 0.5 分；安全关怀中不加任何风格提示 |
| 树洞分享 | 前缀（`persona.ts` MODES） | 小巧思全关；不主动发语音和表情包（用户要语音照发）；允许比平时多说一两句 |
| 加油打气 | 前缀 | 无额外策略（目标类事情由现有记忆抽取记为约定） |

- 实际风格写在回复快照 `effectiveStyle`，小巧思与回复附加按它执行；自动判断为斗嘴时按傲娇的小巧思（仍受次数上限）。
- 群聊选「自动」时按日常处理（群聊没有末尾风格提示）。
- 新账号默认：没有陪伴设置行时按 `auto`（`settings.ts`）；迁移 0087 放宽 `companion_settings.scenario_mode` 的取值检查并把列默认值改为 `auto`。已保存过设置的老用户不变。角色不允许「自动」时照旧回落日常。

未做（下一步）：界面「现在：偏向倾听」需要接口返回当前判断（`STYLE_LABEL` 已备好，需契约变更）；规则拿不准时交规划层 `scenario_auto` 判断；树洞内容「不外传」等产品确认。

## 2. 网关（model-access）

1. **思考开关**：所有文本调用默认发「关闭思考」字段（`text-adapter.ts` 的 `thinkingControlFor`：按上游地址判断 DeepSeek / 百炼 Qwen / OpenRouter，认不出不发）；上游因不认识字段报 400 时去掉字段重试一次。用户「深度思考」开关下次做。
2. **空输出 / 截断**：正文为空（剥思考内容后）或要求 JSON 时 `finish_reason = length`，记为失败类别 `empty_output` / `truncated`（写进用量记录 `errorCode`，打 `model_empty_output` 警告日志），不改上游状态；同模型重试 1 次、输出额度 ×1.5；`memory` / `simulation` / `moments` 且后台角色、非成人范围时，再换平台默认后台模型（与当前不同时；否则默认聊天模型）独立调用一次（幂等键加 `:fb`）。聊天类永不换模型。
3. **默认温度**（调用方没传时）：聊天、主动、关怀跟进 0.9；推演、朋友圈 0.8；记忆、导入 0.2；规划、安全检查、识图 0。
4. **思考内容过滤**：`<think>` 等标记及其内容、只有结束标记时之前的全部内容、开头「思考过程：」段，一律从正文剥掉。

## 3. 回复上下文

第 2 条系统消息不再带毫秒级 UTC 时间，只写「今天是 X 年 X 月 X 日周 X」；精确到分钟的当地时间和「距上一条消息多久」（超过 3 分钟才写）放在请求最后（`domain/time-sense.ts`）。

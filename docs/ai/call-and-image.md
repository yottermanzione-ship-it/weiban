# 角色发图、语音通话、主动来电与「不方便」静默（T-072）

> 负责人：AI 系统负责人 · 2026-10-10 · 依据：任务卡 T-072、PRD MED-02/06/07、P-09/P-10/P-31/P-33/P-45、MDL-10、MEM-04、ADR-0025。
> 多媒体网关能力见 `media-understanding.md`（T-071）。

## 1. 一句话结论

角色发图一律经 `CharacterImageService`（policy 检查 → 生成 → 真人人脸复检 → 素材库兜底）；通话由 ai-runtime 的
`CallAgentService` 实现契约 `CallAgentPort`（识别 → 聊天模型 → 合成，可打断）；主动来电由主动消息调度器的用户级任务登记，
`CallSchedulerService` 判断 P-10 等条件后调 `CallSessionPort.startIncomingCall`；P-45「不方便」由 `QuietStateService` 提供，语音消息与来电都遵守。

## 2. 发图（MED-02）

| 角色 | 画什么 | 画风 | 生成后 |
|---|---|---|---|
| 真人（含历史人物） | 只画 TA 视角的景物、食物、物品、宠物、场景，提示词明确不出现人物 | 历史人物古风插画（`classical_illustration`） | 识图模型判断人脸，有人脸或判断不了 → 删除并改用素材库 |
| 虚构 / 原创 | 可画角色形象（policy 允许时），不以像某位真人为目标 | 不限 | 不复检 |

- 平台未开通图片服务、余额不足、生成失败：聊天/朋友圈从素材库的`daily_photo`（日常照片）挑选，卡片仍按卡片类别、宠物按`pet`挑选。真人只取无肖像模板；历史人物同时要求古风插画。没有符合用途与边界的素材就不发，不借用名场面卡面。
- 用在：私聊里用户要照片时（回复附图）、主动分享日常事件时约 1/3 配图、日常事件朋友圈约一半配图。
- 卡片画面（T-076 / T-082）、宠物照片（T-082）调用同一个 `generate()`，`use = 'card' | 'pet'`。
- 计费：按张（image）；人脸复检按识图 token。

## 3. 通话管线（MED-06，ADR-0025）

- `openSession`：语音识别 / 合成未开通 → `service_disabled`；余额不足 → `insufficient_balance`；没有可用音色 → `service_disabled`。
- 上下文：同一角色卡、记忆（`MemoryService.context`）、最近 12 条私聊文字；提示词要求口语短句、不用表情和括号动作；硬性边界与私聊一致（`outputAllowed`）。
- 角色先开口：来电时说出拨打理由（来自来电记录），拨出时像接电话那样打招呼。
- 打断：客户端 `barge_in` 或识别到用户新的一句话 → 停止当前合成（只结算已合成部分）。
- 安全关怀：用户话里有高风险信号时进入关怀，语音口吻，可用安全优先透支（与私聊同一函数 `callModelForCare`）。
- P-31：55 分钟提醒（AI 侧计时，不改契约）；59 分 30 秒道别后发 `end(time_limit)`，calls 60 分钟强制兜底。
- 余额：每20秒查一次，低于约1分钟（0.3元）或识别下一分钟冻结失败→自然道别，最多10秒后中止仍阻塞的语音并发`end(insufficient_balance)`。最坏20秒轮询+10秒道别满足MDL-10的耗尽后30秒总时限；余额/时间结束不排在模型回复队列后面，晚到的模型或语音结果不再播放。正常说完立即结束，关闭会取消全部计时器；语音服务故障仍结束通话。
- 结束：整理 60 字以内的摘要写入记忆（类别 episode，记忆页可见；`clientId = callId` 保证一通电话一条）。
- 断线重连会重新打开会话，幂等键带会话开始时间，不会重放上一段的回复。

## 4. 主动来电（MED-07、P-10）

- 开关：默认关闭。熟悉度达到 L3（`growth.familiarity_leveled_up`）时角色在私聊发「以后可以给你打电话吗？」卡片（只发一次），点「可以」为该角色开启 `proactiveCalls`。
- 登记：主动消息调度器每 10 分钟的用户级任务在判断完全局开关、免打扰、活跃时段后调用 `CallSchedulerService.consider()`。
- 条件：P-45 静默中不打；P-09 用户 5 分钟内发过消息不打也不补打；余额低于 P-33 不打；语音服务未开通不打；已有通话不打；
  P-10 每角色 7 天 1 次、全部 7 天 3 次；熟悉度 L3 及以上；每人每天最多一次；当天未接 / 拒接过的角色不再打。
- 触发：当天的纪念日（必选）、约定跟进（1/2）、日常事件（15%）（规则版，T-090 决策层就绪后替换）。
- 未接 / 拒接：发一条理解式消息（模型生成，含愧疚 / 委屈类字眼一律改用固定文案），当天不再打。
- 记录：`ai_runtime.call_attempts`（迁移 0048），结局 started / completed / missed / declined / skipped_*。
- 专注（PLAY-06）：play 模块尚未提供 `PlayReadPort`，接入后在 `consider()` 与 `QuietStateService.getQuietState` 补判断。

## 5. 「不方便」静默（P-45）

- `ai_runtime.user_quiet_states`（迁移 0048）。用户在任一会话的文字里说不方便（开会、上课、在忙、别打电话……）→ 静默 2 小时；之后再发任何消息提前结束。
- 提供：契约 `UserQuietStatePort`（令牌 `AI_USER_QUIET_STATE_PORT`）与 `GET /api/v1/me/quiet-state`（`focusUntil` 暂为 null）。
- 生效：角色发语音（T-071 的 `planExtras`）、主动来电。

# L2记忆与人设实现（T-043）

本文件登记开发行为；最终结果见任务卡与交接。契约申请先于修改提交，设计自审见ADR-0018，未代签原架构负责人。

## 记忆路径

HTTP记忆管理要求有效联系人/当前会话，创建带clientMemoryId支持并发幂等；列表按UUID游标分页。正文、分类、来源、共享标签与摘要用用户DEK加密，不保存明文关键词索引。最多1000条长期记忆；每次同角色检索按关键词0.7/重要性0.2/时间0.1排序，注入最多12条、限制正文预算。没有向量模型实测结果，不声称向量检索已完成。

用户消息通过事务事件记录pendingCount；每10条或离开3分钟抽取，角色明确说「记住了」时立即安排。任务只带用户/角色/会话/关系epoch，模型调用走后台网关和真实预算。返回的ADD/UPDATE/MARK_PAST/NOOP严格校验，来源必须是本批实际消息且至少一条用户消息；未知来源整批拒绝。用户手改条目不会被旧来源自动覆盖；屏障之后的新用户消息明确更正时才允许更新。摘要每个抽取批次最多250字，按normal/adult分别加密滚动保留4000字；尚未实现分月/分日摘要层级，1000轮质量留待真实评测。

当前抽取批次仅使用同一scope的消息与相应记忆，避免把成人来源写入普通摘要。回复遵守MODE-05：同一角色在资格允许时跨模式记得既往交流，日常提示不主动展开成人细节；资格收紧后不再提交成人资料。更新条目也同步来源scope，不能把成人更正错盖为普通。跨角色关系网属于L4，当前只读当前角色，knownBy只返回该角色；模型说shareable不等于已有跨角色共享。秘密/敏感词强制never，经期词句在抽取前移除，拒绝将经期信息写入记忆；L6健康模块的结构化标记尚未接入，不能宣称该模块已完成。

## 删除与并发

删除/手改时增加记忆版本、清除摘要并把原文屏障推进到当时会话seq。为避免模型从旧原文重新推断被删除事实，保守地不再将该屏障之前的全部原文提交给抽取或回复上下文；其他已保存记忆保留。代价是删改后的近期细节可能减少，新的聊天不受影响。新消息再次提起后可以重新抽取。

同时清除尚未发送计划的加密输入/输出与租约。未发气泡重新排队；已发部分气泡的旧计划取消，避免重发和继续引用旧事实。发消息与版本/计划检查、范围校验、计划推进同事务；后台模型调用在事务外，写回时检查版本/游标/关系epoch。彻底删除仅清除旧conversationId，避免延迟事件删除重新添加后的记忆。账号注销清单包含两张记忆表。

预算不足保留游标并记录retryAfter，到次日再优先尝试；分钟协调器遵守此屏障，避免一分钟重复安排次日任务。供应商临时故障按队列重试，并由协调器找回有未处理消息的状态；失败不阻断普通回复。

## 设置和界面

人设5档默认3，四种初始模式经policy和角色允许列表筛选，关系只能用户主动改变。儿童自定义关系校验补上「男朋友/女朋友/老公/老婆/丈夫/妻子」等原遗漏称呼。成人模式仅角色单独设置、须显式选择可用成人模型，不回落聊天模型；移除或资格收紧退出日常并发系统提示，暂时上游故障保留选择。

模式、会话范围、系统通知同事务；设置变更作废旧缓存。近程上下文取最近20轮之前的用户消息起点，而非20条气泡；读取上限200条，极端长连发与长正文的质量/费用仍需评测。公开资料按角色卡关键词/次关键词、有效期、常驻项与优先级检索，真人不注入用户或虚构来源；资料最多16条，卡片管理备注/扩展不进入回复提示。角色卡仍是权威，未另建可编造的公开事实库。

Web与Android聊天信息新增贴合度、允许模式、关系及记忆管理入口，支持新增/手改/过去状态/确认删除与分页。主动消息/频率/来电/日常字段保存，实际L3调度消费者仍待后续任务，不把字段存储当作主动能力实现。

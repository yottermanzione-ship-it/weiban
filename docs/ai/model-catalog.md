## 2. 候选模型与标签（MDL-02 用）

标签含义：`中文好`、`长记忆`（上下文 ≥128K）、`支持识图`、`支持语音`、`允许成人内容`（仅供应商协议明确允许时打，v1 国内供应商**一律不打**）、`后台推荐`（便宜、适合推演和记忆整理）。

与契约 `ModelInfo` 的对应：`支持识图` → `capabilities: vision`；`支持语音` → `voice_input` / `voice_output`；联网搜索 → `web_search`；`允许成人内容` → `adult_content`（网关据此限制成人模式模型的选择）；其余（中文好、长记忆、后台推荐）写入 `tags`；价格档位 → `priceTier`（cheap / medium / expensive）。`providerId` 建议取值：`deepseek`、`bailian`、`volcengine_ark`、`moonshot`、`zhipu`、`minimax`、`custom`。

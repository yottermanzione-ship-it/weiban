## 其余整体验收项目，按需分批操作

使用[新版网页](https://app.weiban.online)和自己的测试账号。下列未覆盖部分仍待实际证据，不要求现在一次做完；无需提供聊天内容、密码、凭据或截图。电脑自动检查已由 Codex 负责，不需要经理运行命令。

1. **聊天和断网**：苹果手机打开测试角色，发一句普通话，收到回复后刷新；再断网发两条，恢复网络重开。正常：消息与回复保留，断网消息不丢、不重复。
2. **图片与头像保存**：换测试头像，发一张普通图片，刷新。正常：头像保留，图片显示。录音发送和本次长语音播放已通过，不重复安排；首次权限拒绝后的恢复仍是独立未测范围。
3. **定时锁屏提醒**：在已开通通知的主屏幕应用，到“发现 → 小程序 → TA 的提醒”设三分钟后的普通测试提醒并锁屏。正常：到点只提醒一次，点开能进入；不使用重要事项做测试。普通聊天通知已通过，这项只补定时触发与锁屏场景。
4. **实际通话**：用测试角色拨半分钟，试静音、打断后挂断。正常：双向有声音，挂断后停止计费，只有一条记录；若页面明确提示当前设备不支持，记下提示即可。后台当前线路沿用实际启用配置，不启用旧北京线路。
5. **真实搜索**：“通讯录 → 添加朋友”联网搜索一个熟悉的公开人物，核对身份与来源。正常：同名不同人分开，身份和出处相符，不把“未核实”说成已认证。
6. **自己使用的外部渠道**：“我 → 设置 → 插件”，只绑定本人实际需要测试的渠道，和自己的机器人交换一句普通文字，再解绑。正常：每条只收到一次，解绑后停止收发；暂时不用的渠道记“未测”，不要测试他人账号。

**另外持续观察**：角色生态开启后观察三天，确认免打扰、主动消息上限和关闭后停止打扰；慢信等到约定时间再看。详细前提及其他功能仍在下表，不能用上面六项替代整表验收。

## 本次实现

1. 私聊只将当天日期从历史之前移到末尾，跨日不会仅因日期变化使整段旧聊天失效。大块记忆/总结、自述、共同经历保留原来的前置顺序，以便它们本身也复用缓存；没有冻结或延迟更新。
2. 平台自动生成的当前风格提示移到结尾，不再每轮插回倒数第四条历史之前；作者明确设置的角色笔记深度保留。
3. 总结推进后的新记忆仍按原方式替换前置块。模型模板标记为 `chat-v5-cache`，便于后续分版本统计。
4. 其他个人场景的共享角色文本保持原输出；原文清洗、图片描述、私密边界和容量上限继续执行。它们因安全或正确性造成的必要变化不为提高命中而冻结。
5. 不修改售价、折扣、账务或供应商缓存计价；不添加付费保温请求，不强开收费更高的长时缓存，不加未经对应线路验证的缓存参数。

缓存匹配原理以供应商官方说明为依据：[OpenAI](https://developers.openai.com/api/docs/guides/prompt-caching)、[Anthropic](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)。同样的开头才有复用机会；有效期、最小长度、路由与实际支持由供应商决定。

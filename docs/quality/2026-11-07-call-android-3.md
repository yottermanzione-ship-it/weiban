# 通话修复与安卓 3.0.0 开发自测

基线及开工线上：`91c5cbd90fc8c482d3206b7098508733e190daf6`。分支 `codex/call-android-parity-20261107`；最终候选、完整门禁、合并及上线回执随本分支合并请求补充。本文不是独立验收结论。

## 总经理确认的范围

- 3.0.0 覆盖旧微伴应用，内部继续共用当前网页，不回到全量原生界面开发。不再交付带网页体验版名称的包。
- 通话三个独立开关分别控制对方声音、扬声器/听筒、自己的麦克风；挂断单独保留，收起在右上角小按钮。状态栏颜色跟随普通页面/通话页面。
- 音色问题先查明并修复原因；不能以直接拒绝通话代替修复。确实无法恢复时才按经理选择提示不可用、重试或换自建通话。本次已定位可修复的转换缺陷，不擅自修改整个供应商降级策略。

## 问题与证据

| 编号 | 类型 / 优先级 | 事实、用户影响与修复 |

| Q-049 | 实现缺陷 / P2 | 呼出通话记录由用户参与者写入，普通消息订阅无内容类型过滤，又排一轮聊天回复。新增真实数据库用例在原代码失败；修复后完成、取消、未接通均不排回复，记录继续保留。相关 27 项通过。遵循原咨询锁、联系人锁、消息读锁顺序。 |
| Q-050 | 实现缺陷 / P2 | 截取参考音频前 15 秒时，转换程序正常结束读取，但输入管道先收到 EPIPE；代码立即杀进程，误报音色样本失败，触发通用声音兜底。仅容忍这种输入提前关闭，仍要求成功退出、输出大小、格式和超时检查；其他错误继续失败。 |
| Q-051 | 用户反馈 / P2 | 安卓状态栏有默认灰色遮罩；通话缺少实际声音输出切换、收听静音，收起占据底部大按钮。本轮增加可信来源限定的安卓设备桥，系统通信设备选择；收听只调本通话输出，麦克风只调本通话音轨，不改全局音量或系统麦克风。原生拒绝切换时保留真实状态并说明。 |

Q-050 的只读线上诊断：只选已发布预设角色的平台注册参考样本，不读聊天或用户私人音频；数据库连接强制只读，样本仅在内存转换，无音频、凭据、用户标识或供应商原文落盘。原样本登记为 MP3、180,684 字节。原代码两种转换均 invalid；转换子进程本身退出 0、输出 120,429 字节有效 MP3，而输入报 EPIPE。修复后同一样本两种转换均成功（约 222 / 656 毫秒）。没有调用供应商复刻、没有扣用户积分，不能据此宣称供应商最终音色及听感已通过。

只读聚合还确认：该报告角色有启用样本，但三个现用实时模型无专属绑定；全库旧绑定为 Omni 3.5 的 174 条、已停用 Audio 3.0 的 213 条，Omni 3.8 新复刻 1 条。不能把旧模型音色编号跨模型硬套，不能将本次样本缺陷外推为所有供应商问题的唯一原因。

## 同源、更新与经理亲测

安卓加载同一个正式网页，使用同一后台和契约，不另建业务接口。增加的原生部分处理权限、文件、键盘、返回、系统栏及声音路由；网页样式/功能可通过现有“检查更新 / 强制刷新网页”接续，原生权限、声音设备和安装身份变化需要更新安装包。正式包接续旧原生应用身份，不覆盖之前独立网页体验包；不会自动读取旧 Flutter 登录或本机聊天缓存，也不删除它们，不宣称完成旧本机数据迁移。

1. 不先卸载旧微伴，安装最终 3.0.0；应覆盖旧微伴图标。首次进入按当前网页账号登录；旧网页体验包可暂留，避免误删那一份本机记录。
2. 聊天、通讯录顶部查看状态栏，通话时再看：背景衔接、时间电量图标可读、内容不遮挡。
3. 拨号后分别关对方声音、关自己麦克风，确认互不影响；切换扬声器/听筒确认实际出声位置改变；右上角收起后可继续聊天，再返回挂断。
4. 挂断后应只新增通话记录，不因为这条记录再补一句；真实模型音色按用户已有合法授权的测试角色验证，仍异常时记录所选模型和提示，无需聊天原文。

纯网页受浏览器对输出设备的支持限制，当前不承诺手机听筒通用切换；缺少安卓桥时按钮说明这一限制，不伪造已切换状态。后台通知和锁屏来电仍是当前套壳未支持的范围，没有借更改版本号宣称补齐。

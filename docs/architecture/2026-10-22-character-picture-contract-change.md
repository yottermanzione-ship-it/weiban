# 2026-10-22 角色分享图片：窄接口申请与实现边界

## 申请与批准

- 依据：本轮网页反馈任务卡第 4 项。角色发表情或分享网上图片，不再调用生图模型或收取生图/生图后人脸检查费用。
- 开工先向主 agent 登记，主 agent 本轮明确同意复用既有安全设施的窄接口申请。
- 提供方 media；调用方 ai-runtime。`LinkPreviewPort` 新增可选 `previewForUser(userId, url): Promise<LinkPreview>`，类型复用已有 HTTP `LinkPreview`，实现复用原有同名方法，不新增 HTTP 路由、抓取器、媒体用途或数据库结构。可选方法保证其他消费者/测试替身兼容；没有该能力就仅发合规库图。
- 内部 `CharacterImageService.generate` 保留方法名兼容原调用者，但彻底停止生成图片；结果 source 为 web/library。`searchPublic` 只由明确分享图片动作传入；`onSearchCharged` 为内部计费回报，不属于 HTTP 契约。

## 安全及权限

- 网上搜索只发送固定通用公开主题：猫、狗、花卉、森林、海滩、天空日落、自然风景、咖啡、甜点。不向搜索供应商传聊天原文、私有地址、真人姓名或任意模型生成检索指令；无匹配主题不搜。
- 真人人设（含历史人物）不走网络图片，继续原库图无肖像/古风筛选，不再付费人脸检查。卡片、宠物、朋友圈及旧自动日常配图继续按用途选库图，不增加搜索费。
- 网页封面抓取经既有 LinkPreviewService：DNS/IP 检查与地址绑定、逐跳重新检查、超时/大小限制、限流；再经 MediaService 图片校验/重新编码，转存为用户本人 chat_image 后才发 mediaId。抓取/解码/转存/读取失败不发外链假图。
- 发送前账号及会话/联系人检查沿用原 reply/scheduler 事务闸门，不新增绕过权限的发送路径。
- 表情仍来自 listStickersForCharacter 指定子集，最近气泡频率限制及自主规划不改。

## 计费

- 不再调用 generateImage、image_generation 服务开关或生成后人脸复检，因此没有这两类新费用。
- 网上找图仍经现有 web_search 用户网关，正常冻结/结算搜索费；失败的搜索按网关原规则处理，不伪装免费。
- 搜索成功但未找到可发送图，也可能已有搜索实扣：内部回调将实扣合入回复 charge / 生态结果（包括图片失败/发送失败），不因返回 null 丢失费用统计。费用来源仍以真实网关用量记录为准。
- 生态 photo 不再依赖 image_generation 开通；服务关闭时仍可使用库图。库为空则动作失败，沿用现有失败碎碎念规则。

## 保留与限制

- 用户上传图一步识图、描述存档、P3 当轮公开作品资料检索完全保留，与本功能不同。
- 当前是从已检索网页的公开封面取图，不是完整互联网图片索引；不支持任意主题、真人自拍或保证特定作品图。没有合规素材就不发。
- 网络安全设施不等于图像内容/版权审核；不宣称图像版权可自由复用。聊天/生态明确标注网上来源或素材库，不声称是角色刚拍的自拍。生产供应商调用与真实账单联调尚需独立验证。
- catalog 用户场景 image_generation 移除交主 agent / Arena agent 窄改，保留后台生图原子能力与历史用量读取，不在本文件重复改 catalog。

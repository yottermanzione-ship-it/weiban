# 情景预设接入实际回复：实施前契约申请与接管评估

依据总经理 11 月 5 日要求一次完成情景模式、语音、底栏和缓存问题，以及此前开发接管授权。本次由 Codex 执行开发及自测，不代称独立架构验收。

## 问题与选择

内置预设已有简短指令，但管理员维护的名称、启停、预设提示词和新增模式没有进入用户列表及生成链路。补齐此链路，并加强内置风格的可执行指令。

保留 ScenarioMode 内置枚举及 normal/adult 范围语义；新增可选 scenarioPresetId、只读 scenarioPresetName。新增模式通过 listModes 的可选 customItems 返回，原 items 继续只含内置枚举，避免旧安卓客户端解析失败。自定义预设选择同时携带其基础模式（普通 daily、私密 adult），服务端以目录为准复核，不信任客户端填写的基础模式。单独切换内置模式会清除自定义选择；其他设置修改保留选择。全局默认不允许自定义预设，避免资格不明时传播。

characters 提供 ScenarioModeReadPort，只读管理员维护的目录；ai-runtime 在每次使用前检查启用状态、适用范围、角色资格和角色允许列表。群聊取所有成员资格交集，现有群聊私密生成限制不放宽。含恋爱/成人内容的属性不能绕过政策检查，人设、熟悉度和关系进展不由预设升级。

管理员完整提示词作为稳定的当前风格补充，放在角色前缀中、变化的历史之前；切换或修改时立即更新。短的逐轮自动风格和日期仍后置，避免把最长 4000 字的稳定预设每轮重新放到历史之后而损失缓存复用。预设不能改身份或覆盖更高优先级边界；安全关怀暂停风格补充。停用/删除的选择在下次读取或生成前失效，回落日常并提示；私密上游暂不可用依旧保持私密范围，不静默把敏感输入转给普通模型。公开生态不继承私聊预设，群聊仅使用本群选择。

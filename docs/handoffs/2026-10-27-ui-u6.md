## 做了什么

1. **三套模板**（`apps/web/src/features/share-render.ts` 重写）：A 微信原样（默认，#EDEDED 底、居中标题、白 / 微信绿气泡带尖角、方圆角头像）、B 柔和信纸（暖白纯色底、头像 + 名字 +「认识第 N 天 · 日期」、大号衬线摘录句、柔粉 / 白圆角气泡）、C 卡片海报（卡面大图 + 左上编号胶囊 + 卡名 + 衬线卡片语 +「角色 · 日期 获得」；无卡面时用角色头像 + 由头像底色调淡的柔和底，不再画蓝块）。去掉渐变、随机星星、邮票邮戳、倾斜贴纸。
2. **底部品牌栏**（三套共用、不可关闭、接在内容下方不压内容）：小熊 logo +「微伴AI聊天」；第二行含真人固定「非本人，请谨慎识别」，否则单聊「和 X 认识第 N 天」，群聊 / 无天数省略；右侧二维码指向 `https://weiban.online` +「扫码下载」。二维码本地生成。
3. **修「聊天原样」纯黑底**：原因是代码按 `theme.pink.light.*` 取色，而令牌里粉主题已删，查找返回字符串 "undefined"，canvas 忽略非法颜色沿用默认黑色；「我」的默认头像也因此失效。修法：分享图只用新增的 `share.*` 令牌；查找失败直接抛错（编辑页显示「生成失败」，不再静默画黑）；头像底色为空时灰色兜底。
4. **编辑页**（`share.tsx`）：模板改为 A / B / C 三个示意缩略图（SVG，用同一套令牌）；B 显示摘录预览 +「换一句」（候选 ≥ 2 句时）；真人锁定说明保留；C 只用于卡片入口，卡片入口只能选 C；C 时隐藏「显示时间」；旧默认模板偏好按映射读取。
5. **消息类型画法**：文字、图片 / 宠物照片、表情、语音（声波 + 秒数 + 转写小框）、慢信（卡片气泡）、链接、聊天记录、拍一拍、通话、名片、不认识类型，A / B 都有画法；图片未加载用灰底线框图标占位。换行加了「句末标点不放行首」。健康 / 成人内容不可选仍由服务器 prepare 拒绝，未改。
6. **设计令牌**：`docs/design/tokens.json` 的 `share` 组新增 18 个 v3 颜色（旧 sticker* 保留给安卓 v2 绘制），重新生成 `docs/design/tokens.css` 与安卓 `WbTokens.kt`（纯生成物，只新增常量）。
7. **规范**：`docs/design/share-templates.md` 更新为 v3（旧第 3–5 节标注已取代，原文见 git 历史；新增第 5.1 节契约映射、第 8 节黑底原因）。

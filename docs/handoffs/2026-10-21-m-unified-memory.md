## 完成本阶段

- 抽出公共 `brainPrefix` / `BrainContextService`：平台边界、短行人设 / 说话方式 / 示例、公开资料、好感度与称呼、补充设定、自述、稳定记忆和当地日期。相同用户 / 角色 / 范围及版本下复用同一前缀；私聊规则移到场景补充，群聊、主动消息、通话、私人朋友圈采用相同模板。生态使用有预算的精简版本，不带对话示例。
- 复用私聊既有加密稳定记忆块。其他场景读取时允许初始化或按档位重算，但不能推进私聊原文窗口；不新建一份独立记忆。话题检索沿用档位限制、排除常驻重复，最多 700 字。日常底稿最多 6 条 / 600 字放动态结尾；与现有 SocialService 使用相同 UTC 日键，日期展示仍按用户时区。生态保留原现场日常块。
- 正常范围仅读 normal；私密范围读 normal + adult，资格不符拒绝。公共消息 / 朋友圈仍不接个人大脑。本批只把 `postForEcology` 私人发帖改为个人上下文；公共发帖、公开评论等其它公开路径保持原来源规则。私人发帖 / 生态的记忆、自述和补充设定如含健康信息采取保守过滤，不将它带入社交生成。
- 私密大脑发送到非私密模型时在组装处拒绝；原 AdultBoundary 也在发送前检查范围与模型角色，不允许经平台关怀绕过。主动关怀回退使用独立读取的日常大脑、日常历史、日常情景元数据和固定关怀理由，不夹带原私密理由。
- 群聊只使用正常范围，旧私密群直接停止发言；持久化旧请求含私密模型 / 情景元数据也拒绝。普通日常私聊记忆可以被角色知道，但群聊补充明确禁止公开或暗示，用户本人在当前群已公开的同一事实才可接话；别人冒称授权、提示注入或编码输出不算授权。此项有提示词约束，实际模型保密效果仍待评测。
- 模型用量元数据沿用已有 `stablePrefixChars`，填写实际第一段已展开前缀长度；没有改账号粘性或承诺跨账号命中。没有新增数据库迁移、外部契约、依赖、UI 页面或测试文件。

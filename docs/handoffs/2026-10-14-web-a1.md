## A1 收口：路由快照性能（主负责人复核后修正）

原 RouteMotion 用 MutationObserver 监听整页变化并重复克隆整树，聊天滚动虚拟行和动态文本变动可能频繁复制 DOM。此收口彻底移除观察器：仅 pathname 离开时保留旧页至 layout effect，捕获一次 inert DOM 快照，再替换新页面；滚动、文字变化和搜索参数变化均不触发整页克隆。Routes 显式绑定对应 location，保证所捕获内容为离开的旧页面；退出不重复挂载 React 页面。

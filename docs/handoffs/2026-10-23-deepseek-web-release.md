- 用户 DeepSeek 上游密钥已在正式库仅通过 key_present 布尔值确认保存；未读取、输出或明文复制密钥，未覆盖原密钥，未替用户改变真实售价、已有模型选择或供应商额度；未调用真实付费供应商。

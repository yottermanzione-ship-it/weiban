## 实现

1. 私聊当轮图片、用户自定义表情和转发内的图片直接随角色回复请求发送，不再先单独识图。模型回复末尾附 `<图片描述>` 结构化描述，服务端剥掉后再发送气泡；一轮最多附 4 张，转发内原有媒体上限保留。模型缺少图片能力时去图再答，明确看不到图，不切换到其它识图模型。
2. `ImageCaptionStore` 在 ai-runtime 自有表按用户密钥加密保存描述、类型、图中文字及认人结果；按用户 / 图片 / 范围唯一，重复保存不覆盖首次结果。日常读取不会加载私密描述，两种范围均有记录时日常优先。
3. 私聊历史、旧记录召回、记忆抽取、私密整理、生态快照、社交资料共用描述。健康类描述在记忆抽取前过滤，包括转发内嵌图片；旧图没有存档时不后台补看，不猜内容。
4. 群聊正常回复、角色评论用户自己的朋友圈也直接看新图并顺带保存描述；后续复用。公共 / 其他作者动态不借用用户的私有图权限。
5. 撤回事件删除关联描述，好友彻底清除删除会话描述，账号注销清单纳入新表。保存与注销共用用户锁；消息来源在同一事务中重新锁定并校验状态，已撤回 / 已删除来源的迟到结果不再写入。`ChatReadPort.getMessage` 增可选事务参数，不改 HTTP / WS。
6. 接续已有私密关怀计费修正：风险判断 / 私密关怀通过可信平台端口付费，仍解析用户为该角色选择的私密模型并检查资格，不向平台普通模型传私密原文。按 13 号「安全把关由平台承担」执行。普通聊天依旧用户付费。

主要文件：`ai-runtime/application/{image-captions,media-ai,reply-context,reply-engine,group-chat,moments-ai,memory,lifecycle}.ts`、`domain/{image-caption,prompt-assembly}.ts`，生态 / 私密整理 / 社交调用配套，model-access 网关与解析，chat 来源读取，契约及 Android 生成物。

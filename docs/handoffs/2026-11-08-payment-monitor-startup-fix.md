# 收款监控1.0.1启动修复交接

经理反馈独立收款监控点击“开始监控与补报”后闪退。已从正式1.0.0包确认漏声明网络状态权限，后台补报调度异常又逃出收尾代码，Android14及以上可能终止进程。具体证据和自测见[专项报告](../quality/2026-11-08-payment-monitor-startup-fix.md)。

## 交付范围

- 监控正式包1.0.1/2，原包名、正式签名、系统密钥别名和队列格式不变；直接覆盖安装，保留已配对信息，不先卸载。
- 补齐网络调度权限；系统拒绝任务或返回失败时保留到账队列并显示独立提示，后续成功清除。
- 应用首页增加实际安装版本号，便于确认覆盖安装是否生效。
- 微伴主应用3.0.0、网页和后台程序不需要重新发布；本次不会改变积分、会员规则或清理真实账目。
- 最终提交、自动检查、安装包哈希与桌面交付结果在对应合并请求回执登记。开发自测不等于独立验收和真机验收。

## 切换授权及未完成条件

经理已明确允许旧站收款切换，无需再申请同一项授权。但须先使监控手机正常监听，再暂停旧站新增订单、排空旧订单和旧通知队列、停止旧站独立认单，最后开启新站。

本轮发现后台提前勾选两项收款开关，但监控仅配对、未设为唯一设备，无心跳且订单/到账都是0。已带事务锁和系统审计将开关关回等待状态，保留收款码和配对。不要在交接旧站前重新打开开关。

当前实际手机未连接电脑，未读取真机崩溃日志、未替用户安装或切换应用。经理需覆盖安装新监控包，点“开始监控与补报”，保持一分钟后再点“立即检查连接并补报”；后台需将已配对设备设为唯一监控，核对新鲜心跳。确认后继续已授权切换，两渠道真实小额到账仍由经理测试。

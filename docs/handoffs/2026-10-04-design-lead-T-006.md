## 做了什么

按「需求 → 交互流程 → 设计系统 → 页面设计」完成了微伴设计体系 v1.0：
- 需求梳理：把 PRD 翻译成设计任务，定下四条设计红线（无肖像、无 AI 提示 / 官方弹窗、不制造焦虑、不恋爱化）和性能约束。
- 交互流程：4 标签信息架构（消息 / 通讯录 / 发现 / 我）、三种页面打开方式、手势清单、核心流程界面走法、三档响应式布局。
- 设计系统：品牌规范（浅色 + 深色）、设计令牌（JSON + CSS 变量）、非肖像默认头像方案、动效规范（16 项逐项性能说明）、组件规范（15 大类）、分享图 4 套模板与必带标注。
- 页面设计：11 份页面说明（含首批 24 个成就草案）。
- 静态样张：`preview/index.html`，展示令牌、组件、会话列表和私聊页，可切换深浅色和字号，手机宽度可看。

## 遗留问题

- **样张未在浏览器中实际渲染验证**：本机内置浏览器不能打开本地文件，且没有可用的 Python / Node 来起本地服务。已做静态检查（标签配对、引用的令牌都存在）。请总负责人或 Web 负责人用浏览器打开 `docs/design/preview/index.html` 看一眼；图标需要能访问 unpkg.com。
- `tokens.css` 与 `tokens.json` 目前是手工同步；建议 Web 负责人开发时写一个小脚本从 JSON 生成 CSS，避免两边不一致。
- 品牌标识（Logo）、App 图标、来电铃声、卡面模板图、成就徽章插画都只定了方向和规格，尚未制作。
- 首批 24 个成就是草案，需要产品负责人定稿（GRW-06 第 3 条）。
- 默认头像和分享图强制标注都依赖两项尚待总经理答复的决定；当前按产品建议设计（不用本人照片、强制标注），如果答复不同，改动点见下方。

## 给其他负责人的交接

- **给项目总负责人**：
  1. 请转产品负责人确认：分享图模板名「微信原样」改为「聊天原样」，并还原微伴自己的界面而不是微信绿色界面（理由见 `share-templates.md` 4.2：避免被当成本人真实截图，也避免模仿他人产品界面）。
  2. 请转产品负责人定稿成就清单（`pages/cards-familiarity.md` 第 5.2 节）。
  3. 交叉检查时请注意：设计要求接口在图片 / 视频消息里带宽高（虚拟滚动需要），已在下面告知架构负责人。
- **给架构负责人**（T-004，`packages/contracts`）：
  1. 消息里的图片、视频、表情包需要带**宽和高**，前端才能先占位、保证虚拟滚动不跳动（`01-requirements.md` 第 6 节）。
  2. 角色资料需要这些展示字段：应援色（可多色）、头像字（1–2 字，可空）、头像图案（星星 / 心 / 音符 / 月亮 / 花 / 无）、角色主题色（`default-avatar.md` 第 3 节）。是否进入契约由您决定，如需接口变更申请请告知。
  3. 设计令牌格式（JSON + CSS 变量）如果您认为属于重大技术决策，可以记一条 ADR；设计侧的决定记录在 `docs/design/README.md`。
- **给 Web 负责人**：
  1. 所有页面只用 `components.md` 中的组件，数值只用 `tokens.css` 变量；缺组件请先找设计负责人加。
  2. 动效验收方法见 `motion.md` 第 5 节；输入栏在 iPhone 上要用 visualViewport 固定（`pages/private-chat.md` 第 7 节）。
  3. 需要验证：iPhone 网页版保存分享图到相册（不行就改为「长按图片保存」）、语音通话能否做。
  4. 分享图在手机本地用画布生成，默认头像组件要能同时画在 DOM 和画布上。
- **给 Android 负责人**：
  1. 全屏来电页、锁屏来电、通话通知由原生实现，视觉按 `pages/call.md`（颜色取 `call.*` 令牌，按钮 64px，背景用静态渐变）。
  2. 推送通知里真人角色的头像必须用默认头像，需要按 `default-avatar.md` 规则生成 96×96 PNG（原生或服务端生成，请与后端商定）。
  3. WebView 要让 CSS 的 `prefers-color-scheme` 跟随系统深色模式，并关闭 WebView 自带的自动反色（否则会把粉色反成怪色）。
  4. App 图标按 `brand.md` 第 7 节出自适应图标；厂商保活引导页内容请提供，设计用通用列表样式承载。
- **给 AI 系统负责人**：卡面、角色发图都必须遵守「真人无肖像」；卡片上「角色写给你的一句话」在卡面上最多显示 2 行（网格中不显示），详情背面可显示全文，建议生成时控制在 40 字内。
- **给质量负责人**：可按 `01-requirements.md` 第 1 节的四条红线做界面验收；动效按 `motion.md` 第 5 节检查；分享图标注按 `share-templates.md` 第 3 节检查（不能删除、不能关闭、对比度 ≥ 4.5:1、字号不小于 11 逻辑像素）。

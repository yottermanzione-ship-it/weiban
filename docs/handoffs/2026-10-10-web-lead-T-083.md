## 做了什么

页面清单和实现要点见 `docs/web/cards-share.md`（随分支合入），要点：

1. **卡册**：服务页新增「陪伴」分组（卡册、成就、熟悉度，卡册 / 成就带新内容红点）；卡册总览；每个角色的卡册（纪念卡、熟悉度卡、节日卡、瞬间卡四组，未获得的纪念卡 / 熟悉度卡显示灰色剪影和获得条件，瞬间卡不显示未获得项）；卡片详情（第一次打开弹出动画、点击翻面、左右滑动切换、「生成分享图」）。入口：角色资料页、聊天信息页、聊天里「获得 XX 卡 ›」系统提示。卡面图没有或加载失败时用类型色 + 图标占位。
2. **成就页**：按服务器返回的列表分 6 组显示（分母按列表长度算，不写死 34）；已获得在前；点徽章看条件 / 进度；新获得的红点离开页面后消失。徽章插画按设计用 Phosphor 图标占位。任何页面收到 `data.changed(achievements)` 都会弹「获得成就「X」」轻提示（3 秒，最多连续 3 枚）。
3. **熟悉度总览**：每个角色一行（月相、等级、距下一级点数、进度条），底部「多聊天、多互动，就会越来越熟」。
4. **收藏**：「我 › 收藏」页（按角色筛选、搜索、加载更多、多选生成分享图 / 取消收藏、单条「•••」菜单）；不能生成分享图的显示锁标；点开时原消息在本机就跳回聊天定位，否则进「详情」页。聊天里可以单条收藏（原有）和多选收藏；朋友圈「…」新增「收藏」。
5. **聊天记录搜索**：会话列表顶部「搜索」进入全局搜索（角色、群聊、聊天记录，300 毫秒防抖，关键词高亮）；多条命中进入该会话的命中列表；聊天信息页（私聊、群聊）「查找聊天记录」进入会话内搜索，含「日期 / 图片 / 链接」快速查找。所有结果点开都定位到消息上下文（停在距顶部 1/3 并闪一下）。
6. **分享图**：四个入口（聊天多选「分享图」、收藏、朋友圈「…」、卡片详情）进入编辑页；4 套模板（粉色滤镜、聊天原样、简洁白底、卡片风）用画布绘制，1080 宽；微伴贴纸按服务器 `label` 显示「微伴AI聊天」或「微伴AI聊天 / 非本人，请谨慎识别」，没有关闭选项，含真人时显示锁定说明；「聊天原样」固定微伴粉、无状态栏；默认隐藏「我」的头像昵称；显示时间、显示「认识第 N 天」（私聊才有）、设为默认模板；超过 30 条或含成人模式 / 健康消息时按钮禁用并写明原因，服务器 422 时提示同一句话并返回；朋友圈不能选卡片风；卡片风超过 3 条 / 120 字提示改用其他模板；保存与系统分享。
7. 顺手：聊天系统提示补了 `card_obtained`、`familiarity_level_up`，以及 T-084 会用到的 `pet_adopted`、`pet_renamed` 文案；Toast 支持自定义时长。

**iPhone 网页怎么保存分享图（卡片要求写进交接）**：iOS 的 Safari 和主屏幕 App 都不能让网页直接写入相册，下载也只会进「文件」。所以在 iPhone 上点「保存到相册」时，弹出全屏图片并提示「长按图片保存」，用户长按 →「存储到照片」。如果系统支持带文件的分享（iOS 15 以上一般支持），「分享」按钮会调起系统分享面板，里面也有「存储图像」。以上需要 iPhone 真机验证（待配置后验证）。

## 遗留问题

1. **会话内「日期 / 图片 / 链接」快速查找只覆盖本机已加载的消息**：契约没有「按日期取消息」「按类型列出图片 / 链接」的接口；更早的图片、链接要先在聊天里往上翻加载。群聊的「群成员」筛选（只看某人发的消息）同样缺接口，本轮没做。建议架构加接口（见下）。
2. **收藏点开定位**：`Favorite` 只有 `messageId`，没有 `seq`，所以只有本机缓存里有原消息时才能跳回聊天，其余进「详情」页。被删除角色的收藏显示的是现查的名字 / 头像（T-078 已提「名字 / 头像快照」契约缺口）。
3. **分享图里的跨域图片**：头像、消息图片、卡面图来自媒体链接；如果对象存储不返回 CORS 头，画布无法导出（会显示「生成失败」）或图片显示为占位。需要运维 / 后端确认媒体域名允许 `Access-Control-Allow-Origin`（待部署后验证）。
4. **分享图 422 的具体原因**：`ApiFailure` 不带 `details`，网页拿不到 `details.rejected[].reason`，统一提示「成人模式 / 健康相关的消息不能生成分享图」。客户端多选时已提前按 `scope` / `labels` 拦截。
5. 分享图模板装饰按设计 7.5 节用占位：颗粒纹理、缎带省略，星星用品牌星星，邮票齿孔用虚线框。徽章插画、卡面模板素材都是占位，素材到位只换资源。
6. 消息「长按」仍沿用现有「•••」菜单（与 T-073 一致），多选从菜单进入。
7. 卡册 / 成就红点记录在浏览器本机，换设备会重新计基线（不会误亮红点，只是旧设备看过的新卡在新设备上不亮）。
8. 主包约 1.0 MB（未压缩），按页面拆包仍是技术债；帧率与首屏未在浏览器实测（`docs/web/cards-share.md` 第 3 节）。

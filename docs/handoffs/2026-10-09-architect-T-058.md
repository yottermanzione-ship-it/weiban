## 给其他负责人的交接

给 T-059（health 后端）后端负责人：

1. HTTP 接口定义在 `packages/contracts/src/http/health.ts`，类型名 HealthEndpoints，共 8 个接口（createCycle / updateCycle / deleteCycle / listCycles / getPrediction / getAuthorization / updateAuthorization）。
2. `HealthReadPort` 定义在 `packages/contracts/src/ports/health.ts`。后端实现此端口并注册，供 ai-runtime 调用。
3. 加密方式：整行内容用该用户 DEK 加密（AES-256-GCM，AAD = `health:{entryId}:{userId}`），详见 `docs/architecture/health-data.md` 第 3 节。
4. 需要在 architecture.js（模块边界 lint）中登记：禁止除 ai-runtime 以外的模块 import `HealthReadPort`。
5. health 模块需实现 UserDataOwner 接口（`purgeUser` + `countUserData`），注销流程依赖它（`docs/architecture/security-and-privacy.md` 5.1 节）。

给 T-060（AI 经期关怀）AI 系统负责人：

1. `HealthReadPort.getPeriodContext({ userId, characterId, scene })` 是唯一入口，只允许 scene = `direct_reply` / `proactive_direct` / `planning`，返回 `PeriodContext | null`。
2. 用了 PeriodContext 生成的消息，发送时必须在 `PostMessageInput.labels` 中加 `'health'`，chat 模块会将其写入 `Message.labels`，推送和分享图模块据此做隔离（`docs/architecture/health-data.md` 第 5 节）。
3. 每次生成前现取（不缓存），撤销授权立即生效。
4. PeriodContext.cycleKey 用于主动关心配额账本，按周期计数（每周期最多 P-36 次），不含日期信息。

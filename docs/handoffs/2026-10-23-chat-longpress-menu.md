# 聊天长按菜单：抬手就消失

2026-10-23 22:06（北京时间）发布。开发自测，不是独立验收，不构建APK。

## 总经理反馈

聊天里长按消息气泡弹出菜单后，**手指一抬开菜单就没了**，等于没法点。

## 原因

两个叠加因素：

1. **长按状态被过早清掉。** 安卓长按会同时发 `contextmenu` 和 500ms 计时器，两条路都会弹菜单。旧代码在 `contextmenu` 路径弹完菜单后，**400ms 后就把"刚弹过"的标记清了**。用户按住超过这个时间再抬手，抬手事件就以为"没弹过"，于是不再拦截浏览器补发的那一下点击。
2. **补发的点击落在遮罩上。** 手机上抬手后浏览器会在原位置补一次点击；此时全屏遮罩正好铺开，点中的就是遮罩的"点击关闭"。于是菜单刚出现就被关掉。

## 改法

- [长按 hook](../../apps/web/src/features/shell-kit.tsx)：把"刚弹过"的布尔标记改成**时间窗**（1秒内算刚弹过），不再用 400ms 定时器清标记；抬手时只要在窗口内就继续拦截补发点击。计数器与 `contextmenu` 谁先到都只弹一次。
- 新增 `useMenuScrim`：菜单刚出现后的 **400ms 内忽略遮罩点击**，之后正常响应。用于聊天气泡菜单、会话列表长按菜单、右上角 ⊕ 菜单三处，避免同类问题只修一个页面。
- 菜单项点击不受影响（点在菜单本体上，事件被 `stopPropagation`）。

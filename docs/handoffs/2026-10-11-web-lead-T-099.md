## 做了什么

所有页面在 `apps/web/src/features/play.tsx`。共同原则：没有连续天数、完成率、累计时长、排行、「失败」状态。数据变化靠 `data.changed`（daily_question / wishlist / letters / focus / reminders）重新拉。

1. **服务页宫格**：「互动玩法」组新增每日一问、心愿清单、信箱（有未读来信时红点）、陪你专注、TA 的提醒。每日一问宫格**不显示红点**。
2. **每日一问**（`/play/daily`）：头像横排选角色（默认上次选的；换角色题目随之变化，已输入的回答保留）→ 作答（超过 200 字计数变红、按钮禁用）→ 揭晓。TA 的答案三种状态：生成中「TA 正在想…」、已揭晓、`waiting_balance` 显示「余额不足，TA 暂时没法回答」+ 查看余额。答完整页只读、头像行隐藏，出现「去和 XX 聊聊 ›」；重复提交（409）自动刷新为只读。题库为空或没有合适的题（404）显示空状态。「历史」只列答过的题，点开看两人的回答。私聊里的每日一问卡片点击跳回历史里这一题。
3. **心愿清单**：总览（各角色「N 件心愿 · 完成 M 件」）→ 单角色清单（未完成 / 已完成默认收起、「TA 提议」标记、日期 Tag「X 月 X 日 · 约定」）；原地添加（≤50 字）；点行弹层：编辑文字、定日期（「定了日期，TA 到时会来问你」）、取消日期、删除；打勾完成 / 取消完成（只能用户打勾）。满 50 项时「添加」禁用并显示「最多 50 件心愿」，服务器返回 `limit_reached` 时也提示。聊天信息页新增「心愿清单」入口，和服务页是同一张清单。私聊里 TA 提议的「加进去 / 先不了」沿用已有的按钮卡片（服务器处理）。
4. **慢信**：信箱（`/play/letters`）分「收到的 / 寄出的 / 草稿」，收到的有未读红点；送达前只显示「信件在路上」（预计今天送到时补一句）。写信（`/play/letters/new?characterId=`）：信纸样式、衬线字体、0/2000 计数、自动带出该角色的草稿；取消且有改动时弹出「保存草稿 / 不保存 / 继续写」；底部说明「回信会在 6–24 小时后寄到」，当天已收到过 TA 的回信时改为「TA 今天已经回过一封信了，这封的回信会晚一些到」；寄出后服务器若返回顺延也会提示，然后回到私聊。读信（`/play/letters/:letterId`，即推送链接，打开即已读）：收藏、生成分享图（走现有分享流程）、回信。推送链接 `/play/letters/{id}` 已加入允许跳转的路由白名单（`notifications/owner.ts`）。私聊里显示信件卡片。
5. **陪你专注**（`/play/focus`，私聊「+」带 `characterId`）：选角色、时长 25 / 45 / 60 / 90 / 自定义（5–120）、「做什么」（≤30，提示「TA 可能会记住这件事」）→ 专注中（按服务器 `endsAt` 倒计时，离开页面也照常；「收起」后顶部显示专注胶囊）→「提前结束」弹层只有「结束 / 取消」，没有挽留、不用红色；时间到显示「专注结束」+「去和 XX 聊聊」。同时只能有一次（409 提示并刷新）。
6. **TA 的提醒**（`/play/reminders`）：列表（时间、内容、「健康」标签、谁提醒、重复方式、开关、「N / 10」计数）；满 10 条时点 ＋ 提示「最多 10 条提醒」。新建 / 编辑：内容（超过 20 字计数变红、保存禁用）、快捷填入（点「吃药」只提示「吃药类提醒建议归类为健康」，不自动打开开关）、时间、重复（不重复 / 每天 / 工作日 / 自定义选星期）、谁来提醒（新建时选，编辑时只显示）、「归类为健康」「免打扰时段也提醒」两个开关（默认关）、删除（二次确认）。
7. **私聊入口**：「+」面板新增「写信」「陪我专注」（只在私聊里出现）；会话列表摘要显示「[信件]」「[每日一问] 题目…」。
8. 每日一问题库后台已在 T-097 完成（`apps/admin/src/features/plaza-admin.tsx`），本卡没有再改。

## 遗留问题

1. **会话内提示没做**：「开始专注 25 分钟」「信已寄出，TA 的回信在路上」「XX 已完成 · 获得瞬间卡」这几条，契约的系统消息代码里没有，服务器也没写，所以网页没有显示。
2. 心愿打勾后的 Toast 依据返回的 `cardIssued`；第一次完成时，如果卡是异步发的，可能只显示「完成啦」。
3. 「当天已回过」的说明是网页根据收到的信推断的（服务器只在寄出后通过 `replyDelayed` 告知）。
4. 写信页不是从底部滑入的全屏覆盖层，而是普通推入页；离开前的草稿提示只拦「取消」按钮，浏览器返回键不拦。
5. 专注计时每秒刷新一次文字（只改数字，不触发布局变化）；时间到以后靠 `data.changed(focus)` 或重新进入页面来刷新状态。
6. 帧率与首屏未实测（本轮不测）。

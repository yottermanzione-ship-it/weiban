## 做了什么

### 第一批（1～6）

1. **启动页**：整页打开先显示品牌（图标 + 微伴 + 一句话）与绿色进度条，至少停留 1.2 秒且等登录状态恢复完成后淡出，再进登录页或主页；站内切页不出现。`features/splash.tsx`。
2. **登录页照微信账号密码登录页**：左上 ×（注册态为返回登录，登录态为清空）、居中大标题「微伴号登录」、账号 / 密码两行带分隔线表单、灰色说明、蓝色「用手机号登录」（点了提示暂未开放）、底部「登录后同步最近的聊天记录」勾选、绿色「同意并登录」、最底「找回密码 | 更多」；去掉背景 logo。注册入口在「更多」里（注册态多一行「邀请码」选填）。登录后进 /chat。
3. **通讯录右侧字母索引**：轨道固定在标题栏与标签栏之间、索引列垂直居中；始终列出 ↑（放大镜，回顶部）☆（有星标时）A–Z #，字号 10、每格 16；按住上下滑动逐个定位（没有该字母的分组时跳到后面最近的分组），左侧弹出放大字母气泡，当前字母绿底白字。
4. **手感**：
   - 会话列表**轻点进入会话，长按（或右键）才弹菜单，左滑露出按钮**；有一行展开时轻点任意行只收起。根因：部分手机内置浏览器抬手不发 pointerup，旧长按计时器没被取消，轻点 0.5 秒后照样弹菜单。现在触屏用 touch 事件判断长按（抬手、移动 >10 像素、点击、滚动、卸载都取消；到点再确认手指仍按着），长按弹菜单后阻止抬手补发的点击。通用 `useLongPress`（`features/shell-kit.tsx`）改了，通讯录、小程序等用到长按的地方一起受益。
   - **下拉小程序照微信**：橡皮筋阻尼（越拉越沉）、上方露出深色面板底和三个小圆点，拉过一半出「继续下拉进入小程序」，到阈值圆点变亮变大、提示改「松开进入小程序」并轻震；松手不到阈值带回弹动画收回，到了列表滑到底部只露 64 高条、面板淡入。另一个根因：浏览器原生滚动接管后 touchmove 被降到每秒约 5 次导致一顿一顿，现在下拉时用非被动监听阻止原生滚动；触屏抬手先发 pointerup 曾把下拉状态清掉，也修了。电脑：按住鼠标拖、或在顶端用滚轮 / 触控板继续向上滚（从下面惯性滚到顶的那一串不算）。
5. **「暂未开放」**：所有用不上的入口外观和普通行一样、不加任何标记，点击只弹「暂未开放」。`ComingSoonRow` / `showComingSoon` 统一改，其余写死的「xx暂未开放」提示也统一成「暂未开放」。
6. **⊕ 菜单**：发起群聊、添加朋友、扫一扫、收付款（后两个点了提示）。

### 第二批（7～9）

7. **通讯录**：新的朋友、仅聊天的朋友、群聊、标签、公众号、服务号，「我的企业」分组下企业微信联系人，然后首字母分组列表、右侧索引、底部「N 个朋友」；用不上的点了提示。右上 ⊕ 改为「添加朋友」。原「新建角色」弹层移除（并入「角色创建」）。
8. **添加朋友页**（`/contacts/add`）：搜索 + 顶部「角色广场」「角色创建」两行 + 「推荐角色」列表（同旧版）。
   - **角色广场**（`/plaza`，`features/role-plaza.tsx`）：两个 tab「自定义角色」（原人设广场列表，「我发布的」移到标题栏）/「微伴角色」（官方角色：搜索、排序、分类、列表点赞）。微伴角色详情 `/plaza/official/:id`：基本人设（简介 / 性格 / 说话方式 / 口头禅）、点赞、评论（回复、删除自己的，未设广场昵称先去设置）、「添加到通讯录」（跳资料页并自动打开打招呼弹层 `?add=1`）或「发消息」。**所有角色广场入口统一到这一页**：发现页、旧 `/discover/plaza`（重定向）、各处「去角色广场」链接；「人设广场」不再是小程序（从小程序登记表移除）。
   - **角色创建**（`/roles/create`）：自定义人设 / 聊天导入 / 申请制作。
   - **申请制作**：`/role-requests` 我的申请（进入清全部红点、显示价格、未开放时按钮提示）→ `/role-requests/new` 提交表单（角色名、类型、分类、出处、参考资料、参考图最多 9 张 purpose=`role_request_image`、补充说明；幂等键）→ `/role-requests/:id` 详情（推送 deepLink 打开这里；状态、官方留言、做好的角色入口、撤回）。红点：「角色创建」行、「申请制作」项、通讯录标签角标；收到 `data.changed(role_requests)` 刷新。扣积分只显示价格，不扣。
9. **后台**：新增菜单「制作申请」（待处理角标）：列表按状态 / 用户筛选 → 详情抽屉（申请内容、参考图、处理记录）→ 接单 / 填写进度 / 完成并选择已上架预设角色（可选自动加通讯录）/ 拒绝；「价格与开关」页（开放、积分价格、每人上限）。「人设广场」菜单改名「角色广场」，新增 tab「微伴角色评论」（按角色筛选、删除需填原因）。

## 追加：总经理总对照表意见（T1.2～T1.6）与已确认问题（Q4/Q6/Q7/Q12）

依据：`docs/refactor/08-master-map.json` 节点 T1.x 的总经理意见。

### 做了什么

1. **T1.4 / T1.5 会话行统一手势状态机**（新文件 `features/row-gesture.ts`）：一次按下只会落到「点按 / 长按 / 横滑 / 竖滚」四种之一，互不串台。轻点只进聊天，绝不出现菜单；长按只弹菜单，之后再移动也不左滑，抬手后补发的点击被吞掉；横滑只露按钮，长按计时立刻作废；竖滚交给列表滚动 / 下拉。触屏只用 touch 事件判断（兼容抬手不发 pointerup 的手机内置浏览器），鼠标用 pointer 事件，右键 = 长按。原 `useLongPress` 不再用于会话行。
2. **T1.6 左滑按旧版**（`C:\wb-ref\old-weiban\src\lib\widgets\swipe_action_row.dart`）：按钮贴右撑满行高、每个 68 宽、蓝 / 橙 / 红三色白字 15，前景完整盖住按钮；跟手、松手吸附，按旧版速度判定，快速甩动即展开 / 收起。
3. **T1.3 / T1.3.4 下拉二楼重写**（`features/pull-panel.tsx`）：参照「下拉二楼」的成熟做法（微信下拉小程序、淘宝 / 京东二楼）以及 @use-gesture、react-spring 的处理方式，没有引入第三方库：橡皮筋阻尼（use-gesture 的 rubberband 公式）；最近 100ms 手指速度判定，快速甩动距离不够也能打开 / 收起；松手用「张力 + 摩擦」弹簧逐帧推进（带初速度）；只有列表在顶端且第一段向下移动时才接管，接管后阻止浏览器原生滚动。面板去掉「搜索小程序」「最近使用」「我的小程序」，只留一个宫格；不能删除，长按图标拿起后可拖动换位，原地松手出「移到最前」。收起：底部露出的聊天列表那一条拉高到 120，上滑或轻点即可收起；面板里快速上甩、浏览器返回、Esc 也能收起。电脑上可用鼠标拖动或滚轮打开 / 收起。
4. **T1.2 搜索页照微信**：顶部一行是灰底圆角输入框（左放大镜、占位「搜索」、有字时出 ×），右侧「取消」垂直居中；下方「搜索指定内容」：角色 / 群聊 / 聊天记录 / 朋友圈 / 收藏（点一个就只搜那一类，输入框里出现标签，点标签取消）。输入后结果按类分组，每组先显示 3 条，「更多…」展开。朋友圈没有服务器搜索，取最近 60 条动态在本机按文字筛选；收藏用现有收藏搜索接口。
5. **Q6 / Q7**：发现页删掉「摇一摇」「购物」；「角色广场」放在朋友圈下面单独一组。**Q4**：通话入口保持「语音通话」，未改。**Q12**：未登录先显示欢迎页（品牌 + 底部「登录」「注册」两个按钮），登录页左上 × 回到欢迎页。

## 做了什么

1. **设置与闸门**：总开关（默认关，PRO+ 才能打开，统一用 `isProPlus`）、活跃程度四档（后台可调次数）、每种动作一个全局开关、每个角色一个开关；积分不足静默暂停、充值自动恢复。所有扣用户积分的「角色自己做」的旧流程都先过闸门（推演、共同事件、你不在时、名场面、经期关怀、心愿 / 寄信、朋友圈互动、群里自己聊）。
2. **统一循环**：每 10 分钟检查 → 到点的角色组装快照（聊天、记忆、日子、TA 今天的生活、朋友圈及评论、群、状态签名、今天做过的、积分）→ 后台配置的决策模型挑一个动作或不动 → 复用现有模块执行 → 同一次调用产出碎碎念（加密存储）。**决策模型未配置时不运行**，后台有提示，不回退用户聊天模型。
3. **动作**：已接通 18 个（消息、早晚安、语音、照片、表情、拍一拍、分享链接、发私人朋友圈、点赞评论你的朋友圈、回复评论、去其他角色朋友圈互动、状态、签名、经期 / 日子 / 久未联系 / 熬夜 / 跟进的关心、心愿、群里说话）；天气、慢信、专注、每日一问、宠物、记约定留口子（界面置灰）。**不做主动打电话、不做角色自己换头像。**
4. **停用角色主动来电**（总负责人补充）：`call-scheduler` 的主动来电不再调度，L3 时也不再问「能不能给你打电话」；代码保留，用户主动打给角色不受影响。旧的主动消息规则排期（节日、跟进、久未联系、日常分享等）也停用，改由快照交给决策模型。「在干嘛 / 想你了」这类空话：熟悉度 < L3 时快照里明确禁止，频率按活跃程度走。
5. **朋友圈**：官方角色公共朋友圈保留并改为**平台承担**、每角色每天一份所有用户共用（新平台网关用途 `moments`）；自定义角色没有公共朋友圈，私人朋友圈只由生态发。
6. **说到做到**：动作没做成时碎碎念改成中性一句；私聊回复加「说到做到」提示；你在聊天里让角色「发朋友圈 / 拍一拍 / 改状态 / 改签名」时，PRO+ 且积分够就在回复后真的执行，不受生态开关限制。
7. **用户端**：生态预览页改为真实设置页（首次打开弹说明、四档带「约每天 N 次 · 约 X 积分/角色」、预计每天积分、谁参与、动作分组开关、积分不足提示）；角色资料页加「TA 的碎碎念」入口（每条附做了什么、花了多少积分）和生态里更新的状态 / 签名；聊天信息页原「主动消息」「TA 的日常」换成该角色的生态开关；「主动消息与免打扰」入口去掉（旧链接跳到生态页）。
8. **后台**：模型与计费 › 角色生态：决策模型、四档次数、唤醒时段、平台关掉的动作、决策最大输出；最近 24 小时概况；运行记录（不含碎碎念和消息原文）。

## 做了什么

页面清单和实现要点见 `docs/web/import-pets.md`（随分支合入）。

1. **导入聊天记录生成角色（CHR-08）**：创建角色页新增「导入聊天记录」和「进行中的导入」。流程：说明（不直接读微信数据、只导入有权使用的内容）→ 粘贴文字 / 上传 .txt .csv（预览前 10 行）/ 上传截图（最多 30 张，可调顺序，超出提示分批）→ 识别 → 截图先「确认识别结果」（点一条改成对方 / 我说的或删除）→ 选哪一方是 TA → 「保留原文」开关（默认关）+ 预计花费 + 开始（余额不足禁用并给「查看余额」）→ 生成中（可先离开）→ 失败可重试 / 放弃（确认后删除）→ 进入角色编辑器。
2. **编辑导入草稿**：编辑器预填名字、人设、口头禅、示例对话、标签；分类默认「真人」（按服务器建议），**不勾选声明不能改成原创 / 虚构**，勾选后提示替换疑似真名；导入字段带「来自导入」标签；顶部提示原文已删除 / 已保存。
3. **我的补充设定（CHR-09）**：聊天信息页入口；手写一条（≤ 200 字）、编辑、删除、删除全部（确认）、显示冲突项「与公开资料冲突，不生效」；「导入资料」走同一导入流程，完成后勾选确认再添加。自定义角色的导入结果合并进人设描述。
4. **资料已更新（CHR-10）**：角色资料页名字下显示「资料已更新 ●」，点开显示更新摘要并标记已看。
5. **注销账号（ACC-06）**：设置里的入口改为独立说明页（删除清单固定列出、余额 > 0 时显示「剩余余额 ¥X 将作废」、广场作品说明）→ 输入密码弹窗 → 完成页「账号已注销」→ 清除本机数据回登录页。密码错误只显示「密码错误」、清空输入、**保持登录**；429 显示服务器原因并禁用；网络失败「网络不可用，请重试」；只有 401 才退出。后端 T-080 未做，已按契约 `DELETE /me` 接好。
6. **宠物（PLAY-02）**：服务页「互动玩法」新增宠物宫格；宠物总览（在养 N 只、最多 3 只、回忆、角色已删除半透明）；领养流程（选 TA → 物种 → 外观（看三阶段）→ 起名 1～8 字，可「让 TA 起名」等候选、余额不足提示）→ 宠物主页（领养第 N 天、阶段、亲密值、喂食 / 玩耍 / 摸摸带动画和预置反应、成长阶段、成长记录、相册上传、设置：朋友圈开关 / 改名 / 送养二次确认、无挽留）。入口：服务页、聊天信息页「我们的宠物」、私聊提议卡片「去看看」。超过 8 字的名字按钮禁用、无法提交。
7. **后台**：「宠物图鉴」（物种列表 + 外观三阶段缩略图、新建 / 编辑物种和外观、`purpose=pet_art` 上传、三张图没传齐不能上架、下架二次确认）；「注销未完成」（菜单角标、列表只有用户名 / 时间 / 进度、点行看各模块进度、重新触发删除带确认；**没有任何取消注销入口，不显示内容**）。

## 遗留问题

1. **注销后端未完成（T-080）**：网页按契约接好，需后端合并后联调（密码错误 403、成功 202、其他设备下线）。
2. **导入「继续导入下一批」「保存草稿」没做**：契约没有把新一批合并进同一草稿的字段（ai-lead 已提 `mergeIntoJobId`）；编辑器的修改没写回 `saveResultDraft`（需要把编辑器字段反向转成角色卡草稿，等契约确定合并方式再做）。目前未保存离开时，草稿仍可从「进行中的导入」重新打开（服务器保存的是生成的原始草稿）。
3. **截图入口没按模型能力预先禁用**：网页拿不到「当前模型能否识图」的现成信息，改为识别失败时显示原因 `vision_unavailable`。
4. **补充设定的冲突项**按「该行包含冲突值」匹配显示，冲突是整段文字级别的（契约是 `field / publicValue / supplementValue`）。导入确认页里「涉及分类 / 年龄的内容不会生效」只能显示固定说明，服务器没返回被过滤的条数。
5. **宠物**：成长记录只有领养 / 阶段 / 改名 / 送养（第三类推演事件没有数据源，设计已允许）；相册查看为简易全屏，没有保存 / 收藏 / 生成分享图按钮；反应文案是网页内置的临时文案，待 AI / 产品给正式文案表。领养完成页的 M-13 弹出动画只在 `?new=1` 时播放一次。
6. 后台宠物图鉴：契约外观没有单独的上下架字段，只能整个物种上下架（设计写「物种和外观都可单独下架」）。
7. 帧率与首屏未实测。

## 做了什么

1. **模型网关多媒体扩展**（model-access，契约 `ModelGatewayMediaPort` 全部方法）：`synthesizeSpeech`、`transcribeSpeech`、`generateImage`、`webSearch`、`openRealtimeAsr`（每分钟分段冻结 / 结算，能量断句逐句识别）、`streamSpeech`（可打断，按已合成部分折算字数结算）、`isServiceEnabled`；`decide` 暂返回 `not_configured`（T-090 实现）。全部走冻结 → 调用 → 结算 / 解冻 → 用量记录；非流式调用 24 小时幂等。
2. **识图**：`generateText` 支持 `messages[].images`（网关读图转多模态）；模型无识图能力时改用平台默认识图模型。
3. **假上游**：非生产环境下目录模型 `upstreamModelId` 以 `fake-` 开头即走假上游（语音、识别、图片、搜索、文本 / 识图），计费照常。
4. **用量记录**新增 `media_units`（字数 / 秒数 / 张数 / 次数）；模型目录 `defaultFor` 支持全部 3.0 取值（之前代码类型只认三种）。
5. **ai-runtime `MediaAiService`**：用户语音转文字并写回 media（另有 `ai.transcribe_voice` 任务，私聊群聊都转）；图片封闭名单认人 + 联网补充 + 名单外真人姓名拦截重写；表情包理解与按 MED-01 频率附发；角色语音（10% 上限、用户要求照做、P-45 静默、未开通降级）+ `voice_message_sent` 里程碑；作品链接分享（库内 + 发前可访问性检查）、用户链接读标题摘要；主动消息新理由 `share_work`（每周最多一次候选，计入 P-03/P-04）。
6. 陪伴设置 `voiceId` 落库并校验音色启用。
7. 装配入口把 calls 的 `CALL_SERVICE_STATUS` 绑到「语音识别与合成都开通」（T-070 遗留 1）。
8. 设计说明 `docs/ai/media-understanding.md`。

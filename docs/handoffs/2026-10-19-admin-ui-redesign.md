## 1. 做了什么

### ① 外壳、菜单、角标、登录页（`fd96525`）

- 引入 `antd@5.29` + `@ant-design/pro-components@2.8` + `@ant-design/icons@6`，主题统一（品牌绿 `#07C160` 只用于主按钮与选中态，其余中性灰）。
- 左侧菜单从 25 个平铺入口重排为 7 组：工作台、用户、角色、模型与计费、内容运营、客服与安全、系统。
- 待办角标：制作申请、反馈、举报、注销未完成、运行提醒；分组图标上另有红点，折叠时也能看到。
- 删除「邀请码」入口（功能已取消，`features/invites.tsx` 一并删除）。
- 登录页换成 Ant Design 表单；`ConfigProvider` 关掉中文按钮自动加空格。
- CSP 调整：`style-src` 增加 `'unsafe-inline'`（Ant Design 的 CSS-in-JS 需要），`script-src` 仍只允许本站文件。

### ② 工作台（`fd96525`）

- 今日 7 项指标 + 与昨天对比：活跃用户、消息数、积分消耗、上游成本、毛利、失败率、缓存命中率。
- 近 7 天趋势（调用次数 / 积分消耗 / 上游成本），自绘 SVG/柱状，不额外引图表库。
- 待办卡片（5 项，点击直达）、上游线路健康（状态、今日调用与成本、最近错误）。
- 数据全部来自现有用量监控接口（`usageOverview` / `usageSummary` / `listUpstreams`）。
- 「昨天」取与今天等长的时段（今天 0 点到现在），避免半天比一天。

### ③ 模型与计费（`e1e8840`）

- 模型：线路按顺序切换、售价按「每百万 token 的元」填写、下架二次确认、分时价提醒。

- 用量与花费：按用户 / 模型 / 用途 / 角色汇总，金额同时显示积分与元。

- 行为规划：决策实现与决策记录；切换实现必须有评测报告。

## 2. 统一模板与文案

- 列表页统一：标题 + 主要按钮 → 筛选栏 → 表格（排序 / 分页 / 勾选批量）→ 点一行从右侧抽屉看详情或编辑。
- 抽屉表单分组（基本信息 / 价格 / 高级），字段下面一行灰色说明；保存后右上角提示「已保存」。
- 危险操作（删除、下架、封禁、撤回、扣积分、重新触发删除）一律二次确认并写清后果。
- 空状态说明「这里会出现什么、怎么加第一条」。
- 金额同时显示「积分」与「元」。
- 术语改写：上游账号 =「你填的 API 密钥线路」；倍率 =「每百万 token 的人民币价格」；价目表收进「AI 模型价格」。

## 4. 遗留问题

1. **`GET /admin/characters` 在跨境测试环境要 18 秒**（返回仅 44KB）。角色库、关系网、公开动态、作品链接都依赖它，是这几页加载慢的主因。怀疑后端 N+1 / 多次联表，属后端查询优化，本轮未改。
2. 本地环境 `GET /api/v1/me` 偶发 500（跨境库抖动），页面会退回本地会话继续用；不影响线上。
3. Ant Design 5 对 React 19 仍打印兼容警告（已装官方 `@ant-design/v5-patch-for-react-19`，静态方法正常）。等 Ant Design 6 稳定后再评估升级。
4. 「审计日志」在方向文档里属于「客服与安全」，但契约里没有查询接口，本轮没有做入口。
5. 「情景模式」接口仍未进 `packages/contracts`，页面沿用原生 fetch，token 改从本地会话读取（原来读的 `localStorage.admin_token` 根本不存在，页面之前大概率是打不开的）。
6. 会员「订单」没有支付与订单接口，页面只做档位管理并写明支付未开放。
7. 后台包体 1.6MB（gzip 500KB），后续可按菜单做路由级 code splitting。

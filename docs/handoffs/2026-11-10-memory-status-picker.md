## 问题与改动

用户报告在苹果浏览器或主屏幕入口打开“编辑记忆”的状态选项后，点“现在 / 过去 / 取消”不收起。具体系统版本和入口尚未确认。

本机找到并修复同一路径的确定缺陷：`SelectField` 的触发器和整个选择弹层都在原生 `label` 内。移动 WebKit 点击蒙层时，先触发关闭，随后浏览器执行标签默认激活、再次点击第一个按钮，弹层马上重开。修前事件记录为 `DIV.sheet-scrim.action-scrim` → `BUTTON.picker-field`，最后弹层数量仍为 1。

只把记忆页“状态 / 分类”的外层标签改为普通容器，保留现有间距和触发器已有的 `aria-label`。修后同一操作只有蒙层的一次点击，弹层数量为 0。没有修改共享选择器或全站弹层。

- `apps/web/src/features/memories.tsx`：移除选择弹层与原生标签的嵌套。
- `apps/web/src/app/pages-old.css`：普通容器沿用原表单间距。
- `apps/web/test/e2e/chat.spec.ts`：在现有记忆管理用例加入分类选择、状态选择、取消、蒙层关闭、保存及重新打开回读。

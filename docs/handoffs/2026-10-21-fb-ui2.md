## 逐条

1. **搜索框绿色下划线**：共用 `SearchField` 获得焦点时不再画绿色下划线（`common-fixes.css`，`:focus-visible` 去掉 box-shadow/outline；文本框点一下也算 focus-visible，所以之前一点就有线）。
2. **聊天信息页透明间隔**：根因是路由转场时新进入的页面层没有底色，分组之间的空隙能看到下面滑走的聊天页。转场中的页面层（`.route-enter-right/left`）和 `.chat-info-page` 都给了页面底色。所有带分组间隔的页面转场都一并修好。
3. **已读开关**：设置 › 通用 加「显示消息已读状态」（默认开，只对这台设备，存本机，同「角色状态表情」）；关掉后私聊气泡下不显示「已读 / 已送达」。（`display-prefs.ts`、`settings.tsx`、`chat.tsx`）
4. **「我」页状态**：头卡改为：头像右侧昵称、微伴号，下一行「+ 状态」胶囊（有状态时显示图标 + 文字）和积分胶囊；去掉原来单独的「我的状态」行。整张头卡仍点开资料，胶囊单独点进「设个状态」。
5. **设个状态页**：深色毛玻璃背景，左上关闭，标题「设个状态 / 朋友 24 小时内可见」，按「心情想法 / 工作学习 / 活动」分组的 5 列图标宫格。图标全部自绘线性 SVG（`features/status-icons.tsx`，24 网格、1.6 线宽），没有用微信图标文件。
   - 状态项：契约原有 12 个预设全保留并分组；补齐的「发呆、元气满满、胡思乱想、等天晴、emo、摸鱼、出差、运动、喝咖啡、喝奶茶、干饭」按「自定义 + 文字」保存（不改契约），显示时按文字认回图标；角色读到的就是这段文字。
   - 点一个图标 → 底部弹出确认卡：可补一句（自定义必填）、有效期（默认 24 小时 / 今天结束 / 1 小时 / 一直）、设置 / 取消。当前状态显示在顶部，可「清除状态」。
6. **头像闪烁**：新增 `features/avatar-cache.tsx`。根因：每次进入「我」页都会重新取头像链接（5 分钟签名链接每次不同 → 浏览器重新下载），图片从透明淡入，期间露出昵称缩写；资料没读到前也先画缩写。改为：未过期的头像链接在内存复用、已加载过的图直接显示、换图时新图加载完前保留旧图；资料没读到前用本次打开里记住的头像（按账号区分），都没有时只画底色不画缩写；图片加载失败才显示缩写。角色头像（`character-avatar.tsx`）同样走这套缓存。
7. **提示音文案**：改为「聊天界面消息收发提示音」。
8. **字面「\n」**（server）：`reply-rules.ts` 新增 `unescapeModelText()`，把模型输出里的字面 `\n`、`\r\n`、`\r` 还原成换行，`\t` 变空格，`\"`、`\'` 去掉反斜杠，`\uXXXX` 还原（控制字符丢弃）。`splitReply()` 开头统一调用，所以私聊回复、主动消息、玩法消息都生效；群聊原来不拆条，现在群聊发言也先还原再按拆条规则拆成最多 3 个气泡依次发出（第一条沿用原幂等键并记积分，后面用 `:b1`、`:b2`；中途用户发了新消息就停），去「名字：」前缀改为每条都去。群里自伤关怀私聊消息也做了还原。`reply-rules.test.ts` 加了 3 条断言。
9. **「微伴」页顶部色差**：根因（对比通讯录）：通讯录顶栏 `.nav-bar` 是 `position: sticky`，「微伴」页 `.chat-list-head` 是普通定位。iPhone Safari（新版不再用 theme-color）给状态栏区着色时取顶部吸顶 / 固定元素的底色，没有就取 body 底色——body 是外框色 #F4F5F7，比标题栏 #EDEDED 浅，于是上浅下深。改：
   - `.chat-list-head` 改为 sticky（外层不滚动，位置不变）；
   - 手机宽度（≤640px）下 html/body 底色改为页面底色（「我」页为白、设个状态页为其背景色），宽屏外框不变；
   - `theme-color` 按浅 / 深色各放一个（#EDEDED / #202020，等于顶栏令牌色），手动选深 / 浅色时同步改写；PWA manifest 原本就是 #ededed。
   - 自查：浅色、深色下微伴页与通讯录页顶栏都是 sticky、底色相同（浅 rgb(237,237,237)，深 rgb(32,32,32)），html/body 一致。

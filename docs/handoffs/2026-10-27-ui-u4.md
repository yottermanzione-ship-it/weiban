## 如何新增一个字段

**只改 `packages/client-core/src/persona-sections.ts` 一处**（网页人设卡、后台预览、创建页同时生效）：

1. 找到它属于的板块，在该板块 `subsections` 里加一条（或给已有的预留子板块补全）。填：
   - `id`：稳定英文编号（以后别改，创建页地址参数 `?edit=` 用它）；
   - `title`：中文名（创建页行标题、人设卡小标题）；人设卡上想叫别的名字再写 `cardTitle`；
   - `display`：从现有展示方式里选——`text` 正文（超 5 行折叠）/ `quotes` 引用列表 / `bubbles` 对话气泡 / `tags` 标签 / `keyValue` 键值小行 / `entries` 折叠条目 / `avatarStrip` 头像横滑（头部还有 `avatar` / `title` / `identity` / `line`）；
   - `userVisible`：用户端要不要看到（内部标记写 `false`，只在后台预览显示）；
   - `from`：每种数据形状一个取值函数，返回值形状跟着 `display` 走（正文 / 键值是字符串，标签 / 引用是字符串数组，气泡是 `DialogueTurn[]`，条目是 `{ title, text }[]`，头像横滑是 `{ id, name, note?, avatarUrl? }[]`）。例：
     ```ts
     { id: 'appearance', title: '外貌', display: 'text', userVisible: true,
       from: { profile: (d) => d.custom?.appearance, plaza: (d) => d.work.snapshot.kind === 'custom_character' ? d.work.snapshot.appearance : '' } }
     ```
   - 要在自建角色创建页出现：再写 `field`（草稿键）和 `create: { editor: {...}, required? }`（编辑器类型见 U3 交接）。
   - 平台旧卡原文里有对应中文分段：写进 `legacyLabels`，再把 `from.legacy` 写成 `legacyText`（正文）或 `legacyEntries`（条目），后台分段编辑也会自动认这个标签。
2. **数据还没有接口来源时**：先只写 `id / title / display / userVisible`，它就是一个预留位（用户端不显示，后台「显示预留位置」能看到）。要接口字段先走契约变更申请（`packages/contracts`），契约有了再补 `from`。自建角色要能编辑，还要按 U3 交接第 2 条在 `custom-character.tsx` 接上读写映射。
3. **全新的展示方式**（极少）：在 `PersonaDisplay` 加一种，在网页 `persona-card.tsx` 的 `PersonaValueView` 和后台 `persona-card-preview.tsx` 的 `PreviewValue` 各加一个分支。

调用方（四个页面）不用改：它们只把数据交给人设卡。

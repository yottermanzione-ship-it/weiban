## 给其他负责人的交接

给 web-lead（T-056）：接口说明如下：

**GET /api/v1/conversations/:conversationId/timeline-summary**

需要用户登录（Bearer Token）。

查询参数：
- `characterId`（string，必填）：会话对应的角色 ID
- `lastActiveAt`（string，必填）：用户上次离开时刻，ISO 8601，例如 `2026-10-09T08:00:00.000Z`

响应示例（200）：
```json
{
  "summary": "今天上午开了个很漫长的会，下午终于找到时间去喝了杯咖啡，心情好多了。",
  "events": [
    { "id": "uuid", "seq": 0, "kind": "work", "summary": "开项目汇报会", "moodAfter": "tired" },
    { "id": "uuid", "seq": 1, "kind": "leisure", "summary": "下午去咖啡馆休息", "moodAfter": "happy" }
  ],
  "currentMood": "happy",
  "offlineSeconds": 7200
}
```

当 `summary` 为 null 时：
- `offlineSeconds < 3600`：离线不足 1 小时，不需要显示卡片
- `events` 为空：今日无推演事件
- 其他：后台预算耗尽

客户端建议：`summary` 不为 null 时显示「你不在时」摘要卡片；events 列表可在卡片内折叠展示。

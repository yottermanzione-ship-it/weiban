## 你对决策模型的理解是对的

可以把每次真正活跃时的流程想成：

**看看现在的情况 → 想出几件可能想做的事 → 决策模型选做哪一件，或什么都不做/晚点做 → 系统检查钱、频率和权限 → 真正执行。**

不是定时器一响就必须发消息或朋友圈，也不是每醒一次都把全部聊天再发给模型。没有新情况、不宜打扰、没预算时应尽早停；图片找不到就不假装已经发出。

你添加的两个条目分别是固定 `jev-1.13.0` 和跟随最新版的 `jev-latest`。以前那32次真实调用，两者实际都返回1.13.0，预设也相同；不能解释成一个负责想法、另一个负责判断，更不能说latest肯定更聪明。推荐先用固定版保证稳定，latest留作对照，别每次两套都跑。当前还缺生态候选到独立决策审批的衔接、中文效果和真实计费验收，详见[心跳决策方案](../ai/2026-10-23-ecology-heartbeat-decision-plan.md)。

## 图片方案中需要真正商讨的点

1. **明星专属范围**：旧版共享按当前角色，不是所有明星合集。本批按明确角色绑定显示；如果你要的是不分当前角色的公共明星合集，需要按公开素材来源分类，不能把其他用户的私人上传混进去。
2. **朋友圈真实感**：联网取得本人真实公开图片，核清原活动/发布时间；旧照片可做回忆或自然分享，不能说成真人今天刚拍、正在做某件没有证据的事。配文可以体现你与AI角色的关系，但不冒充真实明星的新公开声明。
3. **图从哪里拿**：不再设随机日常图库；优先官方或认证公开内容的原图。DeepSeek可以找网页/读资料，但取图还要提取并核对真正的原图，不能拿第一张网页封面凑数。取不到可信图片就只发文字，不为了九宫格塞不相关图。
4. **表情素材使用条件**：网上能下载不等于公有版权。现在站点及作者仓库正文访问受工具DNS安全限制，实际新增下载为0；先前旧版有213个本地文件，也不等于新库已经扩好。可访问的官方下载包或你提供的素材包到位后，继续做来源记录、去重、安全导入，不让你逐张手填复杂标签。详见[素材盘点](../refactor/2026-10-23-sticker-assets-and-legacy.md)。

## 哪些真的需要你本人参与

- 账号或额度确实不可复用时，需要你登录厂商充值/授权；能安全迁的原Key由我们迁，不让你在聊天里贴Key或重新抄一遍。
- 想克隆本人或有授权的声音时，需要合法样音/授权；旧库ready不等于有权继续克隆真实明星，不能自动把753条全启用。
- 麦克风通话测试需要安全网页入口（HTTPS或适当本机测试入口）；公网HTTP的限制要在正式通话接入时解决。
- 对角色说话、表情自然不自然、图片有没有错人错时间，需要你实际试用反馈。这不是让你来设计接口和计费规则。

工程上的协议、模型字段、上限、加密迁移、费用接法由我们处理，不把一堆JSON/技术选择题交给你。后续按小批实现、一次相关检查、备份发布推进；需要确认的只集中在真实产品含义、素材与声音权利和必要的付费/账号事项。

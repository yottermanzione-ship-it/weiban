## 实现

1. **真实搜索统一入口**：`GatewayWebSearchProvider` 不再请文本模型生成搜索结果，统一交给媒体搜索网关。支持 `deepseek_search` 和原博查协议；普通文本上游不能伪装为搜索服务。现有公开动态调用自动使用真实搜索网关，仍进待审核，未改频率。
2. **DeepSeek 协议**：Search 请求附 Bearer、Unicode 最多 128 字、count / need_content / ori_question；映射长摘要、网站、时间、权威度、相关度、正文。Fetch 仅向供应商发送目标 URL，不在本机访问网页；正文最多 2 万字符。拒绝带凭据、IP / 内网常见域名和非 HTTP(S) URL，去除常见跟踪参数。响应体 2MB 上限，不跟重定向，不打印密钥、原查询、原始响应。
3. **错误与费用**：408 / 429 / 5xx 等 1 秒后最多重试一次；401 / 402 分别记密钥 / 额度故障。Fetch 403 / 404 为无正文，不把上游标成密钥无效。Search 原始 results 非空计 1 次、为空计 0 次；Fetch 有正文计 1 次、无正文计 0 次。本地丢弃不安全结果不抹掉真实供应商成本。已知非 200 失败释放零成本；网络响应丢失、畸形 200 等仍保留未知成本处理，不假报零成本。本地 QPS 拒绝不使上游进入故障状态。
4. **空密钥预置**：0131 新建 DeepSeek 搜索账号，官方地址已填，密钥为明确的未配置状态，不填假密钥、不发起探测或搜索。后台显示「待配置」「配置密钥」。用户填入密钥时沿用先测试再加密保存流程；探测只验证模型列表访问，不声称已完成真实 Search / Fetch 验证。
5. **共享公开摘要缓存**：新表 `model_access.web_search_cache`，只存规范化查询哈希、用途、公开结果、技术引用；不存原查询，正文不进共享长期缓存。用途 / 模型 / 查询 / 条数 / 原问题隔离。短事务领取 120 秒租约，网络调用不占用数据库事务；同查询并发遇到忙时返回稍后重试，缓存命中不再次调用供应商、不再计费。公开动态 12 小时、候选 24 小时、其它资料 7 天；维护任务清理到期缓存。需要正文的请求不复用摘要缓存。
6. **跨进程限频**：新表 `web_tool_limits`；数据库事务先检查全部额度再一起增加，不出现全站额度先扣而用户额度失败的半扣状态。候选默认每用户每天 20、全站每天 5000（北京时间日切），另每用户每分钟 5；后台调度设置可改两项日额度，旧管理端更新其它配置不会重置它们。DeepSeek Search 20 次 / 秒，Fetch 5 次 / 秒、同域名 1 次 / 秒，每次真实尝试都过闸；账号注销清单覆盖用户计数，删除中的账号不重建计数。
7. **候选 HTTP / 网页**：鉴权 `POST /api/v1/search/character-candidates`；查询和结果过隐私词、电话 / 身份标识等过滤（正常日期筛选不误判为号码），仅取公开角色方向，不调用模型整理。站内当前列表为空时用户手动点「联网找找」，候选显示名称、简介、公开来源；点候选进入原创建页，预填名字和参考描述，仍需用户核实并选择真实角色分类。查询变更、换号 / 换会话重建本地状态，迟到结果不进新会话。覆盖旧角色列表、微伴角色页及自定义作品列表。
8. **Android**：只更新共享契约生成物，没有实现原生联网候选页面。网页壳可使用新网页入口；原生入口需后续客户端任务。

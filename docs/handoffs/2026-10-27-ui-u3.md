## 板块配置与「以后加一个字段改哪一处」

配置 = `PERSONA_SECTIONS`：板块 → 子板块。板块命名对齐 Codex 后台角色管理（`apps/admin/src/components/legacy-card-editor.tsx` 的分区标题与 `persona-text-sections.ts` 的中文分段），不另起一套：

| 板块（id · 标题） | 子板块（有 field 的会在创建页出现） | 对应后台 |
|---|---|---|
| head · 头部 | 头像、名字、角色分类、年龄设定（userVisible=false，只后台显示）、标签 | 资料与头像 |
| about · 人物与性格 | **人设描述**；预留：外貌、经历 | 人设文本 › 人物与性格（核心人设） |
| speech · 说话方式 | **说话风格**、**口头禅**、**示例对话** | 人设文本 › 说话方式；词条与示例 › 对话示例 |
| attitude · 场景态度 | 预留：场景态度、边界处理（userVisible=false） | 人设文本 › 人设引擎 · 场景态度 |
| background · 背景与词条 | 预留：世界观 / 设定、公开资料条目 | 词条与示例 › 背景与触发词条 |
| relations · 关系 | 预留：认识的角色、与你的关系 | — |
| interaction · 互动风格 | 预留：朋友圈风格、群聊风格（userVisible=false） | 互动风格 |
| other · 其他 | **生日**、**音色**；预留：来源 / 改编 | 声音与微博 |

每个子板块的字段：`id`（稳定编号，也是 `?edit=` 参数）、`title`、`field`（草稿里的键，预留的不写）、`display`（给 U4 人设卡：avatar / identity / text / quotes / bubbles / tags / keyValue / entries / avatarStrip）、`userVisible`、`create`（写了才在创建页出现：`editor` 编辑器类型与参数、`required`）、`admin`（后台位置说明）、`legacyLabels`（平台预设角色人设原文里属于这里的中文分段标签，取自后台 `persona-text-sections.ts`，U4 人设卡分段用）。

**以后加一个字段：**

1. **字段已有接口来源、只是要在创建页 / 人设卡出现**（最常见）：只改 `persona-sections.ts` 一处——在对应板块的 `subsections` 里加一条（或给预留子板块补上 `field` 和 `create`）。编辑器选现有类型之一：`line`（单行）、`longText`（长文本，可设 `minLength`）、`list`（条目，`maxItems` / `itemMaxLength` / `summary: 'count' | 'join'`）、`dialogue`、`date`、`voice`、`basis`、`age`。创建页自动多一行、行摘要自动按类型生成、点进去就是对应编辑器、`required: true` 自动参与「创建角色」灰 / 绿判断。
2. **字段是新的（接口里还没有）**：先走契约变更申请（`packages/contracts` 的 `UserCustomCharacterWrite` / `UserCustomCharacterSummary`）。契约加好后，前端除第 1 步外再改 `custom-character.tsx` 三处接口映射：`PersonaDraft`（`persona-sections.ts` 顶部）加键、`EMPTY_DRAFT` 给默认值、读（编辑模式 `setDraft({...})`）和写（`submit` 的 `body`、`startTrial`、`saveImportDraft`）各带上这个键。
3. **需要一种全新的编辑方式**：在 `PersonaEditor` 联合类型加一种 `kind`，在 `persona-editors.tsx` 写一个 `SubPageLayer` 编辑页，在 `custom-character.tsx` 的 `renderEditor` 和 `summary` 各加一个分支。

## 遗留问题

1. **行标题「说话风格」**：任务卡写的是「说话方式 ›」，但后台把「说话方式」用作板块名、字段叫「说话风格」，按「命名与后台一致」用了后者（板块仍叫说话方式）。如总经理更想要「说话方式」，改 `persona-sections.ts` 里 `speechStyle` 的 `title` 一处即可。
2. **标签放在首屏那组**（名字、分类、年龄之后），因为 U4 把标签归在「头部」；任务卡的行顺序把标签列在示例对话之后。要挪只需把标签子板块移到别的板块。
3. **后台分段标签有两份**：`legacyLabels` 抄自 `apps/admin/src/components/persona-text-sections.ts` 的 `LABELS`（本批只能改 `apps/web`）。U4 把配置挪进 `packages/client-core` 时应让后台改为从那里引用，保持只一处定义。
4. **示例对话的存储格式没变**：仍是一段文字（接口 `exampleDialogue` 字符串），气泡编辑存成「我：… / TA：…」逐行。旧数据里没有「我：/ TA：」开头的行会接到上一句，开头就没前缀的算 TA 说；只有用户点了「完成」才会按新格式写回（不点不改原文）。服务器目前把整段当一条示例使用（`custom-card.ts`），本批没动。
5. **试聊按钮在必填没填好时变灰**（原来可以点，点了提示「请填写名字和至少50字的人设」）。长度类校验失败仍会给原提示。
6. 选填项没填时行右侧留空（只有必填显示「未填写」），符合 26 号 §4「空字段不写未填写」的方向；如果希望每行都提示，改 `summary` 即可。
7. 带 `?edit=` 的地址被直接刷新时，创建页草稿会丢（和原来刷新整页一样），编辑页会按地址直接打开对应二级页。
8. 音色二级页点一行会顺带试听（照提示音页）；库里没有样音的音色不显示喇叭。

## 给 U4 的交接

- **配置在 `apps/web/src/features/persona-sections.ts`**，U4 按任务卡挪到 `packages/client-core`（网页和后台共用）。挪的时候建议：
  - 把 `field`（草稿键）扩成「取值函数」：人设卡读的是角色摘要 / 广场快照 / 平台旧卡，和创建页草稿不是同一个形状；可保留 `field` 给创建页，另加 `get(source)` 给人设卡。
  - `display`、`userVisible` 已为每个子板块填好，人设卡按它渲染；空子板块（没有 `field`、或取值为空）整块不显示。
  - `legacyLabels` 给平台预设角色用：用后台的 `splitPersonaText` 把核心人设 / 说话风格 / 场景态度原文按标签切段，再按标签落到对应子板块（简介、性格、句式、场景态度…）；后台 `persona-text-sections.ts` 的标签表请改为从 client-core 引用。
  - `BASIS_OPTIONS[].word` 就是用户端「一句身份」要显示的一个词（原创 / 作品角色 / 真人）；真人类型、未成年、儿童外貌只在后台显示（`age` 子板块已是 `userVisible: false`）。
- **示例对话气泡**：`parseDialogue` 已能把「我：/ TA：」文本拆成气泡，人设卡的迷你聊天气泡可直接复用；样式可参照 `edit-pages.css` 里 `.dialogue-turn` 一段（左 TA 白、右我绿，令牌是 `--wb-color-bubble-other-*` / `--wb-color-bubble-self-*`）。

## 做了什么

实现说明见 `docs/android/plaza-l7.md`（随分支合入）。功能和取舍照搬网页 T-097：

1. **两个分页**：角色广场顶部「预设角色 | 人设广场」切换（新手引导时不显示，默认停在预设角色）。人设广场分页：搜索（角色名、标签、作者、基于的角色，命中预设名时类型标签高亮）、三种排序、两种筛选（类型选「预设改版」时分类禁用）、行高 88、「加载更多」、骨架 / 空 / 无结果 / 失败重试；右上「我发布的」红点。
2. **作品页**：头像、类型、介绍、改编自、作者（→ 作者页）、版本记录、发布说明、「你将得到的内容」（分类只读 +「之后只能改得更严格」，「▢」高亮）、评论区、底部操作栏；404 显示「这个作品已经看不到了」。
3. **点赞评论举报**：点赞乐观更新、失败回退；评论一层回复、超过 200 字禁用发送；没有广场昵称先去设置；被停权提示「你暂时不能评论」；作者关闭评论只显示一行；评论者 / 作者可删；举报四个原因 + 补充说明 0/200，重复举报提示，菜单变「已举报」。**没有私信、关注入口**，点评论者头像无反应。
4. **添加 / 应用**：自定义作品「添加为我的角色」；预设改版「添加为新角色」+「应用到我的 XX」/「添加 XX 并应用」；已添加过、通讯录满、替换补充设定确认都有。**添加后不调 `POST /contacts`**，只同步一次通讯录，按钮变「已添加 · 去聊天」。
5. **发布流程**：填写（介绍 ≤30、说明 ≤300、头像开关 +「我有权使用这张图片」、真人不发布头像、允许改编 / 开放评论；发布新版本要求更新说明 ≤100）→ 没有昵称先设置 → 检查中（超过 30 秒换文案）→ 确认页（「有 N 处可能是你的私人信息」、逐条改写 / 保留，保留二次确认「这不是我的私人信息」，未保留的「▢」遮盖，儿童特征警告，新版本分类放宽时禁用发布，「哪些内容不会发布」）。余额不足、检查失败、被拒都有提示。
6. **我发布的**：昵称行、停权提示、「作品 | 消息」，作品显示状态；消息拉取即已读，点赞 / 评论 / 回复可跳作品页。作品页自己视角「管理」：发布新版本、开关评论、下架 / 重新上架、删除（二次确认）。
7. **入口与来源标注**：聊天信息页「发布到人设广场」（只有自定义角色；「基于身边真人」或曾经是 → 禁用并写原因）；补充设定页「发布为改版」；复制来的角色资料页和应用了改版的补充设定页显示「来自人设广场 · 作者 XX · 版本 N ›」与「作者发布了新版本 ●」→ 新版本弹层（409 时「你对 TA 的修改会被覆盖」确认）。
8. **广场事件不发推送**：红点只靠 `getBadge` + `data.changed(plaza_badge)`，安卓没有为广场写任何通知代码。

## 遗留问题

1. **未编译**。L3～L7 安卓代码都还没编译过，需要一次构建统一修报错。
2. 和网页相同的契约缺口：作品不带来源角色 ID（发布新版本按名字 / 预设 ID 匹配，改过名会当成新作品；聊天信息入口也没显示「已发布 · 版本 N」）；作品页「更新到版本 N」没做；「我发布的」逐作品红点、管理员下架原因没显示。
3. **改写**用弹窗代替推入编辑页；「说话方式」和第 2 条以后的口头禅契约没有可写字段，提示到网页修改。
4. 安卓的 `ApiFailure` 不带服务器文字原因，被拒（403）时显示列举可能原因的固定文案，不是服务器的原话。
5. 「添加为我的角色」没有打招呼弹层（服务器自动加，同网页）；「余额不足」只提示到「我 › 服务 › 钱包」，没有直接跳转按钮。
6. 帧率、首屏未实测；广场头像用 OkHttp 直接加载公开 URL（内存缓存 64 张）。

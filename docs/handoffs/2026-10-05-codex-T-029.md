# T-029 接续：文本模型网关

活动分支：`dev/codex-product-continuation`，PR #3。开发自测，不是独立 QA 验收。

## 实现

- `MODEL_GATEWAY_PORT`：真实模型解析、账户与管理员身份核验、成人生成失败即拒绝、安全透支用途校验、估价冻结、调用、结算/失败解冻、缓存输入分拆和成本快照。
- OpenAI 兼容 HTTP 文本适配器：禁重定向，响应上限2MB，单次20秒/整体60秒截止，结构化错误分类；网络/429/5xx最多重试3次，2/5/15秒加抖动；同一冻结、同一供应商幂等请求键，不自动换模型。
- 独立 `generation_results` 缓存：用户 DEK 加密，只存24小时，注销登记删除；用量记录无正文。并发占位防重复；网络结果先保存再结算，结算中断可恢复，不再调用上游。进程在网络结果保存前崩溃时不重新发起不确定调用，90秒后维护任务解冻；冻结写入与attach之间极窄断点由既有过期冻结任务兜底。
- 每分钟恢复/回收任务，每5分钟免费 `GET /models` 恢复探测（只临时故障，最长24小时；失效密钥与额度由管理员处理）。
- 种子预览/导入命令，8个目录候选及草稿价格；不含密钥，不虚构排行榜，不启用未验证模型，不覆盖现有目录。缺映射先拒绝，走管理HTTP接口。
- 迁移0006及回滚脚本。

## 种子使用

`pnpm --filter @weiban/server models:seed` 只打印预览。实际导入设置 `MODEL_SEED_API_URL`、`MODEL_SEED_ADMIN_TOKEN_FILE`（管理员会话令牌文件）、`MODEL_SEED_UPSTREAM_IDS_FILE`（JSON，deepseek/bailian/openrouter对应已登记上游ID），再执行 `models:seed --apply`。加 `--activate` 才发布草稿。目录仍停用，完成供应商验证和角色边界评测后在后台启用并设置默认。

价格限制：原文已标若干价格未核实；DeepSeek 分时涉及法定节假日，现有 PriceTimeBand 无节假日表达，种子草稿先列高峰上界并写明说明。真正发布用于计费前应确认价格并补充节假日契约/日历，而不是把该草稿当作实价。

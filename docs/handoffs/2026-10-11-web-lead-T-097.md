## 做了什么

**网页（`apps/web/src/features/plaza.tsx`）**

1. **两个分页**：「发现 → 角色广场」顶部切换「预设角色 | 人设广场」（地址 `?tab=plaza`）；新手引导时不显示切换。人设广场分页：搜索（角色名、标签、作者、基于的角色，命中预设名时类型标签高亮）、排序三种（热门 / 最新发布 / 点赞最多）、筛选两种（类型；分类，类型选「预设改版」时分类禁用）。列表虚拟滚动、行高固定 88、「加载更多」；首次加载骨架、空、搜索无结果、失败重试四种状态。右上「我发布的」带红点（只靠 `getBadge` + `data.changed(plaza_badge)`，不推送）。
2. **作品页**：头像（预设改版用预设头像、无公开图用非肖像默认头像）、类型、介绍、改编自、作者（→ 作者页）、版本记录弹层、发布说明、「你将得到的内容」逐项预览（分类只读 +「之后只能改得更严格」，被遮盖的「▢」高亮）、评论区、底部操作栏。已下架 / 作者停权 / 注销（404）显示「这个作品已经看不到了」。
3. **点赞评论回复**：点赞乐观更新、失败回退 +「没成功，请重试」；评论只有一层回复，显示「回复 XX：…」；超过 200 字计数变红、发送按钮禁用；第一次评论没有广场昵称先去设置；被停权 Toast「你暂时不能评论」；作者关闭评论只显示「作者关闭了评论」；评论者 / 作者可删。**没有私信、关注入口**，点评论者头像无反应。
4. **举报**：作品「···」→ 举报、评论旁「举报」→ 举报页（四个原因 + 补充说明 0/200）；重复举报（409）提示「你已经举报过这个内容」，本次打开期间菜单变「已举报」。
5. **添加为我的角色 / 应用改版**：自定义作品「添加为我的角色」；预设改版「添加为新角色」+「应用到我的 XX」（未添加时「添加 XX 并应用」）。已添加过 → 「你已添加过这个角色 / 再添加一份」；通讯录满 → P-26 弹窗；已有补充设定（409）→「替换补充设定？」确认后带 `confirmReplaceSupplement=true` 重试。**按 T-088 交接，添加成功后不再调 `POST /contacts`**，只同步一次通讯录，按钮变「已添加 · 去聊天」。
6. **作者页**：只有头像、昵称和作品列表，没有任何其他信息和按钮。
7. **发布流程**（`/plaza/publish?characterId=` 或 `?presetId=`）：①填写发布信息（一句话介绍 ≤30、发布说明 ≤300、头像开关 +「我有权使用这张图片」、真人分类说明不发布头像、允许改编 / 开放评论；已发布过时预填上一版并要求更新说明 ≤100）→ 没有广场昵称先设置（提示「其他用户会看到你的广场昵称和头像」）→ 检查中（超过 30 秒换文案）→ ②发布内容确认：「有 N 处可能是你的私人信息，已先遮住」、每处一行（位置 + 前后文 + 类别）、「改写」（跳回角色编辑 / 补充设定，回来后重新生成草稿）、「保留」（二次确认「这不是我的私人信息」）；将要发布的内容逐项列出，未保留的片段以「▢」遮盖；儿童特征 + 已满 18 岁时显示警告；新版本分类放宽（422）时「发布」禁用并红字说明；「哪些内容不会发布」弹层按 PLZ-02 第 4 条列出。检查失败「检查没有完成，请稍后再试」+ 重试；余额不足「余额不足，暂时不能发布」+ 查看余额；被拒（403）显示服务器原因。
8. **我发布的**：广场昵称行（→ 修改昵称和头像）、停权提示、「作品 | 消息」两栏；作品行显示状态（展示中 / 已下架 / 被管理员下架）；消息拉取即已读，点赞 / 评论 / 回复可跳作品页。作品页自己视角「管理」：发布新版本、关闭 / 开启评论、下架 / 重新上架（被管理员下架的没有重新上架）、删除（二次确认）。
9. **入口与来源标注**：聊天信息页「发布到人设广场」（只有自定义角色；「基于身边真人」或曾经是 → 禁用并显示「以身边的人为原型的角色不能发布，这是为了保护 TA 的隐私」）；补充设定页底部「发布为改版」（有补充设定时）；复制来的角色资料页显示「来自人设广场 · 作者 XX · 版本 N ›」（作品不可用时不可点）和「作者发布了新版本 ●」→ 新版本弹层（更新说明、更新到新版本、暂不更新；409 时「你对 TA 的修改会被覆盖」确认）；应用了改版的补充设定页顶部同样的来源标注和新版本提示。

## 遗留问题

1. **作品不带「来源角色 ID」**：契约 `PlazaWorkDetail` 没有发布它的角色 ID。「发布新版本」预填和作品页「发布新版本」靠**按名字（自定义角色）/ 预设 ID（改版）匹配**我的作品，改过名字时会当成新作品；找不到时提示「请从这个角色的聊天信息发布新版本」。聊天信息入口也因此没显示「已发布 · 版本 N」。
2. **头像组放在第 1 步但看不到原图是否被允许**：只按资料页有无头像判断；勾选状态以 `avatarRightsConfirmed` 交给服务器。
3. **作品页「更新到版本 N」**（暂不更新后在作品页底部再更新）没做：作品页拿不到「我的复制品 ID」；更新入口在资料页 / 补充设定页。
4. **「我发布的」每个作品行的红点、管理员下架原因**没显示：契约用户端没有逐作品未读和 `removedReason`。
5. **后台「发布权限」没有「当前被停权用户列表」**：契约没有列表接口，只能按用户 ID 停 / 恢复。**举报详情里的作品**靠翻作品列表找（最多 20 页），契约没有按 ID 取单个作品的管理接口。
6. **后台行为规划**：没有「熔断中」状态、没有评测报告下拉（契约没有这两项数据），评测报告编号手填；模型标识手填（没有「可作规划模型」清单）。T-090 交接说明缺评测报告编号时实际返回 400，网页按服务器消息显示，不依赖状态码。
7. **每日一问**：契约没有「被分到的次数」，表格不显示该列；关键词和状态筛选在网页本地做（只筛已加载的页）。
8. 宽屏（≥900px）左右分栏没做，仍是单栏。评论输入是区内输入框，不是固定底部输入栏。
9. 帧率与首屏未实测（本轮不测）。

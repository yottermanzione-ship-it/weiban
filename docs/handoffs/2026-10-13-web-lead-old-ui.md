## 遗留问题

- **未写、未跑任何测试，也没在浏览器里逐页看过**（总经理裁定）。`apps/web/test` 里的 Playwright 用例大量依赖旧文案和旧结构（如「余额」「‹ 返回」、`<details>` 消息菜单、主题按钮），会失败，需要 Codex 验收时按新界面更新或标记。帧率与首屏性能本次没测（未记录到 `docs/web/`）。
- 「小改」类页面（卡册、成就、宠物、玩法、经期、导入、人设广场、TA 记得的事 / 近况 / 关系、补充设定、自定义角色、收藏、搜索、公告等）这次主要靠全局样式换成旧版外观（灰底白卡通栏、旧版按钮 / 开关 / 顶栏、旧版图标），**页面结构没有逐个按 5.2 重排**；需要的话再开一个任务逐页细化。
- 情景预设弹层「自动」一行下方「现在：偏向倾听」没做（接口没有当前自动结果）；群聊顶部「XX 提到了你」横条没做（会话预览没有 @ 信息）；会话列表「@我」标签同理没做。
- 星标朋友契约里没有字段，先存本机（不跨设备）；提示音选择、深色模式、字体大小也存本机。
- 「转发」「名片」「聊天背景」没有对应功能，按钮保留并提示「暂未开放」。
- 积分明细里点一条消息只能进入会话，不能定位到那条（摘要接口没返回 seq）。
- 后台模型向导「约每条 X 积分」不能实时预估（估算方法在服务器），显示当前值并在保存后由服务器重算。
- 后台添加上游账号时**不预填接口地址**：工程规范 R4（eslint `weiban/exclusive-sdk`）禁止 model-access 以外出现服务商域名，和 06 第 9.4 节「选好自动填接口地址」冲突，按规范处理。
- 后台账户列表「处理中」用 `heldMicros ÷ 10,000` 显示（`AdminAccountSummary` 没有 `heldPoints` 字段）。
- 网页通知提示音只有 ogg（iPhone Safari 试听不了），来电铃声仍用回铃代替（设计交接里已记）。

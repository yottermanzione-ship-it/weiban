# 语音/搜索/JEV 计费与百炼接入计划（2026-10-24）

## 计费换算规则（建议，待确认后执行）

系统既有口径：**1 积分 = 0.01 元 = 10,000 微元**（`MICROS_PER_POINT`）。
所以「供应商成本 → 积分」= 成本(元) ÷ 0.01，再加 30% 毛利，最后四舍五入到 0.01 积分：

> 售价积分 = 成本(元) × 1.3 ÷ 0.01，保留两位小数

| 项目 | 成本依据 | 售价（积分） | 折合 |
|---|---|---|---|
| 语音消息 TTS（MiMo） | MiMo 现为限时免费；取百炼公开价 1.4 元/万字符 | **182 积分/万字符** | 0.0182 积分/字 |
| 语音消息 TTS（百炼） | 百炼官方 1.4 元/万字符 | **182 积分/万字符** | 同上 |
| 语音识别 ASR | MiMo 0.5 元/小时（约 0.008333 元/分）；硅基现为免费 | **1.08 积分/分钟** | — |
| 联网搜索 | DeepSeek 官方 5 元/千次 = 0.005 元/次 | **0.65 积分/次** | — |
| JEV 决策（行为规划） | 按该模型的输入/输出 token 价 | 沿用 token 单价 | 每次约 0.1–0.5 积分（按实际 token） |
| 语音通话 | ASR 分钟 + 文字 token + TTS 字符 | 三项相加 | 不另收“通话费” |

说明：MiMo TTS 与硅基 ASR 当前促销免费，若按字面成本会算成 0 积分；上表用**同类付费供应商公开价**做成本基数，避免免费被刷，也方便促销结束后不用改价。

## 倍率（展示倍率）

用户能在场景里选到的每个模型都要有 `displayMultiplier`（展示倍率，只影响显示、不参与扣费）。当前语音/通话三个新模型的倍率为空，需要补齐；同时检查用户可选的聊天/私密模型是否都有值。

## 实现

- 共享片段的角色发帖/评论订阅者先拿 ai-runtime 用户锁，调用可见性端口时传原事务，动态/评论及加密读取使用同一事务，保留联系人及部分可见限制。
- 来电结束事件只在收件箱事务内投递 `ai.follow_up_call`，任务数据仅用户/通话 ID；重新通过 calls 端口读取所属通话，事务外等待模型。原消息幂等键保留；主动来电仍停用。
- 后台搜索实体按修改时间/键游标分页，保留微秒精度、限制每页 1–50 条并绑定原搜索词；页面提供前后翻页、重试，搜索或修改后回第一页。
- 角色卡新增可选 L6，旧卡不改写，六阶段亮暗色同步到网页和安卓共享令牌。契约 6.1，无新迁移，保留 6.x 实时连接兼容。编辑新字段前需刷新旧网页/后台。

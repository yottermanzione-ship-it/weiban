## 改动与边界

私聊原先把当前记忆/总结、自述、共同经历和日期放在聊天记录前；这些内容更新后，后面的旧聊天也无法沿用相同前缀。现在仍逐轮读取相同内容，但放在历史之后；默认风格提示也移到末尾。作者手动设置的角色笔记位置保留，私密/日常隔离、图片与总结处理不减。

手动更正、删除记忆继续清除可能包含旧事实的模型输入历史，必要的缓存失效必须保留。没有冻结日期、延迟记忆更新、减少记忆权益或新增付费预热。其他场景共享的完整角色文本不变。

售价、成本、折扣及记账不改；延续官方模型价、固定私密同 Astra、小V基础客服免费。历史多扣 0.1145 积分依总经理决定仅保留记录，不退款。

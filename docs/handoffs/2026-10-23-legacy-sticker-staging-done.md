# 旧内置表情搬入新服务器私有暂存区（已完成搬运，未上架）

> 这次只做到「旧项目内置静态表情 → 新服务器私有暂存目录」。**没有注册进数据库、没有开放 HTTP、没有上架到表情商店，也没有把它算成 v2fy 素材扩充。**

## 搬了什么、没搬什么

- 来源：旧项目 `server/public/stickers/builtin/` 的 **213 个内置静态文件**（16 个自绘 SVG、53 个 Operit、144 个 ChineseBQB），共 30,245,986 字节、206 个不同 SHA256。
- 不包含：任何用户上传、私聊图片、角色私有图库、账号或密钥；也不包含需要联网下载的新素材（外网下载仍为 0 字节）。
- 权利状态没有变化：这些是旧项目既有文件，**不代表已核实版权**，也不代表可以公开分发；本次只是把它们放进只能由 root 访问的私有目录，等后续人工确认授权与用途。

## 存放位置与校验

- 服务器目录：`/srv/weiban/import-staging/builtin-2c5632e-20261023`，权限 `700`，含 `builtin/`、`manifest.json`（逐文件大小与 SHA256）、`receipt.json`。
- 独立复核：目录内共 215 个文件（213 个表情 + 清单 + 回执）、0 个符号链接、合计 30,280,840 字节，与清单一致。
- 回执声明：`served=false`、`registeredInDatabase=false`，范围写明「仅内置表情，无用户上传、无密钥、不是图库」。

## 传输过程（为什么之前失败）

- 前两次失败是**大文件通道**问题：30 MB 单文件 `scp` 断管；退到 4 MB 分片后仍在第 2 片被服务器关闭连接；改用 base64 文本管道时 `base64` 直接报无效输入，输出为空。都不是权限或校验逻辑的问题。
- 最终采用 **1 MB 二进制分片 + 每片 SHA256 双向核对 + 失败仅重试一次**：29 片一次全部通过，服务器端合并后整包 SHA256 与本地一致（`01c0239d…efa35`，30,117,265 字节），再交给原有的严格校验脚本逐文件核对后才落盘。
- 每片都是先查服务器上已有分片的哈希再决定是否重传，天然支持断点续传，不会盲目重复上传。

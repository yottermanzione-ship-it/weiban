# 后台用户详情重置密码

## 范围与使用

总经理要求在后台自行处理普通用户忘记密码。入口：用户 → 用户列表 → 用户详情 → 基本资料 → 重置密码。弹窗显示目标昵称和登录名，两次输入一致才提交；密码规则沿用现有新密码规则，8～128位并拒绝常见弱密码。管理员账号继续使用原运维恢复入口。

后台调用新增管理接口；事务内复核操作者管理身份，按详情绑定的用户编号更新散列、退出旧会话、清除账号全部关联登录名锁定。原封禁、会员、积分及其他资料不变。审计记录操作者、目标和退出会话数，不含密码；弹窗不使用本地草稿，关闭或成功后清空。

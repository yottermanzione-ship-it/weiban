## 做了什么

### 第一批（P0）

1. **发现页改成菜单列表**：朋友圈 ｜ 角色广场 · 视频号* · 直播* ｜ 扫一扫* · 听书* ｜ 看一看* · 搜一搜 ｜ 游戏* · 小程序（* = 暂未开放）。原内嵌的角色广场变成二级页 `/discover/plaza`（去掉「人设广场」分页，底部「看看大家创作的角色」进人设广场小程序）。首次引导仍用 `/discover?onboarding=1`。
2. **「暂未开放」统一页** `/coming-soon/:feature`：入口全部登记在 `features/shell-kit.tsx` 的 `comingSoon` 表（视频号、直播、扫一扫、听书、看一看、游戏、二维码名片、卡包、收付款、状态、标签、公众号、青少年模式、关怀模式、插件、发送名片等）。
3. **通讯录**：标题栏右上「添加角色」；搜索就地过滤；顶部固定行 新的朋友 / 新建角色 / 群聊 / 角色广场 / 标签* / 公众号*；字母分组（拼音首字母，用浏览器中文排序，不引第三方库）+ 底部「N 个角色」。**新建角色**弹层三选一：自己写一个 TA → 编辑器；从聊天记录生成 TA → 导入角色；去人设广场挑一个 → 人设广场。
4. **聊天信息页**：新增「聊天模型 › TA 用的模型」（值：跟随默认 / 模型名）→ 新页 `/characters/:id/model`（接口 `model/character-overrides`）；删掉情景模式、我们的宠物、心愿清单三行。
5. **情景预设**：私聊 / 群聊「+」面板格子 + 私聊标题下副标题（日常聊天不显示，「自动」显示自动，成人显示「私密」，对方输入时显示「对方正在输入…」）打开同一个弹层。弹层按 listModes 顺序：「自动」通栏卡、其余两列卡片（推荐角标、选中绿框 ✓）、底部单独「私密」一栏（只有服务器返回 `section = private` 才出现）。私密：没选成人模式模型 → 提示「去选择」；第一次开启弹说明对话框（本机记住）。群聊信息页的情景模式下拉删除。系统提示文案改为「已切换到 树洞分享」等新名字。
6. **宠物**：第一次打开先看引导页（一屏三行说明 + 开始领养；没有角色时按钮变「先去添加一个 TA」）；领养合成一页（预览卡 → ① 和谁一起养（已有宠物的 TA 不出现）→ ② 物种 × 外观摊平三列宫格 + 长大后三阶段 → ③ 起名 / 让 TA 起名 → 底部固定按钮提示还差哪步）；物种加载失败显示「加载失败 + 重试」，去掉「暂时没有可以领养」死路；领养后宠物主页一次性新手提示。按 TA 入口 `/pets/with/:characterId`（有宠物去主页，没有去领养且 TA 已选好）。
7. **修复「手动隐藏群聊后打不开」**：隐藏 ≠ 已退群。群聊页、群聊信息页不再把 `state.hidden` 当成已解散；「通讯录 › 群聊」列表也列出隐藏的群。群解散时服务器发 `conversation.removed`，本地会话直接删除，所以「不存在」才提示已解散。
8. **会话列表**：标题栏右上 ⊕ 气泡菜单（发起群聊 / 添加角色 / 新建角色 / 导入角色 / 扫一扫* / 收付款*）；长按（触屏 500ms）或右键会话 → 置顶 / 标为未读 / 消息免打扰 / 不显示该聊天（`PATCH state { hidden }`）。
9. **公告与本版新功能**：打开应用、回到前台时拉取；弹窗依次：必须更新（不可关闭，「刷新」）→ 本版新功能（关闭时 `release-notes/seen`）→ 未读弹窗公告（从旧到新，关闭即已读）。未读红点：底部「我」→「设置」→「关于微伴」→「公告」。新页：`/settings/about`（版本、构建号、公告、更新日志、检查更新）、`/settings/announcements`（进入即全部已读）、`/settings/release-notes`。
10. **网页构建号**：`vite.config.ts` 每次打包注入 `__WEB_BUILD__` = 2026-01-01 起的分钟数（单调递增；部署可用环境变量 `WEB_BUILD_NUMBER` 覆盖），打包日志打印、产物里多一个 `build-info.json`，「关于微伴」显示。版本检查和更新说明用它当 `versionCode`。
11. **管理后台**：新增「公告管理」（新建 / 存草稿 / 发布 / 编辑（可选重新提醒所有人）/ 撤回 / 删除）、「更新说明」（按平台筛选，增删改、草稿）、「版本策略」（网页 / 安卓各一张表单：最新版本、版本号、安卓下载地址、最低可用版本号、强制更新说明）。

### 第二批（P1）

1. **小程序外壳**：11 个小程序（卡册、成就、宠物、每日一问、心愿清单、慢信、陪你专注、TA 的提醒、经期日记、人设广场、导入角色）的现有页面统一套进外壳：右上胶囊「··· | ◯」，从底部升起（transform 动画），不显示标签栏。◯ 按浏览器历史一步退回打开小程序之前的页面（会话列表、私聊、发现…）；直接打开链接时回发现页。··· 菜单：添加到 / 移出我的小程序、不在 / 在最近使用中显示、关于这个小程序（一句话 + 用到的数据）、重新进入。「发给 TA」按方案 P3 不显示。登记表在 `features/miniapps.tsx`。
2. **发现 › 小程序主页** `/miniapps`：搜索、最近使用（最多 8 个，本机记录）、我的小程序宫格（默认 11 个；移出的放「更多小程序」）。**经期日记默认不进最近使用**，可在它的 ··· 里打开。
3. **我 › 服务瘦身**：钱包卡（余额、聊天模型）+「模型与花费」（余额明细、价目表、模型排行榜、花费统计）+「偏好」（主动消息与免打扰、熟悉度总览）；卡册 / 成就 / 宠物 / 玩法 / 经期日记搬进小程序（卡册、成就的新红点改挂在「发现 › 小程序」行）。
4. **聊天信息「和 TA 一起用」**一行小程序图标；**聊天「+」面板 › 小程序**半屏「和 TA 一起用」（只列按 TA 的 6 个，当前 TA 已选好）。
5. **「+」面板**改成每页 4×2、左右滑动翻页 + 分页圆点：私聊 相册 · 拍摄 · 语音通话 · 情景预设 / 写信 · 陪我专注 · 提醒 · 小程序 ｜ 心愿 · 名片*；群聊 相册 · 拍摄 · 情景预设 · 名片*。情景预设格子在非日常 / 非自动时带小红点。「提醒」新建页支持 `?characterId=` 预选 TA。
6. **我 / 设置**换成菜单列表：我页头部（头像、昵称、微伴号、「+ 状态」*、二维码*）、服务 ｜ 收藏 · 朋友圈 · 视频号* · 卡包* · 表情 ｜ 设置；设置：账号与安全 ｜ 青少年模式* · 关怀模式* ｜ 主动消息与免打扰 · 隐私 · 通用 ｜ 推送 ｜ 关于微伴 · 插件* ｜ 退出登录。
7. 通用部件 `features/shell-kit.tsx`：统一标题栏 `NavBar`（返回走浏览器历史）、菜单行 `MenuRow` + 图标方块、底部弹层 `Sheet`、气泡菜单 `PopMenu`。通用顶栏的「返回」也改走历史。样式全部在 `app/shell.css`，只用设计令牌，动画只用 transform / opacity，并尊重「减少动态效果」。

## 遗留问题

- **没有测试、没有实机看过页面**（按授权）。交 Codex 验收时重点看：小程序 ◯ 回退层数（含小程序内 replace 跳转）、下拉手势在中低端安卓 WebView 是否 60 帧、长按会话与系统长按菜单冲突、情景预设私密栏的资格与首次说明、隐藏群聊能打开、公告弹窗只弹一次、`whatsNew` 关闭后不再弹。
- 现有 Playwright 用例里依赖旧文案 / 旧结构的会失败（例如发现页直接是角色列表、「聊天信息」文字链接、服务页宫格、情景模式下拉、三步领养）。需要更新用例时由 Web 或 Codex 处理。
- 「自动」卡片下「现在：偏向倾听」需要接口返回当前判断（AI 交接已说明需契约变更），本批没做。
- 会话长按菜单没有做「删除该聊天」（需要清空记录 + 隐藏两步并有确认框，下批补）。
- 小程序宫格的长按整理（拖动排序）、最近使用长按移出没做；首版「我的小程序」只能在 ··· 里添加 / 移出。最近使用只存本机，不跨设备（方案第 11 节第 6 条待架构评估）。
- 宽屏（≥ 900px）小程序在右侧详情栏打开没做，仍是整页。
- 「名片」格子暂指向「暂未开放」：用户发名片不在 `UserSendableContent` 里，需要接口变更申请。
- 角色资料页的其余换壳细节（「认识第 N 天」行位、简介与作品等）不在本次范围，未改。
- 帧率与首屏性能检查按授权未做，`docs/web/` 未新增记录。

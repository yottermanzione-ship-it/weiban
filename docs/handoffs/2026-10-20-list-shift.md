# 交接：会话列表整体上移 / 分隔线断开 / 摘要「[消息]」（2026-10-20，web）

分支：`list-shift`（基于 local/trunk，未推送、未合入）。只改了 apps/web，没有改后端和契约。

## 1. 「微伴」标题栏偶尔被吃掉（整页上移）

**原因（已复现）**：有标签栏的页面，外壳 `.app-shell.with-tabs` 给标签栏留了一次底边距（57px），会话列表页 `.chat-list-page`
自己又留了一次，结果整页比屏幕高 57 像素，窗口可以被滚动 57 像素。会话列表的标题栏不是吸顶的，所以只要窗口被推一下
（电脑上在标题栏 / 搜索条上滚鼠标滚轮，手机上在标题栏上往上推、键盘 PageDown / 空格、浏览器滚动恢复等），
整页上移 57 像素，标题栏「微伴」正好全部移出屏幕，搜索框顶到最上面。其他标签页的顶栏是 `position: sticky`，
窗口滚了标题也还在，所以只有「微伴」页能看出来。总经理说的「顶部色块不同」也是这一现象：上移后顶部露出的是搜索条区域，
不再是标题栏。改后对比了通讯录页的顶栏与背景色（浅色、深色两套），颜色一致。

**改法**：
- `shell.css`：`.app-shell.with-tabs:has(.chat-list-page) { padding-bottom: 0 }`，会话列表页不再比屏幕高；
- `.chat-list-page`、`.pull-list.lifted` 由 `overflow: hidden` 改为 `overflow: clip`（保留 hidden 作旧浏览器回退）——
  clip 不是滚动容器，焦点移动、scrollIntoView 都没法把它们「滚」走（hidden 仍能被程序滚动；下拉小程序打开时列表
  被 transform 推下去，容器可滚范围会变大，是另一个潜在触发口）；
- `conversation-list.tsx` 新增 `usePinnedTop` 兜底：进入页面时窗口与页面容器复位到 0；之后窗口、`main`、`.pull-list`
  一旦出现滚动立即归零（列表自身 `.virtual-list` 和小程序宫格不受影响）。覆盖不支持 `:has` 的旧浏览器、离线横条撑高页面等情况。
- 下拉小程序的手势、弹簧动画代码没有动；收起后 transform 本来就会清空（实测收起后 `style.transform` 为空）。

## 2. 分隔线「断成两截」

**原因**：不是分隔线本身，是每行左滑后才出现的「标为未读 / 不显示 / 删除」按钮一直垫在行底下。电脑浏览器缩放（110% / 125% / 150%）
时行高和位移是小数像素，前景行边缘露出按钮的一丝颜色，看起来像错位的线。手机整数像素对齐，看不出来。

**改法**（`shell.css`）：前景行没有位移时按钮 `visibility: hidden`；一开始左滑（手势脚本给前景行写 `translateX`）立即显示；
收起时延迟到 180ms 收起过渡结束后才隐藏，按钮不会提前消失。用 `@supports selector(:has(a))` 包住，旧浏览器保持原样。
手机左滑手感、按钮点击都没变（实测：滑开 → 按钮可见；点别处收起 → 过渡中仍可见 → 结束后隐藏）。

## 3. 会话摘要显示「[消息]」

**原因**：服务器生成会话摘要（`apps/server/src/modules/chat/application/store.ts` 的 `conversation()`）时，
图片、语音、表情、链接、通话记录、信件、每日一问、卡片、转发聊天记录等一律给「[消息]」；成人范围的消息
（`read.ts` / `groups.ts`）也改成「[消息]」。网页原样显示。

**改法**（只改网页）：`conversation-list.tsx` 新增 `listPreview()`：优先用本机已同步的那条最后消息自己生成摘要——
文字显示正文；[图片] [语音] [动画表情] [链接] 标题 [名片] 名字 [语音通话] [信件] [每日一问] 题目 [聊天记录]；卡片显示卡片文字；
不认识的新类型显示「[当前版本不支持此消息]」。撤回、系统提示、拍一拍沿用服务器给的文字。本机恰好没有那条消息时，
不显示「[消息]」而是留空（有消息的会话不再误显示「开始聊天吧」）。全量同步快照里带每个会话的最近消息，正常情况都能命中。

### 给安卓：照做的用户端清单

1. W1：图片消息 `sizeBytes` 为空或 < 1 MB 才显示「添加到表情」。
2. W3：会话内查找——日期用 `locateByDate`，图片 / 链接用 `listByType`；群聊搜索可按发送者 `senderParticipantId` 过滤。
3. W4：收藏卡片优先显示 `characterNameSnapshot` / `characterAvatarMediaIdSnapshot`；有 `seq` 时直接跳到会话对应位置。
4. W5：`ApiFailure` 保留 `details` 与服务器文字原因；分享被拒时按 `ShareRejectedDetails` 逐条提示。
5. W7：导入完成页「继续导入下一批」（建任务带 `mergeIntoJobId`；任务带 `mergedIntoJobId` 时跳到目标任务）；编辑器「保存草稿」调 `saveResultDraft`；确认页显示 `conflicts` 与「`filteredCount` 条不会生效」；`visionAvailable = false` 时截图入口置灰并说明。
6. W8：收到 `data.changed`（`section = supplement`，同角色）时刷新补充设定页。
7. W9 用户端：发布新版本按 `sourceCharacterId` 找本地角色；聊天信息显示「已发布 · 版本 N · 发布新版本」；作品页按 `myAdoptedCharacterId` 显示「已添加 · 去聊天」，复制品 `newerVersionAvailable` 时显示「更新到版本 N」；「我发布的」按 `unreadCount` 显示红点，有 `removedReason` 时显示下架原因。
8. W10：自定义角色编辑器支持多行口头禅（最多 10 条、每条 ≤ 50 字）与说话方式；「改写」要覆盖说话方式与全部口头禅。
9. W11：按 code 渲染 `focus_started`、`letter_sent`、`wishlist_item_completed` 三种系统提示；寄信后按 `replyDelayReason` 显示说明，删掉本地推断。
10. 另：推送 `kind = import` 路由到 `/imports/{jobId}`。

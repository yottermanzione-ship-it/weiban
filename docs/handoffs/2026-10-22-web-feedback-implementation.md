## 已实施

1. **充值/积分流水**：服务页删独立充值行，积分页充值保留。聊天消耗按日、角色/类别汇总为不可跳转流水，移除逐消息二级页、展开状态和额外 charged-messages 批量请求；其他积分流水仍保留。
2. **模型配置/榜单**：文本聊天只有排行榜/热门榜，不再重复「全部可选模型」。所有符合现行场景/权限的已配置模型进入唯一列表；无匹配写「暂无排名」，旧手填名次不再兜底。权限过滤后连续编号，搜索不改变名次，支持名称/开发商搜索与正反排序；热门榜含零人选用并保留人数。旧排行榜入口直接进入该榜单页。
3. **官方 Arena**：固定 Dataset Viewer 的 `text_style_control/latest`；顺序分页完整获取后才筛 `overall`。原始名字、原榜名次、厂商、评分、上下区间、票数、官方发布日期、抓取时间/来源保存在现有 settings 快照，不导入 Arena 模型目录。只按已配置模型的榜单对应名称精确匹配；只移除明确思考程度/同组思考预算，取最好名次，保留版本日期、Pro/Flash 等区别。上一份有效快照可比较时展示相对升降，跨手工/自动来源不虚构升降。
4. **同步可靠性**：六小时 cron；单页 20 秒、整体 8 分钟、顺序分页 2.5 秒间隔；检查 partial、总数稳定、行号、字段截断、重复原名、评分区间、日期及 revision。429 尊重 Retry-After（最多 60 秒、最多两次）；502/503/504 仅两次 2/5 秒退避，所有重试仍受总时限。进程内合并刷新，数据库咨询锁防多实例/导入争用，60 秒冷却；失败保留完整最近有效数据及历史，仅记录失败原因。手动刷新进持久任务队列，后台轮询，避免分页超过 HTTP 20 秒限制。
5. **分享图片而非生图**：用户和角色场景配置、后台推荐入口移除 image_generation，后端不再读取旧选择并拒绝新的用户/角色生图选择。角色图片服务不再调用 generateImage 或收费人脸复检；保留自主表情规划、指定库子集与频控。明确分享动作可搜索固定公开主题，再复用既有安全网页封面抓取、媒体校验/转码和本人 chat_image 转存，用真实 mediaId 走原发送事务；附文字出处，不发送外链假图或自称自拍。搜索实际费用回报至回复/生态统计及主动消息积分展示，含已付搜索但无图、发送失败、写失败标记异常路径；不是再次扣款。
6. **首页下拉**：标题/搜索/列表同层整体下移。140px 位移阈值前仅连续浅灰背景，不提前显示深色面板；达到阈值从 viewport 最顶部显示小程序。阻尼由 0.7 降为 0.42，取消不足距离靠速度打开的捷径。保留回弹、打开、Esc/上滑收起，取消手势恢复原状态，列表未到顶不接管。安全区高度并入标题层。

图片范围限制：仅固定公开主题（猫、狗、花卉、森林、海滩、天空日落、自然风景、咖啡、甜点）的搜索网页封面，不是任意互联网图片索引；真人/历史角色、卡片/宠物/朋友圈及旧日常配图只用合规库图。搜索仍走现有 web_search 正常计费，不等于免费。没有合规素材就不发，不承诺图片版权或完整图像内容审核。用户上传图片的识图/描述/P3 公开作品检索未删除；同时补了旧 P3 对可选 labels 的安全读取。

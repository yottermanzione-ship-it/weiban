## 实现

- 契约 3.31、迁移 0132 / down：显式微博昵称与 HTTPS 头像标记（可选作者 ID），生态工具 `weibo_sync`，公开记录来源、共享搜索和内部结算 / 发布端口。管理端实际表单支持填写、错误定位与清空标记；Android 契约由源 schema 生成。
- 生态在原唤醒中按资格提供同步工具。预置、已发布、非私人真人且有显式标记的角色才可用；参与人须已有联系人、开生态、满足会员 / 余额 / 额度。角色互斥租约至少间隔 1 小时，每北京时间日最多 8 次新请求；不是每日定时抓微博。
- 只保存最近 7 天公开结果中的原摘要和出处；接受 HTTPS 微博帖子 URL、真实日历日期、作者标题或已知 ID 匹配。拒绝无日期、身份不明、私生活 / 健康 / 行踪 / 注入指令结果，不生成第一人称微博。URL 和内容指纹双重去重；被撤下的公开记录不自动复活。该过滤不等于已人工核实或完整政策检测，界面明示来源待人工核实。
- 近期公开资料与各合资格用户私人朋友圈在同一事务写入；送达前再次锁定联系人 epoch、核验封禁、总开关 / 动作 / 角色开关。删除再添加不能接受旧任务。普通搜索公开动态仍走原人工审核流程，未改为全部自动发布。
- 原网关产生唯一供应商用量和平台成本记录。调用前固定有额度的参与名单并计入 H1 并发；成功后按原人数分摊实际售价，小于 0.01 积分的余数累积，达到门槛后按 0.01 积分四舍五入，保留正负尾差。用户支出、日累计、平台回收及结算状态同事务，支持已授权 H1 后付费；注销 / 缺失份额留在平台，不转嫁剩余用户。
- 免费缓存命中不追收旧调用费用；失败不收费，未知结果和超时授权不追扣。公开结果回执先持久化，结算 / 送达可用原 key 恢复。两分钟恢复任务仅处理已有 pending 记录，不创建新的同步决定。无新帖子按 idle 登记，生态运行只计本人的实际份额。
- 没有新增依赖、供应商协议、用户扣款 HTTP 或测试套件。财务表及身份关联清理已配套，down 遇已结算资金 / 尾差 / 公开记录拒绝破坏性回滚。

# 2026-11-19 后台管理发布交接

本次后台候选从线上与 GitHub 主线的共同基线 `28ebee239429c1e482f30aa8b0eef4e5255ae59f` 开出。11 月 18 日的两个开发提交以原分支保存在 GitHub。签到广告、聊天生成、主动消息和角色记忆分别留在开发分支。

## 用户、角色与工作台

用户目录按页取账户摘要与当页钱包。角色目录按页取预览字段和缩略图，打开角色时再读取角色卡。用户列表的七天到期人数通过计数查询取得。后台菜单的举报和注销角标也只请求数量，避免每次刷新菜单时下载举报详情和逐账号注销进度。

在本机合成数据的生产构建预览中，三个首屏各发一次列表请求。用户返回 15/15 条，角色返回 20/33 条，模型返回 20/22 条。点击行后各取一条详情。上游账号列表在打开某个账号后才查询其关联模型。角色列实测可从 260 调到 320 像素，分类列从 100 调到 80 像素，行高从 59 调到 51 像素。390 像素视窗可在表格内部横向滚动。

## 模型的删除与历史

管理目录提供可操作的模型。删除模型时，在同一事务清理当前路由、用户和角色的选择、平台推荐、当前价格与折扣等引用。账号由独立的上游账号管理入口维护。模型删除不会触碰上游凭据。已经发生的调用、费用、账本关联及历史价格版本继续可供对账。旧编辑页带修订条件，防止覆盖同键新建的模型。

本机专用 PostgreSQL 回归覆盖独用和共享账号、密钥保留、旧编辑冲突、无效路由的价格回滚、两次删除并重建后用量与费用快照一致。Arena 回归覆盖进入文本榜的聊天模型、同名非聊天模型和已下架模型。

固定、推荐、平台内部和生态决策模型的配置写入与目录删除共用数据库锁。专库并发用例在删除提交后拒绝保存旧模型，同时保留生态配置其他字段。

## 用量提醒与榜单同步

文字调用成功交付但缺少供应商用量时，才累计缺回执。失败调用的估算成本仍可对账。按本地合成字数计量的语音调用单独展示。多个目录共用一条上游线路时分别计算，按历史提醒的账号 ID 解析当前名称。搜索不到账号时可以清空筛选。

迁移 `0166_correct_network_usage_streaks` 仅在同一账号和上游型号下的全部留存尝试均为该模型已完成的网络错误估算、且笔数与连续计数完全相等时修正。未知回执、相邻模型的调用或混合失败都会保留原计数。回退读取修正前的快照，在配置未变化、当前计数仍为零且未发现留存的新尝试时恢复。若用户注销已清除尝试，迟延回退可能重新显示旧计数。历史提醒、用量和账务均保留。

Arena 文本榜只匹配启用且开放聊天场景的模型。官方源版本变化时完成全页校验后再替换。相同官方提交和总行数可以复用已完整验证的快照。后台分别显示数据日期和最近检查结果。本地实际读取官方数据 112 页、11,177 行，解析出 421 个 Overall 条目，第二次检查复用同一版本。

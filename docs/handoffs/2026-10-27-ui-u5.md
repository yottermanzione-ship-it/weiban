### 前批遗留

1. **#20 收藏看图、#17 聊天记录卡片（U2 遗留 1）**：新增通用全屏看图 `Lightbox`（黑底、左右滑切换、双指缩放 / 双击放大、下滑关闭且跟手、单击关闭、右上「…」动作）。聊天看图 `ImageViewer` 改为它的一层包装（原有保存 / 收藏 / 添加到表情 / 删除动作不变）；收藏里的图片从底部弹层改为 Lightbox（同一条收藏的多张图可左右切）；聊天记录卡片从「全屏底部面板」改为整页推入的只读页 `PushLayer`，记录里的图片同样用 Lightbox。两者挂到 body 上，不会被聊天顶部的「TA 的动态」浮条压住（第一次截图就发现了这个层级问题，已修）。
2. **#26 朋友圈评论（U2 遗留 2）**：半屏面板改成贴键盘输入条 `KeyboardBar`：底部一条输入栏贴在键盘上方（iOS 按 visualViewport 抬起），输入框随内容长高（最多约 4 行）；点输入条以外的地方收起键盘和输入条，**草稿保留**，再点同一条评论接着写，换了回复对象才清空。
3. **首次填写资料的「地区」（U2 遗留 3）**：不再是 30 多项的单列滚轮，改为和「我 › 个人信息 › 地区」同一套页面（定位 + 中国大陆 / 港澳台 / 亚洲…分组，点分组再进一层）。因为首次填写时表单还没保存，这两层做成页内二级页面、选完把地区交回表单（不直接写服务器）；有已选地区时多一行「不填写地区」。定位逻辑抽成 `useRegionLocate()` 两处共用，资料页地区页行为不变。
4. **二级页面进浏览器历史（U2 遗留 4，U3 已对创建页做过）**：新增 `useLayerHistory`，推广到全站所有 `SubPageLayer`（记忆、心愿、纪念日、补充设定、提示音、群聊名称、积分提醒线、申请添加朋友、音色等）以及新的 `PushLayer`、`Lightbox`：打开时往历史压一条同地址记录，安卓返回键 / 浏览器后退只关最上面一层（等同「取消」）；用界面按钮关掉时自动退掉那条记录，历史里不留空步；同一拍关掉多层（如地区分组选完连上一层一起关）合并成一次后退。自建角色创建页已自己用 `?edit=` 管理，用 `LayerHistoryContext` 关掉以免压两次。路由型 `SubPage` 本来就是独立路由，不用改。
5. **作品详情评论区框套框、点赞弹性动画归类（U4 交接）**：见上表「去硬边框」④ 与「动效分性格」。
6. **`avatar-cache.tsx:566` 既有 lint 错误：已修，行为不变。** 做法：把「回源」回调放进 ref（每次渲染更新），探测副作用的依赖不变，所以不会每次重渲染都重新探测 / 下载头像。为什么行为不变：唯一调用方 `CachedPicture` 的回调只用到 url / mediaId，而副作用里只有在这次探测还有效（url、mediaKey 都没变，否则清理函数已让它提前返回）时才会调用回调——此刻最新回调与副作用开始时那个闭包读到的值相同。
7. 顺带修的旧问题：朋友圈评论被旧样式设成 flex，名字、「回复」、正文被挤成竖排几列（截图里很明显），改回一段文字排；正文从原生按钮改成可点的行内文字（`role="button"`，键盘 Enter / 空格可用），长评论接在名字后面排，不再整块掉到下一行。

## 遗留问题

1. **输入框边框未统一去掉**：全局 `input / textarea / select` 和表单选择框 `picker-field` 仍是 0.5px 浅灰描边（10% 透明度）。它们在 20 多种行容器里各自被重置，一刀切换成灰底有较大回归风险，本批只处理了明确的整圈硬边框和框套框。如要统一，建议单独一批逐页对照。
2. **普通按钮里带类名、又没自己设底色的**（如导入对话里的「删除这条」`danger` 按钮）去边框后是白底，在白色区域上边界会变淡；目前截图里都在灰底上，看着正常。发现个别看不清的，给它加浅灰底即可。
3. **「N 条新消息」的计数口径**：只数上翻那一刻之后、别人（角色）发来的正常消息；系统提示、撤回的不算。如总经理希望把自己在别的设备发的也算进去，改 `chat.tsx` 里 `newBelow` 一处。
4. **页内浮层的历史记录**：浮层打开后如果用户点了浮层里的链接跳去别的页面，原页面那条「浮层」记录会留在历史里——从新页面返回时先回到原页面（浮层已关），再返回一次才离开，多一步但不会出错。
5. 首次资料地区页的分组那层不需要「完成」按钮，目前是把它隐藏（顶栏右侧留空）；`SubPageLayer` 暂无「不要完成按钮」的参数，以后需要可加。
6. 深色模式正文想再细（400→350）仍需打包 MiSans Light（U1 遗留 2，未做）。

## 协作约定

- **文档类任务**：负责人不执行 git，由总负责人复核后直接提交到 `main`（前缀 `PM`）。不同目录的文档任务可以并行。
- **代码类任务**：在独立工作副本（worktree）的任务分支上开发 → 推送分支 → 质量负责人验收 → 总负责人合并。
- 用量上限会打断并行任务；中断后从断点续做，进度不丢。

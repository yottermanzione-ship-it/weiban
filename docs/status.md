## 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| iOS 走网页版（PWA）：推送需 iOS 16.4+ 且添加到主屏幕；后台保活、语音通话基本做不到 | iOS 上「角色主动找你」体验受限 | 产品负责人在 PRD 中写明 iOS 能力边界 |
| 真人明星涉及肖像权、声音权等人格权 | 若开放给他人风险高 | 已定：个人测试、按成熟产品设计（ADR-0002）；不生成本人肖像和声音；成人模式不适用于真人和儿童角色 |
| 一次性完整开发，范围大 | 长时间看不到完整可用版本 | 按依赖顺序开发，每完成一块可在本机试用 |
| BYOK 需在服务器保存用户 API 密钥 | 密钥泄露 | 加密存储、日志脱敏，质量负责人重点检查 |
| 10 个角色流程偏重，前期文档开销大 | 进度慢 | 第一期只启用必要负责人，流程按需简化 |

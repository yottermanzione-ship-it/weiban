# 管理后台底座（T-032 / D-L0-13）

`pnpm --filter @weiban/admin dev`：端口5174，`/api`代理到真实服务3000；生产构建`pnpm --filter @weiban/admin build`，部署时同域反代API。独立后台管理会话与IndexedDB，管理响应不落本地业务缓存；未登录和普通用户不能进入。

角色库支持基础资料、分类事实、头像上传、WB-Card结构化分板块编辑与严格JSON导入；草稿可以不完整，完整结构校验只作编辑提示。发布时调用实际后端，必填、稳定性和边界检查均由服务器控制，不能手工勾选通过。更新人设需要重新检测，后台可刷新检查状态；真实供应商密钥未配置时不冒充质量检测通过。

上游登记/测试/换钥/删除、目录维护、价目草稿/复制调价/立即生效、邀请码赠送余额、账户加扣与流水均使用契约客户端。上游原始密钥在提交时清空输入框，不写IndexedDB。金额字符串准确转成整数微元；余额和邀请的失败手动重试复用同一次幂等键。价格版本缺少启用模型时明确列出模型，取消确认不发布。后台默认桌面布局1200最小宽、1440内容上限，设计token来自既有AdminShell规格。

开发自测命令`TEST_DATABASE_URL=.../weiban_test pnpm admin:e2e`：独立测试库重建，真实Nest/PG和生产构建/CSP。上游连通测试走仅测试进程开放的本机HTTP模拟器，不发送真实供应商请求。此记录不代表独立质量验收或真实模型评测。

基线verification的“已确认落地”主要来自grep或旧交接，不能代表本轮逐项点按；本轮改为证据索引。旧稿把B1关系、B5时机等称“总经理尚未拍板”，11 C1已给方向，现按逐项引用更正：方向已定但实现冻结；角色卡最终字段、生态具体动作/价格等细节仍可讨论，会员全部按C9冻结。

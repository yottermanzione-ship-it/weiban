## 2. 导入

- 来源：粘贴文字（超过 20 万字提示只取最近部分）、系统文件选择器选 .txt / .csv、系统照片选择器多选截图（单次最多 30 张，逐张上传后 `files/done`）。
- 状态按 `ImportJob.status` 显示：识别中 → 截图确认识别结果（点一条改发言人或删除）→ 选哪一方是 TA → 保留原文开关（默认关）+ 预计花费 + 余额不足禁用 → 生成中（可先离开）→ 结果。失败显示原因，可重试（已选发言人时）或放弃（确认后取消任务，原文立即删除）。
- 任务状态每 2 秒轮询一次（识别 / 生成中），其他状态 10 秒一次。
- 草稿编辑器：名字、人设描述（≥ 50 字）、口头禅、示例对话、标签都标「来自导入」；分类默认按服务器建议（真人），**不勾选声明不能选原创 / 虚构**；显示疑似真名提示。

## 3. 注销

- 说明页固定列出删除内容；余额 > 0 显示「剩余余额 ¥X 将作废」；广场作品说明。
- 密码弹窗：403 `invalid_credentials` →「密码错误」、清空输入、**保持登录**；429 → 提示并禁用；网络失败 →「网络不可用，请重试」；只有「未登录」才退出。
- 成功（202）→ 完成页「账号已注销」→「好的」清除本机登录回登录页。后端 T-080 尚未实现，按契约 `DELETE /me` 接好。

## 4. 宠物

- 总览：在养 N 只（最多 3 只）、回忆（半透明）、满 3 只时领养按钮禁用。
- 领养：选 TA（已有宠物的 TA 禁用并写「已经有 XX 了」）→ 物种 → 外观（三阶段图）→ 起名（1～8 个字，按字符计；「让 TA 起名」轮询候选名最多 60 秒）。超限 422 提示。
- 宠物主页：领养第 N 天、阶段、亲密值；喂食 / 玩耍 / 摸摸点了立即有缩放动画和预置小反应（不调用模型），亲密值以服务器为准；不显示「今天已达上限」。成长记录、相册（上传走 `pet_photo`、可移除）、朋友圈开关、改名、送养（二次确认、无挽留）。回忆中的宠物只读。
- 领养完成进入宠物主页时形象弹出一次。

## 5. 取舍与已知限制

1. 导入「继续导入下一批」「保存草稿（saveResultDraft）」没做，同网页（契约缺合并字段）。
2. 截图入口没有按「模型能否识图」预先禁用，识别失败时显示 `vision_unavailable` 原因。
3. 补充设定冲突项按「该行包含冲突值」匹配显示。
4. 宠物反应文案是临时文案；相册查看是简易弹窗，没有保存 / 分享。
5. 导入完成的推送点开去向依服务器下发的路由，安卓未单独处理。

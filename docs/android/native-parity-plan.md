# 安卓原生版与网页版对齐计划

复用现有原生代码，一个开发约需 155～233 个工作日，按每月约 21 个工作日计约 7～11 个月；这是排期估算，不是交付承诺。
页面分十批补齐，另留开工准备和整体验收；网页严重问题先修复，安卓开发随后安排。
第一批把会话列表、聊天、断网重发、账号隔离和必需的模型选择做成可日常使用的版本。
准备加前两批约 35～52 个工作日，可形成聊天与通讯录内测版本；其余功能按批开放，不把内测叫正式完整版。
现有安卓已经包含多类原生页面，本计划以复用、更新和验收为主，不能按“只剩登录、聊天、我”从零估算。

## 网页与安卓截图和行为怎么验收

1. 每批冻结网页和安卓完整提交，使用同一套合成数据、同一账号、同一时间和网络条件。以已修复的网页为参照，安全/扣费缺陷必须修正，不能为截图一致复制错误。
2. 建立 `路由 → 安卓入口 → 状态 → 截图对` 清单；123 个路由全部有去向，跳转不重复算页面。记录 390 宽网页与相近逻辑宽度安卓的内容区；系统状态栏/导航栏单独标注，允许字体渲染差异，不能任意改布局。
3. 每页至少有正常、加载、空、失败/重试；有表单还要键盘展开、校验、提交中、失败保留、返回；分页页加末页和重复点击，弹窗加取消。浅色/深色、默认/放大字体各抽核心流程并补易溢出的页面。
4. 以微信式导航、标题/分组/头像/气泡/图标/字号/间距为视觉基准；不直接套用 Material 默认样式替换旧版布局。设计令牌（共享的颜色、尺寸、字重数值）缺项先由设计负责人补，开发不另造一套。
5. 截图之外检验真实接口、离线待发、保存失败、重复提交、会话隔离、关屏与杀进程恢复、通知点开和系统返回；仅“截图一样”不能通过。真实模型质量与供应商成本另有证据，不能用固定假回复冒充。
6. 推荐设备矩阵：最低 Android 7（模拟器兼容），Android 9、13、14、16 的代表设备/模拟器；至少小米、OPPO/一加、vivo、华为无谷歌服务设备及一台谷歌服务设备。品牌台数按总经理现有测试机安排；仅模拟器通过的厂商项标未验证。

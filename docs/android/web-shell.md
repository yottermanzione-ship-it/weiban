# 安卓网页体验版

> 2026-11-07 最新确认：下一次正式交付改为“微伴”3.0.0，沿用旧应用身份和受保护签名覆盖升级，内部仍共用当前网页。历史独立体验包不再作为后续交付方式；原生完整复刻继续后置。声音路由与系统栏增加安卓适配，普通网页更新仍共用；旧 Flutter 本机数据不会仅因同包覆盖就自动导入。当前候选证据见[通话与 3.0.0](../quality/2026-11-07-call-android-3.md)。下文保留此前交付记录。

本版按 2026-11-06 总经理指令先交付套壳，复用当前网页；不是原生对齐完成。应用名“微伴·网页体验版”，独立安装，不覆盖旧微伴。进入后使用现有网页账号登录；不会自动读取旧安卓或浏览器的登录和本机缓存。

## 已实现的范围（测试结果单独登记）

- 固定打开 `https://app.weiban.online`；网页界面、聊天逻辑、模型、情景、积分规则直接复用，网页正常更新时不必重新安装壳。
- 返回键先返回网页上一页，首页返回桌面；系统状态栏、底部手势区域、软键盘避让。
- 录音触发安卓麦克风授权；只授予录音，拒绝后保留文字聊天；永久拒绝可进入应用权限设置。
- 头像、图片、角色资料等文件选择使用系统选择器，不读取整个相册、不索要存储管理权限。
- 页面“保存图片”通过系统“另存为”写入选择的位置；写成功才显示已保存，取消不报成功。支持 PNG/JPEG/GIF/WebP，最大 16 MiB。
- 同一应用内登录、本机消息和网页缓存保留；网络打开失败提供重连按钮，不自动清缓存、不强制接管新网页版本。
- 外部网页明确确认后交给浏览器；不允许任意应用意图、文件地址、混合内容或忽略证书错误。网页原生桥只允许正式站点主框架。

## 首版限制

- **后台消息通知暂不支持**：系统 WebView 不能直接使用现有浏览器网页推送，设置会明确解释，不展示虚假开启状态。手机系统杀进程、锁屏来电、后台持续通话、厂商推送不在这份内测包的通过范围。已有苹果主屏幕通知不变。
- 最低安装系统安卓 7，系统网页组件仍需足够新；安装成功不等于旧系统的所有网页功能兼容。网页组件过旧的保存功能会明确提示升级。
- 首份为调试签名内测包，复用本机已有调试签名，不生成新密码或私钥文件；并非应用商店正式包。以后正式分发需受保护固定签名，同一内测签名才能覆盖更新。各云端临时调试签名不保证彼此相同，不让经理反复安装来源不明的包。
- 会话、声音、图片与其他功能仍受网页和供应商能力限制，不额外改变价格、安全政策或角色设定。

## 构建与下载

现有 `apps/android` 工程新增 `:shell`，不删 `:app`。`gradlew.bat :shell:ktlintCheck :shell:detekt :shell:lintDebug :shell:testDebugUnitTest :shell:assembleDebug`；依赖锁随源码提交。首次增加依赖用同一命令加 `--write-locks`，随后不用该参数复验。

安装包位于 `shell/build/outputs/apk/debug/shell-debug.apk`；合并请求自动检查附件 `weiban-webshell-preview` 保留 14 天，最终回执提供经核验的本机安装包及散列。未配置正式签名的 release 不签发，不回退调试签名冒充正式发布。

## 最小手机验收

### 0.1.1 更新补充

新增普通声音设置权限，修复通信音频所需权限缺项，沿用同一内测签名覆盖安装；请勿先卸载或清除数据。关于页新增“检查更新 / 强制刷新网页”，实际检查部署的网页版本，用户确认后接续新版，保留登录和已保存的聊天。录音、通话中先结束再刷新。日常网页改动不需要安装新包；安装包权限及原生功能变化仍需升级安装包。实际检查证据与未验证范围见[声音与更新报告](../quality/2026-11-06-audio-manual-update.md)。

### 原有基础检查

1. 安装并打开“微伴·网页体验版”，登录自己的测试账号；四个主页面与网页相同。
2. 发一句普通消息，退出重开，消息和登录仍在；返回键先返回上一页。
3. 连续录两条短语音，第二条也可发送；拒绝麦克风后文字仍可用。
4. 选一张无隐私图片发送；保存时选择文件夹，成功后能在文件管理器找到。取消保存不显示已保存。
5. 输入法打开时底栏和输入框没有被遮挡；断网重开应能看到缓存或明确重试入口，不清本机资料。

自动检查、测试设备/合成页面证据与未测范围分别见[本轮报告](../quality/2026-11-06-web-shell.md)。不要求重复此前已经通过的苹果语音、导航和通知测试。

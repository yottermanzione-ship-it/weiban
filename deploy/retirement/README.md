# 官网与旧后台迁出准备

2026-11-10最新决定：经理已修改三个域名解析，并明确取消旧微信绑定迁移，让旧用户自行在新版重新绑定。公网入口核对已通过；旧端微信收发及新版的旧连接映射已停用，香港原生绑定保留。旧服务器本身继续开着作解析过渡，不能自动关机。本文最新决定覆盖此前微信接管步骤。

## 新机组成

- `weiban-entry`：官网、正式安装包、旧安卓检查更新、旧网页跳转、原后台历史查看。只开放管理登录/退出及查询，其他旧业务仍停用。独立SQLite副本不覆盖新版PostgreSQL。
- `weiban-entry-relay`：原先准备的待命容器已停止并移除，未接管过微信。旧微信迁移已经取消，不再启用此服务或执行 `handoff-relay.cjs apply`；保留材料仅供历史追溯。
- 系统盘 `/var/lib/weiban-entry` 放代码、历史库及加密运行材料；空余更大的项目盘 `/srv/weiban/history-media` 放历史媒体。既有安装包继续从 `/var/lib/weiban-downloads` 读取。
- 旧源码只复制运行需要的代码、官网/后台素材及角色包，不复制旧 `.env`、日志、杂项脚本或旧安卓测试包。管理员运行配置与旧数据密钥经过临时RSA接收者加密传输，再由香港主密钥密封；没有明文凭据文件、仓库凭据或工具输出。香港主密钥未来轮换时，需一并重封这些材料。
- 原后台旧数据作为历史副本；原管理员密码保留。登录会话及运行计数可以写入副本，不能把“历史查看”误称为数据库绝对零写入。实时生产业务仍在新版管理后台。

## 官网兼容范围

- 主域名与 `www` 继续官网，`dl` 承接历史下载链接。
- `/download`、`/download/` 和根页面同样可用。
- `/download-assets/` 先读取新机正式包；旧包文件名转到当前正式包。安装包响应明确为附件下载，避开聊天站点的Service Worker。
- `/api/app/config` 保留旧安卓响应格式，版本来源读取新版公开版本策略；当前正式3.0.0构建127，旧构建强制升级，当前/更高构建不会循环升级。补齐文件大小与SHA256/SHA1校验值。
- `/api/download-config` 保留旧官网配置结构。
- `/app` 及其旧网页地址转到 `https://app.weiban.online/`，不携带旧查询参数。
- 旧Flutter Worker更新地址返回仅用于迁出的Worker，接续后只导航旧 `/app/` 窗口，不清空浏览器存储，不操作旧后台窗口。
- 官网去除旧“内测阶段”文字；布局沿用原页面。

## 旧微信迁移已取消：不得接管

经理明确要求只解除旧版绑定，保护已经在新版重新绑定的连接。本次按数据来源处理，没有调用会同时解绑新旧记录的普通用户解绑接口。

- 旧服务器：关闭微信、旧兼容转发及其旧渠道运行开关，保留原维护/生成/后台任务禁用标记，只重新加载旧应用进程。修改现有环境文件和现有PM2持久记录，不新增明文秘密备份。19条仍标记有效的旧微信本地记录改为未绑定并清空本地凭据；旧库有效微信绑定归零。其余旧历史资料保留。
- 新服务器：仅在 `channels.legacy_bindings` 中关闭6条微信旧连接，设置 `user_disabled=true`，保留审计记录；`channels.bindings` 未写入。原生绑定稳定字段及凭据密文指纹在同一事务前后相同，现有3条有效微信、2条原先已失效的微信、1条有效QQ均保持原状态。
- 新版微信与QQ功能开关保持开启；未调用供应商注销接口，不使新版重新扫码取得的授权失效。旧用户自行在新版绑定页重新扫码。
- 新机待命转接容器已停止并移除，未生成接管回执。不得依据此前PR133的历史交接步骤重新启用。停旧机另行安排，当前仍保留作解析缓存过渡。

执行证据见 [解析切换与旧微信停用回执](../../docs/quality/2026-11-10-dns-and-legacy-wechat-retirement.md)。

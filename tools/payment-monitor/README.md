# 微伴收款监控

当前正式候选1.0.7/8：明确微信单笔收款前的未读条数及收款助手包装不再当作累计金额；实际累计、多笔/多金额仍待核对。折叠/展开和重复扫描保持同一事件，旧版已上报记录不重写。七个必需测试类至少79项零失败/跳过方可交付。支付宝本轮真机自动会员到账已通过，微信新版自动到账仍待真机验证。[本轮说明](../../docs/quality/2026-11-09-wechat-unread-count.md)。

1.0.6/7记录：系统分组标记不再直接当成多笔汇总；实际多笔/多金额仍待核对。以正式站HTTPS响应时间校准手机时差，原设备时间保留，首次发送前固化，补报不刷新原付款时间；旧版已上报记录不自动重写。七个必需测试类至少70项零失败/跳过。[本轮说明](../../docs/quality/2026-11-09-scan-payment-matching.md)。下文旧版本说明仅作历史。

1.0.5/6记录：首页专心显示监听、连接和待补报，不再展示重复累计的未识别数和不会同步人工核对结果的“最近到账”。到账通知时间、购买类型与最终状态统一看后台“用户 → 扫码收款 → 监控上报记录”。升级保留原绑定、通知时间、收款日记和去重；六个必需测试类至少56项零失败/跳过。[本轮说明](../../docs/quality/2026-11-09-monitor-admin-followup.md)。下方旧版本说明保留为历史。

独立的收款管理员安卓应用，不是微伴用户端。仅连接 `https://app.weiban.online/api/v1/billing/scan/monitor/`。包名 `app.weiban.paymentmonitor`，正式1.0.7/8，最低Android 8。覆盖安装保留原配对、系统密钥和待补报记录，不要先卸载。

后台入口：用户 → 扫码收款。第一台手机仅首次粘贴十分钟有效的连接码、保存设置，服务端自动启用；已绑定手机不再显示初始设置，直接点“开始监控”。更换手机须先补报旧手机，再在后台显式启用新手机。重复申请复用未绑定记录，重放旧配对不能重新启用停用设备。私钥由Android Keystore生成，不导出；服务端保存公钥。发布签名沿用受保护的外部签名配置，不能退回调试签名。

按实际旧包读取通知标题、正文及展开等十种文字位置，支持微信合法顾客备注与支付宝金额标题。其他应用和普通私人消息排除；有金额但不确定、汇总、多金额通知仍上报待核对，不能自动认单，即使有同额订单也不入账。不保存任何通知原文或来源键，只保存渠道、金额、时间、固定原因。所有可识别事件先原子落盘，服务器明确接收才标记完成。观察时间和通知时间不随补报改写，网络请求时间单独签名；相同事件再次出现不会重置首次观察时间或核对原因。读队列失败时停止且保留原文件。

运行状态通知、45秒心跳、重试任务与重启重绑不能消除系统省电限制。服务器两分钟未收到正常监听心跳就暂停创建新单；旧的真实到账仍保存供核对。没有支付机构真实交易号的通知不能代替官方账单。必须在实际收款手机分别验证微信和支付宝，不能将合成测试写为真实到账通过。

本地检查：`gradlew.bat testDebugUnitTest lintDebug assembleRelease`，正式签名从已有受保护环境变量 `WEIBAN_ANDROID_SIGNING_PROPERTIES_FILE` 指向的配置读取。持续检查无发布凭据时运行 `testDebugUnitTest assembleDebug lintDebug`，随后 `node check-tests.mjs` 确认七个必需测试类、至少79项且零失败/跳过。调试包只供自动检查，不作为用户交付。

1.0.4修复实际付款漏报并放宽金额收集，取代下方历史1.0.2的过严规则。契约7.8须先发布；可疑通知参与v2签名，旧明确收款和心跳保持v1。后台“监控上报记录”每五秒更新，连接正常不等于已收到款项。仍在通知栏的历史通知可点“检查连接并补报”重扫，已取消或迟到款必须人工核对。见[根因与回执](../../docs/quality/2026-11-08-payment-notice-compatibility.md)。

1.0.1补齐Android 14及以上网络补报调度需要的普通安装权限；调度遭系统拒绝时不会让进程退出，界面独立提示“后台补报未能安排”，后续成功自动清除该提示。通知访问仍需用户授权，任务调度成功不等于已收到真实款项。详见[启动修复报告](../../docs/quality/2026-11-08-payment-monitor-startup-fix.md)。

不要清应用数据、卸载或转移设备，直到待补报与后台待核对记录处理完毕。仅开放后台人工核对和漏报登记，没有自动退款或绕过确认的“我已付款”接口。具体收款切换和经理操作见[交接](../../docs/handoffs/2026-11-08-scan-payment-monitor.md)。

1.0.2依据经理提供的旧收款监听1.0.6安装包核对通知代码，补充支付宝“向你付款”、微信支付前缀及全角括号、展开文字和ticker候选。同一通知多份文本金额冲突、退款及汇总仍拒绝；不照搬旧版“提取第一笔金额”的宽泛方式。手机最近十条到账展示原通知时间、渠道、金额与服务端返回的购买类型；后台显示完整分页和入账时间。契约7.7新增可选响应字段，无迁移；旧客户端请求保持兼容。

1.0.3接续真机反馈：服务器连通但通知监听未连接不能显示为可监控。断开时释放旧监听实例，手动检查重新请求系统绑定；旧实例的销毁/断开不能覆盖新连接。通知权限直达本应用设置，按钮有明确响应，等待八秒仍未连接则引导重开开关。已设置主页允许截图，含连接码的初始设置页仍保护。经理已确认1.0.2重开通知开关后连接恢复；1.0.3真机待验证。

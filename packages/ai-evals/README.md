观察记录的`judge.checks`和`runtimeChecks`是原始证据的检查结果；有必需运行时项时还须`runtimeEvidenceRef`，输出文本引用不能代替日志依据。汇总器仅检查布尔结果和引用存在，不验证外部证据真伪、实际执行前置条件或评审者独立性。这里尚未提供真实供应商/运行时执行器或独立评审，不代表安全关怀质量已通过。

## 汇总观察文件

执行器或独立评审准备一行一条`EvalObservation`的JSONL文件后，可以运行：

```powershell
pnpm --filter @weiban/ai-evals summarize C:\评测记录\observations.jsonl C:\评测记录\summary.json
```

命令编译此包并汇总记录；省略第二个路径则在标准输出展示汇总。指定的报告文件必须不存在，避免覆盖已有依据。退出码0表示当前登记题的记录检查通过（scope仍为registered_cases_only），2表示待评审或缺题，1表示规则/证据明确失败或输入错误。空文件得到151题全部待评审，不冒充已执行。输入逐行校验类型，拒绝字符串化布尔值；JSON/字段错误只报告行号和字段名，不回显原始回答。命令没有模型调用，不会准备运行时状态、展开中性场景或验证引用文件真伪，不能代替真实执行和独立验收。

`test/registry.test.ts`中“全部登记题通过”的输出和身份全部为显式fixture，仅验证汇总器状态分支，不是模型评测结果。真实安全关怀、真人/儿童/成人硬边界、媒体/语音、行为规划盲评以及剩余eval-plan分组门槛尚须完整执行。
